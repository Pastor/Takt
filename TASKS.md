При выполнении заданий используй CLAUDE.md в качестве общего руководства. Старайся код разделять на модули исходя из
логического назначения. Модель не может быть больше 1000 строк кода (вместе с тестами)

1. Необходимо реализовать бинарный файл проведения симуляции simulation.rs. В него передаются параметры симуляции,
   создается Unit и по шагам симулируется. Аргументы приложения следующие:
    1. Путь к файлу с кодом LAM для симуляции, аргумент обязательный
    2. Папки в которых ищутся include, не обязательный
    3. Количество шагов симуляции которые надо сделать (если не выставлено то доходит до перехода модели в терминальное
       состояние, если выставлено то количество шагов)
    4. Параметр записи симуляции в графическом виде (если указано то происходит запись в gif файл каждого шага, каждый
       кадр gif это сформированный файл viewport - в котором также отмечается текущее состояние и в легенде состояние
       портов и переменных)
    5. Файл симуляции в формате JSON, где в массиве, в элементе массива передаются значения портов, а также может
       передаваться проверочные значения внутренних переменных и портов для каждого шага. Один шаг - один объект в
       массиве. Пример как может выглядеть файл:
       ```json
       [
         { "in": [ 2.5, 0, 1, 1, true, 0, 0 ], "inout": [ 8, 0, 4 ], "guard": { "out": [0, 0, 0, 0], "inout": [0, 0, 0, 0], "vars": { "Model::In::_line": 1 } } },
         {}
       ]
       ``` 
       в примере выше описан один шаг (первый) детально, последующий пустой (только в качестве примера). В нем in -
       значения входных портов по порядку, input - значения входнях данных портов, порта ввода выводы, guard - объект
       проверки показателей модели после выполнении шага симуляции, где out - значения выходных портов, inout - значения
       выходных портов типа ввода вывода, и объект vars - это значения переменных, где ключ - это уникальное глобальное
       имя переменной. Сколько шагов симуляции следует сделать, столько записей в массиве и будет. Если записей меньше
       чем шагов симуляции указанных в параметре выдается предупреждение и симуляция преостанавливается
