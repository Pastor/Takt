# Функции

Функция — это именованный фрагмент вычислений с параметрами и, при необходимости,
возвращаемым значением. Функции выносят повторяющуюся или сложную логику из тел
состояний, делая модель короче и понятнее.

## Определение

Функция объявляется словом `fn`: имя, список параметров (каждый — `имя: Тип`) и
после `->` — тип возвращаемого значения. Тело — в фигурных скобках, значение
возвращает `return`:

```takt
fn double(n: u8) -> u8 {
    return n * 2;
}
```

Если функция ничего не возвращает, стрелку `->` и тип опускают.

## Вызов

Функция вызывается по имени с аргументами в скобках; вызов — это выражение,
которое можно использовать в теле блока или другой функции:

```takt
result := double(x);
```

## Композиция

Функция может вызывать другую функцию — так из простых вычислений собираются более
сложные. Компилятор сам определяет порядок и учитывает зависимости между
функциями:

```takt
fn quad(n: u8) -> u8 {
    return double(double(n));   // quad использует double
}
```

**Рекурсия запрещена:** функция не может вызывать саму себя ни напрямую, ни через
цепочку вызовов (это гарантирует завершимость и предсказуемое время работы —
важно для управляющих систем).

## Внешние функции

`extern fn` **объявляет** функцию, но не задаёт её тело: реализация берётся извне
(из окружения целевой платформы). Так модель обращается к аппаратуре или сервисам,
не привязываясь к конкретной реализации:

```takt
extern fn log_value(v: u8);      // без возврата
extern fn read_sensor() -> u8;   // с возвратом
```

Вызывается внешняя функция как обычная. При генерации кода компилятор оставляет для
неё точку подключения (в C — вызов через указатель, в других целях — свой
механизм); саму реализацию предоставляет платформа.

## Параметры и типы

Параметры и возвращаемое значение могут быть любого типа языка — включая
составные (`[bit; N]`, структуры, перечисления):

```takt
fn pack(flags: [bit; 8]) -> u8 {
    return flags;
}
```

предела.

С исполнительным механизмом станция общается через **внешнюю** функцию `drive_pump`
(1): она командует насосом и объявлена `extern fn` — без тела, реализацию даёт
платформа. Давление приходит с датчика через входной порт `pressure`. Собственные
вычисления вынесены в обычные функции: `clamp` (2) ограничивает значение сверху
пределом `MAX_P`, а `headroom` (3) демонстрирует **композицию** — считает запас до
предела, опираясь на `clamp` (`MAX_P - clamp(p)`). Обе вызываются из состояния `On`:
при входе командой насосу `drive_pump(1)` (4), а каждый такт — пересчётом запаса
`headroom(pressure)` (5). Так, при давлении 30 запас равен 70, а при 120 функция
`clamp` срежет его до предела и запас станет нулевым.

## Частые ошибки

Типичные ошибки при работе с функциями:

- `SE-004` — вызов необъявленной функции (опечатка в имени);
- `SE-009` — две функции с одинаковым именем;
- `SE-053` — рекурсия: функция вызывает себя прямо или по цепочке.
