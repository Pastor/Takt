# Глоссарий

Термины языка Takt, используемые в документе.

**Модель** (`model`) — единица описания: конечный автомат с состояниями,
переменными, портами и функциями.

**Состояние** (`state`) — режим модели; определяет поведение на такте и переходы в
другие состояния.

**Такт** — шаг исполнения модели. За один такт исполняется тело текущего состояния
и вычисляются переходы.

**Переход** (`ref`) — правило смены состояния при выполнении условия.

**Порт** — именованный вход (`in`), выход (`out`) или двунаправленный канал
(`inout`) связи модели с окружением.

**Цель** — платформа генерации кода из модели (`c`, `st`, `rust`, `sv`, `plantuml`
и их варианты).
