# Типы данных

Каждое значение в Takt имеет тип. Тип определяет множество допустимых значений,
их представление в битах и применимые операции. Типы указываются в объявлениях
переменных, констант, портов, полей структур и параметров функций; там, где тип
можно вывести из инициализатора, аннотацию разрешается опустить.

## Примитивные типы

| Тип | Значения | Назначение |
|-----|----------|-----------|
| `bit` | `0`, `1` | один бит; естественный тип линии ввода-вывода |
| `bool` | `false`, `true` | логическое значение (результат условий) |

`bit` и `bool` близки, но различны по смыслу: `bit` — это разряд данных, а `bool`
выражает истинность. Результат сравнения или логической операции — `bool`.

## Целочисленные типы

Целые числа имеют явную ширину и знаковость:

| Ширина | Беззнаковый | Знаковый |
|--------|-------------|----------|
| 8 бит | `u8` | `i8` |
| 16 бит | `u16` | `i16` |
| 32 бита | `u32` | `i32` |
| 64 бита | `u64` | `i64` |

Беззнаковый `uN` представляет значения `0 … 2ⁿ − 1`; знаковый `iN` —
`−2ⁿ⁻¹ … 2ⁿ⁻¹ − 1` (дополнительный код). Арифметика выполняется по модулю
разрядности типа.

## Битовый вектор `[bit; N]`

Запись `[bit; N]` — это **упакованный вектор** из `N` бит. Для `N ≤ 64` он
занимает одно машинное слово (ширина округляется вверх до 8/16/32/64 бит), для
`N > 64` — несколько слов. К отдельному разряду обращаются по индексу — `x.k`
или `x[k]` (нумерация с нуля):

```takt
var flags: [bit; 8] := 0;
// установить бит 3
flags.3 := 1;
```

По представлению `[bit; 8]` эквивалентен `u8`, `[bit; 16]` — `u16` и т. д.:
разница лишь в том, что запись `[bit; N]` подчёркивает **побитовую** природу
значения, а `uN` — числовую.

## Дробные числа

Для дробных величин есть два типа.

**`float`** — число с плавающей точкой. Тип пишется в исходном тексте как `float`;
конкретное представление (аппаратный FPU или фикс-точка) выбирается при генерации
кода и на текст модели не влияет.

**`q(m, n)`** — число с **фиксированной точкой**. Параметр `m` задаёт число целых
бит (**включая знаковый**), `n` — число дробных бит; полная ширина `W = m + n`
не превышает 64. Значение с внутренним целым `v` изображает `v · 2⁻ⁿ`. Требуется
`m ≥ 1` и `n ≥ 1`.

```takt
var gain: q(8, 8) := 1.5;   // 8 целых бит (со знаком), 8 дробных
```

Фиксированная точка удобна там, где нет аппаратного FPU (микроконтроллеры, ПЛК,
FPGA): арифметика над `q(m, n)` детерминирована и одинакова во всех целях.

## Массивы

`[T; N]` — массив из `N` элементов типа `T`. Элементы адресуются индексом с нуля
(`a[i]`); инициализатор перечисляет значения в фигурных скобках:

```takt
var samples: [u8; 4] := {0, 0, 0, 0};
samples[0] := 42;
```

Особый случай `[bit; N]` / `[bool; N]` — упакованный битовый вектор (см. выше).

## Перечисления

Перечисление `enum` вводит именованный тип с фиксированным набором вариантов.
Значения вариантов можно задать явно; если значение опущено, оно на единицу
больше предыдущего (первый вариант без значения — `0`). Значения могут быть
отрицательными.

```takt
enum Mode { Idle = 0, Run = 1, Halt = 2 }
enum Command { Up, Down, Stop }        // 0, 1, 2 неявно
```

Знаковость и разрядность перечисления определяются диапазоном его значений
автоматически.

## Структуры

Структура `struct` — запись из именованных полей; **порядок полей значим**.

```takt
struct Point {
    x: u16,
    y: u16
}
```

Значение структуры создаётся **позиционным** инициализатором `{…}` (значения — в
порядке объявления полей); к полю обращаются через точку:

```takt
const ORIGIN: Point := {0, 0};
var p: Point := {10, 20};
p.x := 100;                 // доступ к полю
```

## Псевдонимы типов

Оператор `type` вводит имя-синоним для существующего типа. Это удобно для
осмысленных имён и повторного использования:

```takt
type Byte = [bit; 8];
type Temperature = q(8, 8);
```

## Вывод типов

Если у объявления есть инициализатор, тип можно не указывать — компилятор выведет
его из выражения:

```takt
var count := 0;         // тип выведен из литерала
const READY := true;    // выведен bool
```

Явная аннотация всё же полезна, когда нужна конкретная ширина или знаковость
(`var count: u16 := 0;`).

**Разбор (с точки зрения типов).** В примере задействованы все основные категории

- `mode` — переменная **перечислимого** типа `Mode` (варианты `Idle`/`Run`/`Halt`);

- `level` — **фикс-точка** `q(4, 4)` (арифметика над однотипными `q`:

- `samples` — **массив** `[u8; 4]` (запись элемента `samples[0] := 1`);
- `ORIGIN` — **структурная** константа типа `Point` (поля `x`, `y`; доступ
  `ORIGIN.x`).

**Порты и вывод.** Вход `start_btn` — примитив `bit`; выход `active` — тип `bool`,
именно в него идёт вывод (`active := true`/`false`). **Сравнение** встречается в
условиях переходов: `start_btn = 1` и `start_btn = 0` (равенство знаком `=`).
Определение модели и её двух состояний (`Idle`, `Working`) здесь второстепенно —
показано лишь как «каркас», на котором объявлены и используются значения разных
типов.

## Частые ошибки

Типичные ошибки при работе с типами:

- использован несуществующий тип (`u9`, опечатка в имени) — `SE-034`;
- неверные параметры фикс-точки `q(m, n)` (`m ≥ 1`, `n ≥ 1`, `m + n ≤ 64`) — `SE-057`;
- дробный литерал непредставим точно в выбранном `q(m, n)` — `SE-058`;
- значение `bit`-переменной не 0 и не 1 — `SE-035`;
- инициализатор перечисления — не из набора его вариантов — `SE-043`;
- обращение к несуществующему полю структуры — `SE-061`; дублирующееся поле — `SE-040`.
