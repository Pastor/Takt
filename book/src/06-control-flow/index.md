# Управляющие конструкции

Тела именованных блоков (`enter`, `exit`, `always`) и функций — это
**последовательности операторов**. Внутри них доступны привычные управляющие
конструкции: ветвления, циклы и выбор по образцу. (Сами блоки и их роль в такте
описывают разделы «Модели и состояния» и «Именованные условия и блоки».)

## Ветвление `if` / `else`

`if` выполняет блок, если условие истинно; необязательная ветвь `else` — иначе:

```takt
if temperature > 0 {
    temperature := temperature - 1;
} else {
    done := 1;
}
```

Условие `if` — это **условие** в смысле предыдущего раздела: `&`/`|` в нём
логические, равенство — `=`.

## Выбор по образцу `match`

`match` выбирает ветвь по значению — удобно для перечислений. Ветвь отделяется
`=>`, тело — в фигурных скобках; `_` — ветвь «во всех остальных случаях»:

```takt
match mode {
    Slow => { speed := ramp(20); }
    Fast => { speed := ramp(80); }
    _    => { speed := 0; }
}
```

## Циклы

**`while`** повторяет тело, пока условие истинно:

```takt
while v < target {
    v := v + 1;
}
```

**`loop`** — синоним `while` (тот же смысл, другое ключевое слово):

```takt
loop v > 0 {
    v := v - 1;
}
```

**`for`** — цикл со счётчиком: инициализатор, условие и шаг разделены `;`:

```takt
for var i: u8 := 0; i < 3; i := i + 1 {
    ticks := ticks + 1;
}
```

## `break` и `continue`

Внутри цикла `break` досрочно прерывает цикл, а `continue` переходит к следующей
итерации:

```takt
while v < target {
    v := v + 1;
    if v = 5 {
        continue;   // пропустить остаток итерации
    }
    if v >= 100 {
        break;      // выйти из цикла
    }
}
```

## `return`

`return` завершает **функцию** и возвращает значение (о функциях — в разделе
«Функции»):

```takt
fn ramp(target: u8) -> u8 {
    var v: u8 := 0;
    while v < target {
        v := v + 1;
    }
    return v;
}
```

> Управляющие конструкции — часть **тел** блоков и функций; они не задают переходы
> автомата. Переходы между состояниями описываются отдельно (`ref`/`next`, см.
> раздел «Модели и состояния»).

Пока конвейер в состоянии `Running`, его тело `always` исполняется каждый такт и
собирает несколько управляющих конструкций. Класс детали `kind` — из перечисления

со счётчиком `for` (2), а ветвление `if … else` (3) обнуляет счётчик по достижении
предела. Отдельно вынесена функция `settle`: она отсчитывает такты стабилизации
детали циклом `while` (4), но не дольше предела — тогда срабатывает `break` (5),
досрочно выходя из цикла, — и `return` (6) возвращает накопленное значение.

## Частые ошибки

Типичные ошибки в управляющих конструкциях:

- `SIM-024` — `break`/`continue` вне цикла;
- `SE-036` — переменная цикла или временная переменная объявлена, но не используется;
- `SE-047` — условие перехода-константа `true` вместо безусловного `next`.

Помните: управляющие конструкции живут в **телах** блоков/функций, а переходы
автомата задаются отдельно (`ref`/`next`).
