# book/ — документ «Язык Takt — описание»

Справочное описание **языка** Takt (не инструментов и не процесса разработки).
Собирается [mdBook](https://rust-lang.github.io/mdBook/) в **PDF** (вывод по
умолчанию; шрифт текста — **Fira Code**).

## Сборка

Зависимости PDF-сборки:

```sh
cargo install mdbook mdbook-pandoc   # mdBook + PDF-бэкенд
# + pandoc (https://pandoc.org/)
# + xelatex (TeX Live / MacTeX)
# + шрифт Fira Code (https://github.com/tonsky/FiraCode), установленный в систему
```

Затем из каталога `book/`:

```sh
make build    # PDF: book/pandoc/pdf/takt-language.pdf
make check    # сборка «на прочность» (для CI)
make clean    # удалить каталог сборки
```

Вывод настроен профилем `pdf` в `book.toml` (`[output.pandoc.profile.pdf]`):
движок `xelatex`, `mainfont`/`monofont` = `Fira Code`, оглавление с нумерацией.
HTML-бэкенд намеренно **не** подключён.

## Структура

- `book.toml` — конфигурация mdBook (заголовок, автор, язык, вывод).
- `src/SUMMARY.md` — **оглавление**: вводная часть, разделы (автонумерация из
  порядка перечисления) и приложения. Это управляющий файл структуры документа.
- `src/title.md`, `src/introduction.md`, `src/purpose.md` — вводная часть (титул,
  введение, назначение документа).
- `src/NN-slug/` — **каждый раздел в своей папке**: `index.md` (текст), подкаталог
  `examples/` (примеры кода на Takt), при необходимости `images/` (изображения) и
  прочие ресурсы.
- `src/appendix-grammar/`, `src/appendix-references/`, `src/appendix-glossary/` —
  приложения (грамматика EBNF, литература, глоссарий).
- `takt.kate.xml` — определение **подсветки синтаксиса** Takt (формат KDE/kate)
  для skylighting (движок pandoc). Подключено в `book.toml`
  (`syntax-definitions`). Ключевые слова/типы синхронны лексеру языка.

## Подсветка кода

Фрагменты кода на Takt оформляются блоком с тегом языка — тогда они
подсвечиваются в PDF:

    ```takt
    model M { start state S { } }
    ```

Подсветка задаётся `takt.kate.xml` (ключевые слова, типы, комментарии `//`/`///`,
строки, числа, операторы). При изменении набора ключевых слов языка файл
правится синхронно с лексером.

## Что попадает в документ

Только **язык**: синтаксис, семантика, модель исполнения, примеры на Takt.
**Не** попадают: детали реализации компилятора/симулятора, номера задач и фич,
ссылки на архитектурные решения и отчёты, история процесса разработки (правило
проекта о документировании — см. `docs/RULE.md`).

Наполнение каждого раздела — отдельная фича; при изменении языка соответствующий
раздел правится в стадии «Документирование» этой фичи.
