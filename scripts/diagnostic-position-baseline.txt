# Реестр кодов БЕЗ ПОЗИЦИИ — узаконенный долг (фичи 0467, 0468).
#
# Правило: диагностика называет МЕСТО. Автор модели, получив отказ без
# координаты, ищет его глазами по всему файлу — а на входе бывает и десяток
# импортированных файлов.
#
# Реестр не даёт нарушителям разрешения — он их ЗАМОРАЖИВАЕТ: гейт
# `scripts/check-diagnostic-quality.py` запрещает появление НОВЫХ кодов без
# позиции. Единственная допустимая правка записи — УДАЛЕНИЕ: координат может
# только прибавляться.
#
# Фича 0470 сняла ещё ШЕСТЬ: место обращения к ячейке стало частью её узла
# (`ST-018`, `SV-017`), слой объявления добрался до инициализаторов цели `rust`
# (`RS-011`) и до объявления функции у `sv` (`SV-002`), заголовок цикла берёт
# позицию своего инициализатора, а причина отказа `CC-001` — место ребра.
# Заодно исправлено ложное срабатывание гейта: координата ЗАМЕТКИ печатается
# после слова «примечание», и общая проверка объявляла безадресными строки,
# место как раз называющие.
#
# ⚠️ ОСТАВШИЕСЯ ТРИ — не долг дисциплины, а устройство: у `Formula::LTL` и у
# именованного блока координат НЕТ ВОВСЕ (их несёт только `Formula::Guard`), а
# у `SE-069` позиция `Implicit` по решению 0134 — контракт относится ко всей
# модели. Дать место первым двум значит завести `Location` в АСД формулы и
# блока — это правка 70+ мест и отдельная фича, а не сокращение долга.
#
# Фича 0468 сняла ДЕСЯТЬ записей из двадцати трёх, а 0469 — ещё ЧЕТЫРЕ: коды
# «Состояние … не найдено» (`CC-005`, `RS-013`, `SV-011`, `ST-013`) корпус
# больше не порождает вовсе — вход, который их давал, оказался корректной
# программой, и она теперь компилируется. Их запись переехала в реестр
# ПОКРЫТИЯ: код без входа проверяется только юнит-тестом.
#
# Фича 0468 сняла ДЕСЯТЬ записей из двадцати трёх, расширив носитель позиции
# (`generator::site`) вторым слоем — ОБЪЯВЛЕНИЕМ — и объявив место там, где
# отказ рождается вне операторов: порт, переменная, объявление функции, ребро
# перехода. Оставшиеся тринадцать держатся не на недосмотре, а на устройстве:
# у узла, о котором говорит отказ, позиции НЕТ вовсе (темпоральная формула,
# цикл `for`, контракт тактирования) либо путь до него не проходит ни через
# оператор, ни через объявление (именованное условие, печать стартового
# состояния). Каждая причина названа отдельно — это работа для отдельных фич,
# а не забытый долг.
#
# Формат: <код> # <цель>: <причина>

RS-010 # rust: ТЕМПОРАЛЬНАЯ формула в теле блока: ни `Formula::LTL`, ни именованный блок позиции не несут — дать её значит завести `Location` в АСД (отдельная фича)
SE-069 # c: позиция ОСОЗНАННО `Implicit`: контракт относится ко всей модели, а `ModelNode` места `clock` не хранит (решение 0134)
ST-010 # st: см. `RS-010`
