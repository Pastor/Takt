# Фича: Дубль ветви case у цели sv: verilator отвергает вывод

- **Номер:** 0412
- **Статус:** ГОТОВО
- **Зависит от:** нет
- **Tier:** 2 — невалидный вывод при рапорте об успехе
- **Класс:** генерация
- **Связанные issue (анализ):** находка [форму S(Модель) = Состояние у соседа не переводят rust и st](0397-state-of-neighbour-rust-st.md)

## Краткое описание

Состояние, названное автором `End`, даёт **тот же** вариант перечисления, что
синтетическая терминальная ветвь (`<MODEL>_END`), и цель `sv` печатала обе.
`verilator` отвечает `%Warning-CASEOVERLAP`, а проверка цели считает
предупреждение ошибкой — при **нулевом** коде возврата `taktc`.

## Замер (2026-08-23, `scripts/probe.sh`)

Вход (композиции нет, формы `S(Модель)` нет — обычная модель):

```takt
var flag: u8 := 0;

start Go {
    always { flag := flag + 1; }
    ref End: flag > 2;
}

state End {
    enter { flag := 0; }
}
```

| Потребитель | `taktc` | Инструмент цели |
|---|---|---|
| эталон | исполняет | — |
| `c`, `c-hal` | OK | `cc` принял — **одна** ветвь `case DUP_END` |
| `st`, `st-at` | OK | `iec2c` принял · `cc` собрал |
| `rust` | OK | `rustc` + `clippy` приняли |
| **`sv`, `sv-mmio`** | **OK** | **`verilator` ОТВЕРГ:** `CASEOVERLAP` |

Расходилась **одна** цель, и видел это только её инструмент.

Класс найден **контрольным входом** фичи — на пробе общей переменной
корня, куда форма `S(Модель) = Состояние` не входила вовсе.

### Decision

Терминальная ветвь печатается **только если её ещё нет**: имена напечатанных
ветвей собираются по ходу цикла, и совпадение с `end_variant(model)` отменяет
синтетическую печать. Это приводит цель `sv` к тому, что `c` делала всегда.

**Убрать ветвь безусловно нельзя** — `unique case` требует покрытия всех
значений, иначе `verilator` отвечает `CASEINCOMPLETE`: обмен одного отказа на
другой. Контрольный тест на это стоит рядом с положительным.

## Итог (что сделано)

Терминальная ветвь `unique case` у цели `sv` печатается только тогда, когда
её вариант не занят состоянием автора. Прежде `state End` давал две ветви с
одним значением, и `verilator` вывод отвергал при нулевом коде возврата
`taktc`; цель `c` на том же входе печатала одну.

Класс найден **контрольным входом чужой фичи** (0397) и к её предмету
отношения не имеет: композиции и формы `S(Модель) = Состояние` во входе нет.

Проверка корпуса класс не покрывает: состояния с именем `End` в `examples/` нет.
