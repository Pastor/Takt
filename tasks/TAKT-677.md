# Исправление 0557-01: Панель диагностики не скрывается кнопкой

> Фича: [панель диагностики по форме журнала прогона](../features/0557-diagnostics-pane-form.md)

## Проблема

Кнопка показа диагностик перестала прятать список: нажатие снимало отметку, а
панель оставалась на экране во всю свою высоту. Замечено заказчиком на живой
странице 2026-09-09, то есть после выкладки.

## Причина

Форма записи, заведённая фичей, дала списку раскладку: `.log { display: flex }`.
Раскладка сильнее атрибута `hidden`, и узел, помеченный им, продолжает
показываться. Правило проекта на этот случай названо в книге оформления —
«каждому узлу, который прячут атрибутом, нужно `[hidden] { display: none }`», —
и новый контрол его не получил.

Класс не новый: тем же местом проект уже платил дважды (панель схемы и полка
режимов). Оба раза правило записывалось, но оно действует на **контрол**, а не
на страницу целиком, и каждый новый контрол обязан взять его себе.

## Решение

`.log[hidden] { display: none; }` — рядом с самим правилом раскладки, чтобы
следующий читатель видел их вместе.

## Проверки

Проверка веб-части: набор о форме записи требует правила прямо (падает списком).
Прогон страницы: нажатие кнопки даёт `display: none` и нулевую высоту, повторное
— возвращает список.
