## Краткое описание

**Адаптеры шин AXI-Lite и Wishbone для цели `sv-mmio` — по требованию.**
Фича [адаптеры шин для цели `sv-mmio` (APB / AXI-Lite / Wishbone)](0169-sv-mmio-bus-adapters.md) закрыта протоколом,
который назвал заказчик (**APB**), и её карточка прямо запрещала делать
остальные «на всякий случай». Каркас готов: флаг `--bus=<протокол>`, отдельный
файл-обёртка рядом с ядром, проверка линта и синтеза **вместе с ядром**, парный
рукописный тестбенч. Новый протокол — новый вариант перечисления `Bus` и один
модуль печати. Уроки APB переносятся: канонические 32-битные шины дают
`UNUSEDSIGNAL` и валят проверка (ширины делать точными), а обёртка в одиночку не
линтуется (`MODMISSING`). AXI-Lite заметно сложнее: пять каналов с
рукопожатием вместо двух фаз, то есть обёртка перестаёт быть чисто
комбинационной. Кандидат: заводить **новой фичей** при появлении требования.

## Причина заморозки (решение заказчика 2026-08-19)

**Требования на протокол нет, и это условие самой фичи.** Её краткое описание
называет повод заведения дословно — «заводить новой фичей **при появлении
требования**», а `Tier 4` выведен из того же: «новая функциональность по
требованию; требования нет». Фича [адаптеры шин для цели `sv-mmio` (APB / AXI-Lite / Wishbone)](0169-sv-mmio-bus-adapters.md), давшая
каркас `--bus=<протокол>`, прямо запрещала делать остальные протоколы «на
всякий случай»: протокол выбрал заказчик (APB), и зонта из прочих шин не
строили намеренно.

Заморозка, а не отмена: работа осмысленна и каркас к ней готов — новый
протокол есть новый вариант перечисления `Bus` и один модуль печати. Фича
берётся в работу **только по явному запросу заказчика** и в
порядок разработки не входит.

Что перенести в работу, когда требование появится (уроки APB):
канонические 32-битные `paddr`/`pwdata` дают `UNUSEDSIGNAL` и валят проверка —
ширины строятся точными по `addr_width`/`data_width` ядра; обёртка **в
одиночку не линтуется** (`MODMISSING`), проверка подаёт её вместе с ядром;
работоспособность доказывает **тестбенч** с настоящими циклами шины, а не
линт — оба инструмента принимают обёртку, которая не работает.
AXI-Lite заметно дороже Wishbone: пять каналов с рукопожатием вместо двух
фаз, то есть обёртка перестаёт быть чисто комбинационной.
