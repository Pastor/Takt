## Краткое описание

Вынести из реестра `scripts/module-size-baseline.txt` **оставшиеся 6
нарушителей** лимита размера модуля, которые [остальные нарушители лимита размера модуля (17 файлов)](0088-module-size-remaining.md)
(Option B её ADR) **сознательно вынесла в преемника** как небезопасные для
чистого перемещения:

- **ядро семантики** — `grammar/src/semantic/tree.rs` (1842),
  `grammar/src/semantic/mod.rs` (1747),
  `grammar/src/semantic/expression.rs` (1360),
  `grammar/src/semantic/type_inference.rs` (1191);
- **пришпиленные к baseline размера** — `grammar/src/bin/lamc.rs` (1993),
  `grammar/src/lib.rs` (1402).

В отличие от безопасной части 0088 (перемещение тестов/печатников,
вывод байт-в-байт неизменен), здесь вынос требует **декомпозиции логики** ядра
семантики и **пересмотра пришпиливания** `lamc`/`lib` (тонкий диспетчер +
библиотека) — с риском задеть публичный API и поведение. Поэтому фича проходит
полный цикл (ADR → анализ → разработка) с сохранением инвариантов.

> Фича зарегистрирована **2026-07-24** при закрытии [остальные нарушители лимита размера модуля (17 файлов)](0088-module-size-remaining.md)
> как её преемник (критерий A5 анализа 0088); далее проходит жизненный цикл по
> своду. Проработка (ADR/анализ/Tier/зависимости) — за стадиями 2–3.
