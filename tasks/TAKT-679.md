# Исправление 0560-02: погашенный вывод цели возвращается при перезагрузке

> Фича: [структура проекта справа и пересмотр состава панелей](../features/0560-project-tree-and-panes.md)

## Проблема

Панель генерации (вывода цели), погашенная кнопкой, снова появлялась при
перезагрузке страницы и при открытии проекта. Замечено заказчиком 2026-09-10.

## Причина

Погашенная панель запоминалась **пустой строкой** (`name ?? ""`), а носитель
настроек `shell.setting` на пустую запись отвечает умолчанием: для него пустое
значение значит «выбора не было». Умолчание панели — показ, поэтому выбор
«погашена» не переживал ни одной перезагрузки. Открытие проекта само панель не
включало — оно лишь следовало за уже восстановленным неверным выбором.

Класс — «отсутствие и отрицание записаны одним значением»: для записи это разные
вещи, а для чтения — одна.

## Решение

Погашенная панель пишется словом `none`. Чтение не менялось: оно и прежде
показывало панель только на `output`, а всё прочее считало погашенной.

## Проверки

Набор веб-части: тест требует, чтобы погашенная панель писалась словом, а не
пустотой. Прогон страницы: погасить → перезагрузить → открыть проект → открыть
файл — панели нет; включить → перезагрузить — панель на месте.
