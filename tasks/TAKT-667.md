# Исправление 0539-10: в легенде пустой пункт условий переходов

> Фича: [графическое представление модели — раскладка состояний и рёбер в отдельном файле](../features/0539-model-layout-ui.md)

## Проблема

На листе без условий переходов легенда всё равно показывала пункт «Условия
переходов» — заголовок, шапку таблицы и строку «условий на листе нет». Заказчик
потребовал не вставлять пункт вовсе, 2026-09-10.

## Причина

Пункт строился всегда, а пустоту называла отдельная строка.

## Решение

Пункт условий добавляется в легенду, только если на листе есть хотя бы одно
условие; строки «условий нет» больше нет.

## Проверки

Прогон страницы: на листе без условий пункта нет, на листе с условиями — есть.
