# Исправление 0564-03: проект открывается сценарием при пустом редакторе модели

> Фича: [управление файлами в структуре проекта](../features/0564-project-file-actions.md)

## Проблема

Проект без назначенного активного файла открывался сценарием: редактор модели
оставался пустым, и страница отвечала `SE-102` («файл не содержит ни одного
состояния») и «строить нечего». Нашлось проверкой переименования проекта
2026-09-10.

## Причина

Без активного файла открывался **первый файл по алфавиту**, какого бы рода он ни
был. У проекта, чьи файлы носят его имя (0572), первым почти всегда оказывается
сценарий: `test-cold.json` стоит раньше `test.takt`, потому что `-` меньше `.`.
Сценарий открывают, не меняя открытого файла (0564-01), — редактор модели так и
оставался пустым.

## Решение

Без назначенного активного файла открывается **первая модель**, и только проект
без моделей — первым файлом.

## Проверки

Набор веб-части зелёный; прогон страницы: проект `test4` (модель, схема, сценарий
`test4-cold.json`, пояснение) открывается моделью.
