# Исправление: временные каталоги тестов могут пересекаться

- **Фича:** [разделение предкоммита на компоненты и выборочный запуск](../features/0190-precheck-selective-gates.md) — параллельные тесты
- **Статус:** ГОТОВО
- **Дата:** 2026-08-23
- **Повод:** разовое падение `conformance_sv_struct_local_tests` в предкоммите

## Что наблюдалось

Один прогон `./scripts/precheck.sh` из шести упал:

```
verilator не собрал тестбенч:
cat: Vtb__ALL.a.verilator_deplist.tmp: No such file or directory
ranlib: warning: file not found 'Vtb__ALL.a'
Undefined symbols for architecture arm64: "_main"
```

Повторный запуск того же теста — зелёный.

## Замер

**Воспроизвести не удалось:** три изолированных прогона набора `conformance_sv`
и четыре полных прогона предкоммита — все зелёные. Отказ остаётся
единственным.

Зато чтение дало **проверяемый** признак. Инвариант требует, чтобы
каталог теста был уникален по тесту: тесты идут параллельно, а каждый помощник
начинает с `remove_dir_all`. Замер по дереву:

| Что считалось | Итог |
|---|---|
| Мест построения временного каталога | 234 |
| Из них без имени потока | 132 |
| Одинаковых **литеральных** каталогов в разных файлах | **0** |
| Одинаковых **шаблонов** `format!` без имени потока в разных файлах | **1** |
| Дублей тега внутри файла без имени потока | 0 |

«Нет имени потока» — **не** признак дефекта: уникальным именем каталог
уникален и так. Настоящий признак — совпадение, и оно было ровно одно:
`takt_conformance_sv_{tag}` в `conformance_sv_tests.rs` и
`conformance_sv_time_tests.rs`. Сегодня их теги не пересекаются, то есть класс
**не проявлен** — но проявится при первом же новом теге.

Там же нашёлся устаревший комментарий: «тесты идут однопоточно, но каталоги
разные». Это неверно с фичи (`--test-threads=1` снят), когда
проза приписывает коду роль, которой у него нет.

## Что сделано

- Оба помощника берут **имя потока** (харнесс Rust называет поток именем
  теста; двоеточия вычищаются).
- Устаревший комментарий заменён объяснением, почему ключ именно такой.
- Заведён проверка `scripts/check-test-temp-dirs.py` (`D1` — общий литеральный
  каталог, `D2` — общий шаблон без имени потока, `D3` — дубль тега в файле без
  имени потока) и контроль `scripts/test-test-temp-dirs.sh` на копии дерева;
  оба — шагом предкоммита.

**Проверка проверяет имена, а не поведение:** тест, строящий имя вычислением,
ему невидим. Граница названа в заголовке — предмет в том, чтобы совпадение не
заводилось незаметно.

**Массовой правки 132 мест не делалось намеренно:** признак дефекта —
совпадение, а не отсутствие имени потока; переписывать уникальные имена значило
бы менять сотню тестов ради формы.

## Проверки

| № | Условие | Результат |
|---|---|---|
| F1 | Проверка на рабочем дереве | 315 файлов, пересечений нет |
| F2 | `D1` — общий литеральный каталог | ловится |
| F3 | `D2` — общий шаблон без имени потока | ловится |
| F4 | **Контроль:** тот же шаблон **с** именем потока | принимается |
| F5 | `D3` — дубль тега | ловится |
| F6 | Пустое дерево | не роняет проверка |
| F7 | Набор `conformance_sv` после правки | 46 тестов зелёные |
| F8 | `./scripts/precheck.sh` | код 0 |

## Что осталось

Исходное падение объяснено **гипотезой**, а не доказано: сбой мог быть и
внешним (verilator собирает C++ на всех ядрах, `-j 0` с фичи). Запись в
кандидатах уточнена — там сказано, что воспроизвести не удалось, и названо,
чем это опасно: отказ, который «бывает», перестают читать.
