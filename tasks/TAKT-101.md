## Итог (что сделано)

Наполнен раздел `book/src/02-lexical/index.typ` описанием **лексической
структуры** языка Takt (язык не меняется, Tier 3; ADR/анализ не
требовались):

- **Кодировка** (UTF‑8, Unicode в идентификаторах), **пробелы** (не значимы),
  **комментарии** (`//`, `///`, `/* */`; `////` — обычный строчный).
- **Идентификаторы** (`_`/`$`/Unicode‑буква в начале; регистр значим; кириллица
  допустима), таблица **ключевых слов** сгруппирована по назначению (сверена с
  таблицей `KEYWORDS` лексера, включая LTL‑буквы `X`/`F`/`G`/`U`/`R`).
- **Литералы**: целые (dec/hex, разделитель `_`, отрицательные), дробные
  (`.5`, экспонента `1e10`), **адресные** (`0x…:бит`), логические, строковые
  (`"…"`/`'…'`, экранирование `\`, `unicode"…"`).
- **Операторы** (арифметика/побитовые/логические/сравнения/`:=`) и **пунктуация**;
  явно разведены `:=` (присваивание) и `=` (равенство/связка).
- Пример `book/src/02-lexical/examples/tokens.takt` — **компилируется** `taktc`
  (цель `c`, EXIT 0), демонстрирует комментарии всех видов, dec/hex‑литералы с
  `_`, операторы `:=`/`=`/`+`.

**Живая проверка:** пример компилируется; `./scripts/precheck.sh` зелёный. Сборка
PDF локально не верифицируется (нет `mdbook`/`mdbook-pandoc`/`xelatex` — вне
`precheck.sh`, как и для 0101).

**Побочная находка (вне объёма 0102):** seed‑пример `book/src/01-overview/
examples/blinker.takt` (фича 0101) **не компилируется** — форма `start state Off`

входа `start Main = Blinker;` (либо состояния на верхнем уровне без обёртки
`model`). Занесено в бэклог `FEATURES.md` для фичи‑преемника 0101.
