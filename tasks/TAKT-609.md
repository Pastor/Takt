# Исправление: примеры разделов — функциональные, из практики

> Фича: [../features/0121-book-example-walkthrough.md](../features/0121-book-example-walkthrough.md) (разбор примеров) · свод · запрос заказчика 2026-07-24

- **Статус:** Исправлено
- **Приоритет:** Tier 3 — качество и наглядность примеров документа

## Проблема

Примеры разделов 02/03/05/06/07 были **искусственными** (абстрактные `Timer`,
набор типов `Mode`/`Point`/`samples`, счётчик `start/stop`, `Slow/Fast`,
`double`/`quad`). Такой пример «оторван» — читателю не за что зацепиться. Пример
из практики (как светофор в разделе «Модели и состояния») нагляден: читатель знает
устройство и его работу, поэтому понимает модель даже при малознакомом синтаксисе.

## Исправление

- **свод** (`docs/RULE.md`) переформулировано: пример раздела — **узнаваемое
  устройство/процесс** промышленной автоматики (не искусственная конструкция);
  структура блока «Пример» — вводная фраза «Рассмотрим модель, описывающую …» +
  **функциональный бриф** → код → **разбор всей модели** (переменные и зачем,
  типы/перечисления, переходы и условия) со **ссылками-выносками** `(N)` по ходу
  повествования на важные для темы места.
- **Примеры заменены на реальные устройства** (все компилируются `taktc`, 0
  предупреждений):
  - **02 Лексика** — **термореле** (порог/гистерезис, все виды комментариев,
    литералы, операторы);
  - **03 Типы** — **кабина лифта** (перечисление направления, структура `Trip`,
    `u8`-этажи, `q(4,4)`-скорость, массив журнала, `bit`/`bool`-порты);
  - **04 Модели/состояния** — **светофор** (усилён бриф «красный–ожидание–жёлтый–…»
    и полный разбор состояний/переходов);
  - **05 Выражения/условия** — **бойлер** (условия с логическими `&`/`|`,
    выражения);
  - **06 Управление** — **сортировочный конвейер** (`match`/`for`/`if-else` +
    функция `settle` с `while`/`break`/`return`);
  - **07 Функции** — **насосная станция** (`extern fn` HAL, `clamp`, композиция
    `headroom`, вызовы).
- **Разборы** переписаны по своду: бриф + разбор всей модели + выноски.
