# Шрифты страницы

Шрифт лежит файлом рядом со страницей: внешних CDN у неё нет (правило 8 книги
контролов) — чужой адрес это и отказ при недоступности, и обращение читателя к
третьей стороне.

## Код — `FiraCode-Regular.woff2`

**Fira Code** Regular `Version 6.002` (`Copyright 2014-2021 The Fira Code
Project Authors`), 103 412 Б, 1586 глифов в `cmap`; получен конвертацией
`FiraCode-Regular.ttf` в WOFF2 (`fontTools`, без подмножества глифов).

- **Источник:** <https://github.com/tonsky/FiraCode>
- **Лицензия:** SIL Open Font License 1.1 — [`OFL-FiraCode.txt`](OFL-FiraCode.txt).

Тем же шрифтом набран документ `book/` (`book/src/template.typ`): код в PDF и в
браузере обязан выглядеть одинаково. Начертание одно — жирного кода на странице
нет, а курсивного у Fira Code нет вовсе, и наклон комментария синтезируется
браузером ровно так же, как в документе.

⚠️ **Этим шрифтом набрана вся страница** — и код, и интерфейс (решение
заказчика 2026-09-05, отменяет чертёжный шрифт по ГОСТ 2.304-81 у интерфейса).
Моноширинность обязательна коду: колонки, выравнивание трассы и позиции
диагностик в пропорциональном шрифте разъезжаются, а вид кода расходится с
документом.

## Почему без подмножества глифов

Замер 2026-09-04: полное начертание Fira Code — 103 412 Б WOFF2 против
3 344 001 Б модуля рядом. Подмножество сэкономило бы десятки килобайт и завело
бы правило «какие глифы нужны», которому нужен свой сторож: пропавший глиф
выпадает в системный шрифт молча.
