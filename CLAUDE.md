# Takt

Takt — язык для описания конечных автоматов и генерации кода для C, ST,
Rust и SystemVerilog. Исходники находятся в Rust workspace, описание языка —
в [книге](book/).

В начале сессии открой проект `ТАКТ` (ID 22) через MCP `anal`
(`https://pastor.axatel.ru/anal/mcp`). Вызови `rules` и `skills` с
`project: 22` и `kind: "agent"`. Полные тексты читай через `rule` и
`skill`. Правила и умения меняй через aNaL.

Заводи задачи и веди постановку, статусы, связи и отчёты в aNaL. Для
задач проекта используй ключи `TAKT-…`. Синхронизацию с Git выполняет
aNaL через ветку `anal/project-22`.

- [Контекст](docs/CONTEXT.md) — состояние проекта и с чего продолжать.
- [Протокол](docs/PROTOCOL.md) — ход работы, проверки и существенные действия.
- Решения — в aNaL. Изменения для пользователей — в [CHANGES.md](CHANGES.md).
- Макеты — в [docs/design/](docs/design/), результаты замеров и проверки — в задаче aNaL.
- Примеры и сценарии — в [examples/](examples/), описание языка — в [book/](book/).
- Проверки проекта — `./scripts/precheck.sh`.

Версия языка **сейчас `0.19.0`**.
