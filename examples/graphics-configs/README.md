# Настройки генерации GIF-симуляции

Файлы JSON в этом каталоге передаются симулятору через `--graphics-config`;
каталог для кадров задаётся `-o`/`--output`, а вид вывода (GIF или SVG) — полем
`output_mode` самого файла настроек:

```sh
cargo run --bin takt-sim -- examples/stacker.takt -n 12 \
    --output out/ \
    --graphics-config examples/graphics-configs/dark.json
```

В файле допустимо указывать только те поля, которые нужно переопределить —
отсутствующие значения берутся по умолчанию (см. `default.json`).

## Доступные пресеты

| Файл              | Описание                                                       |
|-------------------|----------------------------------------------------------------|
| `default.json`    | Полная схема с дефолтными значениями (справочник полей).       |
| `dark.json`       | Тёмная тема с розовым акцентом для подсветки переходов.        |
| `compact.json`    | Кадр 640×480 с уменьшенными узлами и шрифтами.                 |
| `large.json`      | Кадр 1280×960 для больших автоматов.                           |
| `monochrome.json` | Чёрно-белая схема, английские заголовки легенды.               |

## Группы параметров

- `canvas` — размеры холста, задержки кадров (`frame_delay_cs` для обычных,
  `highlight_frame_delay_cs` для кадра подсветки).
- `node` — радиус, цвета, толщина обводки и шрифт состояний.
- `edge` — размер стрелки, базовый изгиб, цвет/толщина обычных
  и подсвеченных рёбер.
- `edge_label` — оформление подписи к подсвеченному ребру: шрифт, фон,
  параметры алгоритма поиска свободного места (`search_radii`, `search_angles`).
- `legend` — ширина, отступы, цвета фона и текста, заголовки колонок
  (можно локализовать).
- `highlight` — рамка highlight-кадра и оранжевая шапка с описанием перехода.
- `model_name` — шрифт и положение заголовка с именем модели.
- `layout` — параметры имитации отжига (температуры, веса штрафов).
