# План

1. Необходимо добавить лексическую обработку (скорректировать уже имеющуюся) формул. Сам
   `enum Formula` задает возможные конструкции формул. Добавь описание формул и их синтаксис в grammar.lalrprop. Формулы
   можно задавать как в моделях, в состояниях и в блоках кода. Пример задания формулы:
   в состоянии Idle:
   ```but
   state Idle {
     : Model = End & var;
     : temperature > 20.5;
   }
   ``` 
   в моделе
   ```but
   model Model {
     var temperature = 0.0;
     
     : temperature > 20.5;
   }
   ```
   в коде
   ```but
   model Model {
     always {
       var i = 0;
       : i < 10;
     }
   }
   ```
   задание формулы всегда начинается с двоеточия `:` и заканчивается точкой с запятой `;`. Одно выражение формулы
   может содержать несколько условий, разделенных запятой. Например:
   ```but
   model Model {
     always {
       var i = 0;
       : i < 10, i > 0;
     }
   }
   ```
   или
   ```but
   model Model {
     always {
       var i = 0;
       : i < 10;
       : i > 0;
     }
   }
   ```
   что в конечном итоге считается эквивалентными записями.
2. Добавь семантический анализ формул
3. Необходимо добавить поддержку генерации кода для формул. У состояний, моделей и блоков кода может быть несколько
   формул. формулы должны проверяться на каждом такте модели, состоянии или блоке кода.
   Включение и отключение обработки формул производится конструкцией `pragma` например:
   ```but
   model Model {
     pragma formula_check = false;
     always {
       var i = 0;
       : i < 10;
     }
   }
   ```
   отключает генерацию кода для проверки формул в данном блоке кода. По умолчанию обработка формул включена.
   Формулы состояний проверяются при каждом такте в состоянии. Формулы блоков кода проверяются при каждом такте блока
   кода. Формулы модели проверяются при каждом такте в модели.
4. Модифицируй формулы. Раздели их на два типа: `LTL` и `Guard`. По умолчанию рассматривается как `Guard` формула. `LTL`
   формула подчиняется семантике в модуле `verification::ltl` и полностью ей соответствует. `Guard` формула с обычной
   проверкой `condition`. Для определения какой вид формулы используется следует их различать синтаксически как
   добавление после `:` типа формулы в квадратных скобках. Например:
   ```but
   model Model {
     always {
       var i = 0;
       :[LTL] X End;
       : i > 0;
     }
   }
   ```
   В данном примере формула `i < 10` считается `LTL` формулой, а `i > 0` - `Guard` формулой.
