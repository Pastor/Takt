# План

1. Следует пересмотреть генерацию си кода для портов. Все порты в моделе должны быть объеденены в один `enum` сишного
   кода, значение констант должно быть адресом. Имя `enum` должно состоять из имени модели и суффикса `Ports`.
   Определение должно быть в заголовочном файле, функции для работы с портами должны принимать в качестве аргумента
   `enum` типа. Придерживайся написанному в `AGENTS.md`
