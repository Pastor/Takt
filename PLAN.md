1. Проаудируй кодовую базу на скрытые баги в модулях LSP, кодогенератора и enum Extend. Для каждого подозреваемого бага: (1) напиши падающий тест, (2) запусти `cargo test <test_name>` для подтверждения, (3) реализуй исправление, (4) запусти полный `cargo test`, (5) закоммить. Итерируй автономно до 5 багов или исчерпания находок. Не запрашивай подтверждения — останавливайся только если исправление затрагивает более 3 файлов архитектурно.
2. Прочитай PROMPT.md и определи все независимые задачи. Для каждой независимой задачи запусти параллельного субагента через Task tool: (1) создай git-воркдерево под .worktrees/<task-slug>, (2) реализуй задачу end-to-end, (3) запусти `cargo test`, захвати сбои, (4) итерируй пока тесты не пройдут или до 3 попыток, (5) верни unified diff и сводку. После всех субагентов проверь патчи, разреши конфликты, влей в main, запусти полный `cargo test`. Отчитайся таблицей задача → статус → количество тестов.
3. Настрой CI-воркфлоу `.claude/ci-repair.sh`: (1) запускает `cargo test --no-fail-fast`, захватывает сбои в JSON, (2) для каждого сбоя вызывает `claude -p` с фокусированным промптом (только падающий тест + релевантные файлы + ошибка), (3) агент исправляет, перезапускает тест, пишет патч в `.claude/patches/<name>.patch`, (4) применяет патчи, запускает полный тест-сьют, создаёт `gh pr create --draft`. Добавь `.claude/state.json` для возобновления прерванных запусков. Покажи скрипт и пробный прогон.
4. После завершения каждой задачи из PROMPT.md добавляй однострочную запись в STATUS.md (название задачи, изменённые файлы, тесты проходят). В начале сессии сначала читай STATUS.md, чтобы возобновить с последней контрольной точки.
5. При написании новых тестов сначала запускай небольшой зонд для захвата реальных выходных значений, затем пиши assertions против этих захваченных значений. Не угадывай ожидаемые строки/адреса.
6.
```bash
mkdir -p .claude/skills/prompt-tasks && cat > .claude/skills/prompt-tasks/SKILL.md <<'EOF'
# Выполнение задач PROMPT.md

1. Прочитай PROMPT.md и перечисли все задачи
2. Для каждой задачи по порядку:
   a. Реализуй изменение
   b. Запусти `cargo test` и исправь сбои
   c. Обнови документацию (README.md)
3. После всех задач: `git diff > changes.patch`
4. Отчитайся по каждой задаче
   EOF
```
