# План

1. Для генератора сишного кода и общего механизма работы примени следующие изменения. Поведение портов должно быть
   следующее. Все порты группируются в перечисления `enum` по типу( `BitPort`, `RationalPort`, `NumericPort` ). Функции
   работы с портами принимают вместо адреса (`int`) соответствующий его работе `enum`. Функции обработчики портов
   декларируются, если в моделях есть соответствующие типы портов. На уровне семантического анализа требуется выдавать
   предупреждение о том, что все порты, которые будут задаваться в дочерних моделях, все равно будут видны всем и
   доступным любому коду при обращении. На уровне синтаксиса убрать задание адреса и указания бита адреса для порта, оно
   становится необязательным (убрать полностью из анализа). Придерживайся написанному в `AGENTS.md`
