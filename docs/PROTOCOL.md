# Протокол Takt

## TAKT-615. Запись в выходной порт из другого порта в Rust

На `v2` (`21b5d777`) уже присутствует исправление `237f7d5b`.
При чтении HAL в правой части генератор вычисляет значение во временной
переменной `takt_value` до вызова записи. Это разводит изменяемые
заимствования HAL и сохраняет порядок операторов модели.

- Буквальный пример из карточки завершается с `SE-102`: в файле нет
  стартового состояния верхнего уровня. С теми же портами и состояниями
  на верхнем уровне `taktc compile -t rust` генерирует рабочий код,
  который принимает `rustc -D warnings`. Возврат вложенного вызова чтения
  в копии сгенерированного файла воспроизводит `E0499`.
- `cargo test --offline -p takt-lang --test targets rust_port_read_in_write_tests -- --nocapture`:
  три теста. Прямое присваивание `bit` и выражение с чтением `u8` в аргументе
  функции компилируются в `rustc` и `clippy-driver` с `-D warnings`.
  Проверена форма вывода для обеих записей и обычный аргумент для записи
  без чтения HAL.
- `cargo test --offline -p takt-sim --test conformance conformance_port_read_in_write_tests -- --nocapture`:
  один тест. Порождённый Rust и эталонный симулятор после трёх тактов дают
  одинаковые значения `(o_sum, o_bit, o_plain) = (21, 1, 3)`. Фикстура
  читает двунаправленный порт после записи в него в том же такте.

## TAKT-704. Тип результата `unit`

В главе «Типы данных» описан `unit`, в главе «Функции» добавлена ссылка
на описание. Явное `-> unit` и опущенная аннотация задают один тип
результата. Вызов выполняет действие, функция завершается в конце тела
или по `return;`.

`make -C book pdf` собрала 180 страниц. Прошли проверки символов шрифта,
лексики, подсветки, кодов диагностик и стиля документов с самопроверками.
Пробная модель с обеими формами объявления прошла генерацию для C, Rust,
SystemVerilog и ST установленным `taktc 0.62.2` (язык 0.19.0).
`takt-sim` выполнил 10 тактов. База ветки сверена с `origin/v2` (ac49d140).

## TAKT-705 — префикс диагностики сценария

На исходной версии `takt-sim` с неизвестным входом `start_bttn` печатал
`Ошибка: Ошибка [SIM-030]: шаг 1: порт …`. Сквозной тест воспроизвёл сбой.

CLI выводит сообщения чтения, разбора и выполнения сценария напрямую.
Общие ошибки прогона сохраняют общий префикс. Сквозной тест проверяет
`SIM-030` и код завершения 1 в обеих локалях. Некорректный JSON проверен
в обеих локалях, с путём к сценарию и кодом завершения 1.

Локально прошли 224 модульных и 208 интеграционных тестов `takt-sim`,
матрица режимов симулятора, проверки форматирования, Clippy, реестра
диагностик и паритета каталогов сообщений.
Проверка ссылок завершилась с 5150 ошибками. Отчёт совпадает с отчётом
для исходного коммита `v2`.

очищают свои каталоги на выходе. Готовые бинарники остаются на месте.

и сверка WASM, режим установки и сохранение кода ошибки при очистке.

## Восстановление реализаций состояний

В `TAKT-702` воспроизведён сбой через `--save-state` и `--load-state`.
После загрузки условие `S(Feeder) = Done` не срабатывало, хотя до
сохранения вложенная модель уже перешла в `Done`. Снимок теперь хранит
дерево реализаций по именам состояний, а загрузка восстанавливает дерево
и заново публикует его в реестре. Старые снимки читаются без поля
`state_impls`. Регрессия проверяет переход по условию на первом такте
после загрузки.

`cargo test --locked -p takt-sim` — 737 тестов прошли, один
документационный тест пропущен. Форматирование, Clippy для `takt-sim`
и проверка стиля документации прошли. `./scripts/precheck.sh`
остановился на 5150 битых ссылках. Список совпал с исходной `v2`.

## TAKT-700 — прогон вложенной композиции

На листе `Load` тест с двумя экземплярами `Heater` воспроизвёл
одновременную подсветку шагов обоих экземпляров. Путь входа теперь несёт
адрес владельца, крошка показывает номер шага, а общая раскладка читается
по прежнему ключу листа. При возврате по крошке и повторном входе
восстанавливается адрес выбранного экземпляра.

Ресурсы IntelliJ пересобраны через `scripts/build-plugin-webview.py`.
Прошли строгий `scripts/check-web.sh` (155 тестов) и проверки ресурсов
панели, дизайна, стиля документации и шрифтов книги. Отдельно на двух
тактах симулятора WASM проверен счётчик шага для двух параллельных
экземпляров. Полный `scripts/precheck.sh` остановился на проверке
Markdown-ссылок. На чистой `v2` (`ac49d140`) подтверждён тот же список
из 5150 битых ссылок.
