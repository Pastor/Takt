# Анализ фичи 0261: Жёлтая зона гейта размера модулей

> Фича: [../features/0261-module-size-warning-zone.md](../features/0261-module-size-warning-zone.md) · ADR: [../adr/0261-module-size-warning-zone.md](../adr/0261-module-size-warning-zone.md) · тест-план: [../tests/0261-module-size-warning-zone.md](../tests/0261-module-size-warning-zone.md)

## Цель и контекст

Дать сигнал раньше отказа. ADR принял Option B: предупреждение, не влияющее на
код возврата, плюс сторож гейта.

## Замер (снят 2026-08-20, правило 30)

Кандидат подтверждён, цифры уточнены (список 0225 от 2026-08-17 сдвинулся):

| Порог | Файлов в зоне |
|---|---|
| ≥ 900 | 23 |
| ≥ 950 | 15 |
| **≥ 970** | **8** |
| ≥ 990 | 3 |

Всего под правилом 485 файлов. Ближайший к пределу — `generator/sv/sv_expr.rs`:
**1000 строк, запас 0** (кандидат называл 998 — файл с тех пор подрос).

**Находка сверх кандидата:** у гейта **нет самопроверки**. Он падал только на
настоящем дереве, то есть «зелено» ничем не отличалось от «не смотрит» — класс,
который 0255 закрыла у гейта диагностик.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет.
- **Влияние на порядок:** смежна с [0099](../features/0099-module-size-core.md)
  (вынос нарушителей ядра, заморожена): жёлтая зона показывает, кто следующий.

## Требования и проверяемые условия

- **R1.** Файлы зоны `970…1000` печатаются списком, с остатком запаса.
- **R2.** Код возврата от предупреждения **не меняется**.
- **R3. Контроль:** файл вне зоны в список не попадает.
- **R4.** Сторож проверяет мутацией все условия гейта: новый нарушитель, рост,
  ужатие, закрытая запись, запись на несуществующий файл.
- **R5.** Сторож гоняет гейт на **временном** дереве (`MS_ROOT`), рабочее не
  трогает.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Список печатается | прогон гейта |
| A2 | Код возврата 0 | там же |
| A3 | Контроль | сторож, проверка 8 |
| A4 | Условия гейта | сторож, проверки 2–6 |
| A5 | Предкоммит | `./scripts/precheck.sh` |

## Особенности по обратной функциональности (правило 11)

**Не нарушается.** Добавлено предупреждение и сторож; поведение отказов
прежнее, код возврата на согласованном дереве прежний.

## Редакторский слой (правило 29)

**Не требуется.**

## Документирование (правило 24)

**Не требуется.** Правило размера модуля описано в `docs/CODE.md`, а не в
`book/` (тот — о языке).

## Риски и зависимости

- **Риск: предупреждение станет фоном.** **Снижение:** порог выбран по замеру —
  восемь строк, а не двадцать три; у каждой строки указан остаток запаса.
- **Риск: порог устареет.** **Снижение:** названо прямо — при росте кодовой
  базы замер повторяется (правило 30).
- **Риск: сторож трогает рабочее дерево.** **Снижение:** гейт получил `MS_ROOT`,
  сторож строит своё дерево во временном каталоге.
