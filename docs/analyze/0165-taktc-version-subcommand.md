# Анализ фичи 0165: `taktc version`

> Фича: [../features/0165-taktc-version-subcommand.md](../features/0165-taktc-version-subcommand.md) · ADR: [../adr/0165-taktc-version-subcommand.md](../adr/0165-taktc-version-subcommand.md) · тест-план: [../tests/README.md](../tests/README.md)

## Цель и контекст

ADR принял **Option C**: подкоманда `version` плюс синонимы `--version`/`-V`,
логика — в библиотеке, контракт вывода — под тестом. Гейт версии не трогается
(Option D отклонён).

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет.
- **Влияние на порядок:** ничего не разблокирует.

## Проверка входных условий (замер 2026-08-18)

Карточка утверждала, что фича «заблокирована лимитом размера модуля». Проверено:
`taktc.rs` — **784** строки при лимите 1000, в `module-size-baseline.txt` его
**нет**, запас — 216 строк. Блокировка снята временем: файл сокращали фичи
0027 и 0043 (вынос `compile`/`address-map` в библиотеку).

⚠️ Вывод на будущее: **входные условия карточки проверяются на стадии
архитектуры, а не наследуются**. Взятое на веру «заблокировано» стоило бы
лишнего выноса кода без надобности.

## Требования и проверяемые условия

- **R1. Число не размножается.** Подкоманда печатает `LANGUAGE_VERSION` и
  `CARGO_PKG_VERSION`, читая их из кода. Ни одного литерала версии в новом коде
  — иначе появится второй источник истины, ровно тот, против которого заведена
  константа (ADR 0085).
- **R2. Три входа — одна реализация.** `version`, `--version`, `-V` дают
  байт-в-байт один вывод: синоним разрешается в диспетчере, а не копией.
- **R3. Тест сверяет с константой, а не с литералом.** Тест, сравнивающий вывод
  со строкой `"0.10.0"`, придётся править при каждом подъёме версии — и он
  ничего не докажет, потому что сам станет вторым источником.
- **R4. Гейт версии не изменён** и продолжает работать до сборки бинарников.
- **R5. Справка и текст «неизвестная команда» называют подкоманду.**
- **R6. Логика в библиотеке.** Бинарник остаётся диспетчером (образец
  `address-map`): так вывод проверяется тестом крейта, а не только прогоном.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | `taktc version` печатает обе версии, код 0 | тест + прогон |
| A2 | `--version` и `-V` дают тот же вывод | тест на равенство трёх выводов |
| A3 | Вывод содержит `LANGUAGE_VERSION` | тест против константы |
| A4 | Вывод содержит `CARGO_PKG_VERSION` | тест против константы |
| A5 | Справка называет подкоманду | тест на текст справки |
| A6 | Текст «неизвестная команда» называет подкоманду | чтение + прогон |
| A7 | Гейт версии зелён и не изменён | `git diff` пуст по файлу гейта; прогон |
| A8 | Раздел документа описывает подкоманду | чтение; гейты 0146/0133 |
| A9 | Предкоммит зелёный | `./scripts/precheck.sh`, **код возврата прочитан явно** |

## Особенности по обратной функциональности

- **Язык не меняется** (правило 22): версия языка остаётся `0.10.0`. Версия
  крейта `takt-lang` растёт минорно — публичный API пополняется функцией
  подкоманды.
- **Правило 29:** LSP и плагины не затронуты. ⚠️ Плагин IntelliJ (0158) зовёт
  `taktc` командной строкой — новая подкоманда ему не мешает и не требуется.
- **Наблюдаемое изменение:** три новых входа CLI, отвечающих версией вместо
  ошибки.

## Риски и границы

- **Риск: формат вывода станет контрактом.** Он и станет — это цена любой
  печати. Смягчение: формат прост (две строки), назван в документе и закреплён
  тестом, так что случайная смена заметна.
- **Риск: тест закрепит литерал версии.** Снимается R3: сравнение идёт с
  константой.
- **Граница: гейт по-прежнему сверяет исходник, а не вывод CLI.** Сознательно
  (ADR, Option D отклонён): иначе гейт зависел бы от собранного бинарника.
  Контракт вывода держит тест крейта.
