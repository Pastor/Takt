# Анализ фичи 0055: Многофайловость LSP

> Фича: [../features/0055-lsp-multifile.md](../features/0055-lsp-multifile.md) · ADR: [../adr/0055-lsp-multifile.md](../adr/0055-lsp-multifile.md) · тест-план: [../tests/0055-lsp-multifile.md](../tests/0055-lsp-multifile.md)

## Цель и контекст

Сделать `import` работающим в редакторе и показать чужую диагностику так, чтобы
она не врала координатами. Кандидат вскрыт отчётом 0053.

## Зависимости (правило 17)

| Фича | Статус | Почему зависимость |
|---|---|---|
| 0053 | `ГОТОВО` | `FileTable`, настоящий `file_no`, `Diagnostic::file`, `construct_model_with_files` |
| 0054 | `ГОТОВО` | общий слой печати позиции (`position_prefix`) — им формируется текст «в файле X:стр:кол» |

Обе закрыты → фича **не блокируется**.

## Меняет ли фича язык (правило 22)

**Нет.** Грамматика и АСД не трогаются. Но **меняется разрешение импорта**
(каталог импортирующего файла — неявный путь): это семантика **инструмента**, а
не языка. Версия языка (0.3.0) не растёт; вывод генераторов на корпусе неизменен.

## Обратная совместимость (правило 11)

**Сохранена намеренной ценой.** Неявный путь добавляется **в конец** списка:

| Случай | Было | Стало |
|---|---|---|
| `-I` находит файл | найден файл из `-I` | **тот же** файл |
| `-I` не задан, файл рядом | `SE-013` | найден |
| Файл есть и рядом, и в `-I` | из `-I` | **из `-I`** (не изменилось) |

Строго аддитивно: меняется только исход, который раньше был ошибкой. Цена —
шадоуинг локального файла одноимённым из `-I` (ADR 0055, A1).

## Требования

| # | Требование |
|---|---|
| R1 | Каталог импортирующего файла — неявный путь поиска в **ядре** (общий для `lamc` и LSP) |
| R2 | Путь добавляется в конец: сборки с `-I` не меняют поведения |
| R3 | Каталог берётся у **импортирующего** файла (вершина стека импортов, иначе корень) |
| R4 | Ошибка из чужого файла несёт заметку с позицией `import` — на каждом уровне |
| R5 | LSP знает путь документа (`collect_diagnostics_at`) |
| R6 | Чужая диагностика привязана к строке `import`, текст называет `в файле X:стр:кол` |
| R7 | Своя диагностика показывается как прежде |
| R8 | Версия языка и вывод генераторов не меняются |

## Критерии приёмки

Совпадают с ADR 0055 (A1–A6); проверяются тест-планом T1–T10.

## Риски

| # | Риск | Митигация |
|---|---|---|
| Р1 | Неявный путь сменит найденный файл в существующих сборках | R2 (в конец); T2; гейт `precheck.sh` на корпусе `examples/` |
| Р2 | Каталог взят у **корня** вместо импортирующего → вложенный импорт не найдётся | R3: вершина стека импортов; T3 (цепочка `top → mid → deep` без `-I`) |
| Р3 | Якорь чужой ошибки угадан по имени файла → врёт на вложенных импортах | R4: якорь из заметки с `file_no == 0`, а не поиск в АСД |
| Р4 | Свою диагностику приняли за чужую → позиция уехала | T4; проверка `file_no == 0` |
| Р5 | Тесты LSP не собираются без фичи `lsp` | тесты под `#[cfg(feature = "lsp")]`; ловит `precheck.sh` |

## Что НЕ входит в объём

- **`goto_declaration` угадывает файл** по имени модели, хотя реестр даёт точный
  путь (ADR 0055, A2) — другой сценарий, кандидат.
- **`initializationOptions`** (аналог `-I` в редакторе) — A3, кандидат.
- **Публикация диагностик в чужие URI** — отвергнута заказчиком (Option E).
