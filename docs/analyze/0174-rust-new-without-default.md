# Анализ фичи 0174: Цель rust: корневая модель без портов (clippy::new_without_default)

> Фича: [../features/0174-rust-new-without-default.md](../features/0174-rust-new-without-default.md) · ADR: [../adr/0174-rust-new-without-default.md](../adr/0174-rust-new-without-default.md) · тест-план: [../tests/0174-rust-new-without-default.md](../tests/0174-rust-new-without-default.md)

## Цель и контекст

Реализовать **Option A** ADR 0174: печатать `impl Default` рядом с публичным
конструктором без аргументов и завести двухслойного сторожа.

Работа целиком в крейте `takt-lang`, генератор цели `rust`. Язык **не
меняется**, версия языка не растёт (правило 22).

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет.
- **Влияние на порядок разработки:** ничего не разблокирует и ничем не
  блокируется.

## Разбор (что именно сломано и где)

| # | Место | Факт |
|---|---|---|
| Д1 | `takt-lang/src/generator/rust/rust_model.rs`, `emit_new` | `args` пусты при `!(is_root && uses_hal)` → у корня без HAL печатается `pub fn new() -> Self` без аргументов |
| Д2 | там же, конец блока `impl` | `impl Default` не печатается **никогда** — линт `clippy::new_without_default` остаётся неудовлетворённым |

**Уточнение к карточке.** Причина слепоты корпуса — не «у всех примеров есть
порты»: у `comprehensive.takt` их **ноль**. Настоящий признак — предикат
`needs_hal`, транзитивный по портам **и** `extern fn`. `comprehensive` зовёт
`extern fn`, получает `new(hal: H)`, и линт молчит. Слепым корпус делает то,
что **ни один** пример не обходится разом без портов и без `extern fn`.

Контрольный замер: перегенерация всего корпуса после правки даёт **пустой
дифф** — правка ни одного примера не касается.

## Требования и проверяемые условия

- **R1. `impl Default` при конструкторе без аргументов.** Условие эмиссии —
  `is_root && !uses_hal`, буквально то же, при котором срабатывает линт.
- **R2. `impl Default` НЕ печатается при `new(hal: H)`.** Не «не нужно», а
  **нельзя**: значение `H` взять неоткуда, вывод не скомпилируется.
- **R3. Вывод принимается `clippy -D warnings`** — тем же линтом и с той же
  политикой, что в гейте `precheck.sh`.
- **R4. Корпус не изменился.** `examples/generated/rust/**` даёт пустой дифф.
- **R5. Сторож взведён.** Отключение эмиссии обязано валить тесты; эмиссия
  «всегда» — тоже.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | `impl Default` эмитится (R1) | `rust_default_impl_tests::model_without_ports_emits_default_impl` |
| A2 | не эмитится при `hal` (R2) | `model_with_port_does_not_emit_default_impl` (контрпример) |
| A3 | вывод проходит линт (R3) | `generated_module_passes_clippy_gate` — тот же `clippy -D warnings`, что в гейте |
| A4 | корпус не изменился (R4) | `git diff examples/generated/rust` пуст |
| A5 | сторож взведён (R5) | мутации генератора: «не эмитить никогда» и «эмитить всегда» |
| A6 | корпус зелёный | `./scripts/precheck.sh` |

## Устройство сторожа

Новый файл `takt-lang/tests/rust_default_impl_tests.rs`, два слоя:

1. **эмиссия** (быстро, без внешних инструментов) — текст вывода: `impl Default`
   есть/нет;
2. **гейт** — `clippy-driver -D warnings` на обёртке с `#![no_std]` в корне,
   дословно как в `precheck.sh`. Мягкая деградация: нет `clippy-driver` →
   пропуск с сообщением (образец — `conformance_rust_tests`).

⚠️ Оба слоя нужны. Один текстовый тест доказывал бы лишь, что мы печатаем
задуманную строку; один прогон линта не сказал бы, **почему** он зелен, и не
поймал бы эмиссию `Default` там, где её быть не должно (R2).

## Особенности по обратной совместимости (правило 11)

Изменение **аддитивно**: печатается новый элемент вывода, существующие не
меняются. Порождённый код всего корпуса байт-в-байт прежний (замер выше). Язык,
симулятор и прочие цели не затронуты — **н/п**.

Публичный API порождённого модуля **расширяется** (`Default` — новый трейт у
корневого типа), что совместимо: ни одна существующая сигнатура не меняется.

## Риски

- **Риск ошибки в предикате.** `impl Default` при `new(hal: H)` не
  скомпилируется, то есть ошибка условия ломает корпус громко, а не молча.
  Снижение: контрпример A2 + мутация «эмитить всегда».
- **Риск, что сторож стережёт не то.** Текстовый тест может пройти при том, что
  линт всё равно недоволен (например, если clippy сменит правило). Снижение:
  второй слой гоняет **настоящий** `clippy -D warnings`.
- **Устаревшие комментарии корпуса.** Три примера (`regulator`,
  `float_regulator`, `pid_regulator`) объясняют свой выходной порт нуждой цели
  `rust`; после фичи объяснение неверно. В объём **не берётся** (косметика по
  трём файлам корпуса) — записано находкой в `FEATURES.md`.
