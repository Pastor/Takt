# Анализ фичи 0376: Неиспользуемая локальная переменная гасится заглушкой

> Фича: [../features/0376-unused-local-stub.md](../features/0376-unused-local-stub.md) · ADR: [../adr/0376-unused-local-stub.md](../adr/0376-unused-local-stub.md) · тест-план: [../tests/0376-unused-local-stub.md](../tests/0376-unused-local-stub.md)

## Цель и контекст

Кандидат заведён закрытием 0375: там замер по локальным переменным дал три
строки, и фича закрыла столбец `sv`. Эта закрывает оставшиеся два.

### Замер (`scripts/probe.sh -n 2`, 2026-08-21)

Вход: `var spare: u8 := n + 5;` — объявлена, ни разу не упомянута.

| Потребитель | Ответ |
|---|---|
| эталон | исполняет |
| `c`, `c-hal` | **`cc` ОТВЕРГ:** unused variable 'spare' [-Wunused-variable] |
| `st`, `st-at` | `iec2c` принял · `cc` собрал |
| `rust` | **`rustc` ОТВЕРГ:** unused variable: `spare` |
| `sv`, `sv-mmio` | verilator принял · yosys синтезировал |

⚠️ `taktc` во всех восьми случаях возвращает **ноль**: класс невидим по кодам
возврата, его показывает только раздел «инструменты целей» пробы (0362).

⚠️ Проверка пробы (правило 30) прошла: `SE-036` не сработала — то есть
предупреждение «переменная не используется» локальных объявлений **не
касается**, и автор о неиспользуемой локальной не узнаёт ниоткуда.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. 0260 и 0337 (идиомы заглушек), 0375 (столбец `sv`) —
  закрыты.
- **Влияние на порядок разработки:** снимает кандидат «Локальная переменная, не
  используемая ВОВСЕ, валит гейты целей `c` и `rust`»; заводит кандидата
  «`SE-036` не видит локальных объявлений».

## Требования и проверяемые условия

- **R1. Гейт `c`.** `cc -std=c11 -Wall -Wextra -Werror -c` собирает вывод.
- **R2. Гейт `rust`.** `clippy-driver -D warnings` принимает вывод.
- **R3. По нужде.** Используемая локальная заглушки не получает.
- **R4. Область видимости.** Заглушка стоит в том блоке, где переменная
  объявлена.
- **R5. Один признак.** Вопрос «используется ли имя» задаётся общим носителем,
  а не двумя копиями у целей.
- **R6. Неизменность.** Вывод корпуса не меняется.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | R1, R2 | `generated_output_passes_target_gates` (прогон `cc` и `clippy-driver`) |
| A2 | R3 | `used_local_gets_no_stub` |
| A3 | R4 | `unused_local_gets_a_stub` (текст: заглушка в теле блока) |
| A4 | R5 | юнит-тесты `generator::local_stub` + отсутствие второго обхода в коде |
| A5 | R6 | `git diff examples/generated/` пуст |

## Особенности по обратной функциональности

Обратная совместимость сохраняется: добавляется строка вывода там, где раньше
вывод не собирался вовсе. Значения не меняются — заглушка эффекта не имеет.

## Риски и зависимости

- **Ошибка в сторону «заглушка не нужна»** даёт отказ гейта — громко.
  **Ошибка в сторону «нужна»** даёт мусорную строку — тихо, поэтому есть
  контрпример.
- **Запись без чтения** (`x := 5;` и больше ничего) признак считает
  использованием: `usage_from_stmt` берёт имя из левой части присваивания.
  Класс `-Wunused-but-set-variable` этой фичей не измерялся — граница названа.
