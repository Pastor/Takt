# Анализ фичи 0216: Печатник живости цели `rust` получает сторожа поведения

> Фича: [../features/0216-rust-live-printer-coverage.md](../features/0216-rust-live-printer-coverage.md) · ADR: [../adr/0216-rust-live-printer-coverage.md](../adr/0216-rust-live-printer-coverage.md) · тест-план: [../tests/0216-rust-live-printer-coverage.md](../tests/0216-rust-live-printer-coverage.md)

## Цель и контекст

Закрыть слепое место цели `rust` — модуль живости инициализатора. ADR принял
Option B: сторож поведения (текст вывода + настоящий `clippy -D warnings`) и
исправление того, что этот сторож найдёт.

## Замер (снят 2026-08-20, правило 30)

**1. Цифры кандидата подтвердились.** `cargo llvm-cov --workspace --features
lsp`:

| Файл | Регионы | Строки | Функции |
|---|---|---|---|
| `generator/rust/rust_live.rs` | 39.84 % | 42.62 % | 17 из 33 исполняются |

**2. Прогон по формам языка нашёл два дефекта.** Обе записи законны, обе дают
вывод, отвергаемый гейтом самого проекта, при **нулевом** коде возврата
`taktc`:

```
error: value assigned to `t` is never read     ← match с ветвью `_`
error: value assigned to `i` is never read     ← for с присваивающим init
```

- **`match`**: `verdict_of` для него не давал вердикта никогда, а печатник
  разворачивает `match` в цепочку `if/else` — анализ и печать разошлись.
- **`for`**: `init` исполняется всегда и раньше тела, но перезаписью не
  считался.

**3. Контроль «замена одного отказа другим».** Просто признать перезапись мало:
отложенная форма `let t: u8;` перед `if/else` — это
`clippy::needless_late_init` (проверено отдельной пробой на чистом Rust).
Поэтому `match` требует **свёртки** в выражение. Для `for` та же проба
показала обратное: `let mut i: u8;` перед блоком `{ i = 0; while … }` линт
принимает — свёртка не нужна.

**4. Контрпримеры сняты** (иначе правка читалась бы как «затирает всё
подряд»): `match` **без** `_` и `if` без `else` перезаписи не доказывают, и
инициализатор обязан остаться.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет.
- **Влияние на порядок:** закрывает класс, дважды породивший фиксы (0148-01,
  0148-02); новых зависимостей не создаёт.

## Требования и проверяемые условия

- **R1.** `match` с ветвью `_`, пишущий переменную во всех ветвях, —
  перезапись; объявление сворачивается в цепочку сравнений.
- **R2.** `for` с присваивающим `init` — перезапись; печатается отложенная
  форма.
- **R3.** Контрпримеры не изменились: `match` без `_`, `if` без `else`, цикл,
  чтение до записи оставляют инициализатор.
- **R4.** Весь вывод фикстуры принимается `clippy -D warnings`.
- **R5.** Свёртка `match` печатается **цепочкой сравнений**, а не `match` Rust:
  образцы Takt — выражения, и `match s { p => … }` связал бы `p` как новое имя
  (то же решение, что у печати оператора `match`).
- **R6.** Корпус не изменился по поведению (сверки и гейт цели зелёные).

## Особенности по обратной функциональности (правило 11)

**Меняется вывод цели `rust`** на двух формах: там, где печаталось мёртвое
начальное значение, теперь его нет. Это **исправление**: прежний вывод не
собирался под политикой линтов, объявленной самой целью. Поведение
порождённого автомата не меняется — значение всё равно затиралось до чтения.

Корпус изменений не даёт: ни один пример не пишет переменную из всех ветвей
`match` и не объявляет счётчик `for` заранее (потому дефекты и дожили).

Язык не затронут; версия языка прежняя (`0.10.0`).

## Редакторский слой (правило 29)

**Не требуется.** Лексика, синтаксис и семантика не менялись — правка внутри
печатника цели.

## Документирование (правило 24)

**Не требуется.** Наблюдаемое поведение языка не меняется: правится форма
порождённого Rust, а не смысл конструкций. Диагностик фича не вводит.

## Риски и зависимости

- **Риск: анализ стал смелее и признает перезапись там, где её нет.**
  **Снижение:** ошибка в эту сторону даёт **ошибку компиляции** порождённого
  кода («used binding is possibly-uninitialized»), то есть громкий отказ, а не
  тихо неверный автомат (свойство, обоснованное ещё в 0050-07). Плюс четыре
  контрпримера в стороже.
- **Риск: свёртка `match` напечатает связывание вместо сравнения.**
  **Снижение:** цепочка строится тем же приёмом, что печать оператора `match`
  (`expression_type` + `coerce_to`), и проверяется текстом.
- **Риск: покрытие снова станет целью.** **Снижение:** сторож проверяет
  **формы и линт**; процент — следствие (ADR 0138: порога нет намеренно).
