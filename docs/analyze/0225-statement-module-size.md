# Анализ фичи 0225: Модуль semantic/statement.rs — 999 строк при пределе 1000

> Фича: [../features/0225-statement-module-size.md](../features/0225-statement-module-size.md) · ADR: [../adr/0225-statement-module-size.md](../adr/0225-statement-module-size.md) · тест-план: [../tests/0225-statement-module-size.md](../tests/0225-statement-module-size.md)

## Цель и контекст

Дать модулю `takt-lang/src/semantic/statement.rs` запас по правилу размера,
вынеся его тесты (599 строк из 976, 61 % файла) в отдельный файл — приём
ADR 0088, образец `semantic/expression/` (фича 0129).

Правка **чисто структурная**: ни одной строки логики не меняется, поэтому язык,
диагностики, генерация и симуляция не затрагиваются.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. Правило и сторож (0027), приём деления (0088) и образец
  выноса тестов (0129) закрыты. Фича 0099 (вынос оставшихся нарушителей ядра —
  `tree`/`mod`/`type_inference`/`lib`) **заморожена** и с этой не пересекается:
  там файлы из реестра долга, здесь — файл, в лимит укладывающийся.
- **Влияние на порядок разработки:** никого не разблокирует. Косвенно облегчает
  любую следующую правку `statement.rs`.

## Требования и проверяемые условия

- **R1. Файл разделён по образцу.** `semantic/statement/mod.rs` (логика) +
  `semantic/statement/tests.rs` (`#[cfg(test)] mod tests`), подключение —
  `#[cfg(test)] mod tests;`, внутри `use super::*` (как у `expression/`).
- **R2. Запас появился.** `mod.rs` — заметно ниже лимита 1000 (ожидание ≈ 380
  строк), `tests.rs` — тоже (ожидание ≈ 600).
- **R3. Реестр долга не пополнен.** `scripts/module-size-baseline.txt` остаётся
  из трёх записей: файл в лимит укладывается, а реестр замораживает
  нарушителей.
- **R4. Набор тестов не изменился.** Те же имена тестов, то же их число;
  ни один не потерян и не отключён.
- **R5. Поведение неизменно.** Компилятор, симулятор и генераторы ведут себя
  так же: `examples/generated/` после прогона предкоммита чист.
- **R6. Сборка строгая.** `clippy --all-targets --all-features -- -D warnings`
  зелёный: вынос тестов часто оставляет неиспользованные импорты.

## Особенности по обратной функциональности (правило 11)

Обратная совместимость **не затрагивается**: перемещение приватного модуля
внутри крейта. Публичный API (`takt_lang::…`) неизменен — `statement` не
экспортируется наружу (`pub(crate)`-уровень), путь `crate::semantic::statement`
сохраняется: директория с `mod.rs` даёт то же имя модуля, что и файл. Версия
языка не поднимается (правило 22), версия крейта — тоже (публичного изменения
нет).

## Редакторский слой (правило 29)

**Не требуется.** Лексика, синтаксис и семантика языка не меняются; новых
токенов, узлов АСД, форм объявления и диагностик нет. LSP (`takt-lang/src/lsp/`)
и плагины (`extensions/`) правок не требуют — они зовут семантику через
публичные входы, а те не двигаются.

## Документирование (правило 24)

**Не требуется.** Язык не меняется; документ `book/` описывает язык, а не
раскладку исходников компилятора.

## Риски и зависимости

- **Риск: молчаливая потеря теста.** Перенос `mod tests` целиком безопасен, но
  ошибка в подключении (`mod tests;` без `#[cfg(test)]` или, наоборот,
  забытый `mod`) даёт «зелёную» сборку при непрогоняемых тестах. Снижение —
  A4: сверка **списка имён** тестов до и после, а не только числа зелёных.
- **Риск: неиспользуемые импорты после разреза** — ловится `clippy -D warnings`
  (A6).
- **Риск: живой контекст отстанет.** `CLAUDE.md` ссылается на модуль
  (`semantic/statement.rs` в разделе о разрешении операторов); путь надо
  поправить — гейт `check-claude-md.py` сверяет пути с деревом и такую ссылку
  поймает.
- Зависимостей от незакрытых фич нет.
