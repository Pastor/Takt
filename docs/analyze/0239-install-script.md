# Анализ фичи 0239: Скрипт релизной сборки и установки инструментов

> Фича: [../features/0239-install-script.md](../features/0239-install-script.md) · ADR: не заводился (фича инструментальная) · тест-план: [../tests/0239-install-script.md](../tests/0239-install-script.md)

## Цель и контекст

Заказчик просит одну команду вместо трёх вызовов `cargo` с разными манифестами
и фичами. Замер текущего состояния (2026-08-17):

| Что | Как сегодня | Оценка |
|---|---|---|
| `taktc` | `cargo build --release --bin taktc` + `cargo install --path grammar --bin taktc` (README) | вторая строка **не работает**: крейт `grammar` переименован в `takt-lang` фичей 0100 |
| `takt-sim` | в разделе установки **не упомянут** | инструмент есть, способа поставить нет |
| `takt-lsp` | `cargo install --path grammar --bin takt-lsp --features lsp` (раздел про редакторы) | тот же устаревший путь; без `--features lsp` бинарника не существует вовсе |

## Зависимости фичи (правило 17/19)

- **Зависит от:** `нет`.
- **Влияние на порядок разработки:** никого не блокирует и не разблокирует.
  Косвенно снижает риск для фичи 0165 (подкоманда `taktc version`): скрипт
  готов её показывать, как только она появится.

## Требования и проверяемые условия

- **R1. Одна команда.** `scripts/install.sh` собирает **релизные** `taktc`,
  `takt-sim`, `takt-lsp` и ставит их в `$PREFIX/bin`.
- **R2. Префикс настраивается** — флагом `--prefix` и переменной `TAKT_PREFIX`;
  умолчание `~/.local` (туда проект уже ставит `iec2c`).
- **R3. Языковой сервер отключаем** (`--no-lsp`): он нужен не всем, а его
  сборка тянет фичу `lsp`.
- **R4. Свой каталог сборки.** Умолчание — `target/install`, а не общий
  `target`; вызывающий волен назвать другой через `CARGO_TARGET_DIR`.
- **R5. Сухой прогон** (`--dry-run`) печатает, что было бы сделано, и **ничего
  не создаёт**.
- **R6. Проверка установленного** (`--check`) — код 1 и поимённый список
  недостающего.
- **R7. Отказ на неизвестном аргументе** (код 2), а не молчаливое игнорирование.
- **R8. Предупреждение о `PATH`**, если `$PREFIX/bin` в нём отсутствует.
- **R9. README актуален**: устаревший `cargo install --path grammar` заменён.

### R4 отдельно: почему каталог сборки — свой

Замер 2026-08-17: рабочий `target` этого репозитория — **110 ГБ**, 629 590
файлов в `debug/deps`. В таком каталоге `cargo test --all-features` не
завершился за 10 минут и был снят; полный `precheck.sh` в нём же, по замеру
фичи 0234, шёл **более суток** там, где здоровая сборка занимает 42 с. Причина:
cargo обходит каталог перед каждой единицей компиляции.

Поэтому «состояние каталога сборки — свойство **инструмента**, а не дисциплина
автора» (формулировка 0234). Скрипт установки, зависающий на чужом мусоре,
своей задачи не решает.

⚠️ Скрипт при этом **ничего не удаляет**: гейт 0234 чистит только собственный
`target/precheck`, и заводить второго уборщика фича не стала.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Справка и отказ на неизвестном флаге | `test-install.sh` (A1, A2) |
| A2 | Состав: три инструмента, три установки | `--dry-run` (A3) |
| A3 | `--no-lsp` убирает языковой сервер | `--dry-run` (A4) |
| A4 | Префикс уважается | `--dry-run --prefix` (A5) |
| A5 | `--build-only` не устанавливает | `--dry-run --build-only` (A6) |
| A6 | `--check` отвергает пустой префикс | `--check --prefix <пусто>` (A7) |
| A7 | Каталог сборки — `target/install` | `--dry-run` (A8) |
| A8 | Настоящая установка работает | ручной прогон в временный префикс: три бинарника на месте и исполняются |
| A9 | README не обещает несуществующего | чтение + гейт ссылок |

## Особенности по обратной совместимости (правило 11)

**Совместимость не затрагивается:** ни языка, ни библиотеки, ни формата вывода
фича не касается. Прежние вызовы `cargo build --release` продолжают работать —
скрипт их не заменяет, а избавляет от необходимости помнить.

## Риски и зависимости

- **R-1. Скрипт ставит поверх работающего бинарника.** Снижение: установка идёт
  `install -m 0755` (замена inode), а не записью поверх, — работающий процесс
  не портится.
- **R-2. Сборка в неожиданный каталог.** Снижение: скрипт **печатает** каталог
  сборки первой строкой; сторож A8 закрепляет умолчание.
- **R-3. Тест гоняет долгую релизную сборку и попадает в предкоммит.**
  Снижение: сторож настоящую сборку **не запускает** (проверяет то, что
  принадлежит скрипту), и в `precheck.sh` не добавляется: релизная сборка не
  входит в предкоммит по объёму.
- **R-4. `taktc --version` в проверке.** Такой команды нет (фича 0165 не
  закрыта), и вызов печатал бы ошибку при успешной установке. Снижение: признак
  свежести — размер и время файла.
