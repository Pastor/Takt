# Анализ фичи 0124: Экспорт графов верификации (Крипке/Бюхи/произведение) в Graphviz DOT

> Фича: [../features/0124-verify-graph-export.md](../features/0124-verify-graph-export.md) · ADR: [../adr/0124-verify-graph-export.md](../adr/0124-verify-graph-export.md) · тест-план: [../tests/0124-verify-graph-export.md](../tests/0124-verify-graph-export.md)

## Цель и контекст

Разделу документа «Практический пример» (фикс `0118-01`) нужны наглядные
диаграммы построения структуры Крипке и автомата Бюхи — **настоящим выводом
инструмента**, а не ручным рисунком (иначе картинка разойдётся с движком при
любой правке). Движок 0049/0068 строит эти структуры в памяти, но экспорта нет.
Фича добавляет экспорт в Graphviz DOT (обоснование формата — ADR 0124: `dot`
установлен, `plantuml` нет; DOT идиоматичен для автоматов).

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. Использует уже закрытые 0049 (верификация) и 0068
  (абстракция по данным); аддитивна (правило 11) — прежний путь `verify` не
  затронут.
- **Влияние на порядок разработки:** завершение **разблокирует** фикс `0118-01`
  (раздел «Практический пример»), которому нужны эти диаграммы.

## Требования и проверяемые условия

- **R1. Диаграмма = вывод движка.** Граф строится из тех же
  `Kripke`/`BuchiAutomaton`/`Product`, что и вердикт.
- **R2. Рендерится установленным инструментом.** DOT → SVG через `dot -Tsvg`.
- **R3. Отбор Крипке совпадает с проверкой.** Управляющая (0049) vs данными
  (0068) — единый `select_kripke`.
- **R4. Отказ, а не молчание.** `buchi`/`product` без `--property`, негодное
  значение флага, `NoStartState`/`Unsupported` — явный отказ с кодом ≠ 0.
- **R5. Аддитивность.** Прежний вывод `verify`/`--trace` — байт-в-байт неизменен.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Валидный DOT Крипке (старт, узлы) | юнит-тест `verification::dot` + `dot -Tsvg` |
| A2 | Автомат: принимающие `doublecircle`, начальные — источники | юнит-тест |
| A3 | Произведение: пары `состояние,qN` | юнит-тест |
| A4 | Отказ без свойства/при негодном значении | юнит-тесты CLI |
| A5 | Отбор Крипке = проверке (data-path метки) | юнит-тест на bit-var |
| A6 | Прежний вывод неизменен | существующие тесты `verify` + гейт 0048 |

## Особенности по обратной функциональности

Только **Rust** (движок + CLI). Цели генерации, симулятор, LSP — не затронуты
(язык/цели/симуляция не меняются).

## Риски и зависимости

- **Расхождение «нарисовали не то, что проверили».** Снят общим `select_kripke`
  (R3): проверка и экспорт выбирают Крипке одним кодом.
- **Двойное экранирование меток** (`\n` разделитель против экранирования кавычек).
  Снято раздельным экранированием компонентов; регресс-тест
  `labels_use_real_newline_not_escaped_backslash`.
