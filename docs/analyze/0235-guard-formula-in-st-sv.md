# Анализ фичи 0235: Цели st и sv теряют охранную формулу

> Фича: [../features/0235-guard-formula-in-st-sv.md](../features/0235-guard-formula-in-st-sv.md) · ADR: [../adr/0235-guard-formula-in-st-sv.md](../adr/0235-guard-formula-in-st-sv.md) · тест-план: [../tests/README.md](../tests/README.md)

## Цель и контекст

ADR принял Option C с уточнением заказчика: цель `sv` **печатает** проверку,
цель `st` **предупреждает** (`ST-022`) и продолжает трансляцию. Анализ отвечает
на четыре вопроса: **куда** в выводе `sv` встаёт `assert`, **откуда** цель
берёт формулы, **где** цель `st` выдаёт предупреждение и **чем** доказать, что
поведение не поехало.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет незакрытых. Смежные закрыты:
  [0044](../features/0044-sim-assert-invariant.md) (десахаризация `invariant`),
  [0203](../features/0203-validate-formulas-traversal.md) (обход формул в
  `validate`, откуда взялась находка), [0045](../features/0045-sv-backend.md)
  (бэкенд SV), [0041](../features/0041-st-backend.md) (бэкенд ST),
  [0064](../features/0064-sv-divider-warning.md) (канал предупреждений `sv`).
- **Смежная незакрытая:** [0168](../features/0168-generator-warnings-return.md)
  (`СОЗДАНА`) — предупреждения генераторов печатаются `eprintln!` из библиотеки.
  `ST-022` наследует этот дефект вместе с образцом; **чинить его здесь нельзя**,
  иначе фича превращается в рефакторинг доставки.

## Требования и проверяемые условия

### R1. Источник формул — общий обход, второго списка мест не заводить

Фича [0203](../features/0203-validate-formulas-traversal.md) свела места
объявления формул в **один** сбор — `semantic/formula/sites.rs`
(`model_formula_sites`, шесть мест, листья `Ltl`/`Guard`). Цели обязаны брать
формулы **оттуда же**, а не обходить дерево заново.

⚠️ Цели `c` и `rust` сегодня печатают формулы **по своему обходу** (тела блоков,
`generate_formula_check` / `emit_guard`). Это существующее устройство, и фича
его не переписывает: она добавляет **новых** потребителей. Но если новый обход
понадобится — он берётся из общего сбора.

**Условие:** ни `sv`, ни `st` не заводят собственного перечня мест объявления
формулы.

### R2. Форма проверки в SV задана пробой, а не вкусом

`assert (<условие>);` — **без** `else $error(…)`:

| Форма | verilator | yosys |
|---|---|---|
| `assert (expr);` | принял | **принял** |
| `assert (expr) else $error("…");` | принял | **ОТВЕРГ** (`TOK_ELSE`) |

⚠️ Отсюда: **имя инварианта в цель `sv` не переносится**. Цель `rust` его
печатает, `c` игнорирует, `sv` не может — и это свойство инструмента, а не
недоделка. Условие обязано быть записано там, где следующий его увидит.

### R3. Место вставки в SV — тактовый блок, и оно не меняет логику

Проба: 29 ячеек, из них `$check` — одна, остальные (8 `$_DFF_PN0_` и
комбинационная обвязка) те же, что без `assert`. То есть проверка попадает в
формальный слой и синтезируемую логику не трогает.

**Условие:** сверка `conformance_sv_tests` остаётся зелёной — трасса не
меняется. Если изменится, значит проверка встала не туда.

### R4. `--guard-disable` обязан работать и в `sv`

Поле `SvMap::guard_enable` существует с самого бэкенда, геттер есть, **читателя
нет**. Фича делает поле живым.

**Условие:** при `--guard-disable` вывод `sv` не содержит `assert`, при
умолчании — содержит. Оба состояния проверяются тестом.

### R5. Предупреждение цели `st` — новый код `ST-022`, трансляция продолжается

Занятые коды кончаются на `ST-021`. Текст обязан называть **причину**
(в IEC 61131-3 конструкции `assert` нет) — иначе автор решит, что это дефект
компилятора.

**Условие:** цель `st` возвращает вывод (`Ok`), а не ошибку; предупреждение
выдаётся **на каждую** охранную формулу, иначе вторая потеряется молча.

### R6. Что остаётся вне объёма — названо

| Наблюдение | Решение |
|---|---|
| предупреждения генераторов печатаются `eprintln!` из библиотеки | дефект доставки, фича [0168](../features/0168-generator-warnings-return.md) |
| `c` игнорирует имя инварианта, `rust` печатает | расхождение старше фичи; не трогаем |
| `Formula::LTL` в целях не эмитится | предмет 0035/0049, не этой фичи |

### R7. Корпус класс не покрывает — фикстура обязательна

Замер: в `examples/` **ноль** программ с формулами. Значит гейты `st`/`sv`
этот класс не увидят никогда, и доказательство обязано прийти **фикстурой**
теста, а не корпусом. ⚠️ Это ровно та причина, по которой потеря дожила
незамеченной.

### R8. Версия языка и документ

Версия языка **не поднимается**: `0.8.0` не выпущена (правило 22). Язык
меняется в наблюдаемой части (вывод целей), поэтому документирование
**требуется**: раздел [«Цели генерации»](../../book/src/14-targets/index.md) —
что каждая цель делает с охранной формулой; приложение
[«Ошибки»](../../book/src/appendix-errors/index.md) — статья `ST-022`.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | цель `sv` печатает `assert (условие);` | тест эмиссии + греп вывода |
| A2 | вывод `sv` принимают **оба** инструмента | verilator + yosys в тесте |
| A3 | форма без `else` закреплена | тест: в выводе нет `$error` |
| A4 | `--guard-disable` подавляет проверку в `sv` | тест на оба состояния |
| A5 | трасса `sv` не изменилась | `conformance_sv_tests` зелёный |
| A6 | цель `st` выдаёт `ST-022` и **продолжает** | тест: `Ok` + предупреждение |
| A7 | предупреждение на **каждую** формулу | тест с двумя формулами |
| A8 | текст `ST-022` называет причину | проверка текста в тесте |
| A9 | вывод корпуса не изменился | предкоммит (в `examples/` формул нет) |
| A10 | документ описывает поведение целей | ревью + гейт 0133 |
| A11 | предкоммит зелёный | `./scripts/precheck.sh` |

## Риски и зависимости

- **Р1. `assert` встанет не туда и изменит трассу.** Снижение: сверка
  `conformance_sv_tests` (A5) — она сравнивает поведение, а не текст.
- **Р2. Соблазн добавить сообщение через `else $error(…)`.** Оно проходит
  verilator и падает на yosys — то есть локально «работает», а гейт краснеет.
  Снижение: тест A3 и запись причины в коде.
- **Р3. Предупреждение выдастся один раз на модель.** Тогда вторая формула
  потеряется молча — ровно тот дефект, который фича лечит. Снижение: тест A7 с
  двумя формулами.
- **Р4. Наследуемый дефект доставки (0168).** `ST-022` печатается из библиотеки
  и не глушится `--quiet`. Названо, в объём не входит.
- **Р5. Класс не покрыт корпусом** (R7): забыв фикстуру, фича «закроется» без
  доказательства. Снижение: A1–A8 — все на фикстурах.
