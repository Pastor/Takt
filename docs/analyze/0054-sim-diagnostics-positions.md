# Анализ фичи 0054: Позиции в диагностиках симулятора

> Фича: [../features/0054-sim-diagnostics-positions.md](../features/0054-sim-diagnostics-positions.md) · ADR: [../adr/0054-sim-diagnostics-positions.md](../adr/0054-sim-diagnostics-positions.md) · тест-план: [../tests/0054-sim-diagnostics-positions.md](../tests/0054-sim-diagnostics-positions.md)

## Цель и контекст

Перенести на `simulation` лечение, которое [0053](0053-diagnostics-file-id.md)
дала `lamc`: печать `путь:строка:колонка`. Заодно — вернуть **код** диагностики,
который симулятор терял.

Кандидат вскрыт отчётом 0053.

## Зависимости (правило 17)

| Фича | Статус | Почему зависимость |
|---|---|---|
| 0053 | `ГОТОВО` | даёт `FileTable`, `Diagnostic::file`, `line_column`, `construct_model_with_files` |

Зависимость закрыта → фича **не блокируется**.

## Меняет ли фича язык (правило 22)

**Нет.** Правится печать диагностик и способ загрузки модели в бинарнике
симулятора. Версия языка (0.3.0) не растёт, вывод генераторов не меняется.

## Обратная совместимость (правило 11)

**Меняется текст ошибок симулятора** — это и есть цель. Прочее (коды возврата,
поведение симуляции, формат `--save-state`) не трогается. Публичный API крейтов
не ломается: `position_prefix` **добавлен**, `format_diagnostics` — приватная
функция бинарника.

## Что было (проба)

```text
$ simulation badsem.lam --steps 3
Ошибка: Семантическая ошибка: Ссылка 'Nowhere' не найдена

$ simulation -I . main53.lam --steps 3     # ошибка ВНУТРИ импорта
Ошибка: Семантическая ошибка: Ссылка 'Nowhere' не найдена
```

Дословно одинаково; ни файла, ни строки, ни кода.

## Требования

| # | Требование |
|---|---|
| R1 | Печать позиции — **общая** функция для `lamc` и `simulation` (не копия) |
| R2 | Симулятор печатает `путь:строка:колонка` и код диагностики |
| R3 | Ошибка внутри импорта названа этим файлом; вложенный импорт — самым внутренним |
| R4 | Ошибки разбора печатаются **все**, каждая со своей позицией |
| R5 | Позиция — в начале строки (как `rustc`/`lamc`): её ищет редактор |
| R6 | Версия языка и вывод генераторов не меняются |

## Критерии приёмки

Совпадают с ADR 0054 (A1–A5); проверяются тест-планом T1–T8.

## Риски

| # | Риск | Митигация |
|---|---|---|
| Р1 | Копия формата в двух бинарниках разойдётся (прецедент 0028-01) | R1: функция физически одна; T4 сверяет вывод с расчётом общего слоя |
| Р2 | Симулятор начнёт печатать только первую ошибку разбора (как `lamc`) | T3: тест на **несколько** ошибок с позициями |
| Р3 | Позиция в середине строки → редактор её не увидит | R5; проверено пробой против формата `lamc` |

## Что НЕ входит в объём

- **Ошибки времени выполнения** (`SIM-0xx`, guard/eval на шаге): у них нет
  позиции в исходнике — нужен такт, и он уже печатается (ADR 0054, A2).
- **LSP-многофайловость** — отдельный кандидат (из 0053).
