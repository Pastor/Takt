# Анализ фичи 0068: Верификация свойств над данными

> Фича: [../features/0068-verify-data-properties.md](../features/0068-verify-data-properties.md) · ADR: [../adr/0068-verify-data-properties.md](../adr/0068-verify-data-properties.md) · тест-план: [../tests/0068-verify-data-properties.md](../tests/0068-verify-data-properties.md)

## Цель и контекст

ADR 0049 абстрагировал данные: атом = имя состояния, `G (temp <= 100)` →
`Verdict::Unsupported`. Расширение — action item **A7(1)**.

**Кандидат утверждал:** «атом-предикат строится **поверх готового** конвейера —
меняется **разметка вершин**, а не звенья». **Проработка это опровергла замером.**
ADR принял **Option D**: абстракция **по формуле** — точно отслеживаются только
переменные из φ.

## Замер (2026-07-17) — он опровергает заявку

**1. Наивный explicit-state неосуществим:**

| Модель | Состояний | `var u8` | `var bit` | \|explicit-state\| |
|---|---|---|---|---|
| `elevator_mini` | 8 | 2 | 0 | 524 288 |
| `extend_complex` | 13 | 2 | 0 | 851 968 |
| `elevator` | 8 | 3 | 0 | **1.3 × 10⁸** |
| `comprehensive` | 5 | 7 | 0 | **3.6 × 10¹⁷** |
| **`stacker`** | 19 | 8 | 5 | **1.1 × 10²²** |

**2. Решающий — ветвление по входам.** `in`-порт есть **среда**, вольная выбрать
любое значение **каждый такт**:

| Модель | `in u8` | `in bit` | Преемников у **каждой** вершины |
|---|---|---|---|
| `elevator_mini` | 0 | 40 | 1.1 × 10¹² |
| `stacker` | 6 | 5 | 9.0 × 10¹⁵ |
| **`elevator`** | **21** | 0 | **3.7 × 10⁵⁰** |

**Вывод:** меняется **не разметка**, а **множество вершин** и **отношение
переходов**. У `elevator` невозможно перечислить преемников **одной** вершины.
Конвейер 0049 работает на **явном** графе — такие объекты он не представит **в
принципе**.

⚠️ **Половина заявки кандидата всё же верна** — но не та, которую он назвал: если
абстрагировать всё, кроме переменных **самой формулы**, то `build_buchi`/
`product`/`emptiness` действительно не трогаются, а меняется **только**
`build_kripke`.

## Зависимости фичи (правило 17/19)

- **Зависит от:** **нет**. Опоры **закрыты**: [0049](../features/0049-model-checking-ltl.md)
  (конвейер), [0051](../features/0051-verify-scope.md) (`--scope`),
  [0052](../features/0052-verify-iterative-traversal.md) (итеративный nested-DFS —
  ⚠️ **важна**: рост числа вершин с 19 до 1280 без неё упёрся бы в стек),
  [0035](../features/0035-ltl-in-blocks.md) (LTL в блоках),
  [0044](../features/0044-sim-assert-invariant.md) (`invariant` как атом).
- **Пересечения:** нет — `verification/` не трогает ни одна незакрытая фича.
- **Влияние на порядок:** никого не блокирует.

## Приоритет (Tier) — обоснование

**Tier 3.**

- **Спроса нет:** свойств над данными в корпусе **ноль** (`lamc verify` их не
  принимает — `Unsupported`).
- **Ничего не сломано:** `Unsupported` — **честный** ответ, а не молчаливое «ложно»
  (принцип 0049).
- Против Tier 2: ни одна фича не зависит; ни один дефект не закрывается.

## Требования и проверяемые условия

- **R1. Отслеживаются только переменные из φ**; всё прочее абстрагировано, как
  сегодня.
- **R2. Вершина** = (состояние, значения отслеживаемых переменных).
- **R3. Ошибаться только в сторону ЛИШНИХ прогонов.** Невычислимое значение →
  недетерминированное по всему домену.
- **R4. Потолок проверяется ДО построения** → `Unsupported`.
- **R5. Домен из типа:** `bit`/`bool` → 2, `enum` → варианты, `u8` → 256;
  `float`/`q` → `Unsupported`.
- **R6. `may_stutter` пересматривается осторожно:** петлю снимать **только** при
  точно вычислимом guard.
- **R7. «Нарушено» помечается «абстракция управления»** (A4 0049).
- **R8. Вердикты 0049 не меняются**; язык не меняется → версия не растёт.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | `G (temp <= 100)` → вердикт; 1280 вершин | Прогон на `comprehensive` |
| A2 | Превышение потолка → `Unsupported` | Фикстура с несколькими `u8` |
| A3 | `float`/`q` в атоме → `Unsupported` | Контрпример |
| A4 | **Гарантия сохранена**: `Holds` там, где держится | Эталонные пары модель × φ; тесты **на вердикт** |
| A5 | **Направление ошибки**: лишний прогон, не пропущенный | Мутация R3 обязана валить тест |
| A6 | `stacker` + φ над одной `bit` → 38 вершин | Прогон |
| A7 | Вердикты 0049 не изменились | Существующие тесты |
| A8 | Завершается на всём корпусе; потолок — до построения | Прогон + замер |
| A9 | Версия не поднята | Ревью |

## Особенности по обратной функциональности

**Правка аддитивна** (правило 11): свойства, дававшие `Unsupported`, начинают
давать вердикт; свойства над именами состояний — **как прежде** (A7). Язык не
меняется, `lamc verify` — та же оснастка. Вывод всех целей не задет (правка внутри
`verification/`).

⚠️ **Расширяется множество вердиктов, а не меняются существующие.** Это и есть
критерий A7 — сторож того, что 0068 не тронула 0049.

## Риски и зависимости

- **R-1. Сломать гарантию «держится»** (главный). Прецедент **прямой и
  болезненный**: первая редакция 0049 ставила самопетлю лишь тупику → Крипке стала
  **недо**-аппроксимацией → `F Done` объявлялось **доказанным** на модели, где оно
  ложно. Снижение: R3 и R6 — сторожа; A5 — мутационный тест на **направление**
  ошибки.
- **R-2. Тесты проверят форму, а не язык.** [Фикс 0010-01](../fixes/0010-01-buchi-acceptance.md):
  `build_buchi` принимал **любой** бесконечный прогон (`F p` принимал слово без
  `p`) и прожил в зелёном CI, потому что тесты `buchi.rs` проверяли «states не
  пусто». Снижение: A4 — тесты **на вердикт** на эталонных парах.
- **R-3. Взрыв в неожиданном месте.** φ с тремя `u8` → 8.4 × 10⁷ вершин.
  Снижение: R4 — потолок **до** построения; `Unsupported` честнее часа счёта.
- **R-4. Соблазн «заодно» сделать BMC/символьный MC.** BMC **отнимает** главную
  гарантию 0049 («держится» перестаёт доказываться) — это размен, а не расширение.
  Снижение: записано в ADR (Option C отклонён).
- **R-5. Опора на 0052.** Рост вершин 19 → 1280 безопасен только потому, что
  nested-DFS **итеративный** (закрытая 0052). Возвращать рекурсию нельзя.

## Побочные находки проработки (вне объёма)

1. **Оставшиеся ветви A7 0049** — `X`-stutter и **контрпример как трасса
   симулятора** — кандидаты; в объём 0068 не входят.
2. **Замеры записать в `CLAUDE.md`** (A-5 ADR): без них следующий читатель
   повторит вывод кандидата про «просто поменять разметку».
