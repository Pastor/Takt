# Анализ фичи 0121: Разбор примеров в разделах с упором на тему

> Фича: [../features/0121-book-example-walkthrough.md](../features/0121-book-example-walkthrough.md) · ADR: [../adr/0121-book-example-walkthrough.md](../adr/0121-book-example-walkthrough.md) · тест-план: [../tests/README.md](../tests/README.md)

## Цель

В блоке «Пример» каждого раздела — разбор с упором на тему (подробно конструкции
темы, вскользь обвязка). Язык **не меняется** (Tier 3). Правило 27 закрепляет.

## Что подчёркивает разбор в каждом разделе (тема — подробно)

- **02 Лексика** (`tokens.takt`): три вида комментариев, dec/hex-литералы,
  `1_000` с разделителем, `:=` vs `=`. Модель/состояния — вскользь.
- **03 Типы** (`types.takt`): тип каждой переменной (`mode: Mode`, `counter: u16`,
  `level: q(4,4)`, `samples: [u8;4]`, `ORIGIN: Point`); порт-вывод `active: bool`;
  сравнение `start_btn = 1/0`. Модель — вскользь.
- **04 Модели/состояния** (`traffic.takt`): три состояния, `start`, блоки
  `enter`/`always`, переходы `ref` по таймеру. Типы/выходы — вскользь.
- **05 Выражения/условия** (`expr.takt`): логические `&`/`|` в условиях против
  побитовых в выражениях; `:=`/арифметика/`if`. Модель — вскользь.
- **06 Управление** (`control.takt`): `match`/`for`/`if-else`/`while`+`break`+
  `return`. Обвязка — вскользь.
- **07 Функции** (`functions.takt`): `extern fn`, `double`, композиция `quad`,
  вызовы. Модель — вскользь.

## Форма

Абзац «**Разбор (с точки зрения …)**» сразу после включённого примера, перед
блоком «Частые ошибки» (правило 26). Построчные комментарии в `.takt` отвергнуты
(раздувают пример).

## Ограничения (правило 24)

Разбор описывает **язык** (что делают конструкции), без деталей реализации,
номеров фич и процесса.
