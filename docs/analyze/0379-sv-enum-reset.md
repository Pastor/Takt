# Анализ фичи 0379: Сброс перечислимого регистра у цели sv

> Фича: [../features/0379-sv-enum-reset.md](../features/0379-sv-enum-reset.md) · ADR: [../adr/0379-sv-enum-reset.md](../adr/0379-sv-enum-reset.md) · тест-план: [../tests/0379-sv-enum-reset.md](../tests/0379-sv-enum-reset.md)

## Цель и контекст

Класс найден **обходным замером**: проба порта перечислимого типа снималась
ради другого вопроса, а показала отказ линта на ветви сброса.

### Замер (`scripts/probe.sh -n 3`, 2026-08-22)

Вход: `enum Mode { Idle = 1, Work = 2 } var m: Mode;` — без инициализатора.

| Потребитель | Ответ | Печать сброса |
|---|---|---|
| эталон | `m = 0` до первой записи | — |
| `c`, `c-hal` | `cc` принял | `model->m = 0;` |
| `st`, `st-at` | принят · собран | `m : USINT := 0;` |
| `rust` | принят · clippy принял | `Default` |
| `sv`, `sv-mmio` | **verilator ОТВЕРГ** | `enumnoinit_m <= '0;` |

Текст: `%Error-ENUMVALUE: Implicit conversion to enum 'mode_e' from 'bit'
(IEEE 1800-2023 6.19.3) … Suggest use enum's mnemonic, or static cast`.

⚠️ Тот же отказ — на **порте** перечислимого типа (`out mode: Mode at 0;`):
порт у цели `sv` тоже регистр.

⚠️ Ветвь «есть инициализатор» была права с фичи 0338: `var m: Mode := Work;`
печатается мнемоникой. Расходились две ветви **одного** правила.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. 0060 (факты перечисления) и 0338 (восстановление
  варианта) закрыты.
- **Влияние на порядок разработки:** нет. Кандидат 0353 («ноль против первого
  варианта») этой фичей **не** закрывается: там вопрос заказчика о правиле
  языка, здесь — форма записи того же нуля.

## Требования и проверяемые условия

- **R1. Линт.** `verilator --lint-only -Wall` принимает вывод.
- **R2. Синтез.** `yosys synth` принимает тот же вывод.
- **R3. Значение.** Регистр сбрасывается в **ноль** — как у эталона.
- **R4. Форма.** Мнемоника, если вариант со значением 0 есть; приведение —
  если нет.
- **R5. Неизменность.** Вывод корпуса не меняется.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | R1 | `enum_reset_passes_the_lint_and_uses_the_right_form` |
| A2 | R2, R3 | `enum_reset_values_match_generated_sv` (тестбенч verilator) |
| A3 | R4 | сверка текста в том же тесте (обе формы) |
| A4 | R5 | `git diff examples/generated/` пуст |

## Особенности по обратной функциональности

Меняется только форма значения сброса у перечислимых регистров цели `sv`;
значение то же. Прежний вывод не проходил линт, то есть работоспособного
поведения там не было.

## Риски и зависимости

- **Подстановка первого варианта** прошла бы линт и **изменила значение** —
  сверка это ловит (мутация проверена: `RTL=[[1, 0], …]` против
  `sim=[[0, 0], …]`).
- **Фикстура обязана читать регистр ДО первой записи**, иначе такт 1 покажет
  не значение сброса, а результат тела.
