# Анализ фичи 0119: Приложения документа + приложение «Ошибки»

> Фича: [../features/0119-book-appendices.md](../features/0119-book-appendices.md) · ADR: [../adr/0119-book-appendices.md](../adr/0119-book-appendices.md) · тест-план: [../tests/README.md](../tests/README.md)

## Цель

Механизм **приложений** документа для справочного материала, перегружающего
основной текст, + первое приложение «Ошибки» + правило 25 (ссылаться, не
дублировать). Язык **не меняется** (Tier 3).

## Источник таблицы кодов

Единый реестр `docs/diagnostics/README.md` (ADR 0077) — **171** запись в 11
секциях по префиксам. Извлечены `Код`+`Значение`; отброшены: столбец «Источник»
(файл:строка — деталь реализации), упоминания фич/ADR (2 значения: `CC-014`
выведен — пропущен; `RS-015` — очищен от «ADR 0050»). В книгу вошло **170**
кодов.

Разбивка по префиксам: SE 58, SIM 29, CC 18, RS 16, SV 14, ST 13, LE 8, AM 6, DF
4, SY 4, PU 1.

## Подробный разбор (реальный вывод, захвачен прогонами)

**38 легковоспроизводимых** ошибок `LE`/`SY`/`SE` — каждая с примером кода и
реальным выводом (харнесс `scratchpad/gendetails.py`: триггер → захват первой
диагностики → генерализация пути к `model.takt`; сверка кода в заголовке с кодом
в выводе — рассинхрона нет). Покрыты: `LE-001/002/004/006/007`, `SY-002/004`,
`SE-001..004/006/009/011..013/028/030/034..036/039/040/042..049/052/053/057..061`.

Не раскрыты (не «легковоспроизводимы» минимальным примером): `LE-003/005/008`
(перебиваются соседним кодом), `SY-001/003` (перебиваются `SY-002/004`), `SE`
внутренние/спец-настройка (`005/007/008/010/014..027/029/033/037/038/050/051/054..056`
— требуют существующего импорта, дубля типа, LTL и т. п.). Коды целей
(`CC`/`RS`/`SV`/`ST`) и симулятора (`SIM`) — в сводной таблице; дораскрываются по
надобности (ADR 0119, Option A).

## Правило 25 и ссылки

Правило 25 в `docs/RULE.md`: справка, перегружающая текст, — в приложение; в
тексте — ссылка. Кандидат: раздел «Диагностики» (15) при наполнении сошлётся на
это приложение вместо инлайна таблицы.

## Ограничения (правило 24)

Номера фич/задач и «Источник» (файл:строка) в приложение не попадают.
