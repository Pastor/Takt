# Анализ 0351: Умолчание значения у цели `rust`

- **Фича:** [../features/0351-rust-default-value-types.md](../features/0351-rust-default-value-types.md)
- **ADR:** [../adr/0351-rust-default-value-types.md](../adr/0351-rust-default-value-types.md)
- **Дата:** 2026-08-21

## Замер (правило 30)

Снят `scripts/probe.sh -n 3` 2026-08-21, четыре входа плюс контрольные.
Сводка — в [ADR](../adr/0351-rust-default-value-types.md); здесь — только
выводы, влияющие на объём.

1. **Отказывает одна цель из восьми.** `RS-014` приходит на переменную без
   инициализатора типа `Struct`, `duration`, `q(m, n)`. Эталон и семь целей ту
   же запись переводят и исполняют.
2. **Контроль отделил умолчание от типа.** Та же переменная с инициализатором
   переводится — значит правится `default_value`, а не отображение типа
   (`rust_type` все три знает).
3. **Соседний дефект в том же месте.** `derive(Default)` не выводится для
   структуры с полем-перечислением (`Mode: Default` не реализован) и с
   полем-массивом `N > 32` (`impl Default for [T; N]` в стандартной библиотеке
   есть только до 32). Прогон `rustc` даёт `E0277` при **нулевом** коде
   возврата `taktc`. Вход с полем-перечислением стоял в замере первым, то есть
   правка одной половины оставила бы вторую невидимой.

## Объём правки

| Место | Что делается |
|---|---|
| `generator/rust/rust_decl.rs::default_value` | три ветви: `Duration` → `0`, `Fixed` → `0`, `Struct` → `<Имя>::default()` |
| `generator/rust/rust_decl.rs::emit_structs` | `Default` уходит из `derive`; печатается ручной `impl Default` |
| `generator/rust/rust_struct.rs` | носитель тела `impl Default` и признака `derives_default` (модуль уже держит знание «как выглядит агрегат структуры», 49 строк) |

⚠️ **Место печати `impl Default` — `rust_struct.rs`, а не `rust_decl.rs`.**
Модуль заведён фичей 0293 ровно под знание «как выглядит агрегат структуры у
цели `rust`», и литерал умолчания есть тот же агрегат: два носителя одной формы
разошлись бы (класс 0084/0193/0195). Размер `rust_decl.rs` — 493 строки, то
есть лимит (0027) правку не гонит; решает принадлежность знания.

## Зависимости (правило 17)

**Нет.** Фичи, чьи решения используются, закрыты: 0061 (формат `q`), 0183
(`duration` как `u32` мс), 0293 (структуры у целей `st`/`rust`/`sv`), 0347
(константа-агрегат печатается путём переменной). Ни одна не требует доработки.

## Обратная совместимость (правило 11)

**Язык не меняется** — ни синтаксис, ни семантика, ни набор диагностик. Версия
языка не поднимается (правило 22).

Меняется **форма порождённого Rust**: у структуры пропадает `Default` в
`derive` и появляется `impl Default`. Наблюдаемое поведение то же (`::default()`
работает как прежде), так что для потребителя порождённого кода изменение
неломающее; снапшоты корпуса и `book/` обновляются в рамках фичи —
детерминированность генерации (0048) делает их дифф осмысленным.

## Риски

- ⚠️ **`clippy::derivable_impls` — риск ПРОВЕРЕН пробой и снят решением.**
  Прогон `clippy-driver -D warnings` 2026-08-21: ручной `impl Default` для
  структуры со скалярными полями даёт «error: this `impl` can be derived» —
  то есть «печатать импл всегда» уронило бы гейт цели. Тот же импл для
  структуры с полем-перечислением и с полем `[u8; 40]` линт проходит с кодом 0.
  Отсюда решение ADR: импл печатается **по нужде**, а признак «derive не
  выводится» совпадает с признаком «линт молчит» по построению.
- **Корпус.** У структур корпуса `derive(Default)` выводится, поэтому вывод
  цели `rust` для `examples/` не меняется вовсе; снапшоты `book/` (гейт 0274)
  остаются прежними. Класс, который фича лечит, корпусом **не покрыт** — в
  `examples/` нет ни структуры с полем-перечислением, ни массива длиннее 32,
  ни переменной без инициализатора типа `q`/`duration`/структуры. Сторожа
  поэтому фикстурные, с прогоном настоящих `rustc`/`clippy`.
