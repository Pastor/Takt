# Анализ фичи 0062: Цель `sv-mmio` — адреса портов как регистровый файл

> Фича: [../features/0062-sv-mmio-target.md](../features/0062-sv-mmio-target.md) · ADR: [../adr/0062-sv-mmio-target.md](../adr/0062-sv-mmio-target.md) · тест-план: [../tests/0062-sv-mmio-target.md](../tests/0062-sv-mmio-target.md)

## Цель и контекст

ADR 0045 отверг потребление адреса целью `sv` («у RTL-модуля процессора нет») и
вынес `sv-mmio` в кандидаты с двумя возражениями — **оба про шину**: выбор
протокола не обоснован требованиями; BFM удваивает объём.

ADR 0062 принял **Option B — шинно-агностичный регистровый файл**: убрав протокол
из объёма, снимаем оба возражения и сохраняем ценность (карта регистров из `.lam`,
«две половины одной шины» `c-hal` + `sv-mmio`). Выбор протокола — **требование**,
и его приносит заказчик; адаптеры APB/AXI-Lite/Wishbone — отдельные фичи.

## Замер (2026-07-17)

| Что | Факт |
|---|---|
| `stacker.lam` | 17 адресов `0x100`…`0x601`, **сгруппированы по назначению** — фактически готовая карта регистров |
| `elevator.lam` | `0x10000000`…`0x10000009` — плоский физический MMIO |
| `extend_complex.lam` | `0x44533932`, биты `1`, `2`, **`33`** — **одно слово, три порта, РАЗНЫХ направлений** (`out`, `out`, `in`) |
| Проверка бита | **отсутствует во всём `grammar/src`** (греп); `bit: Option<i64>` допускает отрицательный |
| `c-hal` на бите 8…31 | читает **всегда 0** (загружен один байт) — **молча неверно** |
| `c-hal` на бите ≥ 32 | **UB** (`int >> 33`, C11 6.5.7p3); `cc -Wall` **молчит** (бит — значение времени выполнения) |
| Гейт `c-hal` | **не компилируется вовсе** — в `precheck.sh` только в гейте **детерминизма** (строка 118) |
| Отсечение карты | `bin/lamc.rs:532` пропускает внешнюю карту **только** для `c-hal` |

Два вывода, определившие решение:

1. **Направление принадлежит биту, а не слову** — регистр не бывает просто
   read-only/write-only.
2. **Язык не выражает ширину адресуемого слова** (есть только адрес и бит) →
   `0x44533932:33` не интерпретируем без решения. Отсюда
   [фикс 0020-01](../fixes/0020-01-port-bit-out-of-range.md).

## Зависимости фичи (правило 17/19)

- **Зависит от:** **[фикса 0020-01](../fixes/0020-01-port-bit-out-of-range.md)**
  (заведён этой проработкой, Tier 1, **не закрыт**).
  **Обоснование:** правило 6 ADR запрещает угадывать ширину регистра. Пока язык не
  выражает ширину адресуемого слова, `sv-mmio` обязана **отказывать** на бите вне
  поддержанного диапазона. Частичный объём (только биты 0…7) технически возможен,
  но **бессмыслен**: `extend_complex.lam` корпуса им не покрывается, то есть цель
  не проходила бы собственный корпус.
  ⚠️ **Формально фикс — не фича**, а `ЗАБЛОКИРОВАНА` определена правилом 17 через
  **фичу**-зависимость. Поэтому статус фичи — `СОЗДАНА`, но в таблице она помечена
  зависимостью от 0020-01 явно: буква правила её не блокирует, существо — блокирует.
  Решение о том, заводить ли под 0020-01 отдельную фичу-владельца, — за
  заказчиком.
- **Не зависит от:** [0045](../features/0045-sv-backend.md) (закрыта — даёт
  каркас `generator/sv/`), [0020](../features/0020-port-address-decl.md) (закрыта —
  даёт `AddressMap`), [0048](../features/0048-deterministic-codegen.md) (закрыта —
  даёт критерий A3).
- **Пересечения по коду:** [0057](../features/0057-sv-sequential-composition.md)
  правит `sv_fsm.rs`; [0061](../features/0061-fixed-point-type.md) — `sv_type.rs`;
  0062 добавляет **новую** цель и трогает `bin/lamc.rs:532` + `generator/mod.rs`
  (вариант `Language`). Конфликты слияния тривиальны, но 0062 разумно вести
  **после** 0057: обе трогают эмиссию модуля.
- **Влияние на порядок:** никого не разблокирует. **Разблокируется** закрытием
  0020-01.

## Приоритет (Tier) — обоснование

**Tier 3.**

- Ничего не сломано: `-t sv` честно игнорирует адрес, и это **принятое** решение
  ADR 0045, а не дефект.
- Пользователя нет: ни одного запроса на MMIO-периферию в требованиях; сценарий
  «софт на процессоре + ускоритель на FPGA» назван ADR 0045 как **вероятный**, а
  не как заявленный.
- Против Tier 2: ни одна фича от неё не зависит; ни один дефект ею не закрывается
  (0020-01 она **вскрыла**, но не чинит).

⚠️ **Ценность фичи выше её Tier, и это стоит сказать:** она замыкает 0020 —
один и тот же адрес начинает значить одно и то же по обе стороны шины. Но
замыкание бессмысленно, пока **одна из сторон** (`c-hal`) читает биты неверно и
не компилируется гейтом. Поэтому рекомендация аналитика: **сначала 0020-01**.

## Требования и проверяемые условия

- **R1. Новая цель.** `-t sv-mmio`, парная к `sv` (прецедент `c`/`c-hal`, 0020-05).
  Цель `sv` **не меняется**.
- **R2. Порт с адресом → бит регистра; без адреса → порт модуля.** Смешение
  допустимо.
- **R3. Интерфейс без протокола:** адрес, данные записи/чтения, стробы;
  синхронный. Ширина адреса — из **максимального** адреса модели.
- **R4. Направление — свойство бита.** Регистр может нести биты обоих направлений.
- **R5. Запись шиной в бит `out` игнорируется; чтение бита `in` возвращает
  записанное.**
- **R6. Не угадывать.** Бит вне поддержанного диапазона → **диагностика**.
- **R7. `--address-map` принимается** целью `sv-mmio` (`bin/lamc.rs:532`).
- **R8. Приоритет источников адреса не меняется** (inline < `address` < карта).
- **R9. Инварианты 0045 держатся:** two-process, `always_comb` читает `_next`,
  уплощение композиции, вход в стартовое состояние не расходует такт (0033).
- **R10. Язык не меняется** → версия не растёт.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Карта регистров `stacker` совпадает с адресами модели | Сверка порождённого с `stacker.lam` |
| A2 | Модуль синтезируется | Гейт **verilator И yosys** |
| A3 | Цель `sv` не изменилась | `git diff --exit-code examples/generated/sv` |
| A4 | **Потактовая сверка через регистры** | `conformance_sv_tests` (новый режим наблюдения) |
| A5 | Смешанное слово (`extend_complex`) — по правилам либо **отказ** | Фикстура + прогон |
| A6 | Запись в `out` игнорируется; чтение `in` возвращает записанное | Тестбенч |
| A7 | Порт без адреса — порт модуля | Фикстура |
| A8 | `--address-map` принимается | Прогон `lamc` |
| A9 | Версия не поднята | Ревью |

## Особенности по обратной функциональности

**Правка аддитивна** (правило 11): добавляется **новая** цель; `sv`, `c`, `c-hal`,
`st`, `st-at`, `rust`, `plantuml`, симулятор и язык — не задеты (A3).

Единственная правка вне новой цели — `bin/lamc.rs:532` (R7): условие расширяется
с `!= "c-hal"` на «не `c-hal` и не `sv-mmio`». Аддитивно: где карта отсекалась,
она отсекается по-прежнему.

`Language` помечен `#[non_exhaustive]` — добавление варианта сборку потребителей
не ломает (та же особенность, что у 0045/0050).

## Риски и зависимости

- **R-1. Угадать ширину регистра** (главный риск). Язык её не выражает
  (`0x44533932:33`), и соблазн «ну пусть будет 64» повторил бы ошибку, за которую
  ADR 0045 отверг fixed-point: генератор молча выбирает семантику. Снижение:
  правило 6 — **отказ вместо догадки**; зависимость от 0020-01.
- **R-2. Тихо неверное чтение/запись.** Класс доказан дважды: у `sv` дефект
  «`always_comb` читает регистр вместо `_next`» приняли **оба** инструмента; у
  `c-hal` бит 8…31 читается как 0 **молча**. Снижение: A4 — сверка **через
  регистры** (оттуда, откуда смотрит потребитель), заводится **вместе** с целью.
- **R-3. Конфликт драйверов** на смешанном слове. Снижение: R5 + A6.
- **R-4. Соблазн «заодно выбрать шину».** Вернул бы возражение ADR 0045.
  Снижение: адаптеры — отдельные фичи (A-2 ADR), каждая по требованию.
- **R-5. Проверять будет нечем с одной стороны.** «Две половины одной шины»
  проверяются только если обе половины проверяемы, а `c-hal` **не компилируется
  гейтом**. Снижение: кандидат заведён; A4 покрывает сторону `sv-mmio`.

## Побочные находки проработки (вне объёма, заведены)

1. **[Фикс 0020-01](../fixes/0020-01-port-bit-out-of-range.md)** (Tier 1): бит
   адреса не проверяется нигде; `c-hal` на бите 8…31 читает **всегда 0**, на ≥ 32
   даёт **UB**; корпус содержит такой случай (`extend_complex.lam:13`).
2. **Цель `c-hal` не компилируется ни одним гейтом** — кандидат. В `precheck.sh`
   она только в гейте детерминизма: её вывод сверяют сам с собой, но никогда не
   подают компилятору. Это и позволило (1) дожить.
3. **Адаптеры шин** (APB / AXI-Lite / Wishbone) — кандидат, по одному на протокол,
   каждый по требованию.
