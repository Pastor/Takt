# Анализ фичи 0332: обещание задачи в тексте диагностики

> Фича: [../features/0332-stub-task-promise.md](../features/0332-stub-task-promise.md) · ADR: [../adr/0332-stub-task-promise.md](../adr/0332-stub-task-promise.md) · тест-план: [../tests/0332-stub-task-promise.md](../tests/0332-stub-task-promise.md)

## Цель и контекст

Гейт заглушек искал одну формулировку; четыре заглушки были написаны другой — и
прожили год, а две из них скрывали настоящие расхождения.

## Зависимости фичи (правило 17/19)

- **Зависит от:** 0217 (гейт заглушек). Закрыта.
- **Влияние на порядок разработки:** нет.

## Требования и проверяемые условия

- **R1.** Обещание задачи в тексте диагностики ловится.
- **R2.** Упоминание фичи в комментарии — не ловится.
- **R3.** Печатаемый комментарий порождённого кода — не ловится.
- **R4.** Четыре найденных текста переписаны на причину.
- **R5.** Рабочее дерево зелёное.

## Разбор

### Почему признак «рядом есть `with_code`»

Он отделяет **диагностику** от прозы. Без него улов — 22 места, из которых
законны почти все: справка CLI перечисляет цели с номерами фич, а печатники
вставляют пояснения в порождённый код.

### Что оказалось за обещаниями

- две ветви **недостижимы**: адресный литерал в позиции значения отсекает
  `SY-008` (0189), форму `S(Модель) = Состояние` перехватывает соседняя ветвь
  (0267) — их тексты переписаны как защитные;
- одна ветвь **достижима** (`return {1, 2};` из функции с массивным возвратом)
  и получила причину: в IEC функция массива не возвращает;
- ещё две за тот же день дали фичи 0330 и 0331 — там за обещанием стояли
  настоящие расхождения.

## Риски

- **Ложные срабатывания** на новых текстах, где номер фичи уместен. Ответ: их
  место — комментарий рядом, а не текст, который читает автор модели.
