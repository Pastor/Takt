# Анализ фичи 0230: Сторож форматтера — корпус восстановлен, KNOWN_GAPS с ратчетом

> Фича: [../features/0230-format-corpus-sentinel.md](../features/0230-format-corpus-sentinel.md) · ADR: [../adr/0230-format-corpus-sentinel.md](../adr/0230-format-corpus-sentinel.md) · тест-план: [../tests/0230-format-corpus-sentinel.md](../tests/0230-format-corpus-sentinel.md)

## Цель и контекст

Корпусный тест форматтера обещал три вещи и не исполнял ни одной честно: обход
съёжился до одного каталога из трёх, список известных пробелов протух, а
проверить это было нечем. Разбор — в
[ADR 0230](../adr/0230-format-corpus-sentinel.md).

**Язык фича не меняет.** Правится сторож (тест) и одна ветка печати
форматтера — фикс [0199-01](../fixes/0199-01-fmt-drops-model-implement.md).
Версия языка остаётся `0.8.0`.

**Замеры (2026-08-05), прогоном:**

| Что | До | После |
|---|---|---|
| Файлов в обходе | 158 (`examples/` — единственный существующий каталог) | 279 |
| Каталогов из списка существует | 1 из 3 | 3 из 3 |
| Не разбирается (намеренно невалидные фикстуры) | — | 22 |
| Непокрытых узлов | 0 | 0 |
| Записей `KNOWN_GAPS`, которым что-то соответствует | 0 из 2 | 0 из 0 |
| Нарушений A3 | 0 (не видел) | **1** → фикс 0199-01 |

⚠️ Опасение кандидата «восстановление путей покраснеет массово — фикстуры
намеренно не нормализованы» **не подтвердилось**: тест не требует каноничности
входа, он проверяет `fmt(fmt(x)) == fmt(x)` и структурное равенство АСД.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет незакрытых. Опирается на
  [0024](../features/0024-lam-formatter.md) (сам форматтер и его корпусный тест),
  [0100](../features/0100-language-rename-takt.md) (переименование каталогов, из-за
  которого обход и съёжился), [0199](../features/0199-model-implements-brace-form.md)
  (форма, чью печать чинит фикс).
- **Влияние на порядок разработки:** закрывает **два** кандидата разом; ничего
  не блокирует.

## Требования и проверяемые условия

- **R1. Обход собирает все три каталога корпуса** — `examples`,
  `takt-lang/tests/data`, `takt-sim/tests/data`.
- **R2. Пропавший каталог валит тест** и называет свой путь: молчаливый возврат и
  есть причина, по которой усадка прожила незамеченной.
- **R3. Протухшая запись `KNOWN_GAPS` валит тест** (ратчет; образец —
  `scripts/module-size-baseline.txt`).
- **R4. Новый непокрытый узел по-прежнему валит тест** — прежнее свойство не
  потеряно.
- **R5. A1 и A3 зелены на восстановленном корпусе** — с учётом фикса 0199-01.
- **R6. Инвариант печати реализации модели проверяется адресно**, а не только
  через наличие подходящего файла в корпусе.
- **R7. Печать форматтера не расширяется.** Объём — сторож и найденный дефект.

## Критерии приёмки и способ проверки

Нумерация совпадает с критериями приёмки ADR 0230.

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | обход собирает три каталога, счёт вырос | сводка теста: 279 файлов (было 158) |
| A2 | пропавший каталог валит тест | мутация: подмена каталога на несуществующий |
| A3 | протухшая запись валит тест | мутация: возврат записи в `KNOWN_GAPS` |
| A4 | новый непокрытый узел валит тест | прежняя проверка сохранена (ветвь `unexpected`) |
| A5 | A1/A3 зелены | прогон `a1_a3_corpus_report` |
| A6 | `./scripts/precheck.sh` — код 0 | прогон |

## Особенности по обратной функциональности

| Функциональность | Задета | Что проверяется |
|---|---|---|
| `taktc fmt` (печать вложенной модели) | да — фикс 0199-01 | реализация уцелела; пустое тело печатается со скобками и разбирается |
| Корпусный тест форматтера | да | три каталога, громкий обход, ратчет |
| Прочие тесты форматтера | нет | 16/16 зелены |
| Фикстуры `tests/data` | нет | не нормализуются: тест каноничности входа не требует |
| Цели генерации, симулятор, LSP | нет | форматтер их не касается |
| Гейт `fmt --check examples/` в предкоммите | нет | корпус примеров как был |

## Риски и зависимости

- **Строгость обхода.** Переименование каталога фикстур теперь валит тест —
  осознанная цена: именно молчание сделало усадку возможной.
- **Дефекты в невидимой половине.** Замер нашёл один (0199-01); других A1/A3 не
  показал. Это не доказательство отсутствия — но теперь они хотя бы наблюдаемы.
- **`book/src` вне корпуса.** Примеры документа держит гейт 0133; дублировать
  проверку не стали, чтобы отказ читался однозначно. Замер показал, что они
  форматируются.
