# Анализ фичи 0274: Снимки порождённого кода в book/ никем не сверяются

> Фича: [../features/0274-book-generated-snapshots-gate.md](../features/0274-book-generated-snapshots-gate.md) · ADR: [../adr/0274-book-generated-snapshots-gate.md](../adr/0274-book-generated-snapshots-gate.md) · тест-план: [../tests/0274-book-generated-snapshots-gate.md](../tests/0274-book-generated-snapshots-gate.md)

## Цель и контекст

Сделать отставание снимков невозможным молча. ADR принял Option B: гейт
пересборки и сравнения плюс сторож гейта.

## Замер (снят 2026-08-19, правило 30)

Пересобраны **все** снимки и сравнены `diff -r`. Кандидат подтверждён, но
**назвал не ту цель**: он говорил о `c` (её снимок правила фича 0213), а `c` и
`c-hal` как раз совпадают.

| Каталог | Итог | Что расходится |
|---|---|---|
| `12-time/generated/c` (fan) | совпадает | — (нужен `--tick-hz=1000`, иначе `SE-069`) |
| `18-showcase/generated/c` | совпадает | — |
| `18-showcase/generated/c-hal` | совпадает | — |
| `18-showcase/generated/rust` | **отстал** | `DWELL_TICKS` → `LIFT_DWELL_TICKS` (0193); нет `assert!` инварианта (0235) |
| `18-showcase/generated/st` | **отстал** | нет блока первого скана `IF state = 0` (0191) |
| `18-showcase/generated/sv` | **отстал** | `DWELL_TICKS` → `lift_DWELL_TICKS` (0193); нет `assert (…)` (0235) |

⚠️ Снимок `st` описывал автомат, **сдвинутый на такт** — тот самый дефект,
который фича 0191 устранила в инструменте; документ его сохранял.

⚠️ Даты файлов — 2026-07-25: снимки не трогали с тех пор, тогда как правки
целей шли до 2026-08-19.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. Опирается на детерминированность генерации (фича 0048,
  закрыта) — без неё diff был бы шумом.
- **Влияние на порядок разработки:** никого не разблокирует, но снимает
  ручную обязанность у каждой будущей фичи, меняющей вывод целей.

## Требования и проверяемые условия

- **R1. Расхождение ловится** и называет каталог.
- **R2. Обновление однокомандно** (`--update`).
- **R3. Снимок без источника отвергается**, а не пропускается молча.
- **R4. Частота такта передаётся** из объявления `clock` примера (иначе цель
  `c` отвечает `SE-069` и гейт «падал» бы не по делу).
- **R5. Гейт самопроверяется** мутацией, на копии дерева.
- **R6. Все снимки согласованы** после фичи.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Расхождение ловится | сторож, проверка 2 |
| A2 | Каталог назван | сторож, проверка 2а |
| A3 | `--update` восстанавливает согласие | сторож, проверка 3 |
| A4 | Снимок без примера отвергнут | сторож, проверка 4 |
| A5 | Частота передаётся | снимок `fan` (модель с `clock 1kHz`) совпадает |
| A6 | Все снимки совпадают | прогон гейта |
| A7 | Предкоммит | `./scripts/precheck.sh` |

## Особенности по обратной функциональности (правило 11)

**Инструменты не меняются** — фича добавляет гейт и обновляет снимки. Язык не
затронут; версии прежние. Наблюдаемое меняется лишь в документе: приложение
теперь показывает актуальный вывод (в трёх целях из шести он отличался).

## Редакторский слой (правило 29)

**Не требуется.** Ни лексика, ни синтаксис, ни семантика не менялись.

## Документирование (правило 24)

**Не требуется отдельно:** правится не текст документа, а его данные —
снимки. Описание языка не затронуто.

## Риски и зависимости

- **Риск: гейт станет выборочным** при ином именовании файлов. **Снижение:**
  случай «каталог `generated` без соседнего `examples`» отвергается явно;
  прочие отступления от соглашения названы в ADR как граница.
- **Риск: медленный шаг.** **Снижение:** замер — около секунды на шесть целей;
  шаг стоит рядом с гейтом примеров, который и так компилирует документ.
- **Риск: сторож портит рабочие снимки.** **Снижение:** он работает на
  **копии** дерева через `BG_ROOT`; `--update` в рабочем дереве вызывается
  только человеком.
