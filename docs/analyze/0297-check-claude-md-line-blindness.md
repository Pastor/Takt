# Анализ фичи 0297: Построчная слепота гейта живого контекста

> Фича: [../features/0297-check-claude-md-line-blindness.md](../features/0297-check-claude-md-line-blindness.md) · ADR: [../adr/0297-check-claude-md-line-blindness.md](../adr/0297-check-claude-md-line-blindness.md) · тест-план: [../tests/0297-check-claude-md-line-blindness.md](../tests/0297-check-claude-md-line-blindness.md)

## Цель и контекст

Убрать причину, а не факт: гейт обязан находить запись независимо от переноса.
ADR принял Option B — разбор по абзацам.

## Замер (снят 2026-08-20, правило 30)

Кандидат подтверждён чтением кода: из пяти классов гейта **четыре** были
построчными, а класс «статус фичи» лечился окном из пяти строк (заплатка, а не
решение).

**Находка сверх кандидата — самопроверка была бутафорской.** Она требовала
«нашлось хоть что-то», а класс 5 (фича 0289) даёт находку «раздел
«Критические инварианты» не найден» на **любом** коротком образце. Значит все
случаи проходили независимо от своего класса, и мутация «вернуть построчный
поиск» **не ловилась**. Проверено прогоном: до правки мутация давала зелёную
самопроверку, после — красную.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет (0149 и 0289 закрыты; здесь правится их общий гейт).
- **Влияние на порядок:** никого не разблокирует.

## Требования и проверяемые условия

- **R1.** Все классы ищут по **абзацу**; номер находки — первая строка абзаца.
- **R2.** Разорванная переносом запись версии крейта ловится.
- **R3.** Каждый случай самопроверки проверяет **свою** находку (по ожидаемой
  подстроке).
- **R4.** Мутация «построчный поиск» валит самопроверку.
- **R5. Контроль:** законный текст находок не даёт.
- **R6.** Граница названа: перенос внутри токена в кавычках не лечится.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Разбор по абзацам | чтение кода + прогон |
| A2 | Разорванная версия ловится | случай самопроверки |
| A3 | Ожидаемая подстрока у каждого случая | код самопроверки |
| A4 | Мутация ловится | прогон с построчным поиском |
| A5 | Контроль | `--self-test` |
| A6 | Предкоммит | `./scripts/precheck.sh` |

## Особенности по обратной функциональности (правило 11)

**Не нарушается.** Правка внутри гейта; текст `CLAUDE.md` не менялся.
Наблюдаемое изменение — координата находки указывает на начало абзаца.

## Риски и зависимости

- **Риск: абзац склеит записи двух разных пунктов** и даст ложное совпадение
  «имя крейта … версия». **Снижение:** окно поиска ограничено 120 символами
  между элементами; на рабочем файле ложных находок нет.
- **Риск: граница (перенос внутри токена) станет незаметной.** **Снижение:**
  названа в коде самопроверки и в ADR — там, где её ищут.
