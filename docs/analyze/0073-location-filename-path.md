# Анализ фичи 0073: `Location::filename()` возвращает номер, а не путь

> Фича: [../features/0073-location-filename-path.md](../features/0073-location-filename-path.md) · ADR: [../adr/0073-location-filename-path.md](../adr/0073-location-filename-path.md) · тест-план: [0073-location-filename-path.md](../tests/0073-location-filename-path.md)

## Цель и контекст

Убрать ложно названный метод `Location::filename()` (возвращает `file_no`
строкой, не путь). Честный аналог `try_file_no()` уже существует; путь после
[0053](../adr/0053-diagnostics-file-id.md) берётся из `Diagnostic::file` /
`FileTable`. Решение — **Option A** ADR 0073 (удалить). Правка внутренняя,
язык/семантика/кодоген не затрагиваются.

## Зависимости фичи (правило 17/19)

- **Зависит от:** **нет.** Метод изолирован (2 тестовых вызова, 0 продуктовых).
  Строится на закрытой 0053 (честный путь уже доступен) — не блокирует.
- **Влияние на порядок разработки:** ни одна фича очереди от 0073 не зависит;
  завершение никого не разблокирует. Может браться в любой момент.

## Требования и проверяемые условия

- **R1. Ложное имя устранено.** `Location::filename()` в коде отсутствует.
- **R2. Покрытие не потеряно.** Проверка «Location несёт правильный `file_no`»
  остаётся — через `try_file_no()` (стоит вплотную к удаляемым вызовам).
- **R3. Прочие аксессоры целы.** `try_file_no`/`start`/`end`/`exclusive_end` и
  `not_a_file()` (панический помощник) продолжают работать (последний
  востребован `start`/`end`/…).
- **R4. Ничего, кроме диагностики, не задето.** Вывод генераторов на корпусе
  байт-в-байт неизменен; версия языка не поднимается.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | `filename()` и его вызовы удалены | `grep -rn '\.filename()\|fn filename' grammar/ simulation/` (исключая `import.rs::filename_path`/`filename_found…` — иное имя) — пусто |
| A2 | Покрытие `try_file_no` сохранено | `parser_tests::location_methods` и `ast_tests` с `try_file_no` — зелёные |
| A3 | Прочие аксессоры и `not_a_file` целы | сборка + тесты `diagnostics`/`parser`/`ast` зелёные |
| A4 | Кодоген неизменен | `./scripts/precheck.sh` зелёный; `git diff examples/generated/` пуст |

## Особенности по обратной функциональности

Публичный API `grammar` **сужается** (удаляется `pub fn filename`). Правило 11:
приемлемо — потребителей вне тестов нет, крейт внутренний, ADR санкционирует.
Язык, семантика, генераторы, симуляция — **не задеты**.

## Риски и зависимости

- **Скрытый потребитель вне workspace** (напр. плагин IntelliJ) — маловероятно
  (метод возвращает номер строкой, бесполезен снаружи); снимается grep'ом по
  всему репозиторию перед удалением.
- **`try_file_no` мог бы тоже считаться лишним** — **нет:** он честно назван и
  покрывает `Option`-случай; в объём 0073 его судьба не входит.
