# Анализ фичи 0085: Константа версии языка в коде + гейт синхронизации с README

> Фича: [../features/0085-language-version-constant.md](../features/0085-language-version-constant.md) · ADR: [../adr/0085-language-version-constant.md](../adr/0085-language-version-constant.md) · тест-план: [../tests/0085-language-version-constant.md](../tests/0085-language-version-constant.md)

## Цель и контекст

Ввести **единственный источник истины** для версии языка Lam в коде
(`grammar::LANGUAGE_VERSION`) и **машинный гейт**, сверяющий эту константу с
канонической строкой версии в `README.md`. Закрывает класс дефекта, при котором
документация отстаёт от фактической версии, а сверить нечем (прецедент: фича 0078
подняла язык до `0.4.0`, но README остался на `0.3.0` — не поймано при закрытии).

Опора на прецедент машинных doc-гейтов проекта (ADR 0027 — размер модуля, ADR 0077
— реестр кодов): *правило, которое нельзя проверить командой, — не правило*.
Обоснование выбора Option A (константа + shell-гейт грепом исходника) — в ADR 0085.

## Зависимости фичи (правило 17/19)

- **Зависит от:** **нет.** Фича самодостаточна: затрагивает только крейт `grammar`
  (новый модуль `version.rs` + реэкспорт), `scripts/` (новый гейт + подключение в
  `precheck.sh`) и `README.md` (правка канонической строки). Ни контракта, ни
  схемы, ни инфраструктуры других незакрытых фич не задействует.
- **Влияние на порядок разработки:** завершение фичи не разблокирует напрямую
  других фич таблицы, но даёт опору правилу 22 (накопление версии) для **всех**
  будущих фич, меняющих язык: появляется единственное место записи номера цикла и
  гейт согласия с README. Порядок хвоста `FEATURES.md` не меняется.

## Требования и проверяемые условия

- **R1. Единственный источник в коде.** `pub const LANGUAGE_VERSION: &str` в
  `grammar/src/version.rs`, реэкспорт `grammar::LANGUAGE_VERSION`. Значение —
  фактическая версия языка `"0.4.0"` (после 0078).
- **R2. Формат константы.** Значение — SemVer-тройка `x.y.z` из десятичных
  компонент; охраняется юнит-тестом `version::tests`.
- **R3. Гейт синхронизации.** `scripts/check-language-version.sh` (POSIX `sh`, без
  внешних зависимостей — образец `check-diagnostic-codes.sh`) извлекает версию из
  константы и каноническую строку `**Версия языка: X.Y.Z**` из `README.md`,
  сравнивает. Возврат 0 при совпадении, ненулевой — при (а) расхождении,
  (б) отсутствии канонической строки, (в) более чем одной канонической строке.
- **R4. Подключение в конвейер.** Гейт вызывается в `precheck.sh` в блоке быстрых
  проверок (рядом с `check-module-size.sh`/`check-diagnostic-codes.sh`, **до**
  долгих тестов). CI получает его автоматически (0090: CI гоняет весь
  `precheck.sh`).
- **R5. Устранение живого рассинхрона.** Каноническая строка `README.md` приведена
  `0.3.0 → 0.4.0`; `precheck.sh` зелёный. Это не подъём версии (правило 22) —
  фиксация уже действующей `0.4.0`.
- **R6. Аддитивность (правило 11).** Вывод всех целей (`c`/`c-hal`/`plantuml`/`st`/
  `st-at`/`rust`/`sv`/`sv-mmio`) и симулятора байт-в-байт неизменен; генераторы не
  трогаются. Версия языка **не** поднимается.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | `grammar::LANGUAGE_VERSION == "0.4.0"`, публичен | юнит-тест `version::tests::exported_and_semver` |
| A2 | Формат константы — `x.y.z` | юнит-тест формата |
| A3 | Гейт зелёный при согласии константы и README | прогон `check-language-version.sh` (код 0) |
| A4 | Гейт красный при искусственном рассинхроне | проба: временно исказить README/константу → ненулевой код |
| A5 | Гейт красный при отсутствии/дубле канонической строки | проба: убрать/удвоить строку → ненулевой код |
| A6 | `precheck.sh` зелёный после правки README | полный прогон `./scripts/precheck.sh` |
| A7 | Вывод целей и симулятора неизменен | гейт воспроизводимости в `precheck.sh` (диффа нет; генераторы не тронуты) |

## Особенности по обратной функциональности

Полностью аддитивно (правило 11): новый публичный элемент API
(`grammar::LANGUAGE_VERSION`) — минорный бамп крейта `grammar`; новый гейт; правка
одной строки документации. Существующий код, тесты, порождаемый вывод и версия
языка не затронуты. Крейт `grammar`: `0.9.0 → 0.10.0` (аддитивный публичный API,
SemVer minor; прецедент 0072 `0.7.0 → 0.8.0`). Крейт `simulation` не трогается.

## Риски и зависимости

- **Риск: гейт привязан к форме объявления константы** (греп строкового литерала).
  Снижение: форма стабильна, покрыта юнит-тестом формата; греп-паттерн узкий
  (`LANGUAGE_VERSION: &str = "…"`), как `check-diagnostic-codes.sh` грепает
  `with_code`.
- **Риск: якорь README неоднозначен** (несколько строк с версией). Снижение: гейт
  падает при ≠1 совпадении канонической строки `**Версия языка: X.Y.Z**`;
  исторические упоминания версий имеют иную форму и под якорь не подходят.
- **Зависимость: `lamc version` (Option B)** заблокирован baseline размера
  `lamc.rs` — вынесен в **кандидат** `FEATURES.md`, вне объёма 0085.
- **Tier:** **Tier 3** (инфраструктура/процесс; текущая боль — устаревшая строка
  README, будущая — незамеченный подъём версии). Живой рассинхрон 0078 придаёт
  фиче конкретную ценность «здесь и сейчас», но класс — процессная страховка, не
  дефект поведения компилятора.
