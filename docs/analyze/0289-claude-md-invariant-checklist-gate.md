# Анализ фичи 0289: Чек-лист критических инвариантов

> Фича: [../features/0289-claude-md-invariant-checklist-gate.md](../features/0289-claude-md-invariant-checklist-gate.md) · ADR: [../adr/0289-claude-md-invariant-checklist-gate.md](../adr/0289-claude-md-invariant-checklist-gate.md) · тест-план: [../tests/0289-claude-md-invariant-checklist-gate.md](../tests/0289-claude-md-invariant-checklist-gate.md)

## Цель и контекст

Сделать вторую точку сопровождения проверяемой. ADR принял Option B: метка у
подробного пункта и двусторонняя сверка номеров.

## Замер (снят 2026-08-20, правило 30)

Кандидат подтверждён: в чек-листе шесть пунктов, каждый ссылается на раздел
(«Семантика и диагностика», «Цели генерации»), а подробные пункты никак не
помечены — связь держится только на чтении.

Проверка `check-claude-md.py` до этой фичи имела **четыре** класса (статус
фичи, путь, версия крейта, ссылка на номер строки); полноты чек-листа среди них
не было.

Сегодняшнее состояние согласовано: все шесть инвариантов имеют подробные
пункты. То есть гейт заводится сторожем.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет (0238 и 0149 закрыты).
- **Влияние на порядок:** никого не разблокирует.

## Требования и проверяемые условия

- **R1.** Номер чек-листа без метки — находка.
- **R2.** Метка без номера в чек-листе — находка.
- **R3.** Дубль номера — находка (метка обязана быть одна).
- **R4.** Отсутствие раздела — находка, а не молчаливый успех.
- **R5. Контроль:** согласованный текст находок не даёт.
- **R6.** Проверка живёт в существующем гейте живого контекста, а не во втором
  скрипте.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Недостающая метка | проба на настоящем `CLAUDE.md` |
| A2 | Лишняя метка | проба на настоящем `CLAUDE.md` |
| A3 | Дубль номера | код проверки + самопроверка |
| A4 | Вырожденность | самопроверка |
| A5 | Контроль | самопроверка (законный образец) |
| A6 | Предкоммит | `./scripts/precheck.sh` |

## Особенности по обратной функциональности (правило 11)

**Не нарушается.** Правка текста контекста и расширение гейта; код инструментов
не затронут.

## Редакторский слой (правило 29)

**Не требуется.**

## Документирование (правило 24)

**Не требуется.** `CLAUDE.md` — контекст проекта, а не описание языка.

## Риски и зависимости

- **Риск: гейт сверяет номера, а не смысл.** **Снижение:** названо прямо;
  соответствие содержания — предмет правила 4.
- **Риск: «законный» образец самопроверки станет вырожденным.** **Снижение:**
  он **дополнен** согласованной парой (чек-лист + метка) — иначе класс 5 давал
  бы находку на самом контроле; поймано при первом прогоне.
