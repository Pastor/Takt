# Анализ фичи 0377: Артефакты сборки не попадают в репозиторий

> Фича: [../features/0377-build-artifacts-gate.md](../features/0377-build-artifacts-gate.md) · ADR: [../adr/0377-build-artifacts-gate.md](../adr/0377-build-artifacts-gate.md) · тест-план: [../tests/0377-build-artifacts-gate.md](../tests/0377-build-artifacts-gate.md)

## Цель и контекст

### Замер (2026-08-21, вопрос заказчика)

```
$ ls -la *.rlib
libshl.rlib         25112  Aug 20 17:12
libvarshift.rlib    28448  Aug 20 17:12
libvarshift32.rlib  28488  Aug 20 17:12          — всего 84 КБ

$ git ls-files | grep rlib          → все три ОТСЛЕЖИВАЮТСЯ
$ git log --diff-filter=A -- libvarshift.rlib
  3c6bec19 fix(0334): сдвиг на величину не меньше ширины типа считает как эталон
```

Имена (`shl`, `varshift`, `varshift32`) в точности отвечают предмету фичи 0334
(сдвиги на переменную величину): это вывод ручных проб `rustc
--crate-type=lib`, запущенных **без `--out-dir`**, и попавший в коммит вместе с
правкой под `git add -A`.

Почему не заметили:

1. `.gitignore` закрывает `/target` и `/*.o`, но не `*.rlib`;
2. `git status` показывает такой файл наравне с исходником;
3. гейта, смотрящего на состав репозитория, не было вовсе.

⚠️ Прочих артефактов замер не нашёл: `git ls-files` по расширениям `.rlib`,
`.rmeta`, `.o`, `.so`, `.dylib`, `.a`, `.exe`, `obj_dir/` даёт только эти три
файла.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. 0315 (у каждого гейта есть сторож) закрыта.
- **Влияние на порядок разработки:** нет; фича процессная.

## Требования и проверяемые условия

- **R1. Чистота.** Отслеживаемых артефактов в репозитории нет.
- **R2. Причина закрыта.** `.gitignore` не даёт таким файлам попасть в индекс.
- **R3. Гейт.** Предкоммит падает **списком** при появлении отслеживаемого
  артефакта.
- **R4. Не мешать пробам.** Файл, лежащий рядом и не добавленный в индекс,
  гейт не роняет.
- **R5. Сторож.** Гейт проверяется мутацией, включая вырожденный вход
  (правило 0315).

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | R1 | `scripts/check-build-artifacts.py` на репозитории |
| A2 | R2 | запись в `.gitignore` + условие 3 сторожа |
| A3 | R3 | условие 2 сторожа: артефакт ловится и **назван** |
| A4 | R4 | условие 3 сторожа |
| A5 | R5 | `scripts/test-build-artifacts.sh` — шаг предкоммита |

## Особенности по обратной функциональности

Удаление трёх файлов ни на что не влияет: на них не ссылается ни один скрипт,
тест или документ (проверено грепом по `docs`, `scripts`, обоим крейтам).

## Риски и зависимости

- **Ложная тревога на пробе.** Снижена выбором предмета: проверяются
  **отслеживаемые** файлы, а не рабочее дерево (урок 0301: сторож, кричащий
  всегда, замолкает навсегда).
- **Новый инструмент — новое расширение.** Список закрытый и лежит в одном
  месте; гейт проверяет и сам себя.
- **История.** Файлы остаются в прошлых коммитах: вычистить их можно только
  переписыванием истории, а оно уже делалось 2026-08-19 и стоило правки
  61 ссылки в 21 документе. Цена не оправдана 84 килобайтами.
