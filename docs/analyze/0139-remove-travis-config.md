# Анализ фичи 0139: Удаление мёртвой конфигурации `.travis.yml`

> Фича: [../features/0139-remove-travis-config.md](../features/0139-remove-travis-config.md) · ADR: [../adr/0139-remove-travis-config.md](../adr/0139-remove-travis-config.md) · тест-план: [../tests/0139-remove-travis-config.md](../tests/0139-remove-travis-config.md)

## Цель и контекст

Убрать из репозитория конфигурацию CI, которая не исполняется и описывает более
слабый набор проверок, чем действующий контракт гейтов (`precheck.sh`, фича
[0090](../features/0090-ci-precheck.md)). Решение — Option A
[ADR 0139](../adr/0139-remove-travis-config.md).

## Зависимости фичи (правило 17/19)

- **Зависит от:** `нет`.
- **Влияние на порядок разработки:** никого не разблокирует; выполняется рано
  потому, что стоит минут и снимает ложный контракт (критерий 4 правила 19).

## Требования и проверяемые условия

- **R1. Полнота удаления.** Удаляется сам файл **и** все ссылки на Travis в
  живых документах (`README.md`, `docs/`, `CLAUDE.md`). Записи в `CHANGES.md` —
  история, они остаются.
- **R2. Гейты не ослабляются.** `precheck.sh` и `ci.yml` не трогаются: контракт
  проверок остаётся ровно тем же.
- **R3. Аддитивность неприменима.** Удаление файла — не изменение поведения
  инструментов: ни компилятор, ни симулятор, ни порождённый код не затронуты.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | `.travis.yml` отсутствует | `test ! -e .travis.yml` |
| A2 | Файл удалён из индекса git | `git ls-files .travis.yml` — пусто |
| A3 | Нет упоминаний Travis в живых документах | `grep -ri travis` по `README.md`, `docs/`, `CLAUDE.md`, `scripts/`, `.github/` — только артефакты фичи |
| A4 | Гейты не ослаблены | `git diff` не содержит `scripts/precheck.sh` и `.github/workflows/ci.yml` |
| A5 | Предкоммит зелёный | `./scripts/precheck.sh` → `EXIT=0` |
| A6 | Ссылки целы (правило 14) | `python3 scripts/check-links.py` |

## Особенности по обратной функциональности

Обратная совместимость **не затрагивается**: язык, порождаемый код и публичный
API не меняются. Единственный потребитель удаляемого файла — сервис Travis CI,
который к репозиторию **не подключён** (прогонов нет, бейджа нет).

## Риски и зависимости

- **Риск: файл кому-то нужен как запасной CI.** Снят разбором Option B в ADR:
  неисполняемая и ни с чем не сверяемая конфигурация запасной не является; при
  необходимости второй провайдер заводится отдельной фичей и обязан звать
  `precheck.sh`.
- **Риск: скрытые ссылки.** Снимается проверкой A3 (грепом по всему дереву, а не
  по памяти).
