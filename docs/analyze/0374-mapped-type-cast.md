# Анализ фичи 0374: Приведение, совпадающее после отображения типа

> Фича: [../features/0374-mapped-type-cast.md](../features/0374-mapped-type-cast.md) · ADR: [../adr/0374-mapped-type-cast.md](../adr/0374-mapped-type-cast.md) · тест-план: [../tests/0374-mapped-type-cast.md](../tests/0374-mapped-type-cast.md)

## Цель и контекст

Класс найден замером-сметой при работе над 0373: проба с функцией над
`duration` показала отказ **не** в функции, а в приведении к `u32`.

### Замер (`scripts/probe.sh -n 3`, 2026-08-21)

Вход: `var d: duration := 5ms; d := twice(d); ms := d as u32;`

| Потребитель | Ответ | Печать |
|---|---|---|
| эталон | `ms = 10, 20, 40` | — |
| `c`, `c-hal` | `cc` принял | `(uint32_t)model->d` |
| `st`, `st-at` | `iec2c` принял · `cc` собрал | приведения нет |
| `rust` | **`clippy` ОТВЕРГ** | `self.d as u32` |
| `sv`, `sv-mmio` | verilator принял · yosys синтезировал | `32'(durparam_d_next)` |

Текст отказа: `error: casting to the same type is unnecessary (u32 -> u32)`.

⚠️ Класс **не виден** по кодам возврата: `taktc` возвращает ноль у всех восьми
целей. Вердикт дал раздел «инструменты целей» пробы (0362).

⚠️ Признак фичи 0361 сравнивал типы Takt и такую запись не ловил: `duration` и
`u32` различны, совпадают их **отображения** (правило 0183).

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. 0183 (отображение `duration`), 0359 (тип именованного
  значения), 0361 (само правило) — закрыты.
- **Влияние на порядок разработки:** снимает кандидат «Приведение
  `duration → u32` цель `rust` печатает лишним `as`» (правило 28).

## Требования и проверяемые условия

- **R1. Гейт цели.** `clippy -D warnings` принимает вывод цели `rust` на входе
  `duration → u32`.
- **R2. Одно правило.** Приведение не печатают все три цели, у которых оно есть
  (`c`, `rust`, `sv`).
- **R3. Контрпример «другой тип».** `b as u16` при `b: u8` печатается.
- **R4. Контрпример «сужение».** `d as u8` при `d: duration` печатается: ширина
  меняется.
- **R5. Значения.** Поведение не меняется — потактовые сверки `duration`
  остаются зелёными.
- **R6. Неизменность.** Вывод корпуса не меняется.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | R1 | `rust_output_passes_clippy` (прогон `clippy-driver -D warnings`) на обоих входах |
| A2 | R2 | `cast_matching_after_type_mapping_is_omitted` (текст вывода трёх целей) |
| A3 | R3 | `real_cast_is_kept` |
| A4 | R4 | `narrowing_cast_from_duration_is_kept` |
| A5 | R5 | сверки `conformance_{c,rust,st,sv}_duration_tests` |
| A6 | R6 | `git diff examples/generated/` пуст, гейт детерминизма зелён |

## Особенности по обратной функциональности

Обратная совместимость сохраняется: значения не меняются, меняется только
форма вывода. Два теста фичи 0183 требовали **текста** приведения — их
утверждения обновлены (предмет проверки, отсутствие пересчёта единиц, сохранён).

## Риски и зависимости

- **Ошибка в сторону «опустить» тиха и меняет значение.** Снижение: два
  контрпримера (расширение и сужение) и сверки значений.
- **Признак зависит от цели.** Это существо дела: печатает вывод цель, и
  отображение принадлежит ей. Второго списка «эквивалентных пар» не заводится —
  он разъехался бы с отображением (класс 0084/0193/0195).
