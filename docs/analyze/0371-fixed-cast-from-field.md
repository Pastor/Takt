# Анализ фичи 0371: Приведение q из поля структуры масштабируется

> Фича: [../features/0371-fixed-cast-from-field.md](../features/0371-fixed-cast-from-field.md) · ADR: [../adr/0371-fixed-cast-from-field.md](../adr/0371-fixed-cast-from-field.md) · тест-план: [../tests/0371-fixed-cast-from-field.md](../tests/0371-fixed-cast-from-field.md)

## Цель и контекст

Устранить молчаливое расхождение значений: приведение `q → целое` из поля
структуры теряло масштабирование у всех четырёх целей. Замер и контроль — в
карточке.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. 0061 (правила q), 0349 (тип операнда знает поле у `st`),
  0358 (база — выражение), 0370 (понижение литерала в полях) закрыты.
- **Влияние на порядок разработки:** порождает кандидата «вывод типа операнда
  — четыре носителя вместо одного».

## Требования и проверяемые условия

- **R1. Тип поля выводится** — в семантике и у каждой цели, где вывод свой.
- **R2. Разряд не трогается.** `x.N` — вопрос правила 0356.
- **R3. Формы: поле, выражение над полями, поле элемента массива.**
- **R4. Правила округления не меняются** — носитель прежний.
- **R5. Значения совпадают с эталоном** (сверка, а не компиляция).
- **R6. Вывод корпуса не меняется**: полей `q` в `examples/` нет.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Инструменты целей принимают вывод | `scripts/probe.sh` на `qfieldcast*.takt` |
| A2 | Значения совпадают | `conformance_c_arrays_tests::fixed_cast_from_field_matches_generated_c` |
| A3 | Мутация ловится | «семантика без типа поля» |
| A4 | Регресс | conformance, targets, lib |
| A5 | Вывод корпуса не изменился | предкоммит |

## Особенности по обратной функциональности

- **Язык не меняется**; правило 29 — не применимо.
- **`extract_type` стал точнее**, и это влияет на вывод типов переменных
  (`var x := g.kp;` теперь `q(8, 8)`, а не `Unsupported`) — регресс проверен
  полным прогоном тестов и корпуса.

## Риски и зависимости

- **Четыре носителя вывода типа.** Правка добавила ветвь поля в каждый; их
  сведение — отдельная работа (кандидат).
- **Ветвь `BitAccess` в семантике исчерпывающая по `Member`**: разряд остаётся
  прежним, и это названо явно.
