# Анализ фичи 0263: Приведение индекса к `usize` по нужде

> Фича: [../features/0263-rust-literal-index-cast.md](../features/0263-rust-literal-index-cast.md) · ADR: [../adr/0263-rust-literal-index-cast.md](../adr/0263-rust-literal-index-cast.md) · тест-план: [../tests/0263-rust-literal-index-cast.md](../tests/0263-rust-literal-index-cast.md)

## Цель и контекст

Цель `rust` печатала `as usize` при **каждой** индексации. На литеральном
индексе это `clippy::unnecessary_cast`, то есть отказ под `-D warnings` — теми
же флагами, что стоят в гейте предкоммита. Фича печатает приведение по нужде,
не трогая индекс-переменную.

## Замер (снят заново, правило 30)

Прогон `clippy-driver --edition 2021 --crate-type=lib -D warnings` по
порождённому модулю, 2026-08-19:

| Исходник | Порождено (до) | `clippy` |
|---|---|---|
| `arr[1] := 7;` | `self.arr[1 as usize] = 7;` | **error** `unnecessary_cast` |
| `seen := arr[1];` | `self.seen = self.arr[1 as usize];` | **error** `unnecessary_cast` |
| `arr[i] := 9;` **(контроль)** | `self.arr[self.i as usize] = 9;` | принято |

Контроль работает: приведение переменной необходимо и замечаний не вызывает —
значит отвергается не индексация вообще, а именно лишнее приведение.

⚠️ Замер кандидата (2026-08-18) воспроизведён полностью; формулировка не
устарела.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет.
- **Влияние на порядок разработки:** не разблокирует. Соседняя запись
  [0299](../features/0299-rust-non-ascii-lowercase-name.md) — тот же класс
  «вывод цели не проходит собственный гейт проекта», но иная причина (имена).

## Требования и проверяемые условия

- **R1. Литеральный индекс печатается без приведения.**
- **R2. Индекс-переменная приведение сохраняет** — иначе не компилируется корпус.
- **R3. Правило — у одного носителя**: печатников индекса два (выражения и
  условия), и оба обязаны звать одну функцию.
- **R4. Порождённый модуль принимается `clippy -D warnings`.**
- **R5. Корпус не затронут** — там индексируют переменной.

## Особенности по обратной функциональности

Меняется **форма** вывода цели `rust` для литерального индекса. Поведение
прошивки то же: `1 as usize` и `1` в позиции индекса — одно значение.

## Версия языка (правило 22)

**Язык не меняется.** Версия языка остаётся `0.10.0`; версия крейта `takt-lang`
поднимается на патч.

## Редакторский слой (правило 29)

**Проверка не требуется, и это ответ:** новых токенов, форм объявления, узлов
АСД и диагностик нет — меняется печать одной формы в одной цели.

## Документирование (правило 24)

**Не требуется:** документ описывает язык, а не форму вывода цели; поведение
индексации не изменилось.

## Риски и зависимости

- **Риск: приведение снимут и у переменной** — весь корпус перестанет
  собираться. Сторож — контрольная проверка T1 (обе формы в одном тесте).
- ⚠️ **Граница:** литерал распознаётся по узлу `Number`. Константа, свёрнутая в
  литерал (0192), тоже печатается без приведения; имя, не свёрнутое до числа,
  приведение сохраняет — ошибка в безопасную сторону.
