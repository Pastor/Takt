# Анализ фичи 0222: Раздел документа не отражает свёртку инициализатора

> Фича: [../features/0222-book-variables-const-fold.md](../features/0222-book-variables-const-fold.md) · ADR: [../adr/0222-book-variables-const-fold.md](../adr/0222-book-variables-const-fold.md) · тест-план: [../tests/0222-book-variables-const-fold.md](../tests/0222-book-variables-const-fold.md)

## Цель и контекст

Описать в документе свёртку инициализатора (фича 0192): значение известно до
запуска, имя значит начальное значение, ссылка — только назад по тексту.
Решение о месте — ADR (Option A: подраздел в «Типах данных»).

## Зависимости фичи (правило 17/19)

- **Зависит от:** [0246](../features/0246-init-forward-reference.md) —
  **закрыта** 2026-08-17. Обоснование: правило «ссылка только назад» до неё не
  соблюдалось инструментами (эталон `0`, прошивка `1`), и документ описывал бы
  обещание, а не правило.
- **Влияние на порядок разработки:** никого не блокирует.

## Требования и проверяемые условия

- **R1. Свёртка описана**: инициализатор вычисляется при сборке, до цели
  доезжает значение.
- **R2. Имя = начальное значение**: показано на переменной, которая меняется в
  теле, — инициализатор берёт её стартовое значение.
- **R3. Порядок объявлений**: ссылка назад законна, ссылка вперёд — `SE-109`;
  у констант порядок не важен.
- **R4. Невычислимое названо**: значение порта и `extern` остаются вычисляемыми
  при инициализации на устройстве.
- **R5. Нормировка не дублируется** — ссылка на раздел «Выражения» (правило 25).
- **R6. Числа подтверждены прогоном** (правило 27д в части проверки).
- **R7. «Частые ошибки» дополнены** `SE-109` (правило 26).

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Подраздел существует и полон по ADR | чтение против списка R1–R5 |
| A2 | Числа примеров верны | прогон модели, собравшей все примеры подраздела |
| A3 | Ссылка на «Выражения» разрешается | `make -C book pdf` (неизвестная метка — ошибка) |
| A4 | «Частые ошибки» дополнены | чтение |
| A5 | Гейты документа зелёные | символы, лексика, сборка |
| A6 | Предкоммит зелёный | `./scripts/precheck.sh` |

## Особенности по обратной функциональности

Правка **аддитивна**: добавлен подраздел и строка в «Частые ошибки»; ни один
существующий текст не переписан, структура документа не менялась. Язык не
меняется — версия языка и версии крейтов не растут (правило 22).

## Риски и зависимости

- **Число в примере расходится с поведением** — класс, ради которого правило 27
  требует прогона. Снижение: все примеры подраздела собраны в одну модель и
  прогнаны; значения (`AREA = 16`, `level = 5`, `snapshot = 11`, `early = 8`)
  взяты из трассы.
- **Соблазн описать реализацию** (порядок проходов семантики, устройство
  свёртки) — правило 24. Снижение: в тексте только наблюдаемое поведение и
  коды диагностик.
- **Правило 29 — не требуется:** язык не меняется, правится документ.
