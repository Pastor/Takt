# Анализ фичи 0238: Живой контекст: раздел критических инвариантов дублирует подводные камни

> Фича: [../features/0238-claude-md-duplicate-invariants.md](../features/0238-claude-md-duplicate-invariants.md) · ADR: [../adr/0238-claude-md-duplicate-invariants.md](../adr/0238-claude-md-duplicate-invariants.md)

## Цель и контекст

`CLAUDE.md` читается целиком в начале каждой сессии, поэтому его объём — плата
постоянная. Запрос заказчика (2026-08-16): «стал большим, убери лишнее».
**Лишнее** определено объективно: то, что в файле сказано **дважды**. Уникальные
факты — цена дорого найденных дефектов (формат 0180) — не сокращаются.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. Продолжает [0180](../features/0180-claude-md-context-diet.md)
  (формат пункта) и [0149](../features/0149-claude-md-consistency-gate.md) (гейт
  согласованности) — обе закрыты.
- **Влияние на порядок разработки:** ничего не блокирует и не разблокирует.

## Замеры (2026-08-16)

**З1. Дубль разделов.** Все шесть пунктов раздела «Критические инварианты (НЕ
нарушать)» (134 строки) повторены в «Технических подводных камнях» (59 строк) —
таблица в ADR. Длинная редакция написана **до** 0180 и его формату не следует.

**З2. Дубль толчейна и CI.** Абзацы раздела «Команды» (48 строк прозы) повторены
пунктами «Документ и процесс» (14 строк).

**З3. Дубль правила форматтера.** «Добавил узел АСД — добавь его печать» стоит и
врезкой в «Добавление конструкции языка», и абзацем раздела «Форматтер».

**З4. Что уникально в длинной редакции** (проверено сверкой code-спанов: 207
идентификаторов удаляемого текста против нового файла):

| Факт | Решение |
|---|---|
| `semantic/reference.rs` — структура данных, а не запрещённый проход | **перенесён** |
| цель `c` адрес не эмитит; `address` — жёсткое ключевое слово | **перенесён** |
| сторож `hal_bit_range_tests.rs` (UB доказан исполнением через `mmap`) | **перенесён** |
| `Cargo.lock` отслеживается, `resolver = "3"`, MSRV 1.97 | **оставлен** в «Командах» |
| перечни `SE-048`…`SE-054`, `AM-001…006` | опущены: реестр диагностик — `docs/diagnostics/README.md` |
| `Token::ColonAssign`, `Chain14<…>`, `word_bytes_for_bit`, `address_map/export.rs`, `--emit svd` | опущены: детали реализации, живут в коде и карточках фич (правило 9) |

## Требования и проверяемые условия

- **R1. Ни один инвариант не описан дважды.**
- **R2. Уникальный факт не теряется** — либо переносится, либо его отсутствие
  обосновано (З4).
- **R3. Чек-лист «НЕ нарушать» сохраняется** — как указатель на подробные пункты.
- **R4. Запись о версиях крейтов остаётся ОДНОСТРОЧНОЙ.** ⚠️ Гейт
  `check_crate_versions` ищет пару «крейт … `сейчас X.Y.Z`» в пределах одной
  строки (кандидат `FEATURES.md`, замер фикса 0202-01); перенос через строку
  молча выключает сверку.
- **R5. Гейты зелёные** — `check-claude-md.py` и предкоммит.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Дублей нет | сверка списков пунктов по разделам |
| A2 | Уникальные факты на месте | grep по 22 ключевым словам + сверка 207 code-спанов удалённого текста |
| A3 | Чек-лист есть | раздел «Критические инварианты» — указатель из шести строк |
| A4 | Версии крейтов однострочно | grep `сейчас .*0\.30\.0` в одной строке |
| A5 | Гейты зелёные | `scripts/check-claude-md.py`, `./scripts/precheck.sh` |

## Особенности по обратной совместимости

Код не затронут. Меняется **контекстный документ**, а не поведение инструментов;
версии крейтов и языка прежние (правило 22).

## Риски

- **Р1. Диета уносит факт.** Снижение — A2: сверка не «на глаз», а по списку
  идентификаторов удалённого текста.
- **Р2. Указатель разъедется с разделами.** Машина полноту чек-листа не
  проверяет; цена названа в ADR как принятая.
