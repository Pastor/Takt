# Анализ фичи 0069: Разделение `address_map.rs`

> Фича: [../features/0069-address-map-eval-split.md](../features/0069-address-map-eval-split.md) · ADR: [../adr/0069-address-map-eval-split.md](../adr/0069-address-map-eval-split.md) · тест-план: [../tests/0069-address-map-eval-split.md](../tests/0069-address-map-eval-split.md)

## Цель и контекст

Кандидат: «Было 587 строк, стало **1054** без тестов (1116 с ними) — вычислитель
выражений адреса добавил ~460. Лимит ~1000 (`CLAUDE.md`) **превышен**».

ADR принял **Option B**: делить **по темам** (`parse`/`env`/`eval`/`resolve`), а
не по лимиту.

## Замер (2026-07-17)

**Размеры подтверждены:** 1116 с тестами, **1054** без.

⚠️ **Уточнение против кандидата: сборка НЕ падает.** Формулировка «лимит превышен»
подразумевает красный храповик. Он **зелёный**: файл в реестре узаконенного долга
(`module-size-baseline.txt:31` → `1116 grammar/src/address_map.rs`); прогон —
«157 файлов, записей долга 22, превышение 12049 строк», отказа нет.

**Как так вышло:** 0042 закрылась **раньше** 0027 (`b5aacfb` → `0eac9ed`), поэтому
к моменту заморозки базы файл уже был 1116 и вошёл в реестр **законно**. Храповик
назад не проворачивали. Значит фича — про **снятие записи**, а не про починку
отказа.

**Структура — восемь частей, четыре самостоятельные темы:**

| Часть | Строки | Размер |
|---|---|---|
| шапка + импорты | 1–35 | 35 |
| **парсер `.ld`-карты** | 36–305 | **270** |
| оверлей/предупреждения | 307–348 | 42 |
| типы разрешения | 350–392 | 43 |
| **среда define** (`AddressEnv`) | 394–563 | **170** |
| диагностики выражения | 565–610 | 46 |
| **вычислитель** | 611–878 | **268** |
| **разрешение адресов** | 879–1054 | **176** |

**Оценка кандидата верна:** вычислитель + `AddressEnv` = 438 строк (он говорил
«~460»); остаток 616 — под лимитом.

⚠️ **Анализ 0042 предвидел вынос**, но оценил прирост в **150–200** строк против
фактических **~460** — предвидение верное, оценка вдвое оптимистичная.

## Зависимости фичи (правило 17/19)

- **Зависит от:** **нет**. Опоры **закрыты**: [0027](../features/0027-module-size-split.md)
  (храповик и форма разделения), [0042](../features/0042-address-defines.md)
  (вычислитель), [0020](../features/0020-port-address-decl.md) (слой адресов),
  [0048](../features/0048-deterministic-codegen.md) (критерий A5).
- ⚠️ **Пересечения — реальные и важные:**
  [0043](../features/0043-address-map-export.md) (экспорт карты, `РАЗРАБОТКА`) и
  [0084](../features/0084-address-map-qualified-key.md) (ключ карты) правят **этот
  же** файл; [фикс 0020-01](../fixes/0020-01-port-bit-out-of-range.md) (бит вне
  диапазона) — тоже.
  **Рекомендация аналитика:** вести 0069 **раньше** 0043/0084/0020-01 — иначе они
  будут править тысячестрочный файл, а потом их правки придётся переносить в
  разделённый. Это критерий 4 правила 19 (необходимость), а не зависимость.
- **Влияние на порядок:** формально никого не блокирует; фактически **удешевляет**
  трёх соседей.

## Приоритет (Tier) — обоснование

**Tier 3.**

- **Ничего не сломано**: храповик зелёный, поведение верно, пользователь дефекта
  не видит.
- Ценность — **место** для соседних фич и снятие записи долга.
- Против Tier 2: ни одна фича формально не заблокирована.

## Требования и проверяемые условия

- **R1. Делить по логике**, а не по лимиту: `parse` / `env` / `eval` / `resolve`.
- **R2. Форма 0027:** каталог + `mod.rs`-реэкспорт; **пути импорта у потребителей
  не меняются**.
- **R3. Поведение неизменно** — любой дифф вывода целей есть **дефект**.
- **R4. Запись из реестра удаляется**; новых записей **не добавляется**.
- **R5. `apply_binary` — одна функция на оба матчера** (сырой АСД у оператора и
  понижённый `ExpressionNode` у inline).
- **R6. Приоритет источников адреса не трогается** (inline < `address` < карта).
- **R7. Тесты переезжают вместе с темами.**
- **R8. Язык не меняется** → версия не растёт.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Все файлы `address_map/` — под лимитом | `check-module-size.sh` |
| A2 | Запись удалена; новых нет | Дифф `module-size-baseline.txt` |
| A3 | Храповик зелёный; долг 22 → **21** | Прогон скрипта |
| A4 | Пути импорта не изменились | `git diff` вне `address_map/` не трогает `use` |
| A5 | Вывод **всех** целей побайтово прежний | `git diff --exit-code examples/generated` |
| A6 | `apply_binary` — одна | Греп |
| A7 | Приоритет адресов не изменился | Тесты 0020/0042 |
| A8 | Предкоммит зелёный | `./scripts/precheck.sh` |

## Особенности по обратной функциональности

**Перекладка; наружный контракт неизменен** (правило 11): реэкспорт из `mod.rs`
сохраняет пути импорта (R2/A4), поведение и вывод всех целей — прежние (R3/A5).
Язык не меняется → версия не растёт (правило 22).

⚠️ **Критерий A5 здесь особенно силён:** генерация детерминирована (закрытая 0048),
поэтому **любая** строка диффа `examples/generated` — содержательная, то есть
дефект. Перекладка обязана дать **пустой** дифф.

## Риски и зависимости

- **R-1. Продублировать `apply_binary`** (главный). Разделение файлов — типичный
  повод завести «свой хелпер» в каждом модуле. ⚠️ `CLAUDE.md` предупреждает прямо:
  арифметика — в **одном** месте для обоих матчеров, «разъехавшись, они дали бы
  **разный адрес для одного текста**». Снижение: R5 + A6 (греп).
- **R-2. Тихое изменение поведения при перекладке.** Снижение: A5 — вывод всех
  целей **побайтово** прежний; опора на детерминизм 0048.
- **R-3. Конфликт слияния с 0043/0084/0020-01** — все правят этот файл. Снижение:
  вести 0069 **раньше** (критерий 4 правила 19).
- **R-4. Соблазн «заодно починить».** В файле живёт [фикс 0020-01](../fixes/0020-01-port-bit-out-of-range.md)
  (бит вне диапазона, Tier 1). ⚠️ Чинить его **здесь нельзя**: перекладка обязана
  дать **пустой** дифф вывода, а фикс его меняет — смешав, мы потеряем сторожа A5.
- **R-5. Заменить одну запись реестра тремя.** Формально храповик пройдёт, а долг
  не сократится. Снижение: R4 — новые файлы обязаны укладываться в лимит (A2).

## Побочная находка проработки

**Оценка анализа 0042 разошлась с фактом вдвое** (150–200 строк против ~460), и
вынос не случился, потому что «ещё влезало». Урок для `CLAUDE.md`: *предвидение
«при росте вынесем» не отменяет обязанности мерить; храповик 0027 существует
именно потому, что дисциплина без машины не работает — `validate.rs` дорос до
3654 строк ровно так же.*
