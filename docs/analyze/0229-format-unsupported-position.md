# Анализ фичи 0229: Отказ форматтера — диагностика с позицией

> Фича: [../features/0229-format-unsupported-position.md](../features/0229-format-unsupported-position.md) · ADR: [../adr/0229-format-unsupported-position.md](../adr/0229-format-unsupported-position.md) · тест-план: [../tests/0229-format-unsupported-position.md](../tests/0229-format-unsupported-position.md)

## Цель и контекст

Отказ `taktc fmt` на непокрытом узле не сообщал **где** он, а на операторе ещё и
печатал `Debug`-дамп узла. Выбор решения — в
[ADR 0229](../adr/0229-format-unsupported-position.md); анализ фиксирует условия,
границы и замер достижимости.

**Язык фича не меняет.** Печать узлов не расширяется: что не форматировалось, то
и не форматируется — меняется **сообщение об отказе**. Версия языка остаётся
`0.8.0`.

**Замер мест отказа (2026-08-05), по исходнику и грамматике:**

| Место | Узел | Достижим из грамматики | Позиция доступна |
|---|---|---|---|
| `format/mod.rs` | `ModelElement::Formula` | **да** (`formula "ltl" { }`) | да — `element_loc` |
| `format/stmt.rs`, печать оператора | `Statement::Assembly` и прочие непокрытые | **да** (`assembly "x86" { }`) | да — позиция узла |
| `format/stmt.rs`, инициализатор `for` | непокрытый оператор в заголовке | да | да |
| `format/expr.rs` | `Expression::CodeBlock` | **нет** — грамматика не строит | да (`loc()` есть) |
| `format/expr.rs` | `Expression::NamedFunction` | **нет** | да |
| `format/expr.rs` | `Type::Function` | **нет** | **нет** — поля `loc` у узла нет |

То есть пользователь достигает двух видов отказа из шести; три места — мёртвые
узлы АСД (класс фичи [0201](../features/0201-dead-lexemes.md)).

**Замер копий помощника:** «позиция оператора» была написана дважды —
`parser/depth/mod.rs` и `semantic/const_eval/call.rs`. Оба разбора исчерпывающие
и одинаковые; третий потребитель сделал бы три.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет незакрытых. Опирается на
  [0202](../features/0202-fmt-diagnostic-formatting.md) (структурная ветвь
  `Parse` и общий формат печати), [0053](../features/0053-diagnostics-file-id.md)
  (путь как часть позиции), [0077](../features/0077-diagnostic-code-registry.md)
  (реестр кодов).
- **Влияние на порядок разработки:** ничего не разблокирует.

## Требования и проверяемые условия

- **R1. Отказ несёт позицию узла** — своя строка и колонка у каждого места, а не
  начало файла.
- **R2. Форма отказа совпадает с формой ошибки разбора** — общая функция печати.
- **R3. Внутреннее представление наружу не выходит** — текст называет вид узла.
- **R4. Код зарегистрирован** — `FM-001` в реестре и в приложении документа.
- **R5. Структура доступна вызывающему** — LSP получает `Diagnostic`, а не строку.
- **R6. Позиция оператора живёт в одном месте** — метод узла АСД; прежние копии
  удалены, разбор исчерпывающий.
- **R7. У `--stdin` координаты не выдумываются** — префикса нет, код и текст есть.
- **R8. Печать узлов не расширяется.** Что отказывало, то и отказывает: фича о
  сообщении, а не о покрытии.

## Критерии приёмки и способ проверки

Нумерация совпадает с критериями приёмки ADR 0229.

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | отказ на `formula` — с путём, строкой, колонкой и кодом | `format_unsupported_tests::formula_element_refusal_points_at_the_element` |
| A2 | отказ на `assembly` — своя позиция, без `Debug`-дампа | `…::assembly_statement_refusal_has_position_and_no_debug_dump` |
| A3 | форма совпадает с ошибкой разбора | `…::refusal_shape_matches_parse_error_shape` |
| A4 | `--stdin` — код и текст без префикса | `…::stdin_refusal_has_code_but_no_path_prefix` |
| A5 | вызывающему доступны код и `Location` | `…::library_refusal_carries_code_and_location` |
| A6 | `FM-001` в реестре и приложении | `scripts/check-diagnostic-codes.sh`, правки документа |
| A7 | `./scripts/precheck.sh` — код 0 | прогон |

## Особенности по обратной функциональности

| Функциональность | Задета | Что проверяется |
|---|---|---|
| `taktc fmt` (файлы, `--check`, `--stdin`) | да | новая форма отказа; код возврата 1 не изменился |
| LSP `textDocument/formatting` | да (аддитивно) | отказ по-прежнему `Err`; теперь со структурой |
| `taktc compile` | нет | форматтер ему не нужен |
| Счётчик глубины разбора (`SY-005`) | да (рефакторинг) | тесты `parse_depth_tests` зелены — позиция та же |
| Константный вычислитель | да (рефакторинг) | тесты `const_eval` зелены |
| Корпус `examples/` | нет | непокрытых узлов не содержит (иначе `fmt --check` в предкоммите падал бы) |

## Риски и зависимости

- **Смена наблюдаемого текста.** Тест 0202 пришпиливал прежнюю форму; обновлён с
  оговоркой. Иных потребителей текста нет.
- **Новый префикс `FM`.** Гейт кодов префикс-агностичен, правок не потребовал.
- **Мёртвые узлы.** Три места отказа недостижимы; `Type::Function` остаётся без
  позиции по причине, названной в коде. Это не долг фичи, а свойство АСД —
  кандидат класса 0201.
