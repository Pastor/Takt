# Анализ фичи 0284: Структура без полей

> Фича: [../features/0284-empty-struct-semantics.md](../features/0284-empty-struct-semantics.md) · ADR: [../adr/0284-empty-struct-semantics.md](../adr/0284-empty-struct-semantics.md) · тест-план: [../tests/0284-empty-struct-semantics.md](../tests/0284-empty-struct-semantics.md)

## Цель и контекст

`struct S { }` язык принимал, а вывод не принимали чужие инструменты. Фича
отвергает форму диагностикой `SE-115` — тем же устройством, каким `SE-105`
(фича 0172) отвергает перечисление без вариантов.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. Образец [0172](../features/0172-empty-enum-semantics.md)
  закрыт.
- **Влияние на порядок разработки:** никого не разблокирует. Замер расширил
  соседний кандидат («структуры не транслируются целями `st` и `rust` дальше
  объявления») на цель `sv`.

## Замер (карточка прямо требовала его перед решением)

Карточка знала о цели `c` и просила «замерить остальные цели: `st`/`rust`/`sv`
на пустой структуре не проверялись». Прогон 2026-08-18:

| Потребитель | Что происходило |
|---|---|
| эталон | исполняет: `e = Empty{}` |
| `c`, `c-hal` | `typedef struct Empty { } Empty;`; `cc -std=c11 -pedantic` → `warning: empty struct is a GNU extension` |
| `st`, `st-at` | `Empty : STRUCT END_STRUCT;`; `iec2c` → `error: no structure element declared in structure type declaration` |
| `rust` | отказ `RS-014` |
| `sv`, `sv-mmio` | `empty_t used_e;` при отсутствующем `typedef`; `verilator` → `Can't find typedef/interface` |

### Контроль отделил причину — и сузил объём

**Непустая** структура `struct Pt { a: u8, b: u8 }`:

- `cc -std=c11 -pedantic` — принимает без замечаний;
- `iec2c` — принимает (POUS.c порождён, ошибок нет);
- `rust` — **тот же** `RS-014`;
- `sv` — **та же** висячая ссылка (`pt_t`), `verilator` отвергает.

То есть к **пустоте** относятся только `c` (расширение GNU) и `st`
(невалидный ST). Цели `rust` и `sv` не переводят структуры **вовсе** — это
соседний класс, и фича его не лечит.

⚠️ **Первая проба не воспроизвела дефект у `rust` и `sv` вовсе:** переменная
была неиспользуемой, и штатный фильтр выбросил её из вывода. Тот же капкан, что
в фиче 0300, — проба обязана использовать объявленное.

⚠️ **Вторая проба дала ложный `redefinition of 'Pair'`** в C: файл назывался
`pair.takt`, корневая модель получила имя `Pair` из имени файла и столкнулась
со `struct Pair` (известный класс 0195). К предмету отношения не имеет —
переименование структуры замер очистило.

## Требования и проверяемые условия

- **R1. Пустая структура отвергается** — `SE-115`, на объявлении, с названным
  выходом.
- **R2. Диагностика накапливается** (правило 0151).
- **R3. Непустая структура остаётся законной.**
- **R4. Пустое перечисление судит свой код** — `SE-105`.
- **R5. Грамматика не трогается** — правило языка выражает семантика.

## Особенности по обратной функциональности

**Совместимость нарушается сознательно** (правило 11): запись, которую язык
принимал, стала ошибкой. Довод — вывод на ней невалиден (`iec2c` отвергает) или
держится на расширении компилятора; выразительности запрет не отнимает — у
пустой структуры одно значение и нет полей.

⚠️ **Корпус класс не содержал:** пустых структур нет ни в `examples/`, ни в
фикстурах, и ни один тест такую запись не закреплял — предкоммит зелёный без
правок корпуса.

## Версия языка (правило 22)

**Язык меняется** — принимаемое множество программ сужается. Версия языка **не
поднимается**: цикл `0.10.0` открыт фичей 0243 (накопление). Версия крейта
`takt-lang`: `0.42.0` → `0.43.0`.

## Редакторский слой (правило 29)

**Проверка не требуется, и это ответ.** Новых токенов, форм объявления и узлов
АСД нет; грамматика не тронута. Диагностика доезжает до редактора: проверка
стоит в `validate_model_all`, а сторож зовёт `collect_compile_diagnostics` —
общий вход CLI и языкового сервера.

## Риски и зависимости

- **Риск: подменить `SE-105`.** Снят отдельным тестом-границей: перечисление
  судит свой код.
- **Риск: «исполнить» правило запретом структур вообще.** Снят контрольным
  тестом на непустую структуру.
- **Граница: цели `rust` и `sv` не переводят структуры вовсе** — не лечится
  этой фичей, вынесено кандидатом (замер расширил его на `sv`).
