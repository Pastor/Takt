# Анализ фичи 0140: ревизия витрины и разделение ролей документов

> Фича: [../features/0140-backlog-revision-doc-split.md](../features/0140-backlog-revision-doc-split.md) · ADR: [../adr/0140-backlog-revision-doc-split.md](../adr/0140-backlog-revision-doc-split.md) · тест-план: [../tests/README.md](../tests/README.md)

## Цель и контекст

ADR зафиксировал два решения заказчика: **разделить роли** README и `book/` и
**ввести правило** о снятии кандидатов. Анализ приводит результат сверки (что
именно правится и на каком основании) и определяет объём каждой задачи.

## Результат сверки блока 2 (2026-07-27)

Проверено **17** записей из 28; каждая — пробой или грепом.

### Опровергнуты или неточны — правятся

| # | Запись | Замер | Что делаем |
|---|---|---|---|
| 1 | «Цель `c` **не эмитит констант перечисления вовсе**» | эмитит: `#define ENUM_EN_M_GO 1` — но **в `.c`**, а кандидат искал в `.h`; при этом присваивание печатается числом (`model->c = 1;`) | переписать: «объявляет, но не использует» |
| 2 | «Пустое перечисление `enum E { }` — четыре разных ответа» | программа **не разбирается**: `SY-002`, парсер требует вариант | снять; вопрос семантики пустого перечисления остаётся, но формулировка была о несуществующем входе |
| 3 | «`rust` глушит `too_many_arguments` **пять раз**» | восемь | поправить число |

### Подтверждены — остаются

`Takt.ebnf` отстал (`==` есть, `:=` нет) · комментарии фикстур со старыми
именами (9 файлов) · тега `v0.4.0` нет (есть `v0.3.0`, `v0.5.0`, `v0.6.0`) ·
`builder.rs` с `_ => None` · нет `new-feature.sh --rebuild` · нет `taktc version`
· нет корпусного SV-примера на `+` (`SV_TRANSLATABLE` его не содержит) ·
`eprintln!` из библиотеки (6 мест в пяти файлах генераторов) · гейт `c` без
`-Werror` (флаг есть только в `conformance_c_tests`) · вложенные `if` не
диагностируются (`unknown_var_zzz` внутри `if` компилируется молча) · полная
маска `[bit;64]` незаписуема (`LE-009`) · бит `−1` у `bit`-порта с голым
адресом (`{ (uintptr_t)0x100u, -1, 1 }`).

### Не проверялись — остаются как есть

Требуют IDE (действия Compile/Simulate плагина, JDK 21) либо дорогого замера
(остаточные потолки стека). Задумки без «сделано/не сделано» (адаптеры шин
`sv-mmio`, насыщение `q`, расхождение `>>`) сверке не подлежат.

⚠️ Это **называется** в отчёте: частичная сверка, выданная за полную, — ровно та
ошибка, которую фича и чинит.

### Находка вне блока 2

`CLAUDE.md` (строка 876) утверждает «версия языка **сейчас `0.4.0`**»;
`LANGUAGE_VERSION` и README дают **`0.6.0`**. Гейт `check-language-version.sh`
сверяет только константу и README, поэтому расхождение молчало. По этой записи в
карточках недавно закрытых фич писалось «версия `0.5.0` остаётся» — ошибка
успела распространиться.

## Требования и проверяемые условия

- **R1. Каждая правка витрины опирается на замер**, названный в отчёте.
- **R2. `CLAUDE.md` согласован с `LANGUAGE_VERSION`.**
- **R3. Правило внесено** в свод и сформулировано проверяемо.
- **R4. Подсказка не мешает.** Скрипт перечисляет кандидатов к ревизии и **не**
  меняет код возврата `precheck.sh`.
- **R5. README сжат, ссылки целы** (правило 14): ни одна ссылка не осталась
  битой, содержание (оглавление) согласовано.
- **R6. `book/` не тронут** — он уже единственный источник по языку; фича лишь
  снимает дубль.

## Особенности по обратной функциональности

Код не затрагивается вовсе: меняются документы, свод и один вспомогательный
скрипт. Язык не меняется, **версия не растёт**. Правило 15 свода
переформулируется — это осознанное изменение процесса, принятое заказчиком.

## Риски и как снижаются

| # | Риск | Снижение |
|---|---|---|
| P1 | Ревизия «на глаз» заменит одни неточности другими | каждая правка — от пробы или грепа; непроверенное **не трогается** и называется |
| P2 | Подсказка станет шумом и её отключат | не влияет на код возврата; печатается только при непустом списке |
| P3 | Сжатие README потеряет то, чего нет в `book/` | сверка по разделам: переносится ссылка, а не удаляется знание; `book/` не трогается |
| P4 | Правило добавит бюрократии | формулировка узкая: только кандидаты, **названные карточкой** закрываемой фичи |
