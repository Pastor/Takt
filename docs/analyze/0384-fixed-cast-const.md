# Анализ фичи 0384: Приведение имени константы к `q(m, n)`

> Фича: [../features/0384-fixed-cast-const.md](../features/0384-fixed-cast-const.md) · ADR: [../adr/0384-fixed-cast-const.md](../adr/0384-fixed-cast-const.md) · тест-план: [../tests/0384-fixed-cast-const.md](../tests/0384-fixed-cast-const.md)

## Цель и контекст

Признак фичи 0383 отвечал только на числовые узлы, и `K as q(8, 8)` при
`const K: float := 2.5;` оставался вне правила. Фича закрывает пробел перевода;
язык не меняется, версия языка остаётся `0.11.0`.

## Замер (правило 30, дата 2026-08-22)

| # | Проба | эталон | `c`, `c-hal` | `st`, `st-at` | `rust` | `sv`, `sv-mmio` |
|---|---|---|---|---|---|---|
| P1 | `gain := K as q(8, 8);` | исполняет | исполняет (через `floor` в рантайме) | `ST-014` | `RS-011` | `SV-003` **на объявлении константы** |
| P2 | после свёртки приведения (промежуточный прогон) | — | ок | ок | **«constant is never used»** — отказ `clippy -D warnings` | `SV-003` (объявление осталось) |
| K1 | **контроль:** `gain := 2.5 as q(8, 8);` | согласие девяти (работа 0383) | | | | |

Выводы:

- у цели `sv` причина отказа **посторонняя** предмету (тип `float` у самой
  константы) — снята вместе с печатью имени;
- **класс двухслойный**: снятие первого отказа обнажает второй, и замер
  снимается дважды (тот же приём, что у 0367).

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет (0192, 0317, 0383 закрыты).
- **Влияние на порядок разработки:** снимает кандидата, заведённого 0383;
  никого не разблокирует.

## Требования и проверяемые условия

- **R1.** `gain := K as q(8, 8);` переводят все восемь целей, значение совпадает
  с эталоном.
- **R2.** Свёрнутая константа в выводе **отсутствует** (иначе `rust` отвечает
  «constant is never used», `sv` — `SV-003`).
- **R3.** Константа, используемая **и** обычным путём, в выводе остаётся.
- **R4.** `SE-036` не даёт ложного предупреждения о константе, использованной
  под приведением; на действительно неиспользуемом объявлении поведение
  прежнее.
- **R5.** Знание одно: признак живёт в `const_eval::fixed_literal`, счёт — у
  `const_eval::fixed_repr`.
- **R6.** Вывод корпуса не изменился.

## Редакторский слой (правило 29)

**Правки не требуются:** ни лексика, ни синтаксис, ни семантика не меняются —
меняется печать уже разобранной конструкции и состав вывода целей. Новых
диагностик нет; существующие (`ST-014`, `RS-011`, `SV-003`) сохраняют коды и
тексты, сужается лишь область их срабатывания.

## Особенности по обратной функциональности

- Вход, который цели отвергали, теперь переводится.
- Константа, использованная **только** под таким приведением, исчезает из
  вывода. Для цели `c` поведение прежнее (значение подставлено), но
  порождённый файл станет короче; корпус не затронут.
- ⚠️ Два сборщика использований отвечают на **разные** вопросы: печать вывода
  (`usage_from_expr`) и сообщение автору (`collect_from_expr`). Расхождение
  намеренное; «выравнивание» их вернёт дефект.

## Риски и зависимости

- **Ложное `SE-036`** — снято тем, что правится только сборщик печати;
  проверено прогоном в обе стороны.
- **Признак узкий** (литерал либо константа со свёрнутым литералом): ошибка
  возможна лишь в сторону прежнего поведения.
- **Корпус класс не покрывает** — таких приведений в `examples/` нет.
