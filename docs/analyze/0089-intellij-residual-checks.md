# Анализ фичи 0089: Остаточные проверки плагина IntelliJ (0022/0023)

> Фича: [../features/0089-intellij-residual-checks.md](../features/0089-intellij-residual-checks.md) · ADR: [../adr/0089-intellij-residual-checks.md](../adr/0089-intellij-residual-checks.md) · тест-план: [../tests/0089-intellij-residual-checks.md](../tests/0089-intellij-residual-checks.md)

## Цель и контекст

Закрыть два остаточных пункта 0022/0023: **CT3** (неалфавитный символ →
`BAD_CHARACTER`) — автотестом; **визуальная `runIde`-проверка** — признать
визуальным остатком (ADR 0089, Option A).

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет (0022/0023 закрыты; 0089 — их остаток). `verifyPlugin` уже
  настроен и проходит (фикс 0023-01).
- **Влияние на порядок:** ничего не разблокирует.

## Требования и проверяемые условия

- **R1 (CT3).** Для набора неалфавитных символов вне операторов/пунктуации
  (`@ $ \` \\ №`) лексер даёт **ровно один** `BAD_CHARACTER`-токен на символ, с
  текстом = сам символ. Ветка `LamLexer.scanOperatorOrPunct` `else ->
  BAD_CHARACTER` уже реализует поведение — тест лишь ставит сторож.
- **R2 (визуальный остаток).** `runIde`-показ цветом — не автоматизируется
  headless; фиксируется в отчёте, не блокирует закрытие.
- **R3 (регресс).** Прочие тесты 0022/0023 зелёные без правки ожиданий.

## Критерии приёмки и способ проверки

| # | Критерий | Способ |
|---|---|---|
| A1 | CT3 зелёный | `LamLexerTest.testArbitraryNonAlphaIsBadCharacter` |
| A2 | регресс плагина | `./gradlew --offline test` |
| A3 | визуальный остаток зафиксирован | отчёт 0089 |

## Особенности по обратной функциональности

Только плагин IntelliJ, только добавление теста — поведение неизменно (ветка
`BAD_CHARACTER` существовала). `grammar`/`simulation` — н/п.

## Риски и зависимости

- Символ, ошибочно классифицируемый как оператор (напр. `#`, `?`, `!` — они **в**
  списке операторов) — выбраны заведомо не-операторы (`@ $ \` \\ №`), проверено по
  `scanOperatorOrPunct`.
- `№` (U+2116) — категория Symbol, не Letter (`isLetter` = false) → идёт в
  `else`-ветку; кириллические **буквы** остались бы идентификаторами (не в наборе).
