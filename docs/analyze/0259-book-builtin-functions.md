# Анализ фичи 0259: Встроенные функции языка не описаны в документе book/

> Фича: [../features/0259-book-builtin-functions.md](../features/0259-book-builtin-functions.md) · ADR: [../adr/0259-book-builtin-functions.md](../adr/0259-book-builtin-functions.md) · тест-план: [../tests/0259-book-builtin-functions.md](../tests/0259-book-builtin-functions.md)

## Цель и контекст

Описать встроенные функции там, где их ищут, — в разделе «Функции» (правило
24). ADR принял Option B: подраздел с таблицей, поведением целей и правилом
затенения.

## Замер (снят 2026-08-19, правило 30)

Кандидат подтверждён: раздел «Функции» о встроенных молчал. Состав реестра
(`takt-lang/src/semantic/builtin.rs`) — шесть имён; поведение снято **прогоном**
(`scripts/probe.sh`, восемь целей + эталон), а не чтением кода:

| Вход | Эталон | `c`/`c-hal` | `st`/`st-at` | `rust` | `sv`/`sv-mmio` | `plantuml` |
|---|---|---|---|---|---|---|
| `min`/`max`/`abs`/`clamp` | значения верны | ✓ | ✓ | ✓ | `SV-002` | ✓ |
| `debug("такт")` | печатает каждый такт | ✓ (вызов **выброшен молча**) | `ST-011` | `RS-011` | `SV-002` | ✓ |
| `S(M) = Done` в условии | ✓ | ✓ | `ST-011` | ✓ | ✓ | ✓ |

Контрольные наблюдения (правило 30 — «то же самое, но без предмета»):

- **Затенение:** `fn clamp(p: u8) -> u8 { return 42; }` даёт `r = 42` — своя
  функция закрывает встроенную. Без этой проверки таблица противоречила бы
  примеру раздела, где `clamp` пользовательская.
- **`S` в выражении:** `r := S(M);` — `SIM-020` у эталона, `CC-022` у цели `c`
  (место формы определено фичей 0247).

⚠️ **Побочно найдено два дефекта поведения** — в объём документной фичи они не
входят и вынесены кандидатами (правило 7):

1. **Арность встроенной не проверяется.** `r := min(1);` компилируется молча;
   цель `c` печатает `model->r = ;` при **нулевом** коде возврата, `cc` такой
   файл отвергает. Эталон отвечает `SIM-020`, но текст говорит про `S(Модель)`
   — то есть о **чужом** случае (класс 0231).
2. **Цель `c` выбрасывает `debug` молча.** Ни строки в выводе, ни
   предупреждения; соседние `st` и `rust` на том же входе отказывают с
   причиной. Три цели — три разных ответа на один вход.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. Оговорка карточки «заводить после 0247» снята закрытием
  той фичи (2026-08-17): место `S(Модель)` определено.
- **Влияние на порядок разработки:** никого не разблокирует. Найденные дефекты
  заведены кандидатами и в очередь не встают.

## Требования и проверяемые условия

- **R1. Полнота.** Таблица перечисляет **все шесть** функций реестра.
- **R2. Верность.** Описание поведения целей совпадает с замером.
- **R3. Затенение названо.** Собственная функция с тем же именем закрывает
  встроенную.
- **R4. Ошибки с кодами** (правило 26) — блок «Частые ошибки» дополнен.
- **R5. Документ собирается**, символы в шрифте, лексика сверена.

## Критерии приёмки и способ проверки

## Особенности по обратной функциональности (правило 11)

**Кода фича не касается вовсе** — правится только документ. Ни язык, ни
инструменты не меняются; версии языка и крейтов прежние.

## Редакторский слой (правило 29)

**Не требуется.** Лексика не менялась: имена встроенных функций **не являются
ключевыми словами** (проверено — `check-book-keywords.py` сверяет `KEYWORDS`
лексера, и `min`/`max`/`abs`/`clamp`/`debug`/`S` там нет). Автодополнение и
подсветка их не выделяют — это отдельный вопрос, к описанию не относящийся.

## Документирование (правило 24)

**Это и есть предмет фичи.** Затронут раздел
[`book/src/07-functions/`](../../book/src/07-functions/index.typ): добавлен
подраздел «Встроенные функции» перед «Примером», дополнен блок «Частые
ошибки». Нового раздела фича не заводит — по ADR (Option A отвергнут).

## Риски и зависимости

- **Риск: таблица разойдётся с реестром** при добавлении седьмой встроенной.
  **Снижение:** названо в ADR как отрицательное следствие и вынесено
  кандидатом; машинной сверки нет — гейт лексики сверяет ключевые слова, а
  имена встроенных ими не являются.
- **Риск: описание поведения целей устареет** (например, `sv` научится
  `min`/`max`). **Снижение:** формулировки привязаны к **причине** («вызов
  функции в комбинационной логике не выражается»), а не к списку кодов; коды
  названы отдельно, в блоке ошибок.
