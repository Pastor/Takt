# Анализ фичи 0373: Локальная переменная структурного типа у цели sv

> Фича: [../features/0373-sv-struct-local.md](../features/0373-sv-struct-local.md) · ADR: [../adr/0373-sv-struct-local.md](../adr/0373-sv-struct-local.md) · тест-план: [../tests/0373-sv-struct-local.md](../tests/0373-sv-struct-local.md)

## Цель и контекст

Класс найден **соседним замером**: при работе над параметром-массивом (0372)
проба с функцией, возвращающей структуру, показала отказ yosys не в параметре,
а в **локальной переменной тела**.

### Замер (`scripts/probe.sh -n 2|3`, 2026-08-21)

| Проба | эталон | `c`/`c-hal` | `st`/`st-at` | `rust` | `sv`/`sv-mmio` |
|---|---|---|---|---|---|
| локальная структура, запись по полям | исполняет | `cc` принял | `iec2c` принял · `cc` собрал | приняли | **yosys: Latch inferred** |
| локальная структура, присваивание целиком (возврат функции) | исполняет | принял | принял | приняли | **yosys: Latch inferred** |
| локальный массив структур | исполняет | принял | принял | приняли | **yosys: Latch inferred** |
| локальный массив скаляров (контроль) | исполняет | принял | принял | приняли | принял · синтезировал |
| локальное перечисление (контроль) | исполняет | принял | принял | приняли | принял · синтезировал |

`verilator --lint-only -Wall` принимал вывод во всех строках: класс видит
**один инструмент из трёх**, и `taktc` возвращает ноль.

⚠️ **Проба переписывалась дважды, и обе ошибки вели к неверному выводу:**

1. первая редакция назвала локальную `pair` при типе `Pair` — идентификаторы
   IEC **регистронезависимы**, и `iec2c` отвергал файл по совершенно другой
   причине (класс 0195 у цели `st`). Расхождение приписали бы структуре в теле;
2. вторая читала только одно поле структуры, и verilator отвечал
   `UNUSEDSIGNAL` на неиспользованные разряды — снова не тот предмет.

Обе ловушки вынесены кандидатами; предмет измерен на пробе, где имена не
сталкиваются, а все поля читаются.

⚠️ **Формы решения мерились по КОДУ ВОЗВРАТА.** Первая попытка считала
`grep '^ERROR'` по выводу yosys — а он печатает `путь:строка: ERROR: …`, то
есть с префиксом. Наивный греп объявил годными **три негодные формы**;
ошибку показал прогон `probe.sh`, который смотрит на код возврата.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. 0293 (структуры у целей), 0304 (локальные объявления
  тел), 0367 (умолчание по полям) — закрыты; фича достраивает их правила.
- **Влияние на порядок разработки:** новых зависимостей не вводит; заводит трёх
  кандидатов (`UNUSEDSIGNAL` на частично использованной локальной структуре,
  имя переменной, совпадающее с именем типа, у цели `st`, приведение
  `duration → u32` у цели `rust`).

## Требования и проверяемые условия

- **R1. Синтез.** `yosys synth` принимает вывод для трёх форм записи структуры
  в локальной переменной.
- **R2. Линт.** `verilator --lint-only -Wall` принимает тот же вывод.
- **R3. Значения.** Потактовая сверка с эталоном совпадает: подъём объявления
  поведения не меняет.
- **R4. Порядок.** Объявление стоит **до** операторов процесса — этого требует
  SystemVerilog (`syntax error, unexpected automatic` при нарушении).
- **R5. Неизменность.** Вывод корпуса не меняется: локальные скаляры,
  перечисления и массивы скаляров печатаются на месте.
- **R6. Один носитель.** Список поднятых заполняет **печатник тел**, а не
  отдельный обход.

## Особенности по обратной функциональности

Обратная совместимость сохраняется: расширяется множество синтезируемых
записей, вывод для уже работавших входов не меняется. Новый отказ `SV-002`
(одно имя с разными типами) касается записи, которая и прежде не работала.

## Риски и зависимости

- **Разделение имени между блоками.** Локальные разных блоков делят объявление.
  Снижение: умолчания печатаются безусловно в начале процесса, поэтому каждый
  блок видит нули — как предписывает объявление в теле; поведение сторожит
  потактовая сверка.
- **Порядок объявлений.** Нарушение — синтаксическая ошибка verilator,
  громкая; сторожит текстовый тест.
- **Расхождение накопителя с печатью.** Исключено по устройству: накопитель
  заполняет сам печатник (тело идёт в буфер).
