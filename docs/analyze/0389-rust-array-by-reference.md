# Анализ фичи 0389: Массив в параметре функции цели `rust` — по ссылке

> Фича: [../features/0389-rust-array-by-reference.md](../features/0389-rust-array-by-reference.md) · ADR: [../adr/0389-rust-array-by-reference.md](../adr/0389-rust-array-by-reference.md) · тест-план: [../tests/0389-rust-array-by-reference.md](../tests/0389-rust-array-by-reference.md)

## Цель и контекст

Цель `rust` передавала массив в параметре по значению — копией на каждый вызов,
тогда как `c` передаёт указатель, `st` — `VAR_IN_OUT`, `sv` — плоский вектор.
Фича приводит форму к ссылке.

## Замер (правило 30, дата 2026-08-22)

Вход: `fn total(a: [u8; 4]) -> u8 { return a[0] + a[1] + a[2] + a[3]; }`.

| Цель | До | После |
|---|---|---|
| `rust` | `fn total(a: [u8; 4])`, вызов `total(self.data)` | `fn total(a: &[u8; 4])`, вызов `total(&self.data)` |
| `c`, `c-hal` | `uint8_t a[4]` (указатель) | без изменений |
| `st`, `st-at` | `VAR_IN_OUT` | без изменений |
| `sv`, `sv-mmio` | плоский вектор + пролог | без изменений |

Наблюдаемое поведение одинаково у всех девяти потребителей — и до, и после.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет.
- **Влияние на порядок разработки:** снимает кандидата 0372.

## Требования и проверяемые условия

- **R1.** Порождённый Rust компилируется и проходит `clippy -D warnings`.
- **R2.** Признак один: сигнатура и аргумент спрашивают общий носитель.
- **R3.** Упакованный бит-вектор (`[bit;N ≤ 64]`) по ссылке **не** передаётся.
- **R4.** Поведение и вывод прочих целей не изменились.
- **R5.** Вывод корпуса не изменился.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | R1 | `scripts/probe.sh` (rustc + clippy) |
| A2 | R2 | чтение: носитель `rust_byref` |
| A3 | R3 | существующие тесты бит-векторов (0262) |

## Редакторский слой (правило 29)

**Не применимо:** язык не меняется — правка формы вывода одной цели.

## Особенности по обратной функциональности

Наблюдаемое поведение прежнее. Вывод цели `rust` на функциях с массивом в
параметре меняется — это внутренний интерфейс порождённого модуля (функции
цели `rust` не публичны).

## Риски и зависимости

- **Borrow checker.** Аргумент `&self.data` берётся неизменяемо, а `self.hal` —
  изменяемо; поля разные, и Rust это допускает. Проверено прогоном `rustc` и
  `clippy`, а также полным гейтом цели на корпусе.
- **Разъезд печатников** — снят общим носителем: разойдись они, вывод не
  собрался бы (`E0308`).
