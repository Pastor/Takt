# Анализ фичи 0088: Остальные нарушители лимита размера модуля (безопасная часть)

> Фича: [../features/0088-module-size-remaining.md](../features/0088-module-size-remaining.md) · ADR: [../adr/0088-module-size-remaining.md](../adr/0088-module-size-remaining.md) · тест-план: [../tests/0088-module-size-remaining.md](../tests/README.md)

## Цель и контекст

Вынести из реестра `scripts/module-size-baseline.txt` **безопасную часть**
нарушителей лимита размера модуля (решение заказчика, [ADR 0088](../adr/0088-module-size-remaining.md),
Option B): 12 чисто-делимых файлов. Ядро семантики и пришпиленные `lamc`/`lib` —
отдельная фича (заводится при закрытии). Вынос — **чистое перемещение**: вывод
генераторов байт-в-байт неизменен, поведение неизменно, пути импорта держит
`mod.rs`-реэкспорт.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет (продолжение 0027, но 0027 закрыта). Иных нет.
- **Влияние на порядок:** не разблокирует другие фичи. Порождает **фичу-преемник**
  (ядро семантики + пересмотр пришпиленных) — заводится при закрытии 0088.

## Декомпозиция на подзадачи (по классам, порядок — по риску/дешевизне)

| № | Подзадача | Файлы (строк) | Приём | Проверка |
|---|---|---|---|---|

| 0088-02 | Генераторы (остальные) | `rust_model` 1345, `c_source` 1169, `rust_expr` 1112 | по печатникам (образец `*_blocks`) | codegen + детерминизм |
| 0088-03 | Парсер | `ast` 1204, `lexer` 1154 | по категориям узлов/токенов | `parser_tests`/`lexer_tests` |

| 0088-06 | Тесты (крупнейший) | `semantic_tests` 5015 | директория-подмодуль по темам (Ce/SE/enum/address/struct/verify/…) | `cargo test --test semantic_tests` |

Каждая подзадача: переместить → обновить реестр → зелёный целевой тест → зелёный
`precheck.sh` → коммит. Ни одно тест-утверждение не меняется (только адрес).

## Требования и проверяемые условия

- **R1.** Каждый вынесенный файл ≤ 1000 строк (либо разбит на подмодули ≤ 1000);
  запись удалена из реестра.
- **R2.** Вывод генераторов (`c`/`rust`/`st`/`sv`/`plantuml`) **байт-в-байт**
  неизменен (детерминизм-гейт + codegen-снапшоты).
- **R3.** Все существующие тесты зелёные **без изменения утверждений**.
- **R4.** Пути импорта потребителей неизменны (`mod.rs`/файловый реэкспорт).
- **R5.** `precheck.sh` зелёный на каждом коммите-выносе (в т.ч.
  `check-module-size.sh`).

## Критерии приёмки и способ проверки

| # | Критерий | Способ |

| A2 | вывод генераторов неизменен | `codegen_tests` + детерминизм-гейт precheck |
| A3 | поведение неизменно | полный `cargo test` |
| A4 | precheck зелёный | `./scripts/precheck.sh` |

## Особенности по обратной функциональности

Полностью аддитивно (правило 11): перемещение кода, реэкспорт держит публичные
пути. Язык не меняется, версии крейтов — при необходимости патч (перемещение
приватных модулей публичный API не трогает).

## Риски и зависимости

- **Скрытая приватная зависимость** выносимой функции от остающейся — ловится
  компилятором (unused import / not found) сразу.
- **Изменение вывода** от случайной правки — ловит детерминизм-гейт + codegen.
- **Тест-бинарники:** директория-подмодуль сохраняет один бинарник на группу.
- **`viewport`:** если дробление окажется нетривиальным — переносится в
  отложенную фичу (решение по факту).
