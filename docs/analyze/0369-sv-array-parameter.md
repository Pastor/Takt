# Анализ фичи 0369: Массив в параметре функции у цели sv

> Фича: [../features/0369-sv-array-parameter.md](../features/0369-sv-array-parameter.md) · ADR: [../adr/0369-sv-array-parameter.md](../adr/0369-sv-array-parameter.md) · тест-план: [../tests/0369-sv-array-parameter.md](../tests/0369-sv-array-parameter.md)

## Цель и контекст

Привести цель `sv` к остальным потребителям на функции с параметром-массивом.
Замер — в карточке.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. 0337 (гашение неиспользованного параметра), 0348 (тот
  же класс у `st`), 0365 (распакованный массив), 0368 (тип элемента) закрыты.
- **Влияние на порядок разработки:** порождает кандидата «массив структур в
  параметре».

## Требования и проверяемые условия

- **R1. Параметр — плоский вектор** ширины `размер × ширина элемента`.
- **R2. Пролог распаковывает** его в массив с именем параметра, поэтому тело
  печатается прежними печатниками.
- **R3. Аргумент — конкатенация в обратном порядке**: `a[0]` в младших
  разрядах.
- **R4. Границы названы:** массив структур и массив массивов в параметре под
  правило не подпадают (ширина элемента не скалярна).
- **R5. Значения совпадают с эталоном** — сверка, а не факт компиляции.
- **R6. Синтез — отдельный сторож** (класс видит только yosys).

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Оба инструмента принимают вывод | `scripts/probe.sh` на `arrparam.takt` |
| A2 | Трасса совпадает с эталоном | `array_parameter_values_match_generated_sv` |
| A3 | Синтез | `array_parameter_is_synthesizable` |
| A4 | Мутации ловятся | порядок конкатенации; распакованный параметр |
| A5 | Вывод корпуса не изменился | предкоммит |

## Особенности по обратной функциональности

- **Язык не меняется**; правило 29 — не применимо.
- **Печатники индексации не трогаются** — в этом и смысл пролога.

## Риски и зависимости

- **Порядок конкатенации** — единственное место, где ошибка даёт валидный RTL
  с зеркальными значениями; его и сторожит сверка.
- **Ширина плоского вектора** считается у носителя (`scalar_width`), а не
  заново.
