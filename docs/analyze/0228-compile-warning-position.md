# Анализ фичи 0228: Предупреждение taktc compile несёт позицию

> Фича: [../features/0228-compile-warning-position.md](../features/0228-compile-warning-position.md) · ADR: [../adr/0228-compile-warning-position.md](../adr/0228-compile-warning-position.md) · тест-план: [../tests/0228-compile-warning-position.md](../tests/0228-compile-warning-position.md)

## Цель и контекст

Предупреждение `taktc compile` печаталось без координат, хотя они у него есть;
ошибка того же прогона координаты несёт. Причина и выбор решения — в
[ADR 0228](../adr/0228-compile-warning-position.md); анализ фиксирует условия и
границы.

**Язык фича не меняет.** Ни лексики, ни синтаксиса, ни семантики, ни набора
диагностик: меняется **печать** существующих предупреждений. Версия языка
остаётся `0.8.0`.

**Замер до правки (2026-08-05), прогоном инструмента:**

| Вход | Что печаталось |
|---|---|
| `var BadVar: u8 := 1;` (не используется), цель `c` | `Предупреждение [SE-036]: переменная 'BadVar' …` — без позиции |
| однобитный порт без позиции бита, цель `c-hal` | `Предупреждение [SE-090]: порт 'lamp' …` — без позиции, **и через свою копию формата** |
| та же модель с семантической ошибкой | `probe.takt:2:17: Ошибка компиляции [SE-034]: …` — позиция есть |
| то же имя вне канона, `taktc fmt` | `probe.takt:2:9: Предупреждение [CS-001]: …` — позиция есть |

То есть расхождение было **между потребителями одной функции печати**: `fmt`
ставил путь, `compile` — нет.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет незакрытых. Опирается на механизмы закрытых фич —
  [0053](../features/0053-diagnostics-file-id.md) (путь как часть позиции),
  [0081](../features/0081-lamc-print-warnings.md) (единая точка предупреждений),
  [0130](../features/0130-diagnostics-batch.md) (реестр файлов у ошибок).
- **Влияние на порядок разработки:** ничего не разблокирует.

## Требования и проверяемые условия

- **R1. Позиция доезжает до пользователя** — путь, строка и колонка у
  предупреждений «своего» файла.
- **R2. Путь разрешается реестром файлов, а не именем входа.** Предупреждение
  импортированного файла называет **его** путь; иначе координаты указывают в
  чужой текст.
- **R3. Формат печати — один на все цели.** Литеральная копия в
  `report_hal_result` устранена; печать идёт через `format_warning`.
- **R4. Форма префикса совпадает с формой префикса ошибки.**
- **R5. `--quiet` глушит предупреждения во всех ветвях печати**, включая
  HAL-цели.
- **R6. Порождённый код не задет.** Предупреждения идут в stderr; снапшоты
  `examples/generated/` не двигаются.

## Критерии приёмки и способ проверки

Нумерация совпадает с критериями приёмки ADR 0228.

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | предупреждение печатается с путём, строкой и колонкой | `cli_warning_position_tests::warning_carries_path_line_and_column` |
| A2 | то же на цели `c-hal` | `…::hal_target_warning_carries_position` |
| A3 | предупреждение импортированного файла называет путь библиотеки | `…::imported_warning_names_the_library_file` |
| A4 | форма префикса совпадает с формой у ошибки | `…::warning_prefix_matches_error_prefix` |
| A5 | `--quiet` глушит, включая HAL-ветвь | `…::quiet_suppresses_hal_warnings` + тест 0081 для цели `c` |
| A6 | `./scripts/precheck.sh` — код 0 | прогон (в том числе гейт детерминизма кодогена: вывод целей не задет) |

## Особенности по обратной функциональности

| Функциональность | Задета | Что проверяется |
|---|---|---|
| `taktc compile`, цель `c` и прочие «простые» | да | новый префикс; `--quiet`; тексты не изменились |
| `taktc compile`, цели `c-hal`/`st-at`/`sv-mmio` | да | копия формата устранена; префикс появился |
| `taktc fmt` | нет | путь ставил и раньше (фича 0226) |
| LSP | нет | печатью не пользуется: позиция уходит диапазоном протокола |
| `takt-sim` | нет | стамп пути у него свой (`takt_sim.rs`) |
| Порождённый код, снапшоты | нет | предупреждения идут в stderr |
| Ошибки `--define` (`DF-…`) | нет | у аргумента командной строки нет места в файле; формат оставлен свой |

## Риски и зависимости

- **Вывод `compile` меняется на всём корпусе.** Риск принят: изменение —
  добавление префикса в stderr, гейты предкоммита сверяют файлы, а не текст
  сообщений.
- **Ограничение HAL-ветви.** Реестр там содержит только корневой файл (цель
  строит своё дерево внутри и таблицу наружу не отдаёт), поэтому предупреждение
  импортированного файла остаётся без префикса. Названо в ADR; расширение
  требует смены сигнатур трёх функций генерации.
- **Соблазн упростить до «штампуем имя входа».** Это Option B, отвергнутый:
  верный код с неверной строкой хуже отсутствия строки. Сторож — тест A3.
