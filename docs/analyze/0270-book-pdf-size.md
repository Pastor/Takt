# Анализ фичи 0270: Вес PDF документа

> Фича: [../features/0270-book-pdf-size.md](../features/0270-book-pdf-size.md) · ADR: [../adr/0270-book-pdf-size.md](../adr/0270-book-pdf-size.md) · тест-план: [../tests/0270-book-pdf-size.md](../tests/0270-book-pdf-size.md)

## Цель и контекст

Выяснить, из чего складывается вес PDF, и решить, нужен ли выигрыш. ADR принял
Option B (решение заказчика): собирать без тегов доступности.

## Замер (снят 2026-08-20, правило 30)

**Способ:** разбор PDF по объектам скриптом (`/Type`, `/Length`, `/FontFile2`)
плюс `pdffonts`.

| Что | Объём | Доля |
|---|---|---|
| файл целиком | 3 076 713 Б | 100 % |
| потоки (весь контент, включая шрифты) | 848 829 Б | 27 % |
| из них встроенные шрифты (4 подмножества) | 51 204 Б | **1.7 %** |
| SVG-диаграммы на входе (3 файла) | 192 КБ | ≈ 6 % |
| **объекты `StructElem`** — 14 208 штук | ≈ 2.2 МБ | **> 70 %** |

Объектов в файле 16 050 при 168 потоках: подавляющее большинство — узлы
структурного дерева PDF/UA.

**Гипотеза кандидата опровергнута.** Он называл подмножества шрифтов и
непересжатые SVG; вместе это 7.7 %. Работа по кандидату (пересжатие диаграмм)
дала бы считанные проценты и оставила бы причину нетронутой.

**Перебор средств:**

| Средство | Размер | Потери |
|---|---|---|
| `--pdf-standard 1.4` | 3.02 МБ | — |
| `--pdf-standard 2.0` | 3.20 МБ | — |
| `ghostscript -dPDFSETTINGS=/prepress` | 1.31 МБ | теги **и** аннотации (47 → 38) |
| **`--no-pdf-tags`** | **947 КБ** | только теги |

Контроль сохранности: в файле без тегов `Outlines` на месте, объектов `/Link` —
54, страниц столько же; объектов 1386 вместо 16 050.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет.
- **Влияние на порядок:** никого не разблокирует.

## Требования и проверяемые условия

- **R1.** PDF собирается без тегов и весит ≈ 947 КБ.
- **R2.** Оглавление и ссылки сохраняются.
- **R3.** Флаг задан **переменной** Makefile: доступный PDF собирается
  `make -C book build TYPST_PDF_FLAGS=`.
- **R4.** Гейты документа (глифы 0146, снимки 0274, примеры 0133, языки
  блоков 0269) остаются зелёными.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Размер PDF | `make -C book build`, `stat` |
| A2 | Оглавление и ссылки целы | разбор PDF (`/Outlines`, `/Link`) |
| A3 | Возврат тегов одной командой | `make -C book build TYPST_PDF_FLAGS=` |
| A4 | Гейты документа | `./scripts/precheck.sh` |

## Особенности по обратной функциональности (правило 11)

**Наблюдаемое изменение названо:** документ перестаёт быть тегированным —
программы чтения с экрана получают плоский текст без структуры. Это осознанная
цена, принятая заказчиком; возврат — снятие флага.

Язык, инструменты и порождаемый код не затронуты; версия языка прежняя.

## Редакторский слой (правило 29)

**Не требуется.** Правка в сборке документа.

## Документирование (правило 24)

**Не требуется.** Содержание документа не меняется.

## Риски и зависимости

- **Риск: флаг исчезнет из Typst.** **Снижение:** сборка тогда упадёт с
  «unexpected argument» — отказ громкий; переменная в Makefile правится одной
  строкой.
- **Риск: доступность понадобится.** **Снижение:** флаг вынесен в переменную, и
  комментарий рядом объясняет, как её снять.
