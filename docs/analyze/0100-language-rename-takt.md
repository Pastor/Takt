# Анализ фичи 0100: Переименование языка Lam → Takt

> Фича: [../features/0100-language-rename-takt.md](../features/0100-language-rename-takt.md) · ADR: [../adr/0100-language-rename-takt.md](../adr/0100-language-rename-takt.md) · тест-план: [../tests/README.md](../tests/README.md)

## Цель и контекст

Реализовать сквозной ренейм **Lam → Takt** по [ADR 0100](../adr/0100-language-rename-takt.md)
(Option A, жёсткий разрыв): расширение `.lam`→`.takt`, бинарники `lamc`→`taktc`/
`lam-lsp`→`takt-lsp`, крейты `grammar`→`takt-lang`/`simulation`→`takt-sim`
(с путями импорта), плагин IntelliJ, EBNF, все примеры и документация; версия
языка `0.4.0`→`0.5.0` (тег `v0.5.0`). **Синтаксис и семантика не меняются** —
ключевые слова, грамматика и генераторы тождественны; меняются имена и тексты.

## Зависимости фичи (правило 17/19)

- **Зависит от:** **нет** (жёстких зависимостей). Фича не ждёт закрытия другой:
  ренейм механический и самодостаточный.
- **Влияние на порядок разработки:**
  - ⚠️ **Пересечение с [0099](../features/0099-module-size-core.md)** (вынос ядра
    семантики + пришпиленных): обе трогают `semantic/*` и **реестр
    `module-size-baseline.txt`** (0100 переезжает пути `grammar/`→новый крейт,
    0099 дробит те же файлы). Рекомендация аналитика (критерий 4 правила 19):
    **брать 0100 ПЕРЕД 0099** — тогда 0099 сразу работает на переименованных
    путях, а не переписывает свои результаты. Не блокировка, а последовательность.
  - Ренейм делает **устаревшими упоминания** `Lam`/`.lam`/`lamc` в карточках
    **незакрытых** фич и `FEATURES.md`; их правит слой документации (0100-06).
    Карточки **закрытых** фич — исторический контекст, не правятся (см. A1).
  - Фича **не в статусе `ЗАБЛОКИРОВАНА`** (зависимостей нет).

## Требования и проверяемые условия

- **R1. Полнота ренейма.** В коде, скриптах, примерах и **активной** документации
  не остаётся `Lam`/`.lam`/`lamc`/`lam-lsp`/`lam_lsp` (кроме явного списка
  исторических артефактов — карточки/ADR/анализ/отчёты закрытых фич).
- **R2. Сборка и поведение.** `cargo build --bin taktc` и `--features lsp --bin
  takt-lsp` успешны; `cargo test` зелёный; поведение компилятора/симулятора/LSP
  **неизменно** (переименование — не смена логики).
- **R3. Расширение.** Компилятор/LSP/симулятор/форматтер принимают **только**
  `.takt`; `.lam` не распознаётся (жёсткий разрыв). Импорт `import "x.takt"`.
- **R4. Крейты и пути.** Крейты `takt-lang`/`takt-sim`; пути импорта
  `takt_lang::`/`takt_sim::` во всех потребителях; публичный API по составу
  неизменен (только имя крейта).
- **R5. Версия.** Версия языка `0.5.0` (константа `LANGUAGE_VERSION` + якорь
  README синхронны, гейт `check-language-version.sh` зелёный); коммит подъёма
  помечен тегом `v0.5.0`.
- **R6. Гейты.** `precheck.sh` зелёный на каждом слое: `check-module-size.sh`
  (пути реестра переехали), детерминизм (снапшоты `examples/generated/`
  пересобраны законно), `check-links.py` (переименованные файлы не оставили битых
  ссылок — правило 14).
- **R7. Плагин IntelliJ.** Собирается и тестируется (`./gradlew --offline test`)
  под именем Takt, `TaktFileType` распознаёт `.takt`.

## Особенности по обратной функциональности

Правило 11 — **сознательный обрыв обратной совместимости** (обоснование в ADR,
драйвер 2): расширение `.lam`, имена `lamc`/`lam-lsp`, имена крейтов и пути
импорта меняются жёстко. Проект **до 1.0**, гарантированных внешних потребителей
нет; цена половинчатой миграции (два расширения навсегда) выше цены разрыва.
Поведение языка (разбор, семантика, генерация, симуляция) **неизменно** — ренейм
не задевает функциональность, только идентичность.

## Риски и зависимости

- **Пропуск пути импорта под фичей `lsp`** — обычная `cargo build` его не видит;
  ловит `precheck.sh` (`--all-features`). Снижение: каждый слой гоняет полный
  precheck.
- **Снапшоты `examples/generated/` меняются законно** (`#include "имя.h"` при
  смене имён примеров) — риск спутать с содержательной регрессией. Снижение:
  пересобрать эталоны в том же коммите (0100-04), детерминизм-гейт подтвердит
  стабильность повторного прогона.
- **Реестр размера модуля** содержит пути `grammar/`/`simulation/` — при ренейме
  крейтов записи обязаны переехать синхронно, иначе гейт краснеет (0100-01/02).
- **Пересечение с 0099** (общие файлы + реестр) — рекомендация брать 0100 раньше
  (см. «Влияние на порядок»).
- **Массовость правки** (~324 файла) — риск ручной ошибки; снижение —
  механические `git mv` + `grep -rl … | xargs sed` по слоям с немедленным
  precheck, а не одна большая правка.
