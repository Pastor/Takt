# Анализ фичи 0387: Локальная переменная, записанная но не прочитанная

> Фича: [../features/0387-write-only-local.md](../features/0387-write-only-local.md) · ADR: [../adr/0387-write-only-local.md](../adr/0387-write-only-local.md) · тест-план: [../tests/0387-write-only-local.md](../tests/0387-write-only-local.md)

## Цель и контекст

Признак 0376 считал запись использованием, и локальная, которую тело только
пишет, оставалась без заглушки. Фича сужает признак до **чтений** и достраивает
заглушку у цели `sv`.

## Замер (правило 30, дата 2026-08-22)

Вход: `var spare: u8 := 0; spare := n + 5;` в теле `always`, без чтений.

| Потребитель | До фичи | После |
|---|---|---|
| `c`, `c-hal` | `cc`: `variable 'spare' set but not used` (**-Werror**) | принял |
| `rust` | `rustc`: `unused variable: spare` | принял, `clippy` принял |
| `sv`, `sv-mmio` | `verilator`: `UNUSEDSIGNAL` | принял, `yosys` синтезировал |
| `st`, `st-at` | принимали | принимают |
| эталон | исполнял | исполняет (трасса та же) |
| `SE-036` | молчала | предупреждает |

⚠️ **Промежуточный замер** (после сужения признака, до правки `sv`) дал у цели
`sv` **другую** ошибку — `ALWCOMBORDER`: поглотитель читал сигнал раньше записи.
Класс двухслойный, замер снимался дважды.

⚠️ **Шум:** прогон по всем `examples/*.takt` — ноль новых предупреждений.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет (0376, 0386 закрыты).
- **Влияние на порядок разработки:** снимает кандидата 0376; никого не
  разблокирует.

## Требования и проверяемые условия

- **R1.** Порождённый C собирается под флагами гейта цели.
- **R2.** Вывод всех восьми целей принимают их инструменты.
- **R3.** `SE-036` предупреждает о записанной-непрочитанной локальной.
- **R4.** Поведение не изменилось (трасса эталона прежняя).
- **R5.** Знание одно: режим сбора — флаг `UsageSet::reads_only`, а не второй
  обход.
- **R6.** Фильтры печати целей (`compute_usage`) режим **не** включают: там
  вопрос «нужно ли имя в выводе».
- **R7.** Корпус не даёт новых предупреждений.

## Редакторский слой (правило 29)

**Правок не требуется:** ни лексики, ни синтаксиса, ни узлов АСД фича не
меняет. Предупреждение `SE-036` доезжает до редактора прежним путём (общая
точка `collect_model_warnings`, 0081/0232); его код и текст не менялись.

## Особенности по обратной функциональности

- Поведение моделей не меняется: заглушки и поглотители синтезатор и
  компиляторы выбрасывают сами.
- Вывод целей `c`, `rust`, `sv` на таких записях становится длиннее на одну-две
  строки. Корпус не затронут (таких переменных в `examples/` нет).
- `SE-036` начинает предупреждать там, где молчала — граница 0386 снята
  осознанно (см. ADR).

## Риски и зависимости

- **Ложное «не читается».** Признак различает место записи и чтение; внутри
  места записи индексы и базы читаются (`arr[i] := 5;` читает `i`).
  Ошибка в сторону «читается» даёт прежнее поведение.
- **Форма поглотителя у `sv`** проверена обоими инструментами; порядок
  (поглотитель после тела) — требование verilator, найденное прогоном.
