# Анализ фичи 0388: Разделение печати объявлений цели `st`

> Фича: [../features/0388-st-decl-split.md](../features/0388-st-decl-split.md) · ADR: [../adr/0388-st-decl-split.md](../adr/0388-st-decl-split.md) · тест-план: [../tests/0388-st-decl-split.md](../tests/0388-st-decl-split.md)

## Цель и контекст

Процессная фича: `st_decl.rs` упёрся в предел размера модуля (1000 при лимите
1000), и следующая правка печати объявлений цели `st` уронила бы гейт. Модуль
разделён по существующей границе пластов вывода.

## Замер (дата 2026-08-22)

| Файл | До | После |
|---|---|---|
| `st_decl.rs` | 1000 (запас 0) | 806 |
| `st_decl_types.rs` | — | 216 |

Вывод корпуса: **дифф пуст** — код перенесён, не изменён.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет.
- **Влияние на порядок разработки:** снимает процессного кандидата, заведённого
  0385; разблокирует будущие правки печати объявлений цели `st`.

## Требования и проверяемые условия

- **R1.** Вывод целей `st`/`st-at` не изменился ни на байт.
- **R2.** Все тесты зелены (в том числе юнит-тесты печати объявлений).
- **R3.** Оба модуля укладываются в лимит без записей в реестре долга.
- **R4.** Граница проходит по ответственности: типы файла против секций
  модели.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | R1 | `git diff --exit-code examples/generated/` после пересборки |

| A3 | R3 | `scripts/check-module-size.sh` |
| A4 | R4 | чтение: состав вынесенных функций |

## Редакторский слой (правило 29)

**Не применимо:** язык не затрагивается — перенос кода внутри цели генерации.

## Особенности по обратной функциональности

Полная: наблюдаемое поведение и вывод не менялись. Изменились только
внутренние пути двух функций крейта.

## Риски и зависимости

- **Незамеченный сдвиг вывода** — снят сверкой снапшотов корпуса (гейт
  0048/0274): любой сдвиг дал бы дифф.
- **Уехавшие «не туда» элементы** (`Extras`, тесты) — назвал компилятор;
  возвращены к своему предмету.
