# Анализ фичи 0279: Вложенная модель подключённого файла и подсказка

> Фича: [../features/0279-qualified-import-model-reference.md](../features/0279-qualified-import-model-reference.md) · ADR: [../adr/0279-qualified-import-model-reference.md](../adr/0279-qualified-import-model-reference.md) · тест-план: [../tests/0279-qualified-import-model-reference.md](../tests/0279-qualified-import-model-reference.md)

## Цель и контекст

Кандидат утверждал, что ссылка на вложенную модель подключённого файла
**невыразима**, и предлагал ввести квалифицированную форму `Lib::Helper`. Замер
это опроверг: форма есть — выборочный импорт. Фича заменяет несуществующую
проблему существующей: автор о форме не знает, потому что диагностика о ней
молчит.

## Замер (снят заново, правило 30)

2026-08-19, пара файлов: `lib.takt` объявляет `model Helper { start Idle … }`,
приложение подключает его.

| Запись | Ответ до фичи | После |
|---|---|---|
| `import "lib.takt"; start Main = Helper;` | `SE-001` «не найдена», молча | `SE-001` **со сноской** о выборочном импорте |
| `import "lib.takt"; start Main = Lib;` | `SE-106` + сноска (у `taktc`); **у `takt-sim` сноски нет** | сноска у обоих |
| `import "lib.takt" as Lib; start Main = Helper;` | `SE-001` | то же + сноска |
| **`import { Helper } from "lib.takt";`** | **исполняется** (`Idle`, `n = 1, 2, 3`) | не изменилось |
| **контроль** `start Main = Helpr;` (опечатка) | `SE-001` без сноски | **не изменилось** |

Два вывода:

1. **Невыразимости нет.** Кандидат проверял три формы из четырёх; четвёртая —
   работает. Новый синтаксис не нужен.
2. **Заметки терялись у эталона.** `takt-sim` строил текст диагностики своей
   функцией без цикла по заметкам, и сноска `SE-106` — единственный указатель
   выхода — до пользователя не доезжала. Класс назван в док-строке самой
   библиотеки: «копия формата в `taktc` уже расходилась однажды».

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет. Предшественники (0211, 0184, 0053, 0243) закрыты.
- **Влияние на порядок разработки:** не разблокирует.

## Требования и проверяемые условия

- **R1. `SE-001` называет выход**, когда имя найдено среди вложенных моделей:
  владельца и форму `import { Имя } from "…";`.
- **R2. Обычная опечатка сноски не получает** — иначе она станет шумом.
- **R3. Позиция сноски — объявление вложенной модели** (чужой файл): координата
  там не печатается (0243), но доезжает до редактора.
- **R4. Заметки печатает общий носитель**, которого зовут и `taktc`, и
  `takt-sim`.
- **R5. Выборочный импорт вложенной модели работает** — совет не ведёт в тупик.
- **R6. Язык не растёт:** квалифицированная ссылка не вводится.

## Критерии приёмки и способ проверки

## Особенности по обратной функциональности

Диагностика становится **полнее**: добавляется сноска и печать заметок у
эталона. Ни одна прежде работавшая запись поведения не меняет.

## Версия языка (правило 22)

**Язык не меняется** — синтаксис и семантика те же, растёт только объём
сведений в диагностике. Версия языка остаётся `0.10.0`; версия крейта
`takt-lang` поднимается на патч.

## Редакторский слой (правило 29)

**Проверка требуется и выполнена.** Новых токенов и узлов АСД нет; заметки
диагностики LSP отдаёт своим путём (`related information` строится из
`Diagnostic::notes`, которые фича только пополняет). Правок редакторского слоя
не нужно — и это ответ, а не молчание.

## Документирование (правило 24)

**Не требуется:** раздел `book/src/09-imports/` уже описывает обе формы —
подключение целиком и выборочное (`import { Thermostat } from "…";`). Фича
ничего в языке не меняет; она доносит существующее правило до автора в момент
ошибки.

## Риски и зависимости

- **Риск: сноска станет шумом.** Снят контролем (T2): подсказка появляется
  только когда имя действительно найдено среди вложенных.
- **Риск: обход по вложенным дорог.** Он идёт **только** на пути отказа, то
  есть один раз перед остановкой сборки.
- ⚠️ **Граница:** обход — один уровень вложенности; глубже подсказка молчит.
  Названо в коде.
