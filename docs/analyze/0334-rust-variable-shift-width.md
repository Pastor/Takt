# Анализ фичи 0334: сдвиг на величину не меньше ширины типа

> Фича: [../features/0334-rust-variable-shift-width.md](../features/0334-rust-variable-shift-width.md) · ADR: [../adr/0334-rust-variable-shift-width.md](../adr/0334-rust-variable-shift-width.md) · тест-план: [../tests/0334-rust-variable-shift-width.md](../tests/0334-rust-variable-shift-width.md)

## Цель и контекст

Кандидат блока 2 назывался «сдвиг на переменную величину ≥ ширины типа».
Замер расширил предмет: **половина** класса — сдвиг **влево** — не работала и
на литеральной величине, то есть вывод цели не собирался вовсе.

## Зависимости фичи (правило 17/19)

- **Зависит от:** 0326 (носитель и правило насыщения), 0263 (приведение по
  нужде), 0333 (описанное разделение обязанностей — для отрицательной
  величины). Все закрыты.
- **Влияние на порядок разработки:** снимает кандидата; заводит нового (цель
  `c` на 32- и 64-битных типах).

## Требования и проверяемые условия

- **R1.** `a >> n` при `n ≥ ширины`: цель `rust` даёт то же, что эталон.
- **R2.** То же для знакового значения (остаётся знак).
- **R3.** `a << n` и `a << литерал`: цель даёт `0` и **собирается**.
- **R4.** Контрольный вход (`n < ширины`) не изменился.
- **R5.** Порождённый код проходит `clippy -D warnings`.
- **R6.** Величина типа `u32` не получает приведения.
- **R7.** Вывод корпуса не изменился.

## Разбор

### Почему сверка значений, а не сборка

Сборка ловит только литеральный случай. Переменная величина собирается
прекрасно и **считает не то** — в релизе тихо, в отладке падением. Поэтому
сторож сверяет числа, а драйвер собирается **без `-O`**: отладочный режим —
тот, где прежний вывод паниковал; в релизе тест показал бы расхождение
значений вместо падения, то есть проверял бы половину класса.

### Что показала мутация

Снятие ветви переменной величины валит **оба** теста, и в выводе видно
исходную панику `attempt to shift right with overflow` — то есть сторож ловит
именно предмет.

## Риски

- **Стоимость `checked_*`.** Одна ветвь на сдвиг; альтернатива — неверное
  значение. Сдвигов в корпусе нет, то есть на сегодняшнем выводе цена нулевая.
