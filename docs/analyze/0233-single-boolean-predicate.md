# Анализ фичи 0233: Правило булевости условия — одно

> Фича: [../features/0233-single-boolean-predicate.md](../features/0233-single-boolean-predicate.md) · ADR: [../adr/0233-single-boolean-predicate.md](../adr/0233-single-boolean-predicate.md) · тест-план: [../tests/0233-single-boolean-predicate.md](../tests/0233-single-boolean-predicate.md)

## Цель и контекст

Свести два правила «что считать булевым условием» в одно. Требование заказчика
2026-08-05, поставлено при закрытии
[0232](../features/0232-implicit-bool-warning-delivery.md), где расхождение этих
правил (по `after`) и сделало проверку неотдаваемой.

**Язык фича не меняет.** Ни синтаксиса, ни семантики, ни набора диагностик, ни
условий их срабатывания: удаляется недостижимая ветвь и второе описание одного
правила. Версия языка остаётся `0.8.0`.

## Замер (2026-08-05)

Инструментированный прогон `check_one_ref` по `examples/`, фикстурам
`takt-lang/tests/data` и `takt-sim/tests/data`, примерам документа:

| Что | Значение |
|---|---|
| проверок условий всего | **433** |
| из них по семантическому правилу | **433** |
| из них по запасному (АСД, `Unresolved`) | **0** |
| проба `S(Ping) = End` (форма, ради которой держали запасной путь) | приходит **разрешённой** |

**Недостижимость структурна, а не случайна:** неразрешённое условие даёт ошибку
`SE-025`, а предупреждения считаются только при отсутствии ошибок — у обоих
потребителей (`taktc compile` прекращает работу; `collect_diagnostics_at`
возвращается раньше сбора предупреждений).

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет незакрытых. Прямое продолжение
  [0232](../features/0232-implicit-bool-warning-delivery.md).
- **Влияние на порядок разработки:** ничего не блокирует.

## Требования и проверяемые условия

- **R1. Правило одно.** Второго описания булевости в коде нет.
- **R2. Поведение не изменилось.** Корпус и примеры документа молчат; настоящие
  срабатывания (число в позиции условия) на месте.
- **R3. Решение о неразрешённом условии — в самом правиле**, а не в
  вызывающем: там же, где все прочие классификации.
- **R4. Молчание на неразрешённом.** Судить о булевости того, чего семантика не
  поняла, — гадание.
- **R5. Покрытие правил сохранено.** Случаи, которые проверяли тесты удалённого
  правила, проверяются по **исходнику**.
- **R6. Размер модулей соблюдён.**

## Риски и зависимости

- **Ветвь `Unresolved` не покрыть тестом.** Она недостижима через публичные
  входы; мутация «предупреждать на `Unresolved`» тестов не валит. Это честная
  граница: поведение ненаблюдаемо, и записано оно как решение, а не как случай.
- **Если конвейер начнёт отдавать `Unresolved`** в предупреждения — проверка
  промолчит вместо разбора «сырого» АСД. Цена — молчание, а не ложное
  срабатывание; в момент такой правки решение придётся пересмотреть осознанно.
- **Удалено ~40 юнит-тестов.** Они стояли на недостижимом коде; предмет покрыт
  таблицей правил по исходникам, то есть ближе к наблюдаемому.
