# Анализ фичи 0091: Правило о размере модуля переносится в docs/CODE.md

> Фича: [../features/0091-module-size-rule-in-code-md.md](../features/0091-module-size-rule-in-code-md.md) · ADR: [../adr/0091-module-size-rule-in-code-md.md](../adr/0091-module-size-rule-in-code-md.md) · тест-план: [../tests/0091-module-size-rule-in-code-md.md](../tests/0091-module-size-rule-in-code-md.md)

## Цель и контекст

Правило о размере модуля (правило **кода**) живёт только в `CLAUDE.md` (живой
контекст, правило 9), а не в своде `docs/CODE.md` (правило 23). Перенести
формулировку в свод; в `CLAUDE.md` оставить указатель + живой контекст. Решение —
Option A ADR.

## Зависимости фичи (правило 17/19)

- **Зависит от:** **нет.** Затрагивает только `docs/CODE.md` и `CLAUDE.md`. Код,
  гейт `check-module-size.sh`, реестр `module-size-baseline.txt` — **не** трогаются
  (правило уже машинно проверяется, 0027).
- **Влияние на порядок разработки:** не блокирует других.

## Требования и проверяемые условия

- **R1. Правило в своде.** `docs/CODE.md` содержит правило: размер модуля ≤ ~1000
  строк (вместе с тестами), «дели по логике», машинная проверка
  `scripts/check-module-size.sh` (precheck+CI) против реестра-долга
  `module-size-baseline.txt` (файл оттуда не имеет права расти; уложившийся в лимит
  обязан быть удалён).
- **R2. CLAUDE.md — указатель + контекст.** Формулировка правила в `CLAUDE.md`
  заменена ссылкой на `docs/CODE.md`; **дубля нет**. Живой контекст (реестр —
  узаконенный долг, поведение храповика «готовься к отказу «вырос»», выполненные
  разделения `validate/`/`lsp/`/`c_expr/`/`index/`) сохранён. Число файлов реестра
  актуализировано (22 → **18**).
- **R3. Целостность.** Ссылки целы (`check-links`), `precheck.sh` зелёный.
- **R4. Аддитивность.** Код/вывод/поведение не затронуты; версии не поднимаются.

## Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Правило в `docs/CODE.md` | инспекция |
| A2 | `CLAUDE.md` не дублирует формулировку, ссылается на свод; контекст цел; 18 файлов | инспекция + `grep` |
| A3 | Ссылки целы | `scripts/check-links.py` |
| A4 | `precheck.sh` зелёный; код не тронут | полный прогон |

## Особенности по обратной функциональности

Полностью документационная правка. Код крейтов, гейты, реестр не затрагиваются —
вывод целей и поведение неизменны; версии языка/крейтов не поднимаются.

## Риски и зависимости

- **Риск: потерять живой контекст при вырезании формулировки из `CLAUDE.md`.**
  Снижение: вырезается **только** формулировка правила; реестр-статус, ратчет и
  список разделений остаются; проба `grep` подтверждает.
- **Tier:** **Tier 3** (процесс/документация; правило кода лежит не в своде —
  вводит в заблуждение ссылку кандидата 0027).
