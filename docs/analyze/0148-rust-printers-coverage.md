# Анализ фичи 0148: Покрытие печатников цели rust тестами

> Фича: [../features/0148-rust-printers-coverage.md](../features/0148-rust-printers-coverage.md) · ADR: [../adr/0148-rust-printers-coverage.md](../adr/0148-rust-printers-coverage.md) · тест-план: [../tests/0148-rust-printers-coverage.md](../tests/0148-rust-printers-coverage.md)

## Цель и контекст

Реализовать **Option A** ADR 0148: закрыть ветви печатников цели `rust` тестами
на **текст** вывода. Работа в крейте `takt-lang`: новый файл тестов плюс правка
`rust_cond.rs` по фиксу 0148-01. Язык **не меняется**, версия языка не растёт.

## Зависимости фичи (правило 17/19)

- **Зависит от:** нет.
- **Влияние на порядок разработки:** ничего не блокирует. Оставляет открытым
  фикс [0148-02](../fixes/0148-02-rust-port-to-port-borrow.md).

## Требования и проверяемые условия

- **R1. Ветвь сверяется текстом.** Для каждой достижимой из валидного исходника
  ветви печатника проверяется **напечатанная строка**, а не факт сборки.
- **R2. Инвариант скобок.** Каждый бинарный узел условия печатается в скобках
  (ADR 0050): расхождение приоритетов C и Rust иначе **молчаливо**.
- **R3. `bit` — булев тип цели.** Сравнение `bit`-операнда с литералом даёт
  компилируемый и `clippy`-чистый вывод (фикс 0148-01).
- **R4. Целые не задеты.** У целого операнда сравнение с числом остаётся
  сравнением.
- **R5. Границы цели громкие.** Непереводимая конструкция даёт **код
  диагностики**, а не молча пропадает из вывода.
- **R6. Корпус не изменился.** `examples/generated/rust/**` — пустой дифф.
- **R7. Набор взведён.** Отключение исправленной ветви обязано валить ровно её
  тесты.

| # | Критерий | Способ проверки |

| A2 | скобки (R2) | `every_binary_condition_node_is_parenthesised` |

## Найденные дефекты

| Фикс | Что | Статус |
|---|---|---|
| [0148-01](../fixes/0148-01-rust-bit-compare.md) | сравнение `bit` с литералом → `bool == 1` (E0308) либо `bool == true` (`clippy::bool_comparison`) | **ИСПРАВЛЕН** |
| [0148-02](../fixes/0148-02-rust-port-to-port-borrow.md) | `led := btn;` → `hal.write_bit(P, hal.read_bit(Q))` → **E0499** | **ЗАВЕДЁН** |

Разделение сознательное: первый лечится **готовым** механизмом коэрции в том же
печатнике, второй вводит **новый** (временные переменные) и требует решений о
именовании, порядке вычисления и способе распознавания — то есть ADR.

## Особенности по обратной совместимости (правило 11)

Тесты **аддитивны**. Правка `rust_cond.rs` меняет вывод **только** на входе,
который прежде не компилировался вовсе: корпус этой формы не содержит, дифф
`examples/generated/rust` пуст. То есть обратная совместимость не затронута —
изменилось лишь то, что раньше не работало.

Симулятор, прочие цели и язык не задеты — **н/п**.

## Риски

- **Риск пришпилить дефект.** Снижается порядком: зонд → правка найденного →
  тест. Так и вскрылись 0148-01 и 0148-02.
- **Риск «покрыли процент, а не поведение».** Снижается тем, что каждый тест
  сверяет **строку** вывода и имеет объяснение, чем именно ветвь опасна.
- **Риск переусердствовать с коэрцией.** Снижается контрпримером A7 и мутацией
  A10.
