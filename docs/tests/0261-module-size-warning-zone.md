# Тест-план фичи 0261: Жёлтая зона гейта размера модулей

> Фича: [../features/0261-module-size-warning-zone.md](../features/0261-module-size-warning-zone.md) · анализ: [../analyze/0261-module-size-warning-zone.md](../analyze/0261-module-size-warning-zone.md) · отчёт: [../reports/0261-module-size-warning-zone.md](../reports/0261-module-size-warning-zone.md)

## Условия проверок

| # | Условие | Как проверяется | Ожидаемый результат |
|---|---|---|---|
| П1 | Контроль: маленький файл принят | сторож, проверка 1 | код 0, без предупреждений |
| П2 | Новый нарушитель ловится | сторож, проверка 2 | отказ «при лимите» |
| П3 | Рост из реестра ловится | сторож, проверка 3 | отказ «вырос» |
| П4 | Ужатие требует правки записи | сторож, проверка 4 | отказ «ужат» |
| П5 | Закрытая запись ловится | сторож, проверка 5 | отказ «уложился в лимит» |
| П6 | Запись на несуществующий файл | сторож, проверка 6 | отказ «несуществующий файл» |
| П7 | Жёлтая зона печатается и не роняет прогон | сторож, проверка 7 | код 0, в выводе «Жёлтая зона» и имя файла |
| П8 | **Контроль:** файл вне зоны | сторож, проверка 8 | «Жёлтой зоны» в выводе нет |
| П9 | Рабочее дерево: список из 8 файлов, код 0 | прогон гейта | как в задаче 0261-01 |
| П10 | Предкоммит | `./scripts/precheck.sh` | код 0 |

## Границы

Гейт по-прежнему меряет `wc -l` — строки целиком (метрика фичи 0027: правило
говорит о размере файла, и метрика обязана совпадать с тем, что видит
читатель).
