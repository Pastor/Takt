# Тест-план фичи 0384: Приведение имени константы к `q(m, n)`

> Фича: [../features/0384-fixed-cast-const.md](../features/0384-fixed-cast-const.md) · ADR: [../adr/0384-fixed-cast-const.md](../adr/0384-fixed-cast-const.md) · анализ: [../analyze/0384-fixed-cast-const.md](../analyze/0384-fixed-cast-const.md)

## Область и цель

Проверяется, что приведение имени константы к `q(m, n)` переводят все восемь
целей, значение совпадает с эталоном, а состав вывода согласован: свёрнутая
константа не печатается, используемая обычным путём — печатается.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Приведение константы | `const K: float := 2.5;`, `gain := K as q(8, 8);` | эталон и `c` дают `set_v = 2`; в выводе `640` | R1 / A1 |
| T2 | Пути согласованы | `gain = ref_gain` | `eq_v = 1` каждый такт | R1 / A1 |
| T3 | Свёрнутая константа не печатается | та же фикстура | имени `K` в порождённом C нет | R2 / A2 |
| T4 | Используемая константа печатается | `mix_v := n + BUMP;` | `BUMP` в выводе есть | R3 / A2 |
| T5 | Инструменты целей | та же фикстура | `cc`, `iec2c` + сборка C, `rustc` + `clippy`, `verilator` + `yosys` приняли | R1 / A3 |
| T6 | `SE-036` не лжёт | константа под приведением | предупреждения нет | R4 / A4 |
| T7 | `SE-036` в силе | неиспользуемая **переменная** | предупреждение выдаётся | R4 / A4 |
| T8 | Нет рантайм-`floor` | та же фикстура | `floor(` отсутствует | R1 / A2 |
| T9 | Корпус | пересборка `examples/generated/` | диффа нет | R6 / A6 |
| T10 | Мутации | «константа → `None`», «сборщик не знает о свёртке» | T1–T4 краснеют | R5 / A5 |
