# Тест-план фичи 0100: Переименование языка Lam → Takt

> Фича: [../features/0100-language-rename-takt.md](../features/0100-language-rename-takt.md) · ADR: [../adr/0100-language-rename-takt.md](../adr/0100-language-rename-takt.md) · анализ: [../analyze/0100-language-rename-takt.md](../analyze/0100-language-rename-takt.md)

## Область и цель

Фича — **сквозной ренейм идентичности** (ADR 0100, Option A): имена, расширение,
тексты. **Синтаксис и семантика языка НЕ меняются** (ключевые слова, грамматика,
проходы, генераторы тождественны). Поэтому правило 16 (примеры/контрпримеры
языка) неприменимо в части «новая семантика»: проверка — **отсутствие регресса
поведения** и **полнота ренейма**. Критерии — A1–A8 [анализа](../analyze/0100-language-rename-takt.md).

## Разбивка проверок по функциональности

Обратная функциональность (правило 11) — весь корпус тестов `takt-lang`/`takt-sim`,
вывод генераторов, публичный API, редакторные расширения. Единые условия
(T3/T5/T8) прогоняются против каждого затронутого слоя; статус — в отчёте.
