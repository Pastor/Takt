# Тест-план фичи 0303: Условное ребро состояния-композиции

> Фича: [../features/0303-composition-state-conditional-edge.md](../features/0303-composition-state-conditional-edge.md) · ADR: [../adr/0303-composition-state-conditional-edge.md](../adr/0303-composition-state-conditional-edge.md) · анализ: [../analyze/0303-composition-state-conditional-edge.md](../analyze/0303-composition-state-conditional-edge.md)

## Область и цель

Вердикт даёт **трасса**: прежний вывод был валиден — `cc -Wall -Wextra -Werror`,
`verilator`, `yosys` и `iec2c` принимали его молча. Проверяется исход автомата,
а не факт компиляции.

## Тестовые данные и окружение

Автотест — `takt-sim/tests/conformance/conformance_composition_edge_tests.rs`:
две фикстуры (сработавшее и несработавшее ребро), наблюдаемая `mark` различает
**исход**, а не факт компиляции. Каталог сборки уникален по имени потока
(инвариант 0190, двоеточие вычищается — 0244); без `cc` половина с прошивкой
пропускается, трасса эталона проверяется всегда.

T3–T6 сняты `scripts/probe.sh` и чтением порождённого кода: закреплять текст
вывода тестом не стали — снапшоты корпуса эту запись не содержат, а сверка
значений сильнее сверки текста.
