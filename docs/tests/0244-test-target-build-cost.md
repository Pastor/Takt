# Тест-план фичи 0244: Стоимость тестовых целей

> Фича: [../features/0244-test-target-build-cost.md](../features/0244-test-target-build-cost.md) · ADR: [../adr/0244-test-target-build-cost.md](../adr/0244-test-target-build-cost.md) · анализ: [../analyze/0244-test-target-build-cost.md](../analyze/0244-test-target-build-cost.md)

## Область и цель

Фича не меняет ни языка, ни поведения инструментов — она меняет **устройство
сборки тестов**. Поэтому проверяется не поведение, а два свойства: **ничего не
потеряно** (число тестов, различимость имён, уникальность временных каталогов) и
**стало быстрее** (замер до и после в одинаковых условиях).

## Тестовые данные и окружение

- Замеры — только на **устоявшейся** файловой системе и **после второго
  прогона** (класс испорченных замеров, найденный при отмене 0242).
- Каталог сборки перед каждым замером «до/после» очищается `cargo clean`, чтобы
  условия совпадали; промежуточные прогоны на частично горячем каталоге в
  сравнение не берутся.
- Окружение: toolchain `1.97.1`, `cc` (Apple clang), cmake + ninja, `iec2c`,
  verilator, yosys — как в `precheck.sh`.
