# Тест-план фичи 0209: Внешний интерфейс модели

> Фича: [../features/0209-model-external-interface.md](../features/0209-model-external-interface.md) · ADR: [../adr/0209-model-external-interface.md](../adr/0209-model-external-interface.md) · анализ: [../analyze/0209-model-external-interface.md](../analyze/0209-model-external-interface.md)

## Область и цель

Две независимые части, и у каждой свой главный риск. У стенда — **умолчание**
(ноль вместо значения делает сверку трасс зелёной при расхождении с прошивкой),
у агрегата — **форма вывода** (присваивание агрегата в C не компилируется).
Поэтому в обеих частях контр-примеры несут не меньше веса, чем примеры.
