# Тест-план 0354: Умолчание `duration` у эталона

- **Фича:** [../features/0354-sim-duration-default.md](../features/0354-sim-duration-default.md)
- **Анализ:** [../analyze/0354-sim-duration-default.md](../analyze/0354-sim-duration-default.md)
- **Дата:** 2026-08-21

## Почему сторож — сверка, а не «отказа больше нет»

Снять `SIM-005` мало: значение обязано **совпасть** с целью. Носители разные —
наносекунды у эталона (0134), миллисекунды у цели (0183), — и ошибка на этой
границе была бы молчаливой.

## Условия проверок

| № | Условие | Ожидание |
|---|---|---|
| С1 | `var d: duration;` без инициализатора, `d := d + tick_len;` по тактам | трасса `ms` эталона = трасса цели `c`: `[1000, 2000, 3000, 4000, 5000]` |
| П1 | предусловие сверки | трасса эталона **накапливающая**: мутация «целочисленный ноль» даёт `[0, 0, 0, 0, 0]` |

⚠️ Имя переменной в фикстуре — `tick_len`, а не `step`: `step` зарезервировано
в IEC 61131-3, и отказ цели `st` пришёл бы раньше предмета.
