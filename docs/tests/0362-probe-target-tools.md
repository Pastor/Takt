# Тест-план фичи 0362: Проба прогоняет инструменты целей

> Фича: [../features/0362-probe-target-tools.md](../features/0362-probe-target-tools.md) · ADR: [../adr/0362-probe-target-tools.md](../adr/0362-probe-target-tools.md) · анализ: [../analyze/0362-probe-target-tools.md](../analyze/0362-probe-target-tools.md)

## Область и цель

Проверяется инструмент снятия замера — `scripts/probe.sh` — и его сторож.
Язык не затрагивается, поэтому примеров и контрпримеров на Takt правило 16 не
требует; вместо них — **пробы-входы**, на которых измеряется поведение самого
скрипта.

## Тестовые данные и окружение

- Пробы: `nested.takt` (`[[u8; 2]; 2]`), `structfn.takt` (структура в
  параметре функции), корпус `examples/*.takt`.
- Инструменты: `cc` (Apple clang), `iec2c` MatIEC (`~/.local/bin`),
  `rustc`/`clippy-driver` 1.97.1, `verilator` 5.050, `yosys`.
- Окружение: macOS (darwin 25.5.0), toolchain из `rust-toolchain.toml`.
