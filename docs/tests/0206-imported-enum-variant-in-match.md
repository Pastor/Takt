# Тест-план фичи 0206: Вариант импортированного перечисления не разрешается в образце match

> Фича: [../features/0206-imported-enum-variant-in-match.md](../features/0206-imported-enum-variant-in-match.md) · ADR: [../adr/0206-imported-enum-variant-in-match.md](../adr/0206-imported-enum-variant-in-match.md) · анализ: [../analyze/0206-imported-enum-variant-in-match.md](../analyze/0206-imported-enum-variant-in-match.md)

## Область и цель

Фича не меняет кода — её предмет **покрытие**. Поэтому тест-план это и есть
результат фичи, а проверки строятся так, чтобы поймать возврат класса, а не
подтвердить сегодняшний успех.

⚠️ «Скомпилировалось» здесь недостаточно: вариант, разрешённый **не в тот
номер**, компилируется и исполняется, молча выбирая чужую ветвь. Поэтому
сверяются номера ветвей в выводе и трасса значений у эталона.
