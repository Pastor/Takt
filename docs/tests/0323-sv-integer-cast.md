# Тест-план 0323: приведение `as` в цели `sv`

> Фича: [../features/0323-sv-integer-cast.md](../features/0323-sv-integer-cast.md) · ADR: [../adr/0323-sv-integer-cast.md](../adr/0323-sv-integer-cast.md) · отчёт: [../reports/0323-sv-integer-cast.md](../reports/0323-sv-integer-cast.md)

## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | Расширение и сужение совпадают с эталоном | `casts_match_generated_sv` |
| П2 | Оба инструмента SV принимают модуль | тот же тест + прогон `yosys` |
| П3 | Знаковая цель печатается через `$signed` | `signed_cast_uses_signed_wrapper` |
| П4 | Регрессия и предкоммит | `cargo test --all-features`, `./scripts/precheck.sh` |

## Почему тесты именно такие

- **Сужение обязательно** (`300 as u8 = 44`): на расширении ошибка в ширине
  незаметна — старшие разряды и так нули.
- **П3 — тест устройства:** без `$signed` знаковая цель осталась бы
  беззнаковой для сравнений и сдвига, и оба инструмента приняли бы такой
  модуль молча.
