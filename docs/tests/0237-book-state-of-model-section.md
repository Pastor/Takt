# Тест-план фичи 0237: Раздел «Импорты» не описывает `S(Модель)`

> Фича: [../features/0237-book-state-of-model-section.md](../features/0237-book-state-of-model-section.md) · ADR: [../adr/0237-book-state-of-model-section.md](../adr/0237-book-state-of-model-section.md) · анализ: [../analyze/0237-book-state-of-model-section.md](../analyze/0237-book-state-of-model-section.md)

## Область и цель

Фича документная: язык не меняется. Проверяется, что описание **верно**
(соответствует поведению инструментов), **полно** в объёме ADR и **проверяемо
машиной** — пример компилируется и прогоняется, ссылка разрешается сборкой.
