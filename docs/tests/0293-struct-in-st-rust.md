# Тест-план фичи 0293: Структуры в целях `st`, `sv` и `rust`

> Фича: [../features/0293-struct-in-st-rust.md](../features/0293-struct-in-st-rust.md) · ADR: [../adr/0293-struct-in-st-rust.md](../adr/0293-struct-in-st-rust.md) · анализ: [../analyze/0293-struct-in-st-rust.md](../analyze/0293-struct-in-st-rust.md)

## Область и цель

У каждой цели — **потактовая сверка** с эталоном, а не факт компиляции: чужие
инструменты принимают и неверный вывод (порядок полей в `struct packed`,
потерянный инициализатор в ST — `iec2c` его принимал).

## Тестовые данные и окружение

Фикстура одна на три сверки —
`takt-sim/tests/data/eval/conformance_struct_init.takt`: структура из двух
полей, агрегатный инициализатор, наблюдаемая `sum = kp + ki` (и порт `probe`
для цели `rust`, где наблюдение идёт через HAL).

Сверки: `conformance_st_tests::struct_init`,
`conformance_sv_tests::struct_init`,
`conformance_rust_tests::struct_fields_match_generated_rust`. Все три мягко
деградируют при отсутствии внешнего инструмента (`iec2c`, `verilator`,
`rustc`), проверяя трассу эталона всегда.
