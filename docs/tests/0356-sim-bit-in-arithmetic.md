# Тест-план 0356: Разряд в арифметике

- **Фича:** [../features/0356-sim-bit-in-arithmetic.md](../features/0356-sim-bit-in-arithmetic.md)
- **Анализ:** [../analyze/0356-sim-bit-in-arithmetic.md](../analyze/0356-sim-bit-in-arithmetic.md)
- **Дата:** 2026-08-21

## Условия проверок

| № | Условие | Ожидание |
|---|---|---|
| П1 | `read_member(Number(0b101), .2)` | `Number(1)` |
| П2 | `read_member(Number(0b101), .1)` | `Number(0)` |
| П3 | `arith := src.7 + 1;` | эталон исполняет, значение как у цели `c` |
| П4 | `ref Done: src.7 = 1;` | переход срабатывает |
| К1 | `Boolean(true) + Number(1)` | **`TypeMismatch`** — правило S8 в силе |
| К2 | `if src.7 { … }` | условие работает (`to_bool` принимает число) |
| С1 | трасса при `acc := acc + src.7 + src.6;`, источник растёт | эталон = цель `c`: `[2, 4, 6, 8, 8]` |

⚠️ **К1 — не формальность:** без него правка читается как «S8 отменено».
Первая редакция фичи именно это и делала, и упал на ней собственный тест
правила.

⚠️ Сверка берёт **два разных** разряда и меняющийся источник: на одном разряде
и постоянном значении ошибка в номере разряда невидима (мутация «сосед» —
проверена).
