# Тест-план 0322: `match` в цели `sv`

> Фича: [../features/0322-sv-match-case.md](../features/0322-sv-match-case.md) · ADR: [../adr/0322-sv-match-case.md](../adr/0322-sv-match-case.md) · отчёт: [../reports/0322-sv-match-case.md](../reports/0322-sv-match-case.md)

## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | Значения по веткам совпадают с эталоном | `match_arms_match_generated_sv` |
| П2 | Оба инструмента SV принимают модуль | тот же тест + прогон `yosys` |
| П3 | `default` печатается всегда | `case_always_has_default` |
| П4 | Регрессия и предкоммит | `cargo test --all-features`, `./scripts/precheck.sh` |

## Почему тесты именно такие

- **Наблюдаемая меняется по веткам** (10 → 20 → 30): выбор не той ветки виден
  значением. Проверка «в выводе есть `case`» этого не показала бы.
- **П3 — тест устройства:** `case` без `default` даёт **защёлку**, и синтезатор
  сообщает об этом только предупреждением, которое легко пропустить.
