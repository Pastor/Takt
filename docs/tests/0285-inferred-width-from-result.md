# Тест-план фичи 0285: Ширина выведенного типа

> Фича: [../features/0285-inferred-width-from-result.md](../features/0285-inferred-width-from-result.md) · ADR: [../adr/0285-inferred-width-from-result.md](../adr/0285-inferred-width-from-result.md) · анализ: [../analyze/0285-inferred-width-from-result.md](../analyze/0285-inferred-width-from-result.md)

## Область и цель

Фича **меняет язык** (наблюдаемое значение), поэтому правило 16 применяется:

- **Пример:** `const STEP := 1 + 255;` — даёт `256`, ширина по результату;
- **Контрпример:** `var u: u8 := 200 + 100;` — даёт `44`, потому что ширину
  выбрал автор.

Оба вошли в языковой раздел «Типы», подраздел «Вывод типов».

⚠️ **Половина проверок — границы, а не предмет.** У этой правки две неудачные
редакции были пойманы **чужими** сторожами (вывод Ce6 и нормирование 0207);
проверки T6–T8 закрепляют их рядом с правилом, чтобы граница была видна вместе
с ним.

⚠️ **Контроль «не изменилось» обязателен** (T5): без него нельзя отличить
«починили ширину» от «поменяли вывод типов вообще».

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Сложение с переполнением операнда | `const K := 1 + 255;` | `256` у эталона и цели `c` | R1 / A1 |
| T2 | Порядок операндов не важен | `255 + 1` | `256` | R1 / A1 |
| T3 | Умножение и сдвиг | `2 * 128`, `1 << 8` | `256` | R1 / A1 |
| T4 | Значение шире разряда | `200 + 200` | `400` (было `144`) | R1 / A1 |
| T5 | Контроль: не изменилось | `300 - 44`, `250` | `256` и `250` | R1 / A2 |
| T6 | Граница: явный тип | `var u: u8 := 200 + 100;` | `44` | R2 / A3 |
| T7 | Граница: отрицательное | `var u := ~0;` | `255` | R4 / A4 |
| T8 | Граница: тип из сигнатуры | `fn get32() -> [bit;32]`, `var val := get32();` | тип `[bit;32]` | R3 / A5 |
| T9 | Корпус цел | — | `./scripts/precheck.sh` зелён без правок `examples/` | A6 |
