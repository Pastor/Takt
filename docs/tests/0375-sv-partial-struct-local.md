# Тест-план фичи 0375: Частично использованная локальная структура у цели sv

> Фича: [../features/0375-sv-partial-struct-local.md](../features/0375-sv-partial-struct-local.md) · ADR: [../adr/0375-sv-partial-struct-local.md](../adr/0375-sv-partial-struct-local.md) · анализ: [../analyze/0375-sv-partial-struct-local.md](../analyze/0375-sv-partial-struct-local.md)

## Область и цель

Проверяются требования R1…R5 анализа. Арбитр класса — **линт цели**
(`verilator -Wall`), а форма поглотителя — **синтез** (`yosys`): именно он
отвергает склейку распакованного массива.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Линт принимает частичное использование | поле записано, не прочитано | код возврата 0 | R1 / A1 |
| T2 | Линт принимает локальный массив структур | читается одно поле одного элемента | код возврата 0 | R1 / A1 |
| T3 | Синтез принимает тот же вывод | `yosys synth` | код возврата 0 | R2 / A2 |
| T4 | Поглотитель массива поэлементный | текст вывода | `_unused_cells = &{1'b0, cells[0].lo, cells[0].hi, cells[1].lo, cells[1].hi};` | R3 / A3 |
| T5 | Значения не изменились | сверка 0373 | трассы совпадают | R4 / A4 |
| T6 | Вывод корпуса не изменился | `precheck.sh` | без диффа | R5 / A5 |
| M1 | Мутация: поглотитель всегда «целиком» | — | падают T3 и T4 | R2, R3 |
| M2 | Мутация: поглотителя нет | — | падают T1, T2 и T4 | R1 |
