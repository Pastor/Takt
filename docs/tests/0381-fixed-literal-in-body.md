# Тест-план фичи 0381: Понижение q-литерала в телах и условиях

> Фича: [../features/0381-fixed-literal-in-body.md](../features/0381-fixed-literal-in-body.md) · ADR: [../adr/0381-fixed-literal-in-body.md](../adr/0381-fixed-literal-in-body.md) · анализ: [../analyze/0381-fixed-literal-in-body.md](../analyze/0381-fixed-literal-in-body.md)

## Область и цель

Проверяются R1…R6. Арбитр — **сверка значений**: прежний вывод цели `c` был
валидным C, разницу между 2 и 512 видит только трасса.

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|

| T2 | Литерал ребра понижен | вывод цели `c` | есть `> 25600`, нет `100.0` | R2 / A2 |
