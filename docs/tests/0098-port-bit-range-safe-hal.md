# Тест-план фичи 0098: диапазон бита адреса порта и безопасный дефолтный HAL

> Фича: [../features/0098-port-bit-range-safe-hal.md](../features/0098-port-bit-range-safe-hal.md) · ADR: [../adr/0098-port-bit-range-safe-hal.md](../adr/0098-port-bit-range-safe-hal.md) · закрывает [фикс 0020-01](../fixes/0020-01-port-bit-out-of-range.md)

## Область и цель

Проверяется устранение **UB** и **молчаливо-неверного чтения** в дефолтном HAL
цели `c-hal`, а также диагностика бита вне диапазона. Критерий 2 фикса требует
проверки **на значениях**, а не грепом: компиляция UB не ловит.

## Проверки

| # | Проверка | Предусловие | Ожидаемый результат | R/A |
|---|---|---|---|---|
| T1 | Бит в диапазоне валиден | `bit := 0x1000:63` | Генерация успешна | R1 / A1 |
| T2 | Бит вне диапазона | `bit := 0x1000:64` | **`SE-060`**, текст называет `[0, 63]` | R1 / A1 |
| T3 | **Значенческий: широкий бит без UB** | бит 33, слово `1<<33` | `read_bit` = 1 (читается `uint64_t`); бит 2 независим → «1001» | R2 / A2 |
| T4 | Границы ширины слова | `word_bytes_for_bit` | 0→1, 8→2, 16→4, 32→8, 33→8, −1→1 | R2 / A2 |
| T5 | **Гейт компиляции c-hal** | `precheck.sh` | 7 примеров с адресами компилируются (`cc -c`); `elevator_mini` — пропуск SE-052 | R4 / A3 |
| T6 | Корпус: `extend_complex` не правлен | генерация | бит 33 валиден (uint64); вывод цели `c` байт-в-байт прежний | R5 / A4 |
| T7 | Прежние ширины HAL не сломаны | `test_hal_port_width_follows_c_type` | bit→1, float→8/4, u16→2 (регресс-сторож 0029) | — |

## Разбивка по функциональности

| Функциональность | Ожидание | Проверка | Статус |
|---|---|---|---|
| Диагностика `SE-060` | ошибка на бит вне [0,63] | T1, T2 | ✅ |
| Дефолтный HAL c-hal | нет UB, чтение по слову | T3, T4, T7 | ✅ |
| Гейт компиляции c-hal | c-hal компилируется | T5 | ✅ |
| Цель `c`, прочие цели | не задеты | T6, детерминизм-гейт | ✅ |
| Язык | не меняется → версия не растёт | — | ✅ |

## Тестовые данные и окружение

- **Юнит + значенческий:** `grammar/tests/hal_bit_range_tests.rs`
  (`compile_to_c_hal` API); границы слова — `c_hal::tests::bit_word_width_by_bit_index`.
- ⚠️ **T3 эмулирует MMIO через `mmap(MAP_FIXED)`** по адресу порта (16 ТБ —
  заведомо свободен и на macOS, и на Linux). Разыменовать абсолютный адрес на
  хосте иначе нельзя. При недоступности `cc`/`mmap` — явный пропуск.
- **Гейт c-hal** требует `cc`; при отсутствии — пропуск (как C-гейт).

## Что план сознательно НЕ проверяет

- **Единую ширину доступа по адресу** (C-1 ADR: per-port, а не per-word) — за
  Option B (язык выражает ширину слова), вне объёма Tier-1 фикса.
- **Линковку c-hal в исполняемый файл** — extern fn/main требуют драйверов на
  пример; гейт компилирует в объект (критерий «c-hal компилируется»).
