# Тест-план фичи 0277: Координата отказа цели — место употребления

> Фича: [../features/0277-expression-usage-position.md](../features/0277-expression-usage-position.md) · ADR: [../adr/0277-expression-usage-position.md](../adr/0277-expression-usage-position.md) · анализ: [../analyze/0277-expression-usage-position.md](../analyze/0277-expression-usage-position.md)

## Область и цель

Проверяется **координата** отказа цели `c` и устойчивость носителя (не залипает,
не занимает чужого). Требования R1…R6 и критерии A1…A4 — в
[анализе](../analyze/0277-expression-usage-position.md).

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | R/A |
|---|---|---|---|---|
| T1 | Координата употребления | `res := mem[1:2];` в строке 7 | `CC-022`, строка 7 (было — строка объявления `mem`) | R1 / A1 |
| T2 | **Контроль:** отказ вне оператора | скалярный инициализатор массива | `CC-017` **без** координаты — чужую не занимает | R2 / A2 |
| T3 | Позиция следует за оператором | четыре оператора, отказ в последнем | координата последнего, не первого | R3 / A3 |
| T4 | Носитель как таковой | прямые вызовы | внутри оператора его позиция вытесняет любую выведенную; вне — остаётся своя | R4 / A4 |
| T5 | Устройство | дифф | `ExpressionNode` не изменён; сигнатуры печатников прежние | R5, R6 / A4 |
| T6 | Гейты | — | `precheck.sh` зелён | — / A4 |
