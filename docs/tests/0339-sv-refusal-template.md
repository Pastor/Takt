## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | Сообщение — префикс плюс текст автора отказа | `refusal_text_reads_as_a_sentence` |
| П2 | Объяснение политики — заметкой (ровно одна) | там же |
| П3 | Носитель шаблона один | `sv002_has_a_single_definition` |
| П4 | Прочие тесты цели зелёные | `cargo test --test targets` |
| П5 | Предкоммит | `./scripts/precheck.sh` |

## Почему тесты именно такие

Текст диагностики машиной иначе не проверить: гейт кодов (0290) сверяет
**наличие** кода, а не то, читается ли сообщение. Поэтому П1 проверяет
конкретные свойства строки, а не её целиком — иначе тест ломался бы от любой
правки формулировки.
