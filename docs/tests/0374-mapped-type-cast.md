# Тест-план фичи 0374: Приведение, совпадающее после отображения типа

> Фича: [../features/0374-mapped-type-cast.md](../features/0374-mapped-type-cast.md) · ADR: [../adr/0374-mapped-type-cast.md](../adr/0374-mapped-type-cast.md) · анализ: [../analyze/0374-mapped-type-cast.md](../analyze/0374-mapped-type-cast.md)

## Область и цель

Проверяются требования R1…R6 анализа. Сторожа двух родов: **текст** вывода
(что печатается и что не печатается) и **прогон гейта цели** — именно он и был
арбитром класса.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Гейт цели `rust` принимает вывод | вход `ms := d as u32;` при `d: duration`, `clippy-driver -D warnings` | код возврата 0 | R1 / A1 |
| T2 | Приведение не печатается тремя целями | тот же вход | нет `as u32`, `(uint32_t)model->d`, `32'(` | R2 / A2 |
| T3 | Контрпример: другой тип | `w := b as u16;` при `b: u8` | приведение печатается всеми тремя | R3 / A3 |
| T4 | Контрпример: сужение от длительности | `tiny := d as u8;` при `d: duration` | приведение печатается всеми тремя | R4 / A4 |
| T5 | Совпадение типов Takt (регресс 0361) | `q := r as u16;` при `r: u16` | приведение не печатается | R2 / A2 |
| T6 | Значения не изменились | сверки `duration` у `c`, `rust`, `st`, `sv` | трассы совпадают с эталоном | R5 / A5 |
| T7 | Пересчёта единиц нет | текст вывода `c` и `rust` | нет `1000000`, `/ 1000`, `* 1000` | R5 / A5 |
| T8 | Вывод корпуса не изменился | `precheck.sh` | `examples/generated/` без диффа | R6 / A6 |
