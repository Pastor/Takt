# Тест-план фичи 0298: Списки лексики раздела «Лексика» сверяются с языком

> Фича: [../features/0298-book-lexicon-lists-sync.md](../features/0298-book-lexicon-lists-sync.md) · анализ: [../analyze/0298-book-lexicon-lists-sync.md](../analyze/0298-book-lexicon-lists-sync.md) · отчёт: [../reports/0298-book-lexicon-lists-sync.md](../reports/0298-book-lexicon-lists-sync.md)

## Предмет проверки

Классы L1…L4 гейта `check-book-keywords.py` и согласованность раздела
«Лексика» с лексером и грамматикой. Отдельно — **утверждение** раздела о
словах LTL: оно проверяется прогоном компилятора, а не чтением.

## Условия проверок

| # | Условие | Как проверяется | Ожидаемый результат |
|---|---|---|---|
| П1 | L1: слово лексера мимо таблицы раздела | `--self-test` (проба без `while`) | находка `("L1", "while")` |
| П2 | L2: слово раздела мимо лексера | `--self-test` (проба со словом `pragma`) | находка `("L2", "pragma")` |
| П3 | L2: контекстное слово LTL названо ключевым | `--self-test` (проба со словом `X`) | находка `("L2", "X")` |
| П4 | L3: терминал мимо таблиц раздела | `--self-test` (проба без `.`) | находка `("L3", ".")` |
| П5 | L4: знак раздела мимо грамматики | `--self-test` (проба со знаком `-->`) | находка `("L4", "-->")` |
| П6 | Контроль: согласованный вход чист | вторая половина `--self-test` | находок нет |
| П7 | Нет раздела/таблицы — ошибка | разбор `lexical_table` | явное сообщение, не пустое множество |
| П8 | Рабочее дерево согласовано | прогон гейта | «40 ключевых слов и 36 знаков» |
| П9 | Примеры и контрпример по словам LTL | `taktc compile -t c` | 7 имён компилируются; `var model` — `SY-002` |
| П10 | Документ собирается, глифы на месте | `make -C book build`, `check-book-glyphs.py` | код 0 |
| П11 | Предкоммит зелёный | `./scripts/precheck.sh` | код 0 |

## Примеры и контрпримеры (правило 16)

**Пример** (законно — слова LTL как имена):

```takt
var X: u8 := 1;
var Guard: u8 := 5;
var total: u8 := 0;

start Run {
    always { total := X + Guard; }
}
```

**Контрпример** (незаконно — настоящее ключевое слово именем):

```takt
var model: u8 := 1;
```

→ `SY-002: нераспознанный токен 'model', ожидалось identifier, "X", "F", "G",
"U", "R", "LTL", "Guard"`.

⚠️ Контрпример обязателен: без него «имя компилируется» не отличает
контекстное слово от любого другого — и утверждение раздела осталось бы
непроверенным.

## Границы

Гейт сверяет **состав** таблиц, а не группировку по назначению: смысловое
деление остаётся на человеке (правило 4).
