# Тест-план фичи 0124: Экспорт графов верификации (Крипке/Бюхи/произведение) в Graphviz DOT

> Фича: [../features/0124-verify-graph-export.md](../features/0124-verify-graph-export.md) · ADR: [../adr/0124-verify-graph-export.md](../adr/0124-verify-graph-export.md) · анализ: [../analyze/0124-verify-graph-export.md](../analyze/0124-verify-graph-export.md)

## Область и цель

Проверить экспорт графов верификации в Graphviz DOT (флаг `taktc verify
--emit-graph`) — критерии приёмки A1–A6 ADR 0124: валидность DOT, различимость
старт/принимающих, отказ без свойства, совпадение отбора Крипке с проверкой,
неизменность прежнего вывода.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | `kripke_to_dot` | управляющая Крипке | `digraph Kripke`, старт-ребро в начальную вершину, все состояния — узлы | A1 |
| T2 | `buchi_to_dot` | автомат `¬(F Filling)` | принимающие — `doublecircle`, начальные — точки-источники | A2 |
| T3 | `product_to_dot` | произведение для `F Ready` | узлы — пары `состояние,qN` | A3 |
| T4 | data-path метка | предикат над bit-var (0068) | метка вершины несёт истинный атом (`A\n{On}`) | A5 |
| T5 | регресс `\n` | любая метка с переносом | одиночный `\n` (перенос DOT), не `\\n` | A1 |
| T6 | экранирование | метка с кавычкой/слэшем | кавычка/слэш экранированы | A1 |
| T7 | разбор `--emit-graph` | раздельная/слитная форма | `kripke`/`buchi`/`product`; умолчание — нет | A1–A3 |
| T8 | негодное значение | `--emit-graph kripk` / без значения | ошибка разбора (не молчаливая проверка) | A4 |
| T9 | `buchi`/`product` без `-p` | нет `--property` | понятный отказ, код ≠ 0 | A4 |
| T10 | рендер | DOT из T1 через `dot -Tsvg` | валидный SVG (ручная проверка) | A1 |
| T11 | прежний вывод | обычный `verify`/`--trace` | байт-в-байт неизменен | A6 |

## Разбивка проверок по функциональности

T1–T6, T10 — эмиттеры (`verification::dot`, юнит-тесты). T7–T9 — CLI-разбор
(`bin/taktc.rs`, юнит-тесты). T11 — весь корпус `verify` (существующие тесты
`verify.rs` + гейт детерминизма 0048 в `precheck.sh`).

Статус: T1 ✅ · T2 ✅ · T3 ✅ · T4 ✅ · T5 ✅ · T6 ✅ · T7 ✅ · T8 ✅ · T9 ✅ ·
T10 ✅ (ручной рендер) · T11 ✅ (`precheck.sh` зелёный).
