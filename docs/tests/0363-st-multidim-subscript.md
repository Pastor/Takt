# Тест-план фичи 0363: Индексация многомерного массива у цели st

> Фича: [../features/0363-st-multidim-subscript.md](../features/0363-st-multidim-subscript.md) · ADR: [../adr/0363-st-multidim-subscript.md](../adr/0363-st-multidim-subscript.md) · анализ: [../analyze/0363-st-multidim-subscript.md](../analyze/0363-st-multidim-subscript.md)

## Область и цель

Проверяется поведение цели `st` на многомерном массиве — валидность вывода
(`iec2c`, затем `cc`) и **совпадение значений** с эталоном.

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
