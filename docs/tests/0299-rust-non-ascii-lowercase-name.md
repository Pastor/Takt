# Тест-план фичи 0299: Регистр имени приводится по Unicode

> Фича: [../features/0299-rust-non-ascii-lowercase-name.md](../features/0299-rust-non-ascii-lowercase-name.md) · ADR: [../adr/0299-rust-non-ascii-lowercase-name.md](../adr/0299-rust-non-ascii-lowercase-name.md) · анализ: [../analyze/0299-rust-non-ascii-lowercase-name.md](../analyze/0299-rust-non-ascii-lowercase-name.md)

## Область и цель

Проверяются нормализация имени, форма вывода цели `rust` и приёмка настоящим
`clippy -D warnings`. Требования R1…R6 и критерии A1…A5 — в
[анализе](../analyze/0299-rust-non-ascii-lowercase-name.md).

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | R/A |
|---|---|---|---|---|
| T1 | Не-ASCII имя поднимается | `out кнопка` | вариант `Кнопка`, строчного варианта нет | R1 / A1 |
| T2 | **Контроль:** верные имена | `out Кнопка`, `out button` | не изменились | R2 / A2 |
| T3 | Коллизия регистра | `out кнопка` и `out Кнопка` | `RS-005` с причиной | R4 / A3 |
| T4 | Настоящий `clippy -D warnings` | три входа | принято | R5 / A4 |
| T5 | Нормализация как таковая | `кнопка`, `кнопка_пуска`, `Кнопка`, `пуск_button` | `Кнопка`, `КнопкаПуска`, `Кнопка`, `ПускButton` | R1 / A1 |
| T6 | Корпус и гейты | — | снимки не изменились, `precheck.sh` зелён | R6 / A5 |
