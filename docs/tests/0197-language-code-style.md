# Тест-план фичи 0197: Стиль кода языка Takt

> Фича: [../features/0197-language-code-style.md](../features/0197-language-code-style.md) · ADR: [../adr/0197-language-code-style.md](../adr/0197-language-code-style.md) · анализ: [../analyze/0197-language-code-style.md](../analyze/0197-language-code-style.md)

## Область и цель

Фича документная: проверяется не поведение программы, а **соответствие текста
инструменту**. Требования R1…R7, критерии A1…A9 анализа.

Главная проверка — **T3**: извлечь все блоки ```takt из раздела и прогнать
`taktc fmt --check`. Свод о стиле, чьи примеры не проходят собственный канон,
опровергает сам себя; ровно это и случилось с первой редакцией.

⚠️ Правило 4: часть утверждений раздела (уместность имени, польза комментария)
машинно непроверяема и остаётся на человеке. Тест-план это фиксирует, а не
делает вид, что покрывает.

## Тестовые данные и окружение

**Вход для T2** — модель с нарочно сбитым оформлением (без пробелов, со
сбитыми отступами, с однострочными телами, с `if/else`), пропускаемая через
`taktc fmt --stdin`.

**Вход для T3** — все блоки ```takt самого раздела, извлечённые из Markdown.

**Окружение:** macOS (Darwin 25.5.0), толчейн `1.97.1`; `./scripts/precheck.sh`.
