# Тест-план 0353: Умолчание переменной у цели `c`

- **Фича:** [../features/0353-c-default-init.md](../features/0353-c-default-init.md)
- **Анализ:** [../analyze/0353-c-default-init.md](../analyze/0353-c-default-init.md)
- **Дата:** 2026-08-21

## Слои

| Слой | Что доказывает |
|---|---|
| 1. эмиссия | нужная форма для каждого из четырёх типов |
| 2. потактовая сверка | значение **верное**: трасса цели `c` = трасса эталона |

⚠️ Второй слой обязателен: мусор стека компилируется и линтуется без единого
замечания — расхождение только в значениях.

## Примеры

| № | Вход | Ожидание |
|---|---|---|
| П1 | `var n: u8;` | `model->n = 0;` |
| П2 | `var a: [u8; 3];` | три присваивания по элементам |
| П3 | `var w: [bit; 128];` | **два** присваивания по словам, не 128 |
| П4 | `struct In { v: u8 } struct Out { i: In, n: u8 } var s: Out;` | `model->s.i.v = 0;` и `model->s.n = 0;` |

## Контрпримеры

| № | Вход | Ожидание | Что ловит |
|---|---|---|---|
| К1 | `var n: u8 := 7;` | `model->n = 7;`, нуля нет | подмену авторского значения умолчанием |
| К2 | неиспользуемая `var spare: u8;` | в выводе её нет вовсе | обнуление несуществующего поля — вывод не собрался бы |

## Потактовая сверка

| № | Вход | Ожидание |
|---|---|---|
| С1 | три формы (скаляр, элемент массива, поле структуры) без инициализаторов, значения растут по тактам | трасса эталона = трасса цели `c`: `[6, 12, 18, 24, 24]` |

⚠️ Харнесс сверки **не обнуляет** модель (`ConformanceDefaultInit m;` без
`= {0}`): обнуление снаружи скрыло бы ровно тот дефект, который лечит фича.
Штатные харнессы корпуса поступают так же.

## Регресс

- `cargo test --test targets c_default_init_tests::`
- `cargo test --test conformance conformance_default_init`
- полный `./scripts/precheck.sh` (гейт цели `c` под `-Wall -Wextra -Werror`,
  оба режима сборки).
