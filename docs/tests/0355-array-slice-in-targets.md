# Тест-план 0355: Срез массива у целей

- **Фича:** [../features/0355-array-slice-in-targets.md](../features/0355-array-slice-in-targets.md)
- **Анализ:** [../analyze/0355-array-slice-in-targets.md](../analyze/0355-array-slice-in-targets.md)
- **Дата:** 2026-08-21

## Слои

| Слой | Что доказывает |
|---|---|
| 1. носитель (юнит-тесты) | границы и пригодность типа |
| 2. эмиссия по целям | форма вывода у `c`, `st`, `rust`, `sv` |
| 3. настоящие инструменты | `cc`, `iec2c`, `clippy -D warnings`, `verilator` принимают вывод |
| 4. потактовая сверка | **значение** верно: скопирован тот кусок |

⚠️ Четвёртый слой обязателен: инструменты целевых языков принимают и неверный
срез — скопировать не тот кусок есть валидный код.

## Примеры

| № | Вход | Ожидание |
|---|---|---|
| П1 | `part := src[1:3];` | четыре цели печатают два присваивания со смещением |
| П2 | `src[:2]`, `src[2:]`, `src[:]` | границы — края |
| П3 | вывод четырёх целей | принят настоящими инструментами |

## Контрпримеры

| № | Вход | Ожидание | Что ловит |
|---|---|---|---|
| К1 | `res := mem[1:2];` при `mem: [bit;8]` | отказ у всех четырёх | печать поэлементно над скаляром — невалидный вывод |
| К2 | `res := mem[1:2];` при `res: u8` | отказ | то же со стороны приёмника |
| К3 | позиция отказа | строка **оператора** | свой отказ на месте дал бы позицию объявления |

## Потактовая сверка

| № | Вход | Ожидание |
|---|---|---|
| С1 | источник меняется по тактам, срез `src[1:3]` | трасса `(lo, hi)` эталона = трасса цели `c` |

⚠️ Границы среза смещены: при нулевом начале ошибка в `start` невидима
(мутация `start = 0` роняет сверку — проверено).
