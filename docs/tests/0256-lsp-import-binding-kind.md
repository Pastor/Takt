# Тест-план фичи 0256: Символ формы `import { A }` объявляется видом Model

> Фича: [../features/0256-lsp-import-binding-kind.md](../features/0256-lsp-import-binding-kind.md) · ADR: [../adr/0256-lsp-import-binding-kind.md](../adr/0256-lsp-import-binding-kind.md) · анализ: [../analyze/0256-lsp-import-binding-kind.md](../analyze/0256-lsp-import-binding-kind.md)

## Область и цель

Проверяется **согласие двух курсоров** на одном имени и целость границы: форма
`import "файл" as M;` обязана остаться именем модели. Проверки идут на ответ
сервера (`references`, `rename`), а не на устройство слоя.

⚠️ Ловушка: равенство ответов доказывает мало, если оба ответа пусты —
поэтому рядом стоит проверка «ответ непуст». Обе ошибки первой пробы вели
именно туда.

## Тестовые данные и окружение

- **`ws0153/ok/`** — библиотека и два потребителя: формы `import "файл";` и
  `import { speed } from "файл";`. Счёт вхождений в существующих тестах 0153
  служит **регрессом** для правки `consumer_occurrences`.
- **`ws0153/alias/`** — новая фикстура фичи: потребитель формы
  `import "файл" as Lib;` для контроля границы.
- **`examples/pid_heater.takt`** — вход замера (11 вхождений `meas` в теле).
- **Окружение:** macOS (darwin 25.5.0), Rust 1.97.1, тесты под `--all-features`.
