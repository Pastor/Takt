# Тест-план 0342: список зарезервированных имён IEC

> Фича: [../features/0342-st-reserved-names.md](../features/0342-st-reserved-names.md) · ADR: [../adr/0342-st-reserved-names.md](../adr/0342-st-reserved-names.md) · отчёт: [../reports/0342-st-reserved-names.md](../reports/0342-st-reserved-names.md)

## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | Каждая запись списка отвергается `iec2c` | `every_reserved_name_is_rejected_by_iec2c` |
| П2 | Контрольное имя принимается | там же (иначе проверка вырождена) |
| П3 | Список берётся из исходника цели | чтение `st_reserved.rs` в тесте |
| П4 | Предкоммит | `./scripts/precheck.sh` |

## Почему тесты именно такие

Знание о чужом инструменте проверяется **прогоном** этого инструмента.
Проверка чтением стандарта повторила бы ошибку, из-за которой список отстал.
