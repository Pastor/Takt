# Тест-план фичи 0085: Константа версии языка в коде + гейт синхронизации с README

> Фича: [../features/0085-language-version-constant.md](../features/0085-language-version-constant.md) · ADR: [../adr/0085-language-version-constant.md](../adr/0085-language-version-constant.md) · анализ: [../analyze/0085-language-version-constant.md](../analyze/0085-language-version-constant.md)

## Область и цель

Проверить, что версия языка имеет единственный источник истины в коде
(`grammar::LANGUAGE_VERSION`), что гейт `check-language-version.sh` ловит рассинхрон
с `README.md`, и что фича аддитивна (вывод целей и симулятора неизменен). Фича
**не** синтаксическая/семантическая (язык не меняется), поэтому примеры/контрпримеры
языка (правило 16) не заводятся — контрпримеры здесь это **красные состояния
гейта** (рассинхрон, нет/дубль якоря).
