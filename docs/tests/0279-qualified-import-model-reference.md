# Тест-план фичи 0279: Вложенная модель подключённого файла и подсказка

> Фича: [../features/0279-qualified-import-model-reference.md](../features/0279-qualified-import-model-reference.md) · ADR: [../adr/0279-qualified-import-model-reference.md](../adr/0279-qualified-import-model-reference.md) · анализ: [../analyze/0279-qualified-import-model-reference.md](../analyze/0279-qualified-import-model-reference.md)

## Область и цель

Проверяются **полнота диагностики** (сноска и её содержание), **отсутствие
шума** (контроль на опечатке) и **доставка заметок** до пользователя эталона.
Требования R1…R6 и критерии A1…A5 — в
[анализе](../analyze/0279-qualified-import-model-reference.md).

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | R/A |
|---|---|---|---|---|
| T1 | Подсказка о выборочном импорте | `import "lib.takt"; start Main = Helper;` | `SE-001` со сноской, называющей владельца `Lib` и форму `import { Helper } from …` | R1, R3 / A1 |
| T2 | **Контроль:** опечатка | `start Main = Helpr;` | `SE-001` **без** сноски | R2 / A2 |
| T3 | Совет не ведёт в тупик | `import { Helper } from "lib.takt";` | дерево строится, `Helper` видна импортёру | R5 / A4 |
| T4 | Заметки у эталона | `import "lib.takt"; start Main = Lib;`, прогон **бинарника** `takt-sim` | в stderr есть `[SE-106]` **и** `примечание:` с именем вложенной модели | R4 / A3 |
| T5 | Язык не вырос | — | правок грамматики, лексера и редакторского слоя нет | R6 / A5 |
| T6 | Гейты | — | `./scripts/precheck.sh` зелён | — / A5 |
