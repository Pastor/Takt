# Тест-план фичи 0086: `var q: u8;` без инициализатора → `SIM-009`

> Фича: [../features/0086-sim-var-without-initializer.md](../features/0086-sim-var-without-initializer.md) · ADR: [../adr/0086-sim-var-without-initializer.md](../adr/0086-sim-var-without-initializer.md) · анализ: [../analyze/0086-sim-var-without-initializer.md](../analyze/0086-sim-var-without-initializer.md)

## Область и цель

Проверить, что переменная без инициализатора существует со значением по умолчанию
(нулевым по типу), чтение её и чтение в теле не дают `SIM-009`, а порты/константы
и «истинно не найденное имя» не регрессируют.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Скаляр без init читается | `var q: u8; var flag: bit; var ratio: q(8,8);` | `q`→0, `flag`→0, `ratio`→repr 0 (значения захвачены зондом) | R1,R2 / A1 |
| T2 | Чтение в теле проходит | `always { seen := q; }` | прогон не `Failed` (нет SIM-009); `seen_q`→0, `seen_flag`→0, `seen_ratio`→repr 0 | R1 / A2 |
| T3 | Ловушка взведена | откат фикса | `unit.variable("q")` → `None` → `num()` паникует (тест естественно падает) | R1 / A1 |
| T4 | `Unresolved` не задет | неизвестное имя в `MockContext` | `predicate.rs` SIM-009-тест зелёный (истинно «не найдена») | R3 / A4 |
| T5 | Нет регресса симуляции | весь корпус | `cargo test -p simulation -- --test-threads=1` зелёный (вкл. conformance C/SV/rust/st) | R4 / A3 |
| T6 | Кодоген неизменен | весь `examples/` | `git diff examples/generated/` пуст; гейт 0048 | R5 / A5 |
| T7 | `precheck.sh` зелёный | все инструменты | `EXIT=0` | R5 / A5 |
