# Тест-план фичи 0217: Ветвь-заглушка до будущей задачи переживает саму задачу

> Фича: [../features/0217-stub-branch-gate.md](../features/0217-stub-branch-gate.md) · ADR: [../adr/0217-stub-branch-gate.md](../adr/0217-stub-branch-gate.md) · анализ: [../analyze/0217-stub-branch-gate.md](../analyze/0217-stub-branch-gate.md)

## Область и цель

Фича добавляет реестр заглушек и гейт. Проверки закрывают три вопроса:

1. **Каждое из трёх условий отказа работает** — иначе храповик держит лишь на
   бумаге (T1–T3).
2. **Гейт не шумит** — `ПОСТОЯННЫЙ`, комментарии и законные записи молчат
   (T4, T5).
3. **Найденное не потеряно** — две живые заглушки заведены фичами с пробами
   (T7).

⚠️ Проверять гейт нужно **внешней мутацией**, а не только самотестом: самотест
гоняет синтетические данные, а мутация — настоящий реестр и настоящий код.
