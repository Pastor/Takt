# Тест-план фичи 0208: Три константных вычислителя компилятора живут порознь

> Фича: [../features/0208-const-evaluators-unification.md](../features/0208-const-evaluators-unification.md) · ADR: [../adr/0208-const-evaluators-unification.md](../adr/0208-const-evaluators-unification.md) · анализ: [../analyze/0208-const-evaluators-unification.md](../analyze/0208-const-evaluators-unification.md)

## Область и цель

Фича — **рефакторинг**: поведение не меняется. Поэтому проверки сторожат не
исправление, а **равносильность**: одно выражение обязано давать одно значение в
обеих позициях языка, а особенности адреса — сохраниться.

⚠️ Из этого прямо следует, что мутация здесь ничего не показывает: тесты зелены
и на версии до правки. Их ценность в будущем — они поймают расхождение, когда
правило поправят в одной таблице из двух. Так и задумано.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Одно значение в обеих позициях | десять операций (`+ - * / % << >> & \| ^`) в `address p = …` и `const K: i64 := …` | значения совпадают | R1 / A1 |
| T2 | Деление на ноль | `8 / 0` в обеих позициях | отказ; у адреса — `SE-055` с прежним текстом | R2 / A2 |
| T3 | Граница сдвига | `1 << 64` и `1 << 63` | 64 — отказ у обоих; 63 — значение | R1, R2 / A2 |
| T4 | Сравнение в адресе | `1 < 2` в `address` | отказ матчера со списком допустимых форм | R4 / A2 |
| T5 | Обёртка по 64 битам | `i64::MAX + 1` | `i64::MIN` | R3 / A3 |
| T6 | Таблица сама по себе | юнит-тесты `int_ops` | обёртка, деление на ноль, границы сдвига, булев результат, отказ на неизвестной операции, равносильность сужения | R1, R3 / A4 |
| T7 | Корпус | предкоммит | `examples/generated/` без изменений | R6 / A5 |
| T8 | Предкоммит | `./scripts/precheck.sh` | код 0 | — / A5 |

⚠️ В T1 тип константы задан **явно широким** (`i64`): с выведенным типом ширину
задал бы левый операнд, и `1 << 8` нормировалось бы в ноль по правилу 0207 —
сравнивались бы ширины типов, а не таблицы операций.
