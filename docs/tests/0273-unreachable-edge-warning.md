# Тест-план фичи 0273: Недостижимое ребро — предупреждение `SE-116`

> Фича: [../features/0273-unreachable-edge-warning.md](../features/0273-unreachable-edge-warning.md) · ADR: [../adr/0273-unreachable-edge-warning.md](../adr/0273-unreachable-edge-warning.md) · анализ: [../analyze/0273-unreachable-edge-warning.md](../analyze/0273-unreachable-edge-warning.md)

## Область и цель

Проверяются **срабатывание** новой диагностики, её **полнота** (все рёбра) и
**отсутствие шума** (законная идиома, корпус). Требования R1…R7 и критерии
A1…A6 — в [анализе](../analyze/0273-unreachable-edge-warning.md).
