# Тест-план фичи 0231: Текст диагностики без внутреннего представления

> Фича: [../features/0231-diagnostic-text-no-debug.md](../features/0231-diagnostic-text-no-debug.md) · ADR: [../adr/0231-diagnostic-text-no-debug.md](../adr/0231-diagnostic-text-no-debug.md) · анализ: [../analyze/0231-diagnostic-text-no-debug.md](../analyze/0231-diagnostic-text-no-debug.md)

## Область и цель

Проверяются **тексты** диагностик — то, что читает автор программы, — и
пригодность самого сторожа. Предмет специфичен: сторож, который нельзя завалить
возвратом дефекта, ничего не сторожит, поэтому мутация здесь равноправна с
прогоном.

Файлы: `takt-lang/tests/diagnostic_text_tests.rs`; обновлённый юнит-тест
`semantic::validate::tests::ast_summary_array_var`.

## Тестовые данные и окружение

- Признаки внутреннего представления взяты из **реальных** дампов, которые видел
  пользователь (`Source(`, `Identifier {`, `Integer {`), а не придуманы.
- Пробы покрывают диагностики, которых фикстуры не порождают; список назван в
  тесте и обязан расти вместе с находками.
- Мутации выполняются вручную с немедленным откатом.
