# Тест-план фичи 0138: измерение покрытия тестами

> Фича: [../features/0138-coverage-measurement.md](../features/0138-coverage-measurement.md) · ADR: [../adr/0138-coverage-measurement.md](../adr/0138-coverage-measurement.md) · анализ: [../analyze/0138-coverage-measurement.md](../analyze/0138-coverage-measurement.md)

## Область и цель

Фича инфраструктурная: код проекта не меняется. Проверяется, что чужая
конфигурация убрана, замер воспроизводим, предкоммит не подорожал — и что
**результатом** стал список слепых зон, а не только процент.

⚠️ Порога покрытия нет намеренно (решение заказчика), поэтому «покрытие не ниже
X» в план не входит: такой проверки в проекте не будет.

## Тестовые данные и окружение

Автоматических тестов у фичи нет — предмет проверки инфраструктурный.

```sh
ls codecov.yml                              # T1
grep -rn codecov README.md .github/         # T2
scripts/coverage.sh                         # T3, T6
PATH=/usr/bin:/bin sh scripts/coverage.sh   # T4
grep -rn coverage scripts/precheck.sh       # T5
./scripts/precheck.sh                       # T10
```

Окружение замера: macOS (darwin 25.5.0), толчейн `1.97.1`,
`cargo-llvm-cov 0.8.7`, компонент `llvm-tools`.
