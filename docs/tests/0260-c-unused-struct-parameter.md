# Тест-план фичи 0260: Неиспользуемый параметр в порождённом C

> Фича: [../features/0260-c-unused-struct-parameter.md](../features/0260-c-unused-struct-parameter.md) · ADR: [../adr/0260-c-unused-struct-parameter.md](../adr/0260-c-unused-struct-parameter.md) · анализ: [../analyze/0260-c-unused-struct-parameter.md](../analyze/0260-c-unused-struct-parameter.md)

## Область и цель

Проверяется, что заглушка печатается **по нужде** (R2, R3) и что оба гейта цели
`c` идут без исключения и дают ноль — в том числе под `-DNDEBUG` (R1).

Сторожем работает сам гейт: он гоняет настоящие `cmake`/`cc` по всему корпусу,
поэтому отдельный тест «в выводе есть строка» был бы слабее. Юнит-тесты
проверяют **признак** — то место, где ошибка была бы тихой.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Признак видит использование | тело с `model->state` / `Child_tick(…, main)` | параметр считается использованным | R2 |
| T2 | Признак видит отсутствие | тело без упоминания | параметр считается неиспользуемым | R2 |
| T3 | Границы идентификатора | тело с `domain`, `MAIN_STATE`, `model_state` | использованием **не** считается | R3 |
| T4 | `assert` не спасает | тело только с `assert(0 != main);` | параметр считается неиспользуемым | R3 |
| T5 | Гейт корпуса | `cmake -Wall -Wextra -Werror` без `-Wno-` | ноль предупреждений | R1 |
| T6 | Гейт `c-hal` | `cc -Wall -Wextra -Werror` без `-Wno-` | ноль предупреждений | R1 |
| T7 | Релизная сборка | `cc -DNDEBUG -Wall -Wextra` по корпусу | ноль (до правки — 53) | R1 |
| T8 | Поведение и снапшоты | — | сверки зелёные, `examples/generated/c` детерминированы | R4, R5 |

## Тестовые данные и окружение

T1–T4 — юнит-тесты в `takt-lang/src/generator/c/c_params.rs` (признак —
чистая функция над текстом). T5–T8 — шаги `./scripts/precheck.sh` на корпусе
`examples/*.takt`; T7 снимается вручную тем же прогоном с `-DNDEBUG`
(в гейте он не закреплён — это отдельная работа, см. отчёт).
