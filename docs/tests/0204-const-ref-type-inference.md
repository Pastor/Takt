# Тест-план фичи 0204: Вывод типов не протягивает тип через ссылку константа-константа

> Фича: [../features/0204-const-ref-type-inference.md](../features/0204-const-ref-type-inference.md) · ADR: [../adr/0204-const-ref-type-inference.md](../adr/0204-const-ref-type-inference.md) · анализ: [../analyze/0204-const-ref-type-inference.md](../analyze/0204-const-ref-type-inference.md)

## Область и цель

Фича меняет **семантику вывода типов**, поэтому по правилу 16 проверки идут на
примерах и контр-примерах языка: что тип выводится, чем он оказывается и как
ведёт себя программа, которую раньше не исполнял никто.

⚠️ Проверять «собралось» здесь недостаточно: тип, выведенный **шире** нужного,
собирается прекрасно и молча меняет арифметику. Отсюда сверка текста объявления
в порождённом C и значенческие трассы эталона.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Ссылка на константу-длительность | `const BASE := 2s; const DWELL := BASE;` | тип `DWELL` — `Duration` | R1 / A1 |
| T2 | Обратный порядок по алфавиту | `const Z := 5; const A := Z;` | тип `A` — `[bit;8]` | R2 / A2 |
| T3 | Цепочка длины три | `A → B → C` | типы `B` и `C` — `[bit;8]` | R2 / A2 |

| T5 | Арифметика длительностей | `const S := 2s + 1s;` | `Duration` (было `Unsupported`) | R3 / A3 |
