# Тест-план фичи 0276: Диагностика семантики без кода и позиции

> Фича: [../features/0276-semantic-diagnostics-without-code.md](../features/0276-semantic-diagnostics-without-code.md) · ADR: [../adr/0276-semantic-diagnostics-without-code.md](../adr/0276-semantic-diagnostics-without-code.md) · анализ: [../analyze/0276-semantic-diagnostics-without-code.md](../analyze/0276-semantic-diagnostics-without-code.md)

## Область и цель

Проверяются **код и позиция** достижимых диагностик и **устройство**: конверсии
`From<&str>` больше нет, безликих мест в семантике не осталось. Требования
R1…R6 и критерии A1…A6 — в [анализе](../analyze/0276-semantic-diagnostics-without-code.md).

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | R/A |
