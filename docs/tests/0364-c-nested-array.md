# Тест-план фичи 0364: Вложенный массив у цели c

> Фича: [../features/0364-c-nested-array.md](../features/0364-c-nested-array.md) · ADR: [../adr/0364-c-nested-array.md](../adr/0364-c-nested-array.md) · анализ: [../analyze/0364-c-nested-array.md](../analyze/0364-c-nested-array.md)

## Область и цель

Проверяется поведение целей `c`/`c-hal` на вложенном массиве: валидность
вывода (`cc -Wall -Wextra -Werror`) и **совпадение значений** с эталоном.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
