# Тест-план фичи 0139: Удаление мёртвой конфигурации `.travis.yml`

> Фича: [../features/0139-remove-travis-config.md](../features/0139-remove-travis-config.md) · анализ: [../analyze/0139-remove-travis-config.md](../analyze/0139-remove-travis-config.md) · отчёт: [../reports/0139-remove-travis-config.md](../reports/0139-remove-travis-config.md)

## Область и цель

Фича **инфраструктурная**: удаляется файл конфигурации, не влияющий ни на язык,
ни на инструменты, ни на порождаемый код. Поэтому правило 16 (тесты синтаксиса и
семантики, примеры и контрпримеры) **неприменимо**: проверять нечего в языке —
проверяется полнота удаления и неизменность контракта гейтов.

## Проверки (условие → ожидаемый результат)

| # | Условие | Ожидаемый результат |
|---|---|---|
| A1 | `test ! -e .travis.yml` | файла нет |
| A2 | `git ls-files .travis.yml` | пустой вывод (удалён из индекса) |
| A3 | `grep -rni travis README.md docs/ CLAUDE.md scripts/ .github/` | совпадения **только** в артефактах фичи 0139 и строках реестров |
| A4 | `git diff --name-only HEAD -- scripts/precheck.sh .github/workflows/ci.yml` | пустой вывод — гейты не изменены |
| A5 | `./scripts/precheck.sh` | код возврата 0, все гейты пройдены |
| A6 | `python3 scripts/check-links.py` | «Битых ссылок нет» |

## Разбивка проверок по функциональности

- **Полнота удаления** — A1, A2, A3.
- **Неизменность контракта гейтов** — A4, A5 (набор проверок тот же и он зелёный).
- **Целостность документации** — A6 (правило 14).

## Тестовые данные и окружение

Отдельных тестовых данных не требуется. Окружение — рабочая копия репозитория,
macOS (Darwin 25.5.0); инструменты гейтов: `cc`/`cmake`/`ninja`, `rustc`+`clippy`,
`verilator`, `yosys`, MatIEC `iec2c`, `python3`.

**Контрпример (что считалось бы провалом):** файл удалён, но в `README.md`
остался бейдж или упоминание Travis — тогда читатель по-прежнему считал бы, что
контракт проверок описан там; проверка A3 существует именно для этого случая.
