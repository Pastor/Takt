# Тест-план фичи 0371: Приведение q из поля структуры масштабируется

> Фича: [../features/0371-fixed-cast-from-field.md](../features/0371-fixed-cast-from-field.md) · ADR: [../adr/0371-fixed-cast-from-field.md](../adr/0371-fixed-cast-from-field.md) · анализ: [../analyze/0371-fixed-cast-from-field.md](../analyze/0371-fixed-cast-from-field.md)

## Область и цель

Проверяется масштабирование при приведении `q → целое`, когда операнд —
поле структуры, выражение над полями либо поле элемента массива.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Поле, цель `c` | `g.kp as u8` | `takt_q_floordiv(…, 1 << 8)` | R1 / A1 |
| T2 | Поле, цель `rust` | то же | `((… as i64) >> 8) as u8` | R1 / A1 |
| T3 | Поле, цель `sv` | то же | `8'($signed(…) >>> 8)` | R1 / A1 |
| T4 | Поле, цель `st` | то же | `LINT_TO_USINT(TAKT_Q_FLOORDIV(…, 256))` | R1 / A1 |
| T5 | Выражение над полями | `(g.kp + g.ki) as u8` | масштабируется; `st` не отказывает | R3 / A1 |
| T6 | Поле элемента массива | `cells[1].kp as u8` | масштабируется | R3 / A2 |
| T7 | Сверка значений | фикстура `CastQ` | `one = 1`, `sum = 4`, `elem = 7` | R5 / A2 |
| T8 | Мутация «без типа поля» | — | сверка красная | A3 |
| T9 | Контроль: приведение переменной | `(a + b) as u8` | вывод прежний | R4 / A5 |
| T10 | Разряд не затронут | `x.3` | вывод прежний | R2 / A5 |
| T11 | Контроль корпуса | `examples/*.takt` | ноль тревог | A5 |
| T12 | Регресс | conformance, targets, lib | зелено | A4 |
| T13 | Вывод корпуса не изменился | предкоммит | снапшоты без диффа | A5 |
