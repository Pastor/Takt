# Тест-план фичи 0377: Артефакты сборки не попадают в репозиторий

> Фича: [../features/0377-build-artifacts-gate.md](../features/0377-build-artifacts-gate.md) · ADR: [../adr/0377-build-artifacts-gate.md](../adr/0377-build-artifacts-gate.md) · анализ: [../analyze/0377-build-artifacts-gate.md](../analyze/0377-build-artifacts-gate.md)

## Область и цель

Проверяются R1…R5 анализа. Гейт процессный, поэтому все проверки — прогон
самого гейта и его сторожа.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Репозиторий чист | текущее дерево | гейт печатает счёт файлов, код 0 | R1 / A1 |
| T2 | Чистый репозиторий принимается | временный репозиторий с одним `.rs` | код 0 | R3 / A3 |
| T3 | Отслеживаемый артефакт ловится | `git add -f libprobe.rlib` | код ≠ 0, имя файла в выводе | R3 / A3 |
| T4 | Неотслеживаемый не роняет | тот же файл вне индекса | код 0 | R4 / A4 |

| T7 | Предкоммит зелёный | `./scripts/precheck.sh` | код 0 | R1–R5 |
