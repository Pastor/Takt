# Тест-план фичи 0370: Понижение q-литерала доходит до полей структуры

> Фича: [../features/0370-struct-field-fixed.md](../features/0370-struct-field-fixed.md) · ADR: [../adr/0370-struct-field-fixed.md](../adr/0370-struct-field-fixed.md) · анализ: [../analyze/0370-struct-field-fixed.md](../analyze/0370-struct-field-fixed.md)

## Область и цель

Проверяется, что дробный литерал в поле `q` понижается так же, как в скаляре и
в элементе массива, — у всех восьми целей.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Поле `q` | `var g: Gains := {1.5, 2.5};` | инструменты всех целей принимают | R1 / A1 |
| T2 | Массив структур с полями `q` | `[Gains; 2] := {{…}, {…}}` | то же | R2 / A1 |
| T3 | Представление поля | — | `kp = 384` в порождённом C | R4 / A2 |
| T4 | Представление поля в массиве | — | `loops[1].kp = 256` | R2 / A2 |
| T5 | Сверка значений | фикстура `FieldQ` | `total = 1024`, `picked = 320` | R5 / A2 |
| T6 | Мутация «не понижать поля» | — | сверка красная | A3 |
| T7 | Контроль: скаляр `q` | `var gain: q(8,8) := 1.5;` | ноль тревог (и до фичи) | — |
| T8 | Контроль корпуса | `examples/*.takt` | ноль тревог | A4 |
| T9 | Регресс | conformance, targets, lib | зелено | — |
