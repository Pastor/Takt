# Тест-план фичи 0223: Три примера объясняют выходной порт устаревшей нуждой цели rust

> Фича: [../features/0223-examples-port-rationale-stale.md](../features/0223-examples-port-rationale-stale.md) · ADR: [../adr/0223-examples-port-rationale-stale.md](../adr/0223-examples-port-rationale-stale.md) · анализ: [../analyze/0223-examples-port-rationale-stale.md](../analyze/0223-examples-port-rationale-stale.md)

## Область и цель

Фича правит **только комментарии** четырёх примеров корпуса. Поэтому проверок
две породы:

1. **Содержательные** — устаревшего объяснения не осталось, новое соответствует
   факту (R1–R3), причём сам факт («порт держит тестбенч SV») перепроверяется
   пробой, а не чтением.
2. **Охранные** — правка текста ничего не сломала: порты на месте, вывод целей
   байт-в-байт прежний, канон `fmt` соблюдён, предкоммит зелёный (R4–R6).

Автотестов фича не добавляет: сторожем содержательной части служат уже
существующие гейты `sv`/`sv-mmio` предкоммита (тестбенч падает `$error`, если
`ready` не поднялся), а греп-сторож на текст комментария отвергнут ADR
(Option C).
