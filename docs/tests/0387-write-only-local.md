# Тест-план фичи 0387: Локальная переменная, записанная но не прочитанная

> Фича: [../features/0387-write-only-local.md](../features/0387-write-only-local.md) · ADR: [../adr/0387-write-only-local.md](../adr/0387-write-only-local.md) · анализ: [../analyze/0387-write-only-local.md](../analyze/0387-write-only-local.md)

## Область и цель

Проверяется, что вывод целей на локальной, которую тело только пишет,
собирается их инструментами, что `SE-036` о ней сообщает и что поведение не
изменилось. Ключевая проверка — **прогон инструментов**: значения здесь не
расходятся, дефект в том, что вывод не собирается.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Порождённый C под флагами гейта | `spare := n + 5;` без чтений | `cc -Wall -Wextra -Werror` принял; в выводе `(void)spare;` | R1 / A1 |
| T2 | Прочие цели | та же фикстура | `iec2c` + `cc`, `rustc` + `clippy`, `verilator` + `yosys` приняли | R2 / A2 |
| T3 | `SE-036` | та же запись | предупреждение выдаётся | R3 / A3 |
| T4 | Поведение | трасса эталона | `1, 2, 3` — как прежде | R4 / A1 |
| T5 | Знание одно | чтение исходника | режим — флаг `reads_only`, второго обхода нет | R5 / A4 |
| T6 | Фильтр печати не затронут | `compute_usage` | режим не включает | R6 / A4 |
| T7 | Мутация | «запись снова считается чтением» | T1 краснеет | R5 / A4 |
| T8 | Шум | прогон по `examples/*.takt` | новых предупреждений нет | R7 / A5 |
| T9 | Порядок у `sv` | вывод цели | поглотитель **после** тела (иначе `ALWCOMBORDER`) | R2 / A2 |
