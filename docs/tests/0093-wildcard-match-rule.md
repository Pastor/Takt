# Тест-план фичи 0093: Запрет _ => в семантических узлах и разрешение конфликта с #[non_exhaustive]

> Фича: [../features/0093-wildcard-match-rule.md](../features/0093-wildcard-match-rule.md) · ADR: [../adr/0093-wildcard-match-rule.md](../adr/0093-wildcard-match-rule.md) · анализ: [../analyze/0093-wildcard-match-rule.md](../analyze/0093-wildcard-match-rule.md)

## Область и цель

Проверить, что правило и исключение записаны в `docs/CODE.md`, а гейт
`check-exhaustive-nodes.sh` защищает инвариант ADR 0025 от обоих путей «тихой
смерти» (пометка узла `#[non_exhaustive]` / снятие `deny` в `eval/`). Фича не
меняет код крейтов — проверки на уровне гейта.
