# Тест-план 0326: сдвиг на ширину типа в цели `rust`

> Фича: [../features/0326-rust-shift-width.md](../features/0326-rust-shift-width.md) · ADR: [../adr/0326-rust-shift-width.md](../adr/0326-rust-shift-width.md) · отчёт: [../reports/0326-rust-shift-width.md](../reports/0326-rust-shift-width.md)

## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | Знаковый сдвиг печатается как `>> ширина−1` | `shift_by_type_width_is_printed_as_saturated` |
| П2 | Сдвига на всю ширину в выводе нет | тот же тест |
| П3 | **Контроль:** обычный сдвиг не изменился | `ordinary_shift_is_unchanged` |
| П4 | **Граница:** переменная величина не трогается | `variable_shift_amount_is_left_alone` |
| П5 | Порождённый Rust собирается и считает как эталон | ручной прогон `rustc` |
| П6 | Регрессия и предкоммит | `cargo test --all-features`, `./scripts/precheck.sh` |

## Почему тесты именно такие

- **П2 проверяет отсутствие** прежней формы: именно она и не компилировалась.
- **Контроль и граница** отделяют «правило сработало где надо» от «сдвиги
  переписываются всегда».
