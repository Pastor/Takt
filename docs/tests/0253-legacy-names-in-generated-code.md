# Тест-план фичи 0253: Старое имя языка в порождаемом коде (lam_q_*, LAM_Q_*)

> Фича: [../features/0253-legacy-names-in-generated-code.md](../features/0253-legacy-names-in-generated-code.md) · ADR: [../adr/0253-legacy-names-in-generated-code.md](../adr/0253-legacy-names-in-generated-code.md) · анализ: [../analyze/0253-legacy-names-in-generated-code.md](../analyze/0253-legacy-names-in-generated-code.md)

## Область и цель

Доказать, что переименование хелперов фиксированной точки (`lam_q_*` →
`takt_q_*`, `LAM_Q_*` → `TAKT_Q_*`) **сменило имя и ничего кроме**: вывод
по-прежнему принимается чужими инструментами, значения потактовых трасс
прежние, а гейт старых имён отныне стережёт и порождаемый код.

⚠️ Ключевая опасность правки — **половинчатость**: эмиссия вызова сменила имя,
а условие вставки определения нет. Такой файл собирается инструментом проекта
и отвергается **чужим** (`cc`: implicit declaration; `iec2c`: unknown POU),
поэтому проверки T3/T4 идут прогоном настоящих компиляторов, а не грепом.

## Тестовые данные и окружение

- **Корпус:** `examples/` (Q-арифметику несёт `regulator.takt`, отсюда снапшоты
  `c/regulator.c` и `st/regulator.st`).
- **Фикстуры сверок:** формы `sat` и `wrap` корпусом **не порождаются** —
  их держат `takt-sim/tests/conformance/conformance_st_tests/fixed_sat.rs` и
  соседние наборы. Без них T5 покрывал бы только `FLOORDIV`.
- **Инструменты:** `cc` (Apple clang), `cmake` + `ninja`, `iec2c` (MatIEC,
  `~/.local/bin/iec2c` + `-I ~/.local/share/matiec/lib`), `verilator`/`yosys`
  (в объём не входят — цель `sv` хелперов не эмитит).
- **Окружение прогона:** macOS (darwin 25.5.0), Rust 1.97.1 (пин
  `rust-toolchain.toml`).
