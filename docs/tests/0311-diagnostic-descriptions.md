# Тест-план 0311: описания записей реестра диагностик

> Фича: [../features/0311-diagnostic-descriptions.md](../features/0311-diagnostic-descriptions.md) · ADR: [../adr/0311-diagnostic-descriptions.md](../adr/0311-diagnostic-descriptions.md) · отчёт: [../reports/0311-diagnostic-descriptions.md](../reports/0311-diagnostic-descriptions.md)

## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | Годный реестр принимается | `test-diagnostic-descriptions.sh` (1) |
| П2 | Служебное слово ловится (D1) | там же (2) |
| П3 | **Долг не покрывает служебное слово** | там же (3) |
| П4 | Короткое описание ловится и покрывается долгом (D2) | там же (4) |
| П5 | Протухшая запись долга ловится (D3) | там же (5) |
| П6 | Пустой реестр — вырожденная проверка | там же (6) |
| П7 | Самопроверка гейта проходит | там же (7) |
| П8 | Рабочий реестр зелёный | `check-diagnostic-descriptions.py` |
| П9 | Гейт 0290 не задет | `check-book-diagnostics.py` |
| П10 | Предкоммит | `./scripts/precheck.sh` |

## Почему тесты именно такие

- **П3 — главное условие фичи:** узаконить «ошибку» долгом значило бы отменить
  её предмет. Без этой проверки класс D1 держался бы на дисциплине.
- **П6:** гейт, у которого нечего проверять, обязан падать, а не рапортовать
  об успехе (класс фикса 0202-01 и урок 0230).
- **Сторож работает на копии дерева** (`DD_ROOT`): проверка рабочих файлов
  ничего не доказывает про поведение гейта на плохом входе.
