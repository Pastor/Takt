# Тест-план фичи 0286: Вычислимое приведение в инициализаторе

> Фича: [../features/0286-sv-const-initializer-expression.md](../features/0286-sv-const-initializer-expression.md) · ADR: [../adr/0286-sv-const-initializer-expression.md](../adr/0286-sv-const-initializer-expression.md) · анализ: [../analyze/0286-sv-const-initializer-expression.md](../analyze/0286-sv-const-initializer-expression.md)

## Область и цель

Проверяется, что отказ идёт по **вычислимости** (R1, R2) и что граница держится
(R3): приведение, меняющее значение, по-прежнему невычислимо.

Правка касается **ветви сброса**: ошибка в значении даёт валидный и
синтезируемый модуль, стартующий не с того числа, — `verilator` и `yosys`
молчат. Поэтому вердикт даёт трасса.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | `sv` переводит приведение | `var v := 5 as u16;` | компиляция успешна, в сбросе `<= 5` | R1, R2 / A1 |
| T2 | Инструменты принимают | тот же вывод | `verilator -Wall`, `yosys synth` — код 0 | R1 / A1 |
| T3 | Трасса совпадает | 4 такта | значения `v` совпадают с эталоном | R2 / A2 |
| T4 | Граница: значение меняется | `var v := 300 as u8;` | `SV-002` | R3 / A3 |
| T5 | Граница: порт | `out led: bit := 0x100 as u8;` | `SE-094`, причина называет диапазон | R3 / A3 |
| T6 | Расширение соседей | `Tuner(limit := 30 as u8)` | переводится (прежде `SE-083`) | R2 / A4 |
| T7 | Регресс | — | корпус и снапшоты без изменений, `precheck.sh` код 0 | R5 / A5 |
