# Тест-план фичи 0128: Диагностика вместо паники на числовом литерале больше `i64::MAX`

> Фича: [../features/0128-lexer-literal-overflow.md](../features/0128-lexer-literal-overflow.md) · анализ: [../analyze/0128-lexer-literal-overflow.md](../analyze/0128-lexer-literal-overflow.md) · отчёт: [../reports/0128-lexer-literal-overflow.md](../reports/0128-lexer-literal-overflow.md)

## Область и цель

Фича **языковая** (меняет диагностики), поэтому правило 16 применяется в полном
объёме: проверки лексики, примеры и контрпримеры.

Проверяется три вещи: отказ инструмента устранён; граница диапазона **не
сдвинулась**; диагностика пригодна к использованию (позиция + текст).

## Проверки (условие → ожидаемый результат)

| # | Условие | Ожидаемый результат |
|---|---|---|
| A1 | лексируется `var x: u64 := 18446744073709551615;` | ровно одна ошибка, `LexicalError::NumberOutOfRange`, код `LE-009` |
| A2 | лексируется `const MASK: [bit;64] := 0xFFFFFFFFFFFFFFFF;` | то же: `LE-009` |
| A3 | лексируются `9223372036854775807`, `0x7FFFFFFFFFFFFFFF`, `255` | ошибок нет |
| A4 | ошибка на `99999999999999999999` | `loc.start()` равен смещению литерала в исходнике; текст ошибки содержит сам литерал |
| A5 | `taktc compile` на файле с `0xFFFFFFFFFFFFFFFF` | `rc = 1`, вывод `…: Ошибка компиляции [LE-009]: …`, **трассы паники нет** |
| A6 | `./scripts/check-diagnostic-codes.sh` | rc 0 (код в реестре, реестр не протух) |
| A7 | `./scripts/check-language-version.sh` | rc 0, версия `0.6.0` |
| A8 | `./scripts/precheck.sh` | `EXIT=0` |

## Примеры и контрпримеры (правило 16)

**Контрпримеры — то, что обязано быть отвергнуто:**

```takt
const MASK: [bit;64] := 0xFFFFFFFFFFFFFFFF;   // LE-009
var big: u64 := 18446744073709551615;         // LE-009
var over: i64 := 9223372036854775808;         // LE-009 (на единицу за границей)
```

**Примеры — то, что обязано приниматься:**

```takt
var max:  i64 := 9223372036854775807;         // ровно i64::MAX
var hmax: i64 := 0x7FFFFFFFFFFFFFFF;          // он же шестнадцатеричной записью
var byte: u8  := 255;
```

Оба списка попадают в документацию: контрпример с маской `[bit;64]` — в
приложение «Ошибки и предупреждения» (подробный разбор `LE-009`), упоминание —
в блок «Частые ошибки» раздела «Лексика».

## Разбивка проверок по функциональности

- **Отказ устранён** — A1, A2, A5.
- **Граница не сдвинулась** — A3 (сторож направления: правка «на всякий случай»
  сузила бы диапазон и покрасила бы этот тест).
- **Диагностика пригодна** — A4.
- **Контракт проекта** — A6 (реестр), A7 (версия языка), A8 (гейты).

## Тестовые данные и окружение

Тесты — `takt-lang/tests/syntax/lexer_tests.rs` (интеграционные, работают прямо с
`Lexer`); отдельных файлов-фикстур не требуется: входы короткие и записаны в
теле тестов. Сквозная проба A5 — через собранный `taktc`. Окружение — пин
толчейна из `rust-toolchain.toml` (фича 0137).
