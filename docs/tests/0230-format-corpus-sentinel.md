# Тест-план фичи 0230: Сторож форматтера — корпус восстановлен, KNOWN_GAPS с ратчетом

> Фича: [../features/0230-format-corpus-sentinel.md](../features/0230-format-corpus-sentinel.md) · ADR: [../adr/0230-format-corpus-sentinel.md](../adr/0230-format-corpus-sentinel.md) · анализ: [../analyze/0230-format-corpus-sentinel.md](../analyze/0230-format-corpus-sentinel.md)

## Область и цель

Проверяется **сам сторож**: что он видит весь корпус, шумит при потере покрытия и
не копит протухшие исключения. Особенность области: предмет проверки — тест,
поэтому основной инструмент — **мутация** (сторож, который нельзя завалить,
ничего не сторожит).

Файл: `takt-lang/tests/format_tests.rs`; фикс печати —
[0199-01](../fixes/0199-01-fmt-drops-model-implement.md).

## Тестовые данные и окружение

- Корпус — репозиторий целиком (три каталога `.takt`), а не подобранные примеры:
  в этом и смысл сторожа.
- Фикстура, на которой виден фикс, — `conformance_model_implement.takt` из
  `takt-sim/tests/data/eval/`: она **и есть** та половина корпуса, которую тест
  не видел.
- Мутации выполняются вручную с немедленным откатом; каждая обязана валить
  **ожидаемую** проверку, а не любую.
