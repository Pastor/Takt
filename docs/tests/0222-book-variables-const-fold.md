> Фича: [../features/0222-book-variables-const-fold.md](../features/0222-book-variables-const-fold.md) · ADR: [../adr/0222-book-variables-const-fold.md](../adr/0222-book-variables-const-fold.md) · анализ: [../analyze/0222-book-variables-const-fold.md](../analyze/0222-book-variables-const-fold.md)

## Область и цель

Фича документная. Проверяется полнота описания против списка требований и
**истинность каждого числа**: правило 27 требует, чтобы значения в тексте
брались из прогона.
