## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | Три названных кода действительно выдаются | прогон эталона на трёх формах |
| П2 | Документ собирается | `make -C book build` |
| П3 | Символы в шрифте, подсветка объявлена | гейты 0146, 0269 |
| П4 | Предкоммит | `./scripts/precheck.sh` |

## Почему тесты именно такие

Документ, называющий коды, обязан называть **те**, что выдаются: проверка —
прогоном, а не сверкой с реестром (реестр говорит, что код существует, а не
что он выдаётся на этой форме).
