# Тест-план фичи 0254: Старое имя в служебных идентификаторах

> Фича: [../features/0254-legacy-names-internal-identifiers.md](../features/0254-legacy-names-internal-identifiers.md) · анализ: [../analyze/0254-legacy-names-internal-identifiers.md](../analyze/0254-legacy-names-internal-identifiers.md) · отчёт: [../reports/0254-legacy-names-internal-identifiers.md](../reports/0254-legacy-names-internal-identifiers.md)

## Предмет проверки

Отсутствие упразднённых имён в рабочих идентификаторах и **сторожевая
способность** гейта: переименование без гейта отрастает обратно.

## Условия проверок

| # | Условие | Как проверяется | Ожидаемый результат |
|---|---|---|---|
| П1 | В дереве нет старых служебных имён | `scripts/check-legacy-names.sh` | «OK: старых имён нет» |
| П2 | Ловится переменная скрипта (`LAMC=…`) | сторож, проверка 7 | гейт падает |
| П3 | Ловится цикл `for lam_file …` | сторож, проверка 7 | гейт падает |
| П4 | Ловится временный каталог `lam_conformance_*` | сторож, проверка 7 | гейт падает |
| П5 | Ловится константа `BUT_KEYWORDS` | сторож, проверка 7 | гейт падает |
| П6 | Ловится импорт `lam_generated` | сторож, проверка 7 | гейт падает |
| П7 | Ловится ключ цвета `LAM_KEYWORD` | сторож, проверка 7 | гейт падает |
| П8 | **Контроль:** действующие имена приняты | сторож, проверка 8 | гейт молчит |
| П9 | Прежние классы гейта целы | сторож, проверки 1–6 | все OK |
| П10 | Плагин IntelliJ собирается и тестируется | `./gradlew --offline test` | код 0 |
| П11 | Регрессия крейтов | `cargo test --all-features` | провалов нет |
| П12 | Предкоммит | `./scripts/precheck.sh` | код 0 |

## Границы

Гейт проверяет **имена**, а не смысл: комментарий, где старое имя уместно как
свидетельство, живёт в `docs/` (исключение по префиксу пути).
