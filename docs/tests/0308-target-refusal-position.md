# Тест-план 0308: координата отказа целей

> Фича: [../features/0308-target-refusal-position.md](../features/0308-target-refusal-position.md) · ADR: [../adr/0308-target-refusal-position.md](../adr/0308-target-refusal-position.md) · отчёт: [../reports/0308-target-refusal-position.md](../reports/0308-target-refusal-position.md)

## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | `c`, `rust`, `st` указывают строку оператора (срез) | `slice_in_statement_points_at_the_statement` |
| П2 | `rust`, `sv` указывают строку оператора (`**`) | `power_in_statement_points_at_the_statement` |
| П3 | **Контроль:** вне оператора позиция оператора не подставляется | `refusal_outside_a_statement_keeps_its_own_position` |
| П4 | Носитель потоковый, сброс работает | юнит-тесты `generator/site.rs` |
| П5 | Регрессия и предкоммит | `cargo test --all-features`, `./scripts/precheck.sh` |

## Почему тесты именно такие

- **Две фикстуры, а не одна:** цель `sv` на входе с массивом отказывает раньше
  — на инициализаторе, — и координата оператора осталась бы непроверенной.
- **Контроль (П3) обязателен:** потоковое состояние опасно тем, что переживает
  вызов; тест доказывает, что вне оператора координата остаётся своей.
- **Прогон бинарника, а не библиотеки:** проверяется тот текст, который видит
  пользователь, вместе с префиксом пути (`diagnostics::position_prefix`).
- **Фикстура контроля пользуется объявлением:** неиспользуемое объявление
  штатный фильтр выбрасывает, и тест мерил бы отсутствие отказа (правило 30).
