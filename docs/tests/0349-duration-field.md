# Тест-план 0349: длительность в поле структуры

> Фича: [../features/0349-duration-field.md](../features/0349-duration-field.md) · ADR: [../adr/0349-duration-field.md](../adr/0349-duration-field.md) · отчёт: [../reports/0349-duration-field.md](../reports/0349-duration-field.md)

## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | `st`: приведение переводится, `iec2c` принимает | `st_duration_field_cast_is_translated` |
| П2 | `sv`: литерал размерный, линт чист | `sv_duration_field_literal_is_sized` |
| П3 | Значения совпадают с эталоном | прогон ST (`sum = 7`) |
| П4 | Массив длительностей не изменился | контроль в фикстуре |
| П5 | Предкоммит | `./scripts/precheck.sh` |

## Почему тесты именно такие

У целей разные причины: у `st` отказ, у `sv` предупреждение, которое гейт
считает ошибкой. Поэтому проверяется и текст (что печатается), и приём
инструментом.
