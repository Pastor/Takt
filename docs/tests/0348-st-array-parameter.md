# Тест-план 0348: массив в параметре функции

> Фича: [../features/0348-st-array-parameter.md](../features/0348-st-array-parameter.md) · ADR: [../adr/0348-st-array-parameter.md](../adr/0348-st-array-parameter.md) · отчёт: [../reports/0348-st-array-parameter.md](../reports/0348-st-array-parameter.md)

## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | `iec2c` принимает вывод | `array_parameter_matches_generated_st` |
| П2 | Порождённый им C **собирается** | там же (сборка драйвера) |
| П3 | Значения совпадают с эталоном | там же (`7 9 3`) |
| П4 | Функция с параметрами обеих секций | `at_index(arr, 1)` в фикстуре |
| П5 | Предкоммит | `./scripts/precheck.sh` |

## Почему тесты именно такие

`VAR_INPUT` с массивом `iec2c` **разбирает** — и порождает C, который не
компилируется. Поэтому сторож проверяет **полный цикл**: принятая разбором
форма не считается годной, пока не собран вывод.

⚠️ Вход с параметрами обеих секций обязателен: перестановка аргументов видна
только на нём.
