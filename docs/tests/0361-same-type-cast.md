# Тест-план 0361: Приведение к тому же типу

- **Фича:** [../features/0361-same-type-cast.md](../features/0361-same-type-cast.md)
- **Анализ:** [../analyze/0361-same-type-cast.md](../analyze/0361-same-type-cast.md)
- **Дата:** 2026-08-21

## Условия проверок

| № | Условие | Ожидание |
|---|---|---|
| П1 | `q := r as u16;` при `r: u16` | приведения нет в выводе `rust`, `c`, `sv` |
| П2 | вывод `rust` | принят `clippy -D warnings` |
| К1 | `w := b as u16;` при `b: u8` | приведение **сохранено** у трёх целей |

⚠️ К1 обязателен: без него правка читается как «приведения не печатаем вовсе»,
и расширение `u8 → u16` потерялось бы вместе со значением.

## Регресс

- `cargo test --test targets same_type_cast_tests::`
- полный `./scripts/precheck.sh` — вывод корпуса обязан остаться прежним.
