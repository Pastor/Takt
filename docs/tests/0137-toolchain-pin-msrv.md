# Тест-план фичи 0137: Фиксация толчейна Rust и MSRV

> Фича: [../features/0137-toolchain-pin-msrv.md](../features/0137-toolchain-pin-msrv.md) · анализ: [../analyze/0137-toolchain-pin-msrv.md](../analyze/0137-toolchain-pin-msrv.md) · отчёт: [../reports/0137-toolchain-pin-msrv.md](../reports/0137-toolchain-pin-msrv.md)

## Область и цель

Фича **инфраструктурная**: меняется окружение сборки, а не язык. Правило 16
(тесты синтаксиса и семантики, примеры и контрпримеры языка) **неприменимо** —
проверяются воспроизводимость окружения и **неизменность** всего остального.

Ключевой вопрос проверки: *не ослабли ли гейты и не изменилось ли поведение
инструментов от смены компилятора*. Поэтому центральная проверка — полный
`precheck.sh` на пиннутом толчейне, а не отдельные команды.

## Проверки (условие → ожидаемый результат)

| # | Условие | Ожидаемый результат |
|---|---|---|
| A1 | `rustup show active-toolchain` в каталоге проекта | `1.97.1-…` с пометкой `overridden by '…/rust-toolchain.toml'` |
| A2 | `cargo fmt --version`, `cargo clippy --version` | компоненты доступны на пине |
| A3 | `grep rust-version takt-lang/Cargo.toml takt-sim/Cargo.toml` | `rust-version = "1.97"` в обоих |
| A4 | `git ls-files Cargo.lock`; `grep Cargo.lock .gitignore` | файл в индексе; записи-игнора нет |
| A5 | `cargo check --locked --all-targets --all-features` | проходит (lock согласован с манифестами) |
| A6 | `grep -n nightly scripts/precheck.sh .github/workflows/ci.yml` | только поясняющие комментарии, ни одного вызова `+nightly`/`@nightly` |
| A7 | `./scripts/precheck.sh` на пиннутом толчейне | код 0; все гейты пройдены |
| A8 | `resolver = "3"` + `cargo check --locked` | проходит; `Cargo.lock` не требует правок (граф зависимостей тот же) |
| A9 | `cargo fmt --check` (stable) на дереве, ранее отформатированном nightly | rc 0 — форматирование не разъезжается между каналами |
| A10 | Число тестов в прогоне `precheck.sh` | не меньше, чем до фичи (2176) — смена компилятора ничего не отключила |

## Разбивка проверок по функциональности

- **Пин действует** — A1, A2.
- **Воспроизводимость зависимостей** — A4, A5, A8.
- **Nightly не требуется** — A6, A9 (и как следствие A7).
- **Ничего не ослабло** — A7, A10.
- **Контракт для потребителя** — A3 (MSRV объявлен).

## Тестовые данные и окружение

Отдельных тестовых данных не требуется: проверяется само окружение. Прогон —
macOS (Darwin 25.5.0), rustup 1.29.0; инструменты гейтов `precheck.sh`:
`cc`/`cmake`/`ninja`, `verilator`, `yosys`, MatIEC `iec2c`, `python3`.

**Контрпример (что считалось бы провалом):**

1. `precheck.sh` зелёный, но `grep nightly` находит живой вызов `+nightly` —
   значит канал по-прежнему задаётся в двух местах и пин фиктивен (проверка A6).
2. `cargo check` проходит, но **без** `--locked` — значит lock мог быть тихо
   переписан, и воспроизводимость не доказана (проверка A5 требует именно
   `--locked`).
3. Число прошедших тестов меньше прежнего — смена компилятора отключила часть
   набора (проверка A10).
