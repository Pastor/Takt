# Тест-план фичи 0380: Fixed-point в параметре функции

> Фича: [../features/0380-fixed-point-parameter.md](../features/0380-fixed-point-parameter.md) · ADR: [../adr/0380-fixed-point-parameter.md](../adr/0380-fixed-point-parameter.md) · анализ: [../analyze/0380-fixed-point-parameter.md](../analyze/0380-fixed-point-parameter.md)

## Область и цель

Проверяются R1…R6. Два слоя: приём формы (семантика) и валидность вывода цели
`st` (порядок POU) — второй вскрылся только после первого.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Форма принимается | `fn whole(v: q(8, 8)) -> u8` | вывод порождают восемь целей | R1, R3 / A1 |
| T2 | Значения совпадают с целью `c` | фикстура, 3 такта | `[[1,1],[1,2],[2,3]]` | R4 / A2 |
| T3 | Хелпер раньше вызывающей функции | вывод `st` | `TAKT_Q_FLOORDIV` до `Probe_whole` | R5 / A3 |
| T4 | `iec2c` принимает вывод | тот же вывод | код возврата 0 | R5 / A4 |
| T5 | Контроль: `q` в возврате | `-> q(8, 8)` | переводится (и прежде переводился) | R1 |
| T5а | Контроль: арифметика над параметром | `fn twice(v: q(8, 8)) { return v * v; }` | переводится всеми восемью целями | R3 |
| T6 | Контроль: `duration` в параметре | `fn f(v: duration)` | переводится | R1 |
| T7 | Граница: `q(8, 8) sat` в параметре | — | `SY-002` от разбора | R2 |
| T8 | Вывод корпуса не изменился | `precheck.sh` | без диффа | R6 / A5 |
| M1 | Мутация: вставка перед `FUNCTION_BLOCK` | — | падают T3 и T4 | R5 |
