# Тест-план фичи 0150: позиционная форма предупреждает о себе

> Фича: [../features/0150-sim-positional-scenario-deprecation.md](../features/0150-sim-positional-scenario-deprecation.md) · ADR: [../adr/0150-sim-positional-scenario-deprecation.md](../adr/0150-sim-positional-scenario-deprecation.md) · анализ: [../analyze/0150-sim-positional-scenario-deprecation.md](../analyze/0150-sim-positional-scenario-deprecation.md)

## Область и цель

Проверяется поведение инструмента (новая диагностика, прежняя работа формы) и
удержание репозитория на именованной форме гейтом. Требования — R1…R6 анализа.
