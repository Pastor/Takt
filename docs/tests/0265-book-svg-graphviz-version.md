# Тест-план фичи 0265: SVG диаграмм и версия graphviz

> Фича: [../features/0265-book-svg-graphviz-version.md](../features/0265-book-svg-graphviz-version.md) · анализ: [../analyze/0265-book-svg-graphviz-version.md](../analyze/0265-book-svg-graphviz-version.md) · отчёт: [../reports/0265-book-svg-graphviz-version.md](../reports/0265-book-svg-graphviz-version.md)

## Условия проверок

| # | Условие | Как проверяется | Ожидаемый результат |
|---|---|---|---|
| П1 | Версии graphviz в SVG нет | `grep` по committed файлам | пусто |
| П2 | Повторная регенерация стабильна | два прогона скрипта, `git status` | изменений нет |
| П3 | Каталог у носителя | `grep 'target/debug'` в скрипте | только в комментарии-истории |
| П4 | Регенерация работает | прогон скрипта | три SVG, код 0 |
| П5 | Гейт ловит SVG с версией | порча файла + прогон предкоммита | отказ с именем файла |
| П6 | Гейт ловит пустой `.dot` | обнуление файла + прогон | отказ |
| П7 | Документ собирается | `make -C book pdf` | код 0 |
| П8 | Предкоммит | `./scripts/precheck.sh` | код 0 |

## Границы

Гейт ловит **служебную** строку версии. Если смена `dot` изменит геометрию
диаграммы, дифф будет содержательным — и решать его судьбу человеку.
