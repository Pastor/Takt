# Тест-план фичи 0376: Неиспользуемая локальная переменная гасится заглушкой

> Фича: [../features/0376-unused-local-stub.md](../features/0376-unused-local-stub.md) · ADR: [../adr/0376-unused-local-stub.md](../adr/0376-unused-local-stub.md) · анализ: [../analyze/0376-unused-local-stub.md](../analyze/0376-unused-local-stub.md)

## Область и цель

Проверяются R1…R6 анализа. Главный арбитр — **прогон гейтов целей** теми же
флагами, что в предкоммите: класс жил именно там, при нулевом коде возврата
`taktc`.

|---|---|---|---|---|
| T1 | Заглушка печатается | локальная не используется | `(void)spare;` у `c`, `let _ = spare;` у `rust` | R4 / A3 |
