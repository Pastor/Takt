# Тест-план фичи 0378: Имя переменной, совпавшее с именем типа, у цели st

> Фича: [../features/0378-st-name-type-clash.md](../features/0378-st-name-type-clash.md) · ADR: [../adr/0378-st-name-type-clash.md](../adr/0378-st-name-type-clash.md) · анализ: [../analyze/0378-st-name-type-clash.md](../analyze/0378-st-name-type-clash.md)

## Область и цель

Проверяются R1…R6 анализа: отказ называет причину, регистр не спасает, а
непересекающееся имя по-прежнему переводится и **принимается MatIEC** — без
последнего правка читалась бы как «структуры у цели `st` не работают».
