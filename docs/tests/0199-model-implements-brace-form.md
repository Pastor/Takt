# Тест-план фичи 0199: реализация модели

> Фича: [../features/0199-model-implements-brace-form.md](../features/0199-model-implements-brace-form.md) · ADR: [../adr/0199-model-implements-brace-form.md](../adr/0199-model-implements-brace-form.md) · анализ: [../analyze/0199-model-implements-brace-form.md](../analyze/0199-model-implements-brace-form.md)

## Область и цель

Проверяется, что форма `model M = A | B { … }` работает **у всех пяти
потребителей** (эталон и четыре цели) и что конфликт «реализация + собственное
состояние» назван диагностикой, а не теряется молча.

⚠️ Проверка всех четырёх целей — не формальность: первая редакция правки чинила
**только эталон**, и это выявил прогон целей.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | форма исполняется эталоном | `model M = A \| B { always … }` | композиция тикает, тело исполняется | R1 / A1 |
| T2 | форма переводится целями | та же | `c`, `rust`, `sv`, `st` принимают | R2 / A1 |
| T3 | трассы совпадают | фикстура сверки | эталон ≡ цель `c` потактово | R3 / A1 |
| T4 | тело — ровно раз за такт | накапливающее тело | `n = 1..N`, не `2N` | R4 / A2 |
| T5 | конфликт назван | реализация + свой `start` | `SE-101`, две позиции, во всех целях | R5 / A3 |
| T6 | форма без тела | `model M = A \| B;` | `SY-002` | R6 / A4 |
| T7 | эквивалент не задет | `model M { start Inner = A \| B; }` | работает как раньше | R7 |
| T8 | разворот сделан состоянием | вывод цели `c` | в заголовке есть состояние `Implement` | — |
| T9 | корпус и документ | всё дерево | предкоммит зелёный, дифф `examples/generated/` пуст | R8 / A5 |
