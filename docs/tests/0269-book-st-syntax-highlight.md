# Тест-план фичи 0269: Подсветка блоков `st` и `ebnf`

> Фича: [../features/0269-book-st-syntax-highlight.md](../features/0269-book-st-syntax-highlight.md) · анализ: [../analyze/0269-book-st-syntax-highlight.md](../analyze/0269-book-st-syntax-highlight.md) · отчёт: [../reports/0269-book-st-syntax-highlight.md](../reports/0269-book-st-syntax-highlight.md)

## Предмет проверки

Подсветка девяти блоков документа и сторожевая способность гейта. Цвет
проверяется **рендером страницы**: сборка документа на неизвестном языке блока
молчит с кодом 0.

## Условия проверок

| # | Условие | Как проверяется | Ожидаемый результат |
|---|---|---|---|
| П1 | Блок `st` цветной | рендер настоящего блока приложения в PNG | ключевые слова, типы, литералы, комментарий — цветные |
| П2 | Блок `ebnf` цветной | рендер пробной страницы | терминалы и `::=`/`\|` выделены |
| П3 | **Контроль:** `c` как был | тот же рендер | подсветка не изменилась |
| П4 | Литерал `16#FF` цел | рендер | выделен целиком, а не как `16` + `#FF` |
| П5 | C1: язык не объявлен | `--self-test` | находка `C1` |
| П6 | C2: нет файла подсветки | `--self-test` | находка `C2` |
| П7 | C3: файл не подключён | `--self-test` | находка `C3` |
| П8 | C4: объявлен впустую | `--self-test` | находка `C4` |
| П9 | **Контроль:** согласованный вход чист | `--self-test` | находок нет |
| П10 | Рабочее дерево проходит гейт | прогон гейта | «10 языков, 3 своих» |
| П11 | Документ собирается, глифы на месте | `make -C book build`, `check-book-glyphs.py` | код 0 |
| П12 | Предкоммит | `./scripts/precheck.sh` | код 0 |

## Границы

Полнота определений по стандартам не проверяется: гейт следит за
объявленностью языка, а не за тем, все ли слова выделены.
