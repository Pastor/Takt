# Тест-план фичи 0094: Доработка scripts/new-feature.sh (идемпотентность, статус ADR, поздние стадии)

> Фича: [../features/0094-new-feature-script-fixes.md](../features/0094-new-feature-script-fixes.md) · ADR: [../adr/0094-new-feature-script-fixes.md](../adr/0094-new-feature-script-fixes.md) · анализ: [../analyze/0094-new-feature-script-fixes.md](../analyze/0094-new-feature-script-fixes.md)

## Область и цель

Проверить, что генератор заготовок стал идемпотентным (нет дублей), даёт честный
`Draft` у ADR, умеет добирать одну позднюю стадию (в т.ч. `report`) и не сломал
дефолтный путь. Фича инфраструктурная — язык не меняет; проверки — прогоны скрипта
в temp-дереве (`NF_ROOT`).
