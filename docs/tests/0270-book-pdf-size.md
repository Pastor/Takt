# Тест-план фичи 0270: Вес PDF документа

> Фича: [../features/0270-book-pdf-size.md](../features/0270-book-pdf-size.md) · анализ: [../analyze/0270-book-pdf-size.md](../analyze/0270-book-pdf-size.md) · отчёт: [../reports/0270-book-pdf-size.md](../reports/0270-book-pdf-size.md)

## Условия проверок

| # | Условие | Как проверяется | Ожидаемый результат |
|---|---|---|---|
| П1 | PDF собирается и весит ≈ 947 КБ | `make -C book build`, `stat` | 946 850 Б |
| П2 | Оглавление сохранено | разбор PDF на `/Outlines` | найдено |
| П3 | Ссылки сохранены | разбор на `/Link` | 54 объекта |
| П4 | Страниц столько же | разбор на `/Type /Page` | как до правки |
| П5 | Тегов нет (флаг действует) | разбор на `/StructElem` | 0 |
| П6 | **Контроль:** возврат тегов | `make -C book build TYPST_PDF_FLAGS=` | ≈ 3.08 МБ, теги на месте |
| П7 | Гейты документа зелёные | `./scripts/precheck.sh` | код 0 |

## Границы

Вид страниц не проверяется машиной: теги не влияют на отрисовку, но убедиться
в этом можно только рендером (сделан при замере).
