# Тест-план фичи 0066: Литералы по целевому типу в телах цели `st`

> Фича: [../features/0066-st-bool-literals.md](../features/0066-st-bool-literals.md) · ADR: [../adr/0066-st-bool-literals.md](../adr/0066-st-bool-literals.md) · анализ: [../analyze/0066-st-bool-literals.md](../analyze/0066-st-bool-literals.md)

## Область и цель

Проверяется **текст литералов** в телах цели `st`. Язык не меняется →
примеров/контрпримеров синтаксиса правило 16 не требует.

⚠️ **Особенность плана: компилируемость здесь ничего не доказывает.** Проба
показала, что `iec2c` принимает **и** `b := 0`, **и** `b := FALSE` — то есть гейт
зелен **в обоих** случаях, до и после правки. Проверять надо **текст** (T1–T4) и
**неизменность поведения** (T9).

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | `BOOL` — ложь | `cmd_fork := 0;` (`stacker`) | **`cmd_fork := FALSE;`** | R3 / A1 |
| T2 | `BOOL` — истина | `cmd_fork := 1;` | **`cmd_fork := TRUE;`** | R3 / A1 |
| **T3** | **Перечисление** | `command := 2;` (`elevator_mini`) | **`command := Command_Stop;`** — константа объявлена рядом (`Command_Stop : USINT := 2;`) | R4 / A2 |
| T4 | **Значение без варианта** | Присвоение числа, которому не соответствует ни один вариант | Печатается **числом** (догадываться нельзя — перечислимой переменной можно присвоить произвольное число) | R4 / A4 |
| T5 | Место 1 — присваивание | Тело `always` | Покрыто | R2 / A3 |
| T6 | Место 2 — сброс переменной | Сброс | Покрыто | R2 / A3 |
| T7 | Место 3 — блок `enter` | `enter { cmd_fork := 0; }` | Покрыто | R2 / A3 |
| T8 | Гейт | `./scripts/precheck.sh` | `iec2c` принимает весь корпус. ⚠️ Он принимал и **до** правки — сторожем не является | R6 / A5 |

| T10 | Прочие цели | Перегенерация | `c`/`c-hal`/`rust`/`sv`/`plantuml` — **побайтово прежние** | R6 / A6 |
| T11 | Дифф `st` | Перегенерация | **Только** литералы; объяснимо построчно (детерминизм 0048) | R5 / A7 |
| T12 | `print_expression` не тронут | — | Сигнатура прежняя: точка решения — `coerce_to` (R1) | R1 / A3 |

## Тестовые данные и окружение

- **Опорные примеры корпуса:** `stacker.lam` (`cmd_fork : BOOL` — T1/T2),
  `elevator_mini.lam` (`enum Command` — T3).
- **Фикстура T4** — новая: присвоение числа, не совпадающего ни с одним вариантом.
- **`iec2c`:** `-I ~/.local/share/matiec/lib` **обязателен**.
- **Замер, обосновавший «не дефект компилируемости»** (для воспроизведения):
  `b := FALSE` ✔, `b := 0` ✔, `b := 1` ✔, **`b := 2` ✘**, `IF b = 1` ✔.

## Ограничение плана

⚠️ **T9 неисполним, пока не закрыта [0065-03](../development/0065-03-st-conformance.md)**
(потактовой сверки для `st` **не существует**). До неё неизменность поведения
доказывается гейтом `iec2c` и **ревью диффа** — то есть слабее, чем следовало бы.
Это и есть причина рекомендации вести 0066 **после** 0065.
