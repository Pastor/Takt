# Тест-план фичи 0075: эталонная модель порождает компилируемый C

> Фича: [../features/0075-lib-src-reference-model.md](../features/0075-lib-src-reference-model.md) · ADR: [../adr/0075-lib-src-reference-model.md](../adr/0075-lib-src-reference-model.md)

## Область и цель

Проверяется, что компиляционная проверка эталона ведётся настоящим `cc`, а не
строковым совпадением, и что перевод межмодельной ссылки `S(Ping) = End` сохранён.

## Проверки

| # | Проверка | Предусловие | Ожидаемый результат | R/A |
|---|---|---|---|---|
| T1 | Эталон компилируется | `SYNTH_SRC` → `compile_to_c` → `cc -c` | rc=0 (эталонный C компилируется) | R2 / A1 |
| T2 | Перевод `S(Ping) = End` | вывод `SYNTH_SRC` | содержит `main->entry_parallel0.ping0.state == THIS_IS_MY_MODEL_PING_END` | R2 / A2 |
| T3 | Нет заглушек | вывод | нет `TODO`/`FIXME` | R2 / — |
| T4 | Разбор полного `SRC` | `parse_simple` | `SRC` разбирается (покрытие парсера) | R1 / A3 |
| T5 | Прочее не задето | `precheck.sh` | зелёный; язык/версия не изменились | R5 / A4 |

## Разбивка по функциональности

| Функциональность | Ожидание | Проверка | Статус |
|---|---|---|---|
| Компиляционный тест эталона | `cc -c` вместо строки | T1 | ✅ |
| Сторож `S(Ping)=End` | перевод в C | T2 | ✅ |
| Покрытие парсера (`SRC`) | разбор всех конструкций | T4 | ✅ |
| Прод-код, прочие цели | не задеты | T5 | ✅ |
| Язык | не меняется → версия не растёт | — | ✅ |

## Тестовые данные и окружение

- **Тесты:** `grammar/tests/reference_model_tests.rs` (`compile_to_c` + `cc -c`,
  скип без `cc`); `lib.rs::parse_simple` (полный `SRC`).

## Что план сознательно НЕ проверяет

- **Компилируемость полного `SRC`** — он живёт для разбора; его дефекты C
  (`read_numeric`, const `[bit;N]`) — кандидаты (`read_numeric` локален; const —
  за 0078).
