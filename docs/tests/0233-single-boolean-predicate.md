# Тест-план фичи 0233: Правило булевости условия — одно

> Фича: [../features/0233-single-boolean-predicate.md](../features/0233-single-boolean-predicate.md) · ADR: [../adr/0233-single-boolean-predicate.md](../adr/0233-single-boolean-predicate.md) · анализ: [../analyze/0233-single-boolean-predicate.md](../analyze/0233-single-boolean-predicate.md)

## Область и цель

Фича переписывает **устройство** проверки, не меняя её поведения. Значит
проверок две группы: (1) поведение осталось прежним; (2) правила по-прежнему
покрыты — но тестами по **исходнику**, а не по внутренней функции (иначе тест
снова прирастёт к устройству и следующая перестройка сломает его без причины).

Файлы: `takt-lang/src/semantic/validate/tests_implicit_bool.rs`,
`takt-lang/tests/semantic/implicit_bool_delivery_tests.rs` (фича 0232, регресс).

## Тестовые данные и окружение

- Таблица правил построена по **удалённым** тестам: каждый случай, который
  проверялся у второго правила, получил строку — иначе удаление означало бы
  потерю покрытия.
- Проба `S(Ping) = End` взята из замера: это единственная форма, ради которой
  второе правило держали.
- Мутации выполняются вручную с немедленным откатом; T10 фиксирует **границу**
  наблюдаемости, а не дефект.
