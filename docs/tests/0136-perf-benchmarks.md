# Тест-план фичи 0136: бенчмарки производительности

> Фича: [../features/0136-perf-benchmarks.md](../features/0136-perf-benchmarks.md) · ADR: [../adr/0136-perf-benchmarks.md](../adr/0136-perf-benchmarks.md) · анализ: [../analyze/0136-perf-benchmarks.md](../analyze/0136-perf-benchmarks.md)

## Область и цель

Фича инфраструктурная. Проверяется, что бенчи **меряют то, что заявлено** (а не
ранний отказ или вырожденный вход), не влияют на предкоммит и дают числа,
пригодные для сравнения.

⚠️ Проверки «время не больше X» в плане нет: порога нет по решению заказчика.

## Тестовые данные и окружение

Вход генерируется самими бенчами (цепочка на N состояний, модель со счётной
работой, модель с отслеживаемыми переменными) плюс `examples/stacker.takt`.

Окружение: macOS (darwin 25.5.0), Apple Silicon, толчейн `1.97.1`,
`criterion 0.5`, профиль `bench` (оптимизация).

```sh
cargo build --benches
scripts/bench.sh
./scripts/precheck.sh
```
