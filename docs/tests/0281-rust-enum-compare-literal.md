# Тест-план фичи 0281: Сравнение перечисления с числом в цели `rust`

> Фича: [../features/0281-rust-enum-compare-literal.md](../features/0281-rust-enum-compare-literal.md) · ADR: [../adr/0281-rust-enum-compare-literal.md](../adr/0281-rust-enum-compare-literal.md) · анализ: [../analyze/0281-rust-enum-compare-literal.md](../analyze/0281-rust-enum-compare-literal.md)

## Область и цель

Проверяется форма вывода цели `rust` и его приёмка настоящими `rustc` и
`clippy -D warnings`. Требования R1…R6 и критерии A1…A6 — в
[анализе](../analyze/0281-rust-enum-compare-literal.md).

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | R/A |
|---|---|---|---|---|
| T1 | Сравнение с числом | `ref Done: c = 1;` при `c: Command` | `self.c == Command::Go`; `== 1` в выводе отсутствует | R1 / A1 |
| T2 | `!=` и обратный порядок | `ref Done: 0 != c;` | `Command::Stop` в сравнении, числа нет | R2 / A2 |
| T3 | **Контроль:** имя варианта | `ref Done: c = Go;` | не изменилось | R4 / A3 |
| T4 | Присваивание и сравнение согласованы | обе формы в одной модели | одно и то же имя варианта в обоих местах | R3 / A4 |
| T5 | Настоящие `rustc` и `clippy -D warnings` | три входа | сборка успешна | R6 / A6 |
| T6 | Значение вне вариантов | `ref Done: c = 7;` | отказ с причиной «не соответствует ни одному варианту» | R5 / A5 |
| T7 | Корпус и гейты | — | `examples/generated/` не изменились, `precheck.sh` зелён | — / A6 |
