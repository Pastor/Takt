# Тест-план фичи 0088: Остальные нарушители лимита размера модуля (безопасная часть)

> Фича: [../features/0088-module-size-remaining.md](../features/0088-module-size-remaining.md) · ADR: [../adr/0088-module-size-remaining.md](../adr/0088-module-size-remaining.md) · анализ: [../analyze/0088-module-size-remaining.md](../analyze/0088-module-size-remaining.md)

## Область и цель

Фича — **чистое перемещение** кода (Tier 3, качество/процесс): разбиение
файлов-нарушителей размера на подмодули ≤ 1000 строк без изменения поведения и
байт-в-байт вывода генераторов. Соответственно проверки — не «новая
функциональность», а **отсутствие регресса** и выполнение критериев приёмки
A1–A5 анализа (реестр 18 → 6, вывод неизменен, все тесты зелёные, precheck
зелёный, заведена фича-преемник).

Синтаксис/семантика языка **не затронуты** → правило 16 (примеры/контрпримеры
языка) неприменимо: фича не меняет язык.

## Разбивка проверок по функциональности

Обратная функциональность (правило 11) — весь корпус тестов `grammar` и
`simulation`, вывод генераторов, публичный API. Единые условия (T3–T6)
прогоняются против каждой задеваемой подзадачи; статус фиксируется в отчёте.
