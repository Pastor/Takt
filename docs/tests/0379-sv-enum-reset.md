# Тест-план фичи 0379: Сброс перечислимого регистра у цели sv

> Фича: [../features/0379-sv-enum-reset.md](../features/0379-sv-enum-reset.md) · ADR: [../adr/0379-sv-enum-reset.md](../adr/0379-sv-enum-reset.md) · анализ: [../analyze/0379-sv-enum-reset.md](../analyze/0379-sv-enum-reset.md)

## Область и цель

Проверяются R1…R5. Арбитр отказа — **линт цели**; арбитр значения —
**потактовая сверка**: обе формы записи линт принимает, но одна из них меняет
значение.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Значение сброса — ноль | фикстура, чтение регистров ДО первой записи | `[[0, 0], [2, 1]]` у эталона и у RTL | R3 / A2 |
| T2 | Линт принимает вывод | `verilator --lint-only -Wall` | код возврата 0 | R1 / A1 |
| T3 | Форма без нулевого варианта | `enum Mode { Idle = 1, Work = 2 }` | `<= mode_e'(0);` | R4 / A3 |
| T4 | Форма с нулевым вариантом | `enum Phase { Zero = 0, One = 1 }` | `<= PHASE_ZERO;` | R4 / A3 |
| T5 | Синтез | `yosys synth` (через пробу) | код возврата 0 | R2 / A2 |
| T6 | Вывод корпуса не изменился | `precheck.sh` | без диффа | R5 / A4 |
| M1 | Мутация: первый вариант | — | падают T1 и T3 | R3 |
