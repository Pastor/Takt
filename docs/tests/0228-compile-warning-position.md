# Тест-план фичи 0228: Предупреждение taktc compile несёт позицию

> Фича: [../features/0228-compile-warning-position.md](../features/0228-compile-warning-position.md) · ADR: [../adr/0228-compile-warning-position.md](../adr/0228-compile-warning-position.md) · анализ: [../analyze/0228-compile-warning-position.md](../analyze/0228-compile-warning-position.md)

## Область и цель

Проверяется **печать** предупреждений `taktc compile`: позиция доезжает, путь
разрешён верно, формат один на все цели, `--quiet` работает. Наблюдается прогоном
бинаря (`CARGO_BIN_EXE_taktc`) с перехватом stderr — так, как это видит
пользователь.

Файл: `takt-lang/tests/targets/cli_warning_position_tests.rs`; смежный (не задет) —
`cli_warnings_tests.rs` (фича 0081).

## Тестовые данные и окружение

- Фикстуры пишутся в **уникальный по тесту** каталог (фича 0190): тест импорта
  требует, чтобы библиотека лежала рядом с импортёром (фича 0055).
- Ожидаемые строка и колонка сняты **пробой** инструмента, а не выведены из
  чтения кода.
- Префикс разбирается помощником `position_of`, который возвращает `None`, если
  префикса нет вовсе, — ровно то состояние, в котором предупреждения жили до фичи.
