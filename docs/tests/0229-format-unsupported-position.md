# Тест-план фичи 0229: Отказ форматтера — диагностика с позицией

> Фича: [../features/0229-format-unsupported-position.md](../features/0229-format-unsupported-position.md) · ADR: [../adr/0229-format-unsupported-position.md](../adr/0229-format-unsupported-position.md) · анализ: [../analyze/0229-format-unsupported-position.md](../analyze/0229-format-unsupported-position.md)

## Область и цель

Проверяется **сообщение об отказе** `taktc fmt`: позиция, форма, отсутствие
внутреннего представления, доступность структуры вызывающему. Наблюдается
прогоном бинаря (`CARGO_BIN_EXE_taktc`) плюс одной проверкой на уровне библиотеки
— там, где предмет не текст, а тип.

Файлы: `takt-lang/tests/format_unsupported_tests.rs`, обновлённый
`fmt_diagnostic_tests.rs` (фича 0202).

## Тестовые данные и окружение

- Обе достижимые формы отказа (`formula`, `assembly`) — из **замера** анализа, а
  не выбраны наугад: прочие три места грамматикой не строятся.
- Ожидаемые строка и колонка сняты **пробой** инструмента.
- Каталог теста уникален по имени потока (фича 0190).
- Проверка «нет `Debug`-дампа» перечисляет подстроки, которые пользователь
  **видел** до фичи, — это не догадка о форме.
