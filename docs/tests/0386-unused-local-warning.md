# Тест-план фичи 0386: `SE-036` видит локальные объявления тел

> Фича: [../features/0386-unused-local-warning.md](../features/0386-unused-local-warning.md) · ADR: [../adr/0386-unused-local-warning.md](../adr/0386-unused-local-warning.md) · анализ: [../analyze/0386-unused-local-warning.md](../analyze/0386-unused-local-warning.md)

## Область и цель

Проверяется, что неиспользуемая локальная переменная тела получает `SE-036` с
координатой **объявления**, что используемая молчит, и что проверка доходит до
всех трёх мест объявления тела (блок модели, блок состояния, функция) и во
вложенные блоки.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Неиспользуемая локальная | `always { var spare … }` | `SE-036` про `spare` | R1 / A1 |
| T2 | Координата | тот же вход | смещение = начало `var spare` | R2 / A1 |
| T3 | Используемая локальная | `o := t;` | предупреждения нет | R3 / A1 |
| T4 | Вложенный блок | `if n < 2 { var deep … }` | `SE-036` про `deep` | R4 / A1 |
| T5 | Область видимости | объявлено снаружи, использовано в `if` | предупреждения нет | R5 / A1 |
| T6 | Блок уровня модели | `always { var idle_only … }` вне состояния | `SE-036` | R4 / A1 |
| T7 | Тело функции | `fn step(...) { var tmp … }` | `SE-036` | R4 / A1 |
| T8 | Мутации мест обхода | снять обход блоков / функций / состояний | сторож краснеет в каждом случае | R4 / A2 |
| T9 | Корпус | прогон `taktc` по `examples/*.takt` | новых предупреждений нет | R7 / A4 |
| T10 | Знание одно | чтение | `generator::local_stub` — обёртка над носителем семантики | R6 / A3 |

## Тестовые данные и окружение

- Сторож — `takt-lang/tests/semantic/unused_local_tests.rs` (пять тестов).
- ⚠️ **Первая редакция сторожа покрывала одно место из трёх:** мутация «снять
  обход блоков модели» её не роняла, потому что `always` фикстуры принадлежал
  **состоянию**. Тест дополнен входами уровня модели и функции — после этого
  ловятся все три мутации.
- Окружение: `rustc` 1.97.1, macOS 25.5.
