# Тест-план фичи 0275: Команды в README.md никем не проверяются

> Фича: [../features/0275-readme-commands-gate.md](../features/0275-readme-commands-gate.md) · ADR: [../adr/0275-readme-commands-gate.md](../adr/0275-readme-commands-gate.md) · анализ: [../analyze/0275-readme-commands-gate.md](../analyze/0275-readme-commands-gate.md)

## Область и цель

Две группы: (1) гейт ловит негодные команды и не мешает годным; (2) дефект,
найденный гейтом (паника на команде с картой адресов), устранён по существу —
координата указывает в файл карты.

⚠️ Проверка «гейт падает» без контроля «настоящий README проходит» ничего не
доказывает: гейт, падающий всегда, прошёл бы её тоже.

## Тестовые данные и окружение

- **Копия дерева сторожа:** README, `examples/*.takt`, `examples/*.map`,
  `scripts/*`, плюс `examples/generated/rust/Cargo.toml` (его называет
  `--manifest-path`; без него сторож ругался на настоящий README).
- **Вход дефекта:** `examples/elevator.takt` + `examples/elevator.plc.map` —
  карта с кириллическими комментариями, на которых печать и падала.
- **Окружение:** macOS (darwin 25.5.0), Rust 1.97.1.
