# Тест-план фичи 0295: Хвостовой комментарий тела и его хозяин

> Фича: [../features/0295-format-element-comment-binding.md](../features/0295-format-element-comment-binding.md) · ADR: [../adr/0295-format-element-comment-binding.md](../adr/0295-format-element-comment-binding.md) · анализ: [../analyze/0295-format-element-comment-binding.md](../analyze/0295-format-element-comment-binding.md)

## Область и цель

Проверяются **сохранность привязки** комментария и **устройство** печати:
закрывающая скобка тела идёт через один носитель. Требования R1…R5 и критерии
A1…A5 — в [анализе](../analyze/0295-format-element-comment-binding.md).

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | R/A |
|---|---|---|---|---|
| T1 | Хвост остаётся в своём теле | хвостовой комментарий в `enum`, `struct`, `fn`, блоке, состоянии, вложенной модели | отступ каждого комментария равен глубине его тела (4/4/4/12/8/4) | R1, R3 / A1, A2 |
| T2 | Идемпотентность | вывод первого прогона | второй прогон ничего не меняет | R4 / A3 |
| T3 | Канонический текст не трогается | проба в каноне | вывод байт-в-байт равен входу | R3 / A2 |
| T4 | Устройство печати | исходник `format/mod.rs` | нет закрытия тела в обход `close_body`; падение — списком мест | R2 / A4 |
| T5 | Канон корпуса | `examples/` | `fmt --check` зелён, файлы не изменились | R5 / A5 |
