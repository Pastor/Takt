# Тест-план фичи 0081: `lamc compile` печатает предупреждения

> Фича: [../features/0081-lamc-print-warnings.md](../features/0081-lamc-print-warnings.md) · ADR: [../adr/0081-lamc-print-warnings.md](../adr/0081-lamc-print-warnings.md)

## Область и цель

Проверяется **доставка** предупреждений компилятора пользователю через `lamc
compile` — и их **молчание** при `--quiet` и на чистом файле. Наблюдение —
перехватом **stderr** бинаря (`CARGO_BIN_EXE_lamc`): именно так их видит
пользователь.

## Проверки

| # | Проверка | Предусловие | Ожидаемый результат | R/A |
|---|---|---|---|---|
| T1 | Неиспользуемая переменная | `unused_variable.lam` | stderr содержит `SE-036`, формат «Предупреждение» | R1 / A1 |
| T2 | Недетерминизм переходов | `nondeterministic_warn.lam` | stderr содержит `SE-037` | R1 / A2 |
| T3 | `--quiet` глушит | `--quiet unused_variable.lam` | предупреждений нет | R3 / A3 |
| T4 | Чистый файл | `all_vars_used.lam` | предупреждений нет (нет ложных) | — / A4 |
| T5 | Код возврата | корпус, `precheck.sh` | rc=0 сохранён; вывод целей не изменился | R4 / A5 |

## Разбивка по функциональности

| Функциональность | Ожидание | Проверка | Статус |
|---|---|---|---|
| Доставка предупреждений CLI | печатаются для всех целей | T1, T2 | ✅ |
| `--quiet` | глушит | T3 | ✅ |
| Отсутствие ложных | чистый файл молчит | T4 | ✅ |
| Прочие цели, генерация | rc и вывод не изменены | T5 | ✅ |
| Язык | не меняется → версия не растёт | — | ✅ |

## Тестовые данные и окружение

- **Тесты:** `grammar/tests/cli_warnings_tests.rs` — прогон бинаря `lamc`,
  перехват stderr. Фикстуры — `grammar/tests/data/semantic/valid/`
  (`unused_variable.lam`, `nondeterministic_warn.lam`, `all_vars_used.lam`).

## Что план сознательно НЕ проверяет

- **Полноту каждой категории** (unreachable/constant_condition/ltl/…): их
  срабатывание проверяют существующие юнит-тесты семантики; 0081 лишь **подключает**
  их к CLI. T1/T2 репрезентативны для механизма доставки.
- **Чистку `elevator.lam`** (unused `action`) — находка, кандидат вне объёма.
