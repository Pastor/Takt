# Тест-план фичи 0365: Распакованный массив у цели sv

> Фича: [../features/0365-sv-unpacked-array.md](../features/0365-sv-unpacked-array.md) · ADR: [../adr/0365-sv-unpacked-array.md](../adr/0365-sv-unpacked-array.md) · анализ: [../analyze/0365-sv-unpacked-array.md](../analyze/0365-sv-unpacked-array.md)

## Область и цель

Проверяется поведение целей `sv`/`sv-mmio` на распакованном массиве:
валидность вывода под флагами гейта цели и **совпадение значений** с эталоном.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | Массив без инициализатора | `var row: [u8; 2];` | verilator и yosys принимают | R1 / A1 |
