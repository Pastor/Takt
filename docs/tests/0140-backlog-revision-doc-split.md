# Тест-план фичи 0140: ревизия витрины и разделение ролей документов

> Фича: [../features/0140-backlog-revision-doc-split.md](../features/0140-backlog-revision-doc-split.md) · ADR: [../adr/0140-backlog-revision-doc-split.md](../adr/0140-backlog-revision-doc-split.md) · анализ: [../analyze/0140-backlog-revision-doc-split.md](../analyze/0140-backlog-revision-doc-split.md)

## Область и цель

Фича процессная: код не меняется, меняются документы, свод и один
вспомогательный скрипт. Поэтому проверяется не поведение программы, а
**достоверность утверждений** и то, что процесс не сломан.

⚠️ Главное требование к ревизии — каждая правка опирается на **замер**, а не на
память: неверная запись должна замениться верной, а не другой неверной.

## Тестовые данные и окружение

Автоматических тестов у фичи нет — предмет проверки текстовый. Инструменты:

```sh
python3 scripts/check-links.py
./scripts/check-stale-candidates.sh 0131
./scripts/precheck.sh
git diff --stat book/
```

Замеры кандидатов сняты пробами `taktc`/`takt-sim` и грепом по дереву; они
перечислены в анализе и отчёте.
