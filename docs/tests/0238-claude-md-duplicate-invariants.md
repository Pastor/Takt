# Тест-план фичи 0238: Живой контекст: раздел критических инвариантов дублирует подводные камни

> Фича: [../features/0238-claude-md-duplicate-invariants.md](../features/0238-claude-md-duplicate-invariants.md) · ADR: [../adr/0238-claude-md-duplicate-invariants.md](../adr/0238-claude-md-duplicate-invariants.md) · анализ: [../analyze/0238-claude-md-duplicate-invariants.md](../analyze/0238-claude-md-duplicate-invariants.md)

## Область и цель

Правка документа, поэтому проверки — сверки текста, а не прогоны кода. Главная
опасность диеты одна: **унести факт**. Против неё стоит T2 — механическая сверка
идентификаторов удаляемого текста, а не чтение глазами.
