# Тест-план фичи 0165: `taktc version`

> Фича: [../features/0165-taktc-version-subcommand.md](../features/0165-taktc-version-subcommand.md) · ADR: [../adr/0165-taktc-version-subcommand.md](../adr/0165-taktc-version-subcommand.md) · анализ: [../analyze/0165-taktc-version-subcommand.md](../analyze/0165-taktc-version-subcommand.md)

## Область и цель

Проверяется то, что видит пользователь: три входа CLI, их вывод и согласованность
с константами. Требования — R1…R6 анализа.

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
| T1 | `taktc version` | — | обе версии, код 0 | R1 / A1 |
