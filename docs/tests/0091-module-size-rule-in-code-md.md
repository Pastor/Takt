# Тест-план фичи 0091: Правило о размере модуля переносится в docs/CODE.md

> Фича: [../features/0091-module-size-rule-in-code-md.md](../features/0091-module-size-rule-in-code-md.md) · ADR: [../adr/0091-module-size-rule-in-code-md.md](../adr/0091-module-size-rule-in-code-md.md) · анализ: [../analyze/0091-module-size-rule-in-code-md.md](../analyze/0091-module-size-rule-in-code-md.md)

## Область и цель

Проверить, что правило о размере модуля перенесено в свод `docs/CODE.md`, а
`CLAUDE.md` ссылается на него без дубля формулировки, сохранив живой контекст.
Документационная правка — проверки на уровне инспекции/грепа и целостности ссылок.
