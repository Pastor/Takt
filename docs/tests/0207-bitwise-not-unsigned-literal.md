# Тест-план фичи 0207: Отрицание ~0 для беззнакового типа — два правила языка столкнулись

> Фича: [../features/0207-bitwise-not-unsigned-literal.md](../features/0207-bitwise-not-unsigned-literal.md) · ADR: [../adr/0207-bitwise-not-unsigned-literal.md](../adr/0207-bitwise-not-unsigned-literal.md) · анализ: [../analyze/0207-bitwise-not-unsigned-literal.md](../analyze/0207-bitwise-not-unsigned-literal.md)

## Область и цель

Фича меняет **семантику языка**, поэтому по правилу 16 проверки идут примерами и
контр-примерами. Контр-примеры здесь несут не меньше веса, чем примеры: без них
правка неотличима от «разрешить всё».

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |
|---|---|---|---|---|
