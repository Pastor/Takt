# Тест-план фичи 0239: Скрипт релизной сборки и установки инструментов

> Фича: [../features/0239-install-script.md](../features/0239-install-script.md) · ADR: не заводился (инструментальная фича) · анализ: [../analyze/0239-install-script.md](../analyze/0239-install-script.md)

## Область и цель

Проверяется то, что принадлежит **скрипту**: разбор аргументов, состав команд,
выбор каталога сборки, отказы и сообщения. Требования R1–R9 анализа.

⚠️ **Настоящую релизную сборку сторож не запускает.** Она занимает минуты и
принадлежит cargo, а не скрипту; в предкоммит такой тест не добавляется. Сборка
проверяется **один раз вручную** при приёмке (T9).

Фича языка не меняет, поэтому примеров и контрпримеров на Takt (правило 16)
здесь нет.
