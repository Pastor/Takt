# Тест-план фичи 0243: Переопределение типа

> Фича: [../features/0243-type-redefinition-diagnostic.md](../features/0243-type-redefinition-diagnostic.md) · ADR: [../adr/0243-type-redefinition-diagnostic.md](../adr/0243-type-redefinition-diagnostic.md) · анализ: [../analyze/0243-type-redefinition-diagnostic.md](../analyze/0243-type-redefinition-diagnostic.md)

## Область и цель

Проверяется новое правило языка: имя типа занимается один раз. Отдельно —
что запрет **не задел** законные записи и что чистка фикстур не изменила их
поведения.

## Проверки (условие → ожидаемый результат)

| # | Проверка | Предусловие | Ожидаемый результат | Ссылка на R/A |

| T14 | Реестр и документ согласованы | гейты | коды в реестре, разборы в приложении, глифы в шрифте | R8 / A7 |
