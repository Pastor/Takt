# Тест-план фичи 0148: Покрытие печатников цели rust тестами

> Фича: [../features/0148-rust-printers-coverage.md](../features/0148-rust-printers-coverage.md) · ADR: [../adr/0148-rust-printers-coverage.md](../adr/0148-rust-printers-coverage.md) · анализ: [../analyze/0148-rust-printers-coverage.md](../analyze/0148-rust-printers-coverage.md)

## Область и цель

Закрыть ветви печатников цели `rust` сверкой **текста**. Проверяются R1–R7
анализа и критерии A1–A11.

⚠️ Проверять «собралось» здесь бесполезно: молча неверная трансляция собирается
тоже. Расхождение приоритетов C и Rust (`a == b | c` — `1` в C, `false` в Rust)
не даёт ни отказа, ни предупреждения.

Ожидания сняты **зондом** с фактического вывода.

## Примеры и контрпримеры (правило 16)

Фича **язык не меняет** — языковых примеров в `book/` не заводится. Пример и
контрпример относятся к **порождаемому тексту**:

- **примеры** — T1–T13, T15–T25: законные конструкции и их перевод;
- **контрпример** T14 — целое с числом: без него «починка», сводящая к операнду
  всё подряд, прошла бы T9–T13 и сломала обычные сравнения;
- **контрпримеры-границы** T26, T27 — конструкции, на которых цель законно
  отказывает. Важны тем, что доказывают: непереводимое даёт **код**, а не тихо
  пропадает из вывода.

Мутация T28 проверяет **сам набор**, а не продукт.
