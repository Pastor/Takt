# Тест-план фичи 0129: Устранение переполнения стека на глубине выражений и операторов

> Фича: [../features/0129-semantic-deep-nesting.md](../features/0129-semantic-deep-nesting.md) · анализ: [../analyze/0129-semantic-deep-nesting.md](../analyze/0129-semantic-deep-nesting.md) · отчёт: [../reports/0129-semantic-deep-nesting.md](../reports/0129-semantic-deep-nesting.md)

## Область и цель

Фича **языковая**: вводится ограничение и новая диагностика `SE-062`, поэтому
правило 16 применяется полностью — проверки, примеры и контрпримеры.

Особенность области: проверяется поведение при **отказе**, а не вычисление.
Поэтому центральные проверки идут через **публичный API и через CLI**: тест на
внутренний счётчик доказал бы работу механизма, но не то, что точки входа
прикрыты. Это не теория — ровно так и вышло со сторожем операторов: механизм
работает, а путь до него в сегодняшних проходах недостижим.

## Примеры и контрпримеры (правило 16)

**Контрпример — отвергается с `SE-062`:**

```takt
var x: u8 := 0;
start S {
    ref S: (((( … ))))  = 1;   // несколько сотен вложенных скобок
}
```

**Пример — принимается как прежде** (вложенность реальных спецификаций):

```takt
var x: u8 := 0;
const LIMIT: u8 := 5;
start S {
    ref Done: ((x + 1) * 2) >= LIMIT;
}
```

Контрпример с разбором и способом обхода (именованные условия `cond`,
промежуточные переменные) вынесен в приложение «Ошибки и предупреждения»;
упоминание — в блок «Частые ошибки» раздела «Выражения».

## Разбивка проверок по функциональности

- **Отказ устранён** — A1, A2, A9 (главная проверка: три инструмента, ни одного
  аварийного завершения).
- **Граница работает и названа** — A4, A5.
- **Обычный код не задет** — A3, A12 (вывод корпуса неизменен).
- **Механизм корректен** — A6, A7, A8 (учёт выхода из рекурсии).
- **Контракт проекта** — A10 (реестр кодов), A11 (реестр размера модулей).

## Тестовые данные и окружение

Входы порождаются в тестах (`"(".repeat(depth)`), файлов-фикстур не требуется.
Юнит-тесты механизма — в `takt-lang/src/semantic/validate/depth.rs`,
интеграционные — в `takt-lang/tests/semantic/deep_nesting_tests.rs`. Сквозная проба A9 —
через собранные `taktc` и `takt-sim`. Окружение — пин толчейна `1.97.1`
(фича 0137).

⚠️ **Замер, определяющий предел, зависит от окружения:** глубина, которую
выдерживает стек, различается между профилями сборки и размерами стека потока
(измерено: 240–280 в основном потоке CLI, 48–64 в потоке `cargo test`). Поэтому
тесты проверяют **правило** (предел срабатывает и не мешает обычному коду), а не
конкретную глубину падения.
