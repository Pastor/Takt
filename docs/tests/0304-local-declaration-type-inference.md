## Примеры и контрпримеры (правило 16)

**Пример** (предмет фичи):

```takt
start Run {
    always {
        var g := F + 1;   // тип выводится
        sum := sum + g;
    }
    ref Run: sum < 100;
}
```

**Контрольный вход** — то же объявление на верхнем уровне (`var top := F + 1;`):
работал всегда, и его совпадение показывает, что предмет именно тело блока.

⚠️ **Тело обязано накапливать.** Первая редакция фикстуры не имела перехода:
состояние уходило в `END` после первого такта (правило 0303), накопление не
наблюдалось, и трассы разошлись (6,12,18 против 6,6,6). Поймано самой сверкой.
