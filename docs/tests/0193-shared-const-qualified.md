# Тест-план фичи 0193: Цели `rust` и `sv` — одноимённые константы разных моделей

> Фича: [../features/0193-shared-const-qualified.md](../features/0193-shared-const-qualified.md) · ADR: [../adr/0193-shared-const-qualified.md](../adr/0193-shared-const-qualified.md) · анализ: [../analyze/0193-shared-const-qualified.md](../analyze/0193-shared-const-qualified.md)

## Область и цель

Проверяется, что одноимённые константы разных моделей **не сливаются** в целях
`rust` и `sv`, что цели `c`/`st` при этом не задеты, и что сторож этого класса
**значенческий**, а не «собралось».

⚠️ Ключевая особенность плана: гейты целевых языков здесь **непригодны как
свидетели**. `clippy -D warnings`, `verilator` и `yosys` дефектный вывод
принимают — он валиден, просто считает не то. Поэтому центральная проверка — T7
(потактовая сверка), а её ценность доказывается T8 (мутация).

## Тестовые данные и окружение

Фикстура (одна на весь план — она же проба ADR):

```takt
out a: u8;
out b: u8;
model A { const K: u8 := 2; start Run { always { a := K; } ref Run; } }
model B { const K: u8 := 3; start Run { always { b := K; } ref Run; } }
start Main = A | B;
```

Контрпример для T4/T5 — тот же вход, где модель `B` пишет литерал вместо своей
константы: `K` модели `B` объявлена, но не используется.

Окружение: macOS (Darwin 25.5.0), толчейн `1.97.1`, `rustc`/`clippy-driver`,
`verilator`; `./scripts/precheck.sh`. Отсутствие инструмента → соответствующая
половина сверки **пропускается с сообщением**, трасса эталона проверяется всегда.
