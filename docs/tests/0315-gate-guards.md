# Тест-план 0315: сторожа гейтов

> Фича: [../features/0315-gate-guards.md](../features/0315-gate-guards.md) · ADR: [../adr/0315-gate-guards.md](../adr/0315-gate-guards.md) · отчёт: [../reports/0315-gate-guards.md](../reports/0315-gate-guards.md)

## Условия

| # | Условие | Проверка |
|---|---|---|
| П1 | Битая ссылка ловится; целая, внешняя, в коде и в блоке — нет | `check-links.py --self-test` |
| П2 | Снятый атрибут `deny` ловится | `test-exhaustive-nodes.sh` (2) |
| П3 | Атрибут **в комментарии** не засчитывается | там же (3) |
| П4 | Пропавший файл — отказ | там же (4) |
| П5 | Отставшие README / живой контекст ловятся | `test-language-version.sh` (2, 3) |
| П6 | Отсутствующий и двойной якорь ловятся | там же (4, 5) |
| П7 | Разошедшийся адрес и doc-ссылка ловятся | `test-repo-url.sh` (2, 4) |
| П8 | Отставший `cd <имя>` ловится | там же (3) |
| П9 | Каждый сторож принимает здоровый вход | все (1) |
| П10 | Предкоммит зелёный | `./scripts/precheck.sh` |

## Почему тесты именно такие

- **«Хорошее проходит» (П9) обязательно:** сторож, ловящий всё подряд,
  доказывает лишь, что гейт умеет падать.
- **Вырожденный вход (П4, П6)** — гейт, которому нечего проверять, обязан
  падать; иначе зелёный прогон означает пустоту с обеих сторон (класс фикса
  0202-01).
- **Проверяется предмет гейта, а не его запуск:** атрибут в комментарии,
  двойной якорь, `cd <имя>` — это те самые дефекты, ради которых гейты
  заводились.
