# Тест-план фичи 0225: Модуль semantic/statement.rs — 999 строк при пределе 1000

> Фича: [../features/0225-statement-module-size.md](../features/0225-statement-module-size.md) · ADR: [../adr/0225-statement-module-size.md](../adr/0225-statement-module-size.md) · анализ: [../analyze/0225-statement-module-size.md](../analyze/0225-statement-module-size.md)

## Область и цель

Фича — **чистый рефакторинг раскладки**: блок тестов переезжает из
`semantic/statement.rs` в `semantic/statement/tests.rs`, логика не меняется.
Отсюда две группы проверок:

1. **Цель достигнута** — файл разделён, запас появился, реестр долга не
   пополнен (R1–R3).
2. **Ничего не потеряно** — тот же набор тестов, то же поведение компилятора,
   строгая сборка (R4–R6).

Главный риск здесь — **молчаливая потеря тестов**: ошибка в подключении даёт
зелёную сборку при непрогоняемом файле. Поэтому проверяется не число зелёных
тестов, а **список их имён** до и после.
