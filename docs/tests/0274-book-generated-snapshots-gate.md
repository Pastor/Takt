# Тест-план фичи 0274: Снимки порождённого кода в book/ никем не сверяются

> Фича: [../features/0274-book-generated-snapshots-gate.md](../features/0274-book-generated-snapshots-gate.md) · ADR: [../adr/0274-book-generated-snapshots-gate.md](../adr/0274-book-generated-snapshots-gate.md) · анализ: [../analyze/0274-book-generated-snapshots-gate.md](../analyze/0274-book-generated-snapshots-gate.md)

## Область и цель

Проверяется **гейт**, а не снимки: снимки — следствие. Главное свойство —
расхождение ловится и называет место; рядом обязателен контроль «согласованное
дерево принимается», иначе гейт, падающий всегда, прошёл бы проверку тоже.

## Тестовые данные и окружение

- **Данные гейта:** `book/src/18-showcase/{examples,generated}` (пять целей) и
  `book/src/12-time/{examples,generated}` (цель `c`, модель с `clock`).
- **Сторож** работает на копии дерева (`BG_ROOT`), рабочие снимки не трогает.
- **Окружение:** macOS (darwin 25.5.0), Rust 1.97.1; компилятор берётся из
  `target/precheck/debug/taktc` (переопределяется `TAKTC`).
