## Краткое описание

`takt-lang/src/semantic/statement.rs` — 999 строк при пределе ~1000. Подробности находки, замеры и оговорки — в разделе «Что известно на
входе»; форма решения определяется стадиями архитектуры и анализа.

> правилу 17.

## Что известно на входе

> Фича заведена **из кандидата** блока 2 `FEATURES.md` (запрос заказчика

> стадии 2–3 жизненного цикла; ниже — запись кандидата **как есть**, вместе с
> замерами и оговорками, сделанными при его заведении.

> ⚠️ Замеры кандидата **не перепроверялись** при переводе в фичу: их

> кандидатов устаревают, и две из них оказались неверны).

**Класс:** инструменты и процесс (Tier 4 — приоритет по решению заказчика
2026-08-03: синтаксис → семантика → генерация → остальное).

**`takt-lang/src/semantic/statement.rs` — 999 строк при пределе ~1000.**
Замер при закрытии 0155 (`scripts/check-module-size.sh` зелёный, но запаса
нет). Следующая правка модуля обязана начинаться с разделения по образцу
`semantic/validate/` («директория-подмодуль + `use super::*`», приёмы фичи
0088), иначе гейт размера её отвергнет. В реестр долга
`scripts/module-size-baseline.txt` файл **не вносить**: реестр замораживает
нарушителей, а этот в лимит укладывается.

Прежде блок был пуст: все кандидаты переведены в фичи 0143–0177 (2026-07-28,
решение заказчика) — каждая получила карточку стадии 1 без проработки, и отбор
«что брать, что не брать» идёт по таблице блока 1, а не по этому списку. Две
записи, помеченные «УСТАРЕЛО», сняты как опровергнутые (сверка цели `st` есть —
`takt-sim/tests/conformance/conformance_st_tests.rs`; гейт компиляции `c-hal` есть —
`scripts/precheck.sh`). Заметка о расхождении `>>` между целями работой не
является и перенесена в живой контекст [CLAUDE.md](../../CLAUDE.md).

Новые находки записывать сюда: подтверждать пробой или чтением кода и указывать,
при какой работе вскрыта.

## Документирование (правило 24)

**Не требуется.** Язык не меняется: перемещается блок тестов внутри крейта
`takt-lang`. Документ `book/` описывает язык, а не раскладку исходников
компилятора. Версия языка не поднимается (правило 22).

## Итог (что сделано)

`takt-lang/src/semantic/statement.rs` разделён на `semantic/statement/mod.rs`
(**381** строка — логика) и `semantic/statement/tests.rs` (**602** — тесты) по
образцу `semantic/expression/` (приём ADR 0088, применённый фичей 0129). Логика
не переписывалась: ветви исчерпывающего `match` в `resolve_ast_statement`
остались в одном файле.

⚠️ **Замер кандидата устарел вдвойне.** Число: не 999, а **976** (после того
замера файл правили трижды, и две правки его сократили). Вывод «следующая
правка обязана начинаться с разделения, иначе гейт её отвергнет» — опровергнут
историей: гейт не отказывал ни разу. Настоящий предмет — **малый запас** (24
строки), а не блокировка. Вдобавок файл был лишь **седьмым** из девяти в зоне
≥ 970 строк; класс вынесен кандидатом («жёлтая зона» гейта размера).

Список имён тестов совпал побайтово (26), порождённый код не изменился,
`./scripts/precheck.sh` — код 0 (3110 тестов).
