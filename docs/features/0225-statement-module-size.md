**`takt-lang/src/semantic/statement.rs` — 999 строк при пределе ~1000.**
Замер при закрытии 0155 (`scripts/check-module-size.sh` зелёный, но запаса
нет). Следующая правка модуля обязана начинаться с разделения по образцу
`semantic/validate/` («директория-подмодуль + `use super::*`», приёмы фичи
0088), иначе гейт размера её отвергнет. В реестр долга

нарушителей, а этот в лимит укладывается.

решение заказчика) — каждая получила карточку стадии 1 без проработки, и отбор

записи, помеченные «УСТАРЕЛО», сняты как опровергнутые (сверка цели `st` есть —
`takt-sim/tests/conformance_st_tests.rs`; гейт компиляции `c-hal` есть —
`scripts/precheck.sh`). Заметка о расхождении `>>` между целями работой не
