## Краткое описание

Замер 2026-08-21 на `struct Pair { … } var pair: Pair := {1, 2};`:

| Потребитель | Ответ |
|---|---|
| эталон, `c`, `c-hal`, `rust`, `sv`, `sv-mmio` | исполняют / инструменты приняли |
| `st`, `st-at` | **`iec2c` ОТВЕРГ:** «invalid located variable declaration» |

`taktc` возвращал **ноль**, а ответ `iec2c` указывает на `AT %…`, которых в
объявлении нет вовсе: по тексту причину не найти. Причина — идентификаторы IEC
61131-3 **регистронезависимы** и делят одно пространство имён, поэтому `pair` и
`Pair` для MatIEC одно имя.

⚠️ Класс найден **пробой чужой фичи** (0373): там он дважды увёл замер не туда.

## Итог (что сделано)

- Столкновение имени переменной с именем объявленного типа отвергается
  **`ST-023`**, называющим оба имени и говорящим, что модель остаётся валидной
  для прочих шести целей (прецеденты `ST-014`, `SV-012`).
- ⚠️ **Отказ, а не переименование:** внутри самой цели уже два отказа того же
  рода (`ST-014` — столкновение со стандартной библиотекой, `ST-020` — символ
  вне алфавита), и переименование за автора расходилось бы с ними; кроме того,
  оно потребовало бы одного носителя имени для объявления и **всех** обращений.
- ⚠️ Сравнение **без учёта регистра** — иначе проверка не ловила бы ничего:
  совпадение по регистру в IEC не значит ничего.
- ⚠️ **Имена берутся из того, что цель ПЕЧАТАЕТ, а не из того, что объявлено**
  (фикс [0378-01](../fixes/0378-01-enum-namesake-false-positive.md)): в разделе
  `TYPE` у цели `st` есть только **структуры** — перечисление идёт целым типом
  плюс `VAR CONSTANT` (откат Option C, 0041-02), псевдоним раскрывается. Первая
  редакция брала все три карты модели и отвергала `var mode: Mode;` — вход,
  который `iec2c` принимает.
- ⚠️ Проверки имени сведены в **одну воронку** `check_st_declaration`, и её
  зовут все три места объявления: переменная, порт и константа. Прежде каждое
  звало `check_st_name` по отдельности — а новая проверка, добавленная в одно
  из трёх, разошлась бы с остальными (класс 0084/0193/0195).
- ⚠️ Контрпример обязателен: непересекающееся имя переводится, и `iec2c` вывод
  принимает.
- Вывод корпуса не изменился.

Детали — в [отчёте](../reports/0378-st-name-type-clash.md).
