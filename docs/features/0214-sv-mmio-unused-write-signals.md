**Цель `sv-mmio` на модели без входных битов оставляет `reg_wdata`/`reg_wen`
неиспользованными.** Замер при закрытии
[0189](0189-anonymous-ports.md) (2026-08-01):
`verilator --lint-only -Wall` даёт четыре `UNUSEDSIGNAL` и на
`examples/regulator.takt` (все порты — `out`), то есть свойство **старше**
фичи и к анонимным ячейкам не сводится. Гейт это принимает (предупреждения
verilator кода возврата не меняют), но сигнал шины, который никуда не идёт, —
либо лишний в интерфейсе, либо признак незаконченной трактовки записи.
Возможные меры: эмитить `reg_wdata`/`reg_wen` только при наличии
записываемых битов (меняет форму интерфейса — нужен ADR) либо позволить шине
писать в такие регистры с приоритетом над автоматом (два драйвера одного
разряда — требует арбитража в `always_ff`).
