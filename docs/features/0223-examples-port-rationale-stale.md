**Три примера объясняют свой выходной порт нуждой цели `rust` — объяснение
устарело.** Вскрыто при закрытии
[0174](0174-rust-new-without-default.md) (2026-07-29).
Комментарии `regulator.takt`, `float_regulator.takt` и `pid_regulator.takt`
говорят: «выходной порт нужен и цели `rust` (модель без портов →
`clippy::new_without_default`)». После 0174 модель без портов получает
`impl Default` и линт молчит, то есть порт по этой причине больше не нужен.
⚠️ **Порты снимать не предлагается** — у `regulator` и `pid_regulator` на
`ready` завязаны тестбенчи SV; речь только о правке **комментариев**.
В объём 0174 не взято: косметика по трём файлам корпуса, не относящаяся к
предмету фичи.
