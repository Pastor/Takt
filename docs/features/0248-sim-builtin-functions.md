## Краткое описание

Встроенные функции языка (`min`, `max`, `abs`, `clamp`, `debug`, `S`) не
исполняются симулятором: ветвь отвечает `SIM-020` и останавливает прогон, тогда
как цели их переводят. Найдено гейтом ветвей-заглушек фичи
[0217](0217-stub-branch-gate.md).

> Фича зарегистрирована по находке гейта 0217 (2026-08-17); далее проходит
> жизненный цикл по правилу 17.

## Что известно на входе

**Класс:** семантика/эталон (Tier 2 — расхождение эталона с целями).

Ветвь `FunctionDefinitionNode::Builtin` в `takt-sim/src/unit/statement.rs`
отвечает `SIM-020` «встроенная функция … пока не поддерживается симулятором»,
номера задачи не называя.

**Проба 2026-08-17:** `m := min(n, 3);` — эталон останавливает прогон
`SIM-020`, а цель `c` тот же вход переводит **верно**:
`model->m = (((model->n) < (3)) ? (model->n) : (3));`. То же с `debug(n)`.

Затронуты все встроенные из `semantic/builtin.rs`: `debug`, `S`, `min`, `max`,
`abs`, `clamp`.

⚠️ Это ровно тот класс, ради которого заведены потактовые сверки (уроки 0045 и
0050): цель компилируется и считает, эталон не исполняется вовсе — сверить их
на такой модели нечем.

Проработка — стадии 2–3: реализовать вычисление встроенных в эталоне (`debug` —
побочный эффект вывода; `S` пересекается с фичей 0245) и завести сверку
значений, доказывающую совпадение с целями.
