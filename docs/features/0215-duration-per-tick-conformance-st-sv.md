**Класс:** инструменты и процесс (Tier 4 — приоритет по решению заказчика
2026-08-03: синтаксис → семантика → генерация → остальное).

**Потактовых сверок длительностей для целей `st` и `sv` нет.** Замер при
закрытии [0183](0183-duration-type-in-targets.md) (2026-07-29):
значения `duration` и вычисляемая выдержка сверяются с эталоном только для целей
`c` и `rust` (`conformance_{c,rust}_duration_tests`). Для `st` и `sv` проверяется
**текст** вывода на конкретные числа миллисекунд плюс прогон `iec2c` и
`verilator`. ⚠️ Это слабее: оба инструмента принимают и молча неверный код —
ровно на этом стояли дефекты 0041 и 0045.
Чего не хватает: обвязки наблюдения — для `st` трансляция MatIEC → C и драйвер к
`POUS.c` с точными именами полей (образец есть в `conformance_st_tests.rs`), для
`sv` тестбенч RTL (образец — `conformance_sv_tests.rs`). Работа механическая, но
не однострочная.
