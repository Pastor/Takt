# Фича 0407: Степень в инициализаторе константы не сворачивается

- **Номер:** 0407
- **Статус:** СОЗДАНА
- **Зависит от:** нет
- **Tier:** 1
- **Класс:** семантика
- **Связанные issue (анализ):** находка фичи [0404](0404-language-coverage-debt.md)

## Стадии жизненного цикла (правило 17)

Все стадии — **разделы этой карточки** (правило 32). Отдельным артефактом
остаются только исправления — [`docs/fixes/`](../fixes/README.md).

## Краткое описание

`const SPAN: u16 := 2 ** 8;` — вычислимая при компиляции запись, но
константный вычислитель оператор `**` не знает, и один вход даёт **четыре**
разных ответа.

## Замер (правило 30, 2026-08-23, `scripts/probe.sh`)

| Потребитель | Ответ |
|---|---|
| эталон | `v = 0` — значение константы теряется **молча** |
| `c` | `CC-023`: «невычисленное значение константы … узел не прошёл семантическое понижение» |
| `st`, `rust` | переводят верно |
| `sv`, `sv-mmio` | `SV-002` |
| `plantuml` | принимает |

⚠️ **Tier 1**: эталон и цели расходятся **значением**, и у эталона расхождение
молчаливое — ноль вместо 256. Та же запись **в теле** работает у всех восьми
целей (фича 0328 завела целую степень), то есть ломается именно свёртка
инициализатора (0192).

## Заметки к проработке

- Носитель свёртки — `semantic/const_eval/`; таблица целочисленных операций
  живёт в `const_eval/int_ops.rs` (фича 0208). Оператора `**` в ней нет.
- ⚠️ Семантика степени уже задана фичей [0328](0328-integer-power.md): счёт
  **целыми**, с обёрткой по правилу 0127. Второго знания о ней заводить
  нельзя — свёртка обязана звать ту же таблицу.
- ⚠️ Код `CC-023` у цели `c` означает «дефект инструмента» (класс 0212), и
  здесь он **уместен**: узел действительно не прошёл понижение. Чинить надо
  свёртку, а не текст отказа.
- Найдено при попытке написать пример для книги: запись, естественная для
  ёмкости окна (`2 ** 8`), не переводится.
