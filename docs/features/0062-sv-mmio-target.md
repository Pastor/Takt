# Фича 0062: Цель `sv-mmio`: адреса портов → регистровый файл на шине

- **Номер:** 0062
- **Статус:** ГОТОВО (2026-07-20; `./scripts/precheck.sh` зелёный)
- **Зависит от:** **[фикс 0020-01](../fixes/0020-01-port-bit-out-of-range.md)** (Tier 1, заведён этой проработкой, **не закрыт**) — язык не выражает ширину адресуемого слова, поэтому `0x44533932:33` не интерпретируем, а правило 6 ADR запрещает **угадывать**. ⚠️ Формально `ЗАБЛОКИРОВАНА` определена правилом 17 через **фичу**-зависимость, а 0020-01 — фикс; буква правила фичу не блокирует, **существо — блокирует**. Прочие опоры **закрыты**: [0045](0045-sv-backend.md) (каркас `generator/sv/`), [0020](0020-port-address-decl.md) (`AddressMap`), [0048](0048-deterministic-codegen.md) (критерий A3).
- **Приоритет / Tier:** **Tier 3** — ничего не сломано (`-t sv` честно игнорирует адрес: это **принятое** решение ADR 0045, а не дефект), пользователя нет, ни одна фича от неё не зависит. ⚠️ **Ценность выше Tier:** фича замыкает 0020 — адрес начинает значить одно и то же по обе стороны шины.
- **Крейт:** `grammar` (новая цель; правка `bin/lamc.rs:532`), `simulation` (сверка)
- **Связанные issue (анализ):** новая фича (перевод кандидата из `FEATURES.md`); исполняет отложенный **Option B** [ADR 0045](../adr/0045-sv-backend.md) (вопрос 5); вскрыла [фикс 0020-01](../fixes/0020-01-port-bit-out-of-range.md)

## Краткое описание

Карта адресов ([0020](0020-port-address-decl.md)) целью `sv` **не потребляется**:
MMIO-адрес для RTL бессмыслен — разыменование `*(volatile*)` в аппаратуре не
существует. Но осмысленна другая трактовка: породить **регистровый файл** на
APB/AXI-Lite/Wishbone, где адрес задаёт смещение регистра. Это **самостоятельная
цель**, а не флаг `sv`.

Вынесено закрытой [0045](0045-sv-backend.md) (ADR, вопрос 5, Option B).

> **Объединены два кандидата.** В `FEATURES.md` находка была записана **дважды** —
> «Цель `sv-mmio`: адреса портов → регистровый файл на шине» и «Цель `sv-mmio`» —
> с одним и тем же содержанием; при заведении сведены в одну фичу (решение
> заказчика 2026-07-17).

## Итог проработки (2026-07-17)

**Возражения ADR 0045 сняты — оба они про шину, а не про регистровый файл.**
ADR 0045 вынес Option B в кандидаты, потому что тот «требует выбрать шину (APB?
AXI-Lite? Wishbone?) — решение, для которого в требованиях нет **никакого**
основания», и тянет **BFM** в тест-план. Убрав протокол из объёма, снимаем оба и
сохраняем всю ценность.

**Принято** ([ADR](../adr/0062-sv-mmio-target.md), Option B): **шинно-агностичный
регистровый файл** — модуль получает простой синхронный регистровый интерфейс
(адрес, данные, стробы) **без протокола**; адаптеры APB/AXI-Lite/Wishbone —
отдельные фичи **по требованию**. Выбор протокола есть **требование**, и приносит
его заказчик, а не угадывает архитектор. Побочно: регистровый интерфейс дёргается
в тестбенче напрямую — **BFM не нужен**.

**Замер, определивший дизайн:**

| Файл | Адреса | Что показал |
|---|---|---|
| `stacker.lam` | 17 шт., `0x100`…`0x601`, сгруппированы по назначению | это **уже** карта регистров |
| `elevator.lam` | `0x10000000`… | плоский физический MMIO |
| `extend_complex.lam` | `0x44533932`, биты **1, 2, 33** | **одно слово — три порта РАЗНЫХ направлений** |

Отсюда правило: **направление принадлежит биту, а не слову** — регистр не бывает
просто read-only/write-only.

⚠️ **Вскрыт [фикс 0020-01](../fixes/0020-01-port-bit-out-of-range.md) (Tier 1),
и он блокирует полный объём.** Бит адреса **не проверяется нигде** (греп по всему
`grammar/src`; `bit: Option<i64>` допускает даже отрицательный). Цель `c-hal` на
бите 8…31 читает **всегда 0** (загружен один байт), на бите ≥ 32 даёт **UB**
(`int >> 33`, C11 6.5.7p3); `cc -Wall` **молчит** — бит есть значение времени
выполнения. Корпус такой случай **содержит** (`extend_complex.lam:13`). Дожило
потому, что **`c-hal` не компилируется ни одним гейтом**: в `precheck.sh` она
только в гейте **детерминизма** — вывод сверяют сам с собой, но компилятору не
подают.

Следствие для 0062: язык **не выражает ширину адресуемого слова**, поэтому цель
обязана **отказывать**, а не угадывать (правило 6 ADR). Угадать — значит повторить
ошибку, за которую ADR 0045 отверг fixed-point.

⚠️ **Рекомендация аналитика:** сначала **0020-01**. Замыкание «две половины одной
шины» бессмысленно, пока одна из половин (`c-hal`) читает биты неверно и не
компилируется гейтом.

Язык не меняется → версия не растёт (правило 22).

## Итог (что сделано) — 2026-07-20

Принята **Option B** ADR (шинно-агностичный регистровый файл). Реализация по
задачам 0062-01 (интерфейс + карта регистров) и 0062-02 (приём карты + сверка);
блокер [0020-01](../fixes/0020-01-port-bit-out-of-range.md) снят фичей-владельцем
[0098](0098-port-bit-range-safe-hal.md) **до** взятия 0062 в работу.

**Сделано:**

- **Цель `-t sv-mmio`** (вариант `Language::SvMmio`, диспетчер `generate()`); ядро
  регистрового файла — новый модуль `generator/sv/sv_mmio.rs`. Автомат, композиция,
  сброс, функции — **переиспользуют** генератор `sv` без изменений; отличается лишь
  плумбинг портов.
- **Порт с адресом → бит регистра, без адреса → порт модуля** (правило 2):
  `collect_ports` исключает адресованные; адресованный `out` становится внутренним
  регистром автомата (`sv_fsm::Fsm::build`, `declare_reg: true`), адресованный
  `in` — регистром, пишущимся шиной (отдельный `always_ff` в `sv_mmio`).
- **Интерфейс без протокола** (правило 3): `reg_addr` (ширина — из максимума
  адреса), `reg_wdata`/`reg_rdata` (ширина — из максимума `bit + width`, не
  фиксированные 64: лишние старшие биты дали бы `UNUSEDSIGNAL`), `reg_wen`;
  синхронный. Адаптеры APB/AXI-Lite/Wishbone — по-прежнему отдельные фичи (A-2).
- **Направление по биту** (правило 4): чтение `reg_rdata` собирает слово из всех
  портов адреса; запись касается только `in`-битов (правило 5). Смешанное слово
  (out+in по одному адресу) собирается верно (тест `mixed_direction_word_*`,
  синтез yosys ✓).
- **Не угадываем** (правило 6): `SE-060` (бит вне `[0, 63]`, из слоя 0098),
  `SV-013` (срез вне 64-битного регистра), `SV-014` (имя = сигнал интерфейса),
  `SV-006` (адресованный `inout`).
- **`--address-map` принят** (правило 7): единственная правка вне новой цели —
  `bin/lamc.rs` (`consumes_addresses += "sv-mmio"`) + `compile_to_sv_mmio` в
  `compile_sv_mmio.rs`. Приоритет источников (0020) не тронут. ⚠️ **`SE-052` снят
  для `sv-mmio`**: used-порт без адреса — не ошибка, а порт модуля.

**Критерии приёмки:** A1 (карта регистров `stacker` = адреса модели) ✓ —
`sv_mmio_tests`; A2 (verilator **и** yosys) ✓ — гейт `precheck.sh`; A3 (цель `sv`
байт-в-байт) ✓; **A4 (потактовая сверка через регистры)** ✓ —
`conformance_sv_mmio_tests::per_tick_trace_matches_generated_sv_mmio`; A5
(смешанное слово по правилам, не угадано) ✓; A6 (T6/T7 — запись в `out`
игнорируется, чтение `in` возвращает записанное) ✓ — самопроверяющийся тестбенч;
A7 (порт без адреса = порт модуля) ✓; A8 (`--address-map` принят, приоритет
прежний) ✓; A9 (язык/версия не менялись) ✓.

**Отклонения и находки:**

- **Смешанное слово с `out`-битами не проходит `verilator -Wall`** и потому **не
  в гейте**: биты `reg_wdata`, соответствующие `out`-позициям, шиной не читаются →
  `UNUSEDSIGNAL`. Это неотъемлемо (write-шина регистрового файла с read-only
  битами). Опорный пример гейта — `stacker` (уникальные адреса, плотные u8-входы,
  `-Wall` чист); смешанное слово проверено кодогенным тестом + `yosys`.
  `extend_complex` (реальное смешанное слово корпуса) не SV-транслируем сам по
  себе (`extern fn`).
- **Дедупликация `bin/lamc.rs`:** ветки `c-hal`/`st-at`/`sv-mmio` и
  `plantuml`/`st`/`rust`/`sv` сведены к `report_hal_result`/`report_simple_result`
  — это окупило добавления, файл **ужат** 2009 → 1993 (реестр долга обновлён).
  `compile_to_sv_mmio` вынесен в `compile_sv_mmio.rs` (`lib.rs` под лимитом).
- **Тайминг сверки:** запись входа шиной синхронна (защёлкивается на фронте),
  поэтому потактовая сверка ведётся на **автономной** фикстуре (выходы без
  входов); семантика входов проверена отдельно с явным таймингом (гонка снятия
  `reg_wen` в тот же слот — артефакт тестбенча, не модуля).

Язык не менялся → версия не поднята (правило 22).
