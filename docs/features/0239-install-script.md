## Краткое описание

Собрать релизные `taktc`, `takt-lsp` и `takt-sim` и поставить их в `bin`
префикса — одной командой, без запоминания трёх вызовов `cargo` с разными
манифестами и фичами.

## Что известно на входе

До фичи README предлагал два вызова:

```sh
cargo build --release --bin taktc
cargo install --path grammar --bin taktc
```

Обе строки **устарели**: крейт `grammar` переименован в `takt-lang` ещё фичей
0100, то есть `cargo install --path grammar` не работает вовсе. Симулятор и
языковой сервер в разделе установки не упоминались; `takt-lsp` вдобавок
требует фичи `lsp`, без которой бинарника не существует, — и об этом знал
только раздел про редакторы.

⚠️ Второе известное: сборка **в общий `target`** может идти часами. Замер фичи
0234 и повторный замер 2026-08-17 (рабочий каталог — 110 ГБ, 629 590 файлов в
`debug/deps`): cargo обходит каталог перед каждой единицей компиляции. Скрипт,
который зависает на чужом мусоре, бесполезен.

## Документирование (правило 24)

**Не требуется** для языковых разделов: фича не меняет ни синтаксис, ни
семантику, ни поведение целей. Правку получил `README.md` — он по правилу 15
описывает инструментарий и сборку.

## Итог (что сделано)

`scripts/install.sh` собирает **релизные** бинарники трёх инструментов и ставит
их в `$PREFIX/bin` (по умолчанию `~/.local/bin` — тот же префикс, куда проект
уже ставит `iec2c`).

- Флаги: `--prefix`, `--no-lsp`, `--build-only`, `--check`, `--dry-run`,
  `--help`; переменные `TAKT_PREFIX` и `CARGO_TARGET_DIR`.
- ⚠️ **Каталог сборки по умолчанию — свой** (`target/install`): состояние
  каталога сборки есть свойство инструмента, а не дисциплина автора (урок
  0234). Вызывающий волен назвать другой через `CARGO_TARGET_DIR`.
- ⚠️ **`taktc --version` скрипт не зовёт**: подкоманды версии у компилятора нет
  (незакрытая фича 0165), а `--version` он отвергает как неизвестную команду.
  Признак свежести — размер и время файла, которые скрипт печатает.
- Скрипт **предупреждает**, если `$PREFIX/bin` не в `PATH`: молча установленный
  и невидимый инструмент выглядит как несработавший скрипт.
- Сторож — `scripts/test-install.sh` (A1–A8): разбор аргументов, состав команд,
  выбор каталога, отказы. Настоящую релизную сборку он не гоняет — она занимает
  минуты и принадлежит cargo, а не скрипту.
- `README.md`: раздел сборки переписан — устаревший `cargo install --path
  grammar` заменён на вызов скрипта, добавлены симулятор и языковой сервер.
