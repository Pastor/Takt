## Краткое описание

Внешний интерфейс модели не выражается: `extern fn` не исполняется симулятором, агрегат не может быть аргументом параметра. Подробности находки, замеры и оговорки — в разделе «Что известно на
входе»; форма решения определяется стадиями архитектуры и анализа.

**Внешний интерфейс модели не выражается: `extern fn` не исполняется
симулятором, агрегат не может быть аргументом параметра.** Вскрыто фиксом
[0186-01](../fixes/0186-01-example-decomposition.md) (2026-07-30, две пробы)
при попытке сделать интерфейс памяти внешним — по предложению заказчика.
Первое: `extern fn mem_read(addr: u8) -> u8;` цель `c` принимает (метод HAL), а
симулятор останавливает прогон — «внешняя функция не имеет тела». Значит модель
с внешним интерфейсом **непроверяема эталоном**: сверка поведения невозможна, а
примеры документа (их гейт исполняет) такой формы содержать не могут. Второе:
`Memory(prog := {9, 8, 7, 6})` отвергается `SE-083` — константный вычислитель
агрегат не сворачивает, поэтому «программа как аргумент» не выражается.
Устранение первого — стенд/заглушка для `extern fn` в симуляторе (это ADR:
откуда брать значения); второго — агрегатные значения в константном
вычислителе.

## Итог (что сделано)

Две независимые части, обе подтверждены пробой.

**1. Модель с внешним интерфейсом стала проверяемой эталоном.** `extern fn` со
значением останавливал прогон `SIM-019` — сверка поведения была невозможна, а
примеры документа такой формы содержать не могли. Теперь значения приходят **из
сценария** (решение заказчика 2026-08-16): одно на такт либо **таблицей по
первому аргументу** — так описывается «память», из которой читает модель. ⚠️
Умолчания нет: не задали — прежний отказ. Ноль сделал бы прогон зелёным там, где
эталон и прошивка расходятся.

**2. Агрегат стал выражаться аргументом параметра.** `Memory(prog := {9, 8, 7, 6})`
отвергалось `SE-083`; теперь вычисляется общим константным вычислителем.

⚠️ **Снятие этого отказа обнажило неготовность цели `c`:** она печатала
`p.prog = {9, 8, 7, 6};` — не выражение, а инициализатор объявления, и `cc`
отвечал «expected expression». Дефект был **недостижим**, пока семантика
отвергала форму раньше. Урок общий: снимая отказ, проверяй **всех**
потребителей формы — отказ мог быть единственным, что их прикрывало.

⚠️ Вторая находка того же рода: стенд не доезжал до вложенных областей видимости
(тело блока, тело функции, `Unit` в роли контекста) — умолчание трейта в любом
из трёх мест означает «стенда нет».

Границы названы: таблица ищет по **первому** аргументу; цели `st` и `sv`
агрегатный аргумент не печатают (`ST-017`, `SV-002`) — отказы пришпилены тестом.

Живая проверка: `./scripts/precheck.sh` зелёный, вывод корпуса неизменен,
мутация роняет 4 из 5 тестов агрегата. Подробности — в
[отчёте](../reports/0209-model-external-interface.md); фиксов не потребовалось.
