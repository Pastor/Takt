## Краткое описание

Метод даёт `format!("{}", file_no)` — то есть **номер строкой**, тогда как имя
обещает **путь**; `parser_tests.rs:944` это закрепляет ассертом
`loc.filename() == "0"`.

После [0053](0053-diagnostics-file-id.md) путь доступен честно
(`Diagnostic::file`), поэтому метод — **ловушка для следующего читателя**.

Лечение: переименовать/удалить, поправив тесты.

Выявлено в [ADR 0053](../adr/0053-diagnostics-file-id.md) (A1).

## Итог (что сделано)

Ложно названный `Location::filename()` (возвращал `file_no` строкой при имени,
обещающем путь) **удалён** — принят **Option A** ADR 0073. Метод был избыточен:
рядом живёт честно названный `try_file_no()` с тем же значением, и «сделать, чтобы
`filename()` возвращал путь» **неосуществимо** — `Location` несёт только `file_no`,
путь — в отдельном реестре `FileTable` (0053), доступном через `Diagnostic::file`.

Метод использовался **только** в двух тестах, дублировавших проверку `try_file_no`
(в `parser_tests` оба ассерта стояли на соседних строках); обе проверки удалены,
покрытие держит `try_file_no`. Правка внутренняя: язык, семантика, кодоген и
симуляция не затронуты, вывод генераторов **байт-в-байт неизменен**, версия языка
не поднята. Публичный API `grammar` формально сужен (потребителей вне тестов нет —
правило 11, санкционировано ADR).

Реестр размера обновлён: `parser_tests.rs` ужат на строку (1893 → 1892) — долг
фиксируется по факту. `precheck.sh` зелёный; отчёт —
[`0073`](../reports/0073-location-filename-path.md).
