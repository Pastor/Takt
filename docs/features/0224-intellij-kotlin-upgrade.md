**Подъём Kotlin в плагине `intellij-takt` снял бы ограничение на пусковой JDK.**
Вскрыто при закрытии [0159](0159-intellij-jdk21-build.md)
(2026-07-29). Таблица версий Java внутри `kotlin-gradle-plugin` **2.0.21**
обрывается на `JAVA_21` (замер: чтение класса commons-lang3 `JavaVersion` из
jar), поэтому пусковой JDK новее ломает `compileKotlin`. Более свежий Kotlin
ограничение снял бы вовсе. ⚠️ Не сделано в 0159 по трём причинам: нужна **сеть**;
нужна проверка совместимости с `org.jetbrains.intellij.platform` 2.1.0 и
платформой 2024.2; и **проверить исход нечем** — JDK 22+ на машине нет, то есть
«починка» осталась бы недоказанной.
