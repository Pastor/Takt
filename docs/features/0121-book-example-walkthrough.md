## Краткое описание

В блоке «Пример» каждого языкового раздела `book/` добавлен **разбор** примера с
**упором на тему раздела**: конструкции темы разбираются подробно (в «Типах» —
типы переменных, вывод и его тип, сравнения), обвязка (модель/состояния/функции) —
вскользь. Вводит **правило 27** и ретрофитит разделы 02–07. Язык не меняется (Tier 3).

## Итог (что сделано)

- **Правило 27** (`docs/RULE.md`): блок «Пример» сопровождается разбором с упором
  на тему раздела (конструкции темы — подробно, обвязка — вскользь), сразу после
  включённого примера; существующие разделы дополняются, новые пишутся сразу с
  разбором.
- **Ретрофит разделов 02–07** абзацем «**Разбор (с точки зрения …)**»:
  - **02 Лексика** — три вида комментариев, dec/hex-литералы, `:=` vs `=`;
  - **03 Типы** — тип каждой переменной (`mode`/`counter`/`level`/`samples`/
    `ORIGIN`), порт-вывод `active: bool`, сравнение `start_btn = …`;
  - **04 Модели/состояния** — три состояния, `start`, `enter`/`always`, `ref`;
  - **05 Выражения/условия** — логические `&`/`|` в условиях против побитовых в
    выражениях, `:=`/арифметика;
  - **06 Управление** — `match`/`for`/`if-else`/`while`+`break`+`return`;
  - **07 Функции** — `extern fn`, `double`, композиция `quad`, вызовы.
  Во всех — обвязка (модель/состояния/функции) упомянута вскользь.

**Живая проверка:** сборка PDF (`mdbook`+`xelatex`, TeX Live 2026) чистая
(`Missing character`/`undefined`/`Overfull` = 0); `precheck.sh` зелёный. Разделы
08–16 получат разбор при наполнении (правило 27).
