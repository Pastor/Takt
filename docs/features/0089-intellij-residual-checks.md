## Краткое описание

Остаток закрытых [0022](0022-intellij-syntax-highlight.md) и
[0023](0023-intellij-navigation-include.md):

- визуальная **`runIde`**-проверка в среде с GUI;
- юнит-тест **CT3**: произвольный неалфавитный символ → `BAD_CHARACTER`.

`verifyPlugin` **настроен и пройден** (фикс
[0023-01](../fixes/0023-01-verifyplugin-descriptor.md)): Compatible для IC
2024.3/2025.1/2025.2 — список IDE обновлять по мере выхода новых релизов. Сборка
по-прежнему под 2024.1.x/JDK 17.

> **Уточнение (0039).** Утверждение «собрать плагин в CI-среде нельзя», кочевавшее
> по остаточным пунктам, **опровергнуто пробой**: `buildPlugin --offline` и
> `cleanTest test --offline` проходят успешно — 53 теста за ~8 с. GUI требует
> **только** `runIde`. Остаточным пунктом остаётся **визуальная проверка**, а не
> сборка.

> Фича зарегистрирована **2026-07-17** переводом кандидата из `FEATURES.md`
> (решение заказчика: «завести фичи по кандидатам, пока без проработки»).
