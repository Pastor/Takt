## Краткое описание

Остаток закрытых [0022](0022-intellij-syntax-highlight.md) и
[0023](0023-intellij-navigation-include.md):

- визуальная **`runIde`**-проверка в среде с GUI;
- юнит-тест **CT3**: произвольный неалфавитный символ → `BAD_CHARACTER`.

`verifyPlugin` **настроен и пройден** (фикс
[0023-01](../fixes/0023-01-verifyplugin-descriptor.md)): Compatible для IC
2024.3/2025.1/2025.2 — список IDE обновлять по мере выхода новых релизов. Сборка
по-прежнему под 2024.1.x/JDK 17.

> **Уточнение (0039).** Утверждение «собрать плагин в CI-среде нельзя», кочевавшее
> по остаточным пунктам, **опровергнуто пробой**: `buildPlugin --offline` и
> `cleanTest test --offline` проходят успешно — 53 теста за ~8 с. GUI требует
> **только** `runIde`. Остаточным пунктом остаётся **визуальная проверка**, а не
> сборка.

> Фича зарегистрирована **2026-07-17** переводом кандидата из `FEATURES.md`
> (решение заказчика: «завести фичи по кандидатам, пока без проработки»).
> **Проработка не проводилась:** ADR, анализ, зависимости, Tier и объём — за
> стадиями 2–3 (правило 17). Текст ниже — **перенос находки кандидата** вместе с
> подтверждающими её пробами; это описание проблемы, а **не** принятое решение.

## Итог (что сделано)

**Закрыта (`ГОТОВО`, 2026-07-23).** Разрешены два остаточных пункта 0022/0023
(ADR 0089, Option A):

- **CT3 — автотестом:** `LamLexerTest.testArbitraryNonAlphaIsBadCharacter`
  (символы `@`, `$`, `` ` ``, `\`, `№` → `BAD_CHARACTER`, ровно один токен на символ).
  **Production-код не менялся** — ветка `LamLexer.scanOperatorOrPunct`
  `else -> BAD_CHARACTER` существовала; добавлен лишь сторож против регресса.
- **Визуальная `runIde`-проверка — признанный визуальный остаток** (GUI, как A11
  0022/0023/0038): не блокирует закрытие, зафиксирована в
  [отчёте](../reports/0089-intellij-residual-checks.md).

`./gradlew --offline test` — зелёный, **81 тест, 0 падений** (регресс 0022/0023
без правки ожиданий). Версия плагина **не поднимается** (только тест); язык не
меняется. Ни одна фича от 0089 не зависела — порядок хвоста не изменился.
