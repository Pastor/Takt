**Класс:** синтаксис языка (Tier 1 — приоритет по решению заказчика
2026-08-03: синтаксис → семантика → генерация → остальное).

**Форма `model M = A | B { … }` не работает ни в одной стороне.** Замер при
закрытии [0194](0194-sim-composition-model-always.md)
(2026-08-03): эталон даёт пустую трассу `[—]` и завершение на первом же шаге,
цель `c` отвергает вход `CC-005` («State with name ' ()' not found»). То есть
форма разбирается грамматикой, но ни один потребитель её не исполняет — отказ
приходит поздно и невнятно, а эталон **молчит**. ⚠️ В корпусе формы нет, и
фича 0194 её не покрывала: правку своей ветви `build_impl` она сделала
симметрично, но **проверить значением не смогла** — ломается раньше.
Решить надо, чем эта форма отличается от `model M { start Inner = A | B; }`:
либо она синоним (и тогда должна работать), либо не должна разбираться вовсе
(и тогда нужен внятный отказ на разборе, а не `CC-005` из кодогена).
