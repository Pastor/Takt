## Краткое описание

Версия языка живёт **только** в `README.md:1007`; рассинхрон между документацией и
фактическим поведением компилятора **ничем не ловится**.

⚠️ Обостряется решением заказчика от 2026-07-15 (правило 22: версия
**накапливается**): исполнение решения затруднено именно тем, что константы в коде
нет — пять фич пула заявляли подъём версии, а сверить их не с чем.

Выявлено при [0045](0045-sv-backend.md).

> Фича зарегистрирована **2026-07-17** переводом кандидата из `FEATURES.md`
> (решение заказчика: «завести фичи по кандидатам, пока без проработки»).
> Проработана и закрыта **2026-07-22**.

## Итог (что сделано)

**Закрыта 2026-07-22 (`ГОТОВО`).** Реализована **Option A**
[ADR 0085](../adr/0085-language-version-constant.md): единственный источник истины
версии языка — константа `grammar::LANGUAGE_VERSION` (`grammar/src/version.rs`,
реэкспорт из `lib.rs`), и машинный гейт `scripts/check-language-version.sh` в
`precheck.sh` (а значит и в CI по [0090](0090-ci-precheck.md)), сверяющий её с
канонической строкой `**Версия языка: X.Y.Z**` в `README.md` (три условия отказа:
расхождение / нет якоря / дубль якоря). Прецедент машинных doc-гейтов —
[ADR 0077](../adr/0077-diagnostic-code-registry.md), [ADR 0027](../adr/0027-module-size-split.md).

**Побочно устранён живой дефект 0078:** гейт на первом прогоне поймал, что фича
0078 подняла язык `0.3.0 → 0.4.0`, а `README.md` остался на `0.3.0`. Каноническая
строка приведена к `0.4.0`. Это **не** подъём версии (правило 22) — фиксация уже
действующей `0.4.0`.

**Аддитивно (правило 11):** вывод всех целей и симулятора байт-в-байт неизменен
(генераторы не тронуты); версия языка `0.4.0` без изменений; крейт `grammar`
`0.9.0 → 0.10.0` (аддитивный публичный API). `lib.rs` удержан на baseline 1402
ужатием crate-doctest на 3 строки; `lamc.rs` не тронут — `lamc version` (Option B)
вне объёма (**кандидат**, заблокирован baseline размера `lamc.rs`).
