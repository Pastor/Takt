## Краткое описание

`takt-lang/src/generator/st/st_decl.rs` достиг **1000 строк при лимите 1000**
(замер фичи [0385](0385-contextual-from.md)): следующая правка печати
объявлений цели `st` уронила бы гейт размера. Модуль разделён по границе,
которую его же шапка называла с самого начала — «два пласта вывода»:

| Пласт | Где теперь |
|---|---|
| `TYPE … END_TYPE` (структуры, именованные типы общих массивов, формы массивов из параметров) | `st_decl_types.rs` |
| Секции `VAR…` внутри `FUNCTION_BLOCK` | `st_decl.rs` |

Вывод не изменился ни на байт: фича переносит код, а не правит его.

## Документирование (правило 24)

**Не требуется** — язык не затрагивается вовсе: перенос кода внутри цели
генерации, вывод прежний.

## Итог (что сделано)

- Печать объявлений цели `st` разделена на два модуля по существующей границе
  пластов; `st_decl.rs` — 806 строк, `st_decl_types.rs` — 216.
- ⚠️ **Граница выбрана не по размеру, а по ответственности:** типы печатаются
  один раз на файл и до первого использования (в IEC порядок значим), секции
  `VAR…` принадлежат конкретной модели. Ровно это и написано в шапке `st_decl`
  с задачи 0041-02.
- ⚠️ **Структура `Extras` осталась в `st_decl`**: она описывает дополнения к
  **секциям**, а не к типам, — попав в вынесенный блок механически, была
  возвращена.
- Сторож — снапшоты корпуса `examples/generated/st` (гейт 0048/0274): вывод
  байт-в-байт прежний, диффа нет.
