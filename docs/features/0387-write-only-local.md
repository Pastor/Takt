## Краткое описание

Признак «локальная не используется» (0376) считал **запись** использованием,
поэтому `var spare: u8 := 0; spare := n + 5;` без единого чтения заглушки не
получал. Замер 2026-08-22 показал, что класс шире, чем предполагал кандидат:

| Потребитель | Ответ на вывод |
|---|---|
| `c`, `c-hal` | `cc -Wall -Wextra -Werror`: **`variable 'spare' set but not used`** |
| `rust` | `rustc -D warnings`: **`unused variable: spare`** |
| `sv`, `sv-mmio` | `verilator -Wall`: **`UNUSEDSIGNAL`** |
| `st`, `st-at` | принимают |
| эталон | исполняет |

То есть вывод **пяти** целей отвергают их же инструменты при **нулевом** коде
возврата `taktc`. Семантика при этом молчала: `SE-036` (0386) считала запись
использованием.

## Документирование (правило 24)

**Не требуется.** Язык не меняется: диагностика та же (`SE-036`), синтаксис и
семантика прежние. Расширяется область срабатывания уже описанного
предупреждения и состав вывода целей.

## Итог (что сделано)

- Признак «локальная не используется» спрашивает теперь **чтения**: цель
  присваивания — место записи, а не чтение (внутри неё читаются индексы и
  базы). Тем самым починились сразу заглушка целей `c`/`rust` (0376) и
  предупреждение `SE-036` (0386) — знание одно.
- ⚠️ **Режим задан флагом `UsageSet::reads_only`, а не вторым обходом:** копия
  правила «что считать упоминанием» разошлась бы с оригиналом молча (класс
  0084/0193/0195). Фильтры печати целей режим **не** включают — там вопрос
  другой («нужно ли имя в выводе»).
- ⚠️ **У цели `sv` появился поглотитель обычной локальной** (прежде он был
  только у поднятых со структурой, 0375), и присваивание печатается **после
  тела**: чтение сигнала раньше записи verilator встречает `ALWCOMBORDER`, а
  гейт цели считает предупреждение ошибкой. Класс двухслойный — замер снимался
  дважды.
- ⚠️ **Кандидат называл вопрос уже, чем он есть:** «не измерялось, отвечает ли
  `cc`». Прогон показал отказ инструментов **пяти** целей при нулевом коде
  возврата `taktc`.
- ⚠️ Граница 0386 («запись считается использованием») снята осознанно.
- Поведение не изменилось; корпус даёт ноль новых предупреждений.
