## Краткое описание

Замер 2026-08-21 по вопросу заказчика: в **корне** репозитория лежали три
файла — `libshl.rlib`, `libvarshift.rlib`, `libvarshift32.rlib`, 84 КБ. Они
**отслеживаются гитом**: `git log --diff-filter=A` показывает коммит
`3c6bec19` («fix(0334): сдвиг на величину не меньше ширины типа считает как
эталон»), то есть это вывод ручных проб `rustc`, запущенных без `--out-dir`,
попавший под `git add -A` вместе с правкой.

Ни один гейт этого не видел: `.gitignore` закрывает `/target` и `/*.o`, но не
`*.rlib`, а `git status` показывает такой файл наравне с исходником.

## Документирование (правило 24)

**Не требуется** — язык и вывод инструментов не затронуты; фича процессная.

## Итог (что сделано)

- Три файла удалены из репозитория.
- `.gitignore` закрывает `*.rlib`, `*.rmeta`, `*.d`, `*.so`, `*.dylib` в корне —
  туда кладут вывод инструменты, запущенные без `--out-dir`.
- Заведён гейт `scripts/check-build-artifacts.py` (шаг предкоммита): падает
  **списком** отслеживаемых файлов с расширениями артефактов.
- ⚠️ **Проверяются отслеживаемые файлы, а не рабочее дерево:** файл, лежащий
  рядом и не добавленный в индекс, вреда не делает — его отсекает `.gitignore`;
  проверка рабочего дерева ругалась бы на каждую пробу.
- ⚠️ Сторож `scripts/test-build-artifacts.sh` (правило 0315) строит **временный
  репозиторий** — копии дерева здесь мало, нужен свой индекс — и доказывает
  четыре условия, включая отказ на вырожденном входе.
