## Краткое описание

`/` и `%` синтезируются в **аппаратный делитель** — крупный и медленный блок;
автор `.lam` об этом из текста модели не узнаёт. Код `SV-009` **зарезервирован, но
не принят** (задача 0045-06).

Открытый вопрос — полезная подсказка это или шум; решается пробой `yosys stat` на
модели с делением. В корпусе деления **нет**, поэтому и повода принять решение
пока не было.

Вынесено закрытой [0045](0045-sv-backend.md).

## Итог проработки (2026-07-17)

**Проба сделана — ровно та, которую предписала 0045-06. Она дважды перевернула
вывод.**

**Шаг 1 — обобщённый синтез** (`yosys synth -flatten`), ячеек: `u32` → `+` 240,
`*` 3030, `/` 3437, `%` 3525. Предварительный вывод: `*` почти так же дорог, как
`/` (разрыв ×1.13) → предупреждать только про `/` значит вводить в заблуждение.
**Вывод оказался неверным.**

**Шаг 2 — FPGA-поток** (`yosys synth_ice40 -dsp -flatten`, `u32`):

| Операция | `SB_LUT4` | DSP |
|---|---|---|
| `a + b` | 49 | 0 |
| `a * b` | **17** | **3** ← **дешевле сложения** |
| **`a / b`** | **558** | **0** ← ×11 от сложения |
| **`a % b`** | **591** | **0** |
| `a / 2` (константа) | **17** | 0 ← сдвиг |
| `a / 3` (константа) | **106** | 0 ← ≈ сложение |

⚠️ **Шаг 1 моделировал не ту технологию:** обобщённое отображение на вентили не
знает про DSP. На FPGA у умножения аппаратная поддержка **есть**, у деления —
**нет**. Деление в RTL действительно особенное.

**Ответ на вопрос 0045-06: подсказка — но только для переменного делителя.**
В форме, которую подразумевал кандидат («предупреждать на всякое `/`»), это был бы
**шум**: сработало бы на `a / 2`, который **дешевле сложения**.

**Принято** ([ADR](../adr/0064-sv-divider-warning.md), Option B): `SV-009` —
**предупреждение** (не ошибка) на `/` и `%` **с переменным делителем**;
делитель-константа → молча; про `*` → молча (замер: DSP). Текст называет **порядок
и следствие**, а не LUT — они технологичны и устареют.

⚠️ **Находка, вошедшая в объём: у цели `sv` канала предупреждений НЕТ ВОВСЕ.**
Греп по `generator/sv/`: ни `Diagnostic::warning`, ни `report` — ноль вхождений;
у `rust` (`mod.rs:199`) и `st` (`mod.rs:290`) он есть. Без канала `SV-009` была бы
**немой**, поэтому его заведение — часть фичи.

⚠️ **Находка вне объёма (кандидат): сам канал дефектен.** `report` печатает
`eprintln!` **из библиотеки**, а не возвращает диагностики вызывающему
(`compile_to_sv` → `Result<(), Diagnostic>`): `--quiet` их **не глушит**, LSP
получит их в свой stderr, тест может проверить только перехватом stderr.

Язык не меняется → версия не растёт (правило 22).

## Итог (что сделано) — 2026-07-20

Принята **Option B** (ADR): `SV-009` — **предупреждение** на `/` и `%` **с
переменным делителем**; делитель-константа (числовой литерал, скобки снимаются) —
**молча**; про `*` — молча (замер: DSP). Реализовано в `generator/sv/`:

- **Обнаружение** — в `sv_expr.rs::print_expression`, единственной точке
  трансляции всех выражений (тела, условия, функции): арии `Divide`/`Modulo`
  зовут `warn_variable_divisor`, а тот через `is_constant_divisor` (синтаксическая,
  консервативная проверка — action A-2) дописывает `sv009()` в приёмник. Q-путь
  (`fixed_bin`) не мешает — предупреждение эмитится до него (action A-3 закрыта
  на будущее: делитель тот же).
- **Приёмник** — `Fsm::warnings: RefCell<Vec<Diagnostic>>`, доступный печатнику
  через новое поле `Scope::warnings` (интерьерная мутабельность: `&mut` сквозь 32
  места вызова печатника не протаскивается).
- **Канал доставки** — новая `report` в `generator/sv/mod.rs` по образцу
  `rust`/`st` (action A-5: у цели `sv` канала **не было вовсе**). ⚠️ Образец
  воспроизведён **вместе с дефектом** (action A-6, вне объёма — кандидат):
  `eprintln!` из библиотеки, `--quiet` не глушит.
- **Текст** (правило 5): называет причину (нет аппаратного делителя) и следствие
  (потолок частоты), **без** конкретных LUT (они технологичны — action A-1).

**Проверки** — юнит-тесты в `sv_expr.rs` (перехват stderr не понадобился: приёмник
инспектируется напрямую через `print_with_warnings`): T1/T3 (переменный `/`,`%` →
`SV-009`), T2/T4/T6 (`a/2`, `a/3`, `a%4` → молчание — они же **негативный сторож
T11**: мутация «предупреждать на любое `/`» их валит), T5 (`a*b` → молчание), T8
(текст: причина+следствие без LUT). T9/T10: деления в корпусе нет (греп) → вывод
всех целей побайтово прежний, `precheck.sh` зелёный.

Язык не менялся, версия не поднята (правило 22).
