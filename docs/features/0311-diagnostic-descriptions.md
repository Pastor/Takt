## Краткое описание

Разбор с примером есть у 83 кодов из 229 — для остальных реестр
`docs/diagnostics/README.md` единственное объяснение. Десять его записей
объяснением не были: «ошибка», «предупреждение», имя конструкции. Записи
переписаны по коду эмиссии, а гейт запрещает заводить новые.

> Фича зарегистрирована из блока кандидатов `FEATURES.md`; предмет
> переформулирован — см. «Итог».

## Документирование (правило 24)

**Не требуется** для языковых разделов: правится справочник кодов
(`docs/diagnostics/`), а не описание языка. Сводная таблица приложения
«Ошибки» не задета — её сверяет гейт 0290, и он остался зелёным.

## Итог (что сделано)

**Справочник отвечает на вопрос «что это значит» для всех 229 кодов.**

- **Десять безликих записей переписаны** по коду эмиссии: `DF-001`…`DF-004`
  («ошибка»/«предупреждение»), `CS-001`, `FM-001`, `AM-001`, `ST-004`,
  `SV-005`, `SV-006`.
- **Гейт `check-diagnostic-descriptions.py`** (шаг предкоммита) с
  самопроверкой и сторожем на копии дерева: **D1** — служебное слово
  (без исключений), **D2** — короткое описание вне узаконенного долга,
  **D3** — протухшая запись долга.
- ⚠️ **Предмет кандидата переформулирован, и это замер:** он требовал «список
  кодов, у которых разбор обязан быть». Такой список — решение о **пользе**,
  машине недоступное; его пришлось бы вести руками, и он разошёлся бы с
  документом (класс 0084/0193/0195). Проверяемая часть того же беспокойства —
  «справочник обязан отвечать», и она формулируется без списка.
- ⚠️ **Короткое ≠ плохое:** «Модель не найдена» объясняет исчерпывающе. Таких
  записей 15, все занесены в долг с ратчетом; порог 25 символов — граница между
  описанием и ярлыком, проверенная на всём реестре.
- ⚠️ **Служебное слово долгом не покрывается**, и на это стоит отдельное
  условие сторожа: узаконить «ошибку» значило бы отменить предмет фичи.
- ⚠️ **Пустой реестр — вырожденная проверка**, а не успех (урок 0230: обход,
  молча вернувшийся ни с чем, рапортует о полноте).

Детали — в [отчёте](../reports/0311-diagnostic-descriptions.md); отвергнутые
варианты (разбор для каждого кода, сверка с текстом сообщения) — в
[ADR](../adr/0311-diagnostic-descriptions.md).
