## Краткое описание

Фича 0125 завела в настройки плагина пути к `taktc`/`takt-sim`, дополнительные
параметры компилятора и выходную директорию — но **как задел**: они хранятся и
**не исполняются**. Фича-преемник — собственно запуск из IDE.

> Фича зарегистрирована из бэклога кандидатов (отобрана заказчиком 2026-07-28); далее проходит жизненный цикл по правилу 17.

## Что известно на входе

- Настройки плагина существуют и сохраняются; исполняющего кода за ними нет.
- Смешение с LSP-редактированием раздуло бы 0125 — объём вынесен сознательно.
- Плагин **вне** `precheck.sh`/CI: верифицируется только запуском IDE.

## Направление решения (наметка, не решение)

- Run Configuration API IntelliJ: конфигурации «Compile» и «Simulate»,
  использующие уже имеющиеся настройки.
- Разбор вывода инструментов в проблемы IDE (формат позиции —
  `diagnostics::position_prefix`, `путь:строка:колонка`) + консоль.
- ⚠️ Колонка в диагностике — **в символах**, не в байтах (в `.takt` есть
  кириллица): разбор обязан это учесть.

⚠️ Окончательный выбор — за стадиями **архитектуры** (ADR) и **анализа**: раздел
выше фиксирует то, что уже проверено, а не предрешает реализацию.
