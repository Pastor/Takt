## Краткое описание

Добавляет `taktc verify --emit-graph <kripke\|buchi\|product>`: выгружает
структуру Крипке, автомат Бюхи для `¬φ` или их произведение — те же структуры,
что использует проверка, — в формат **Graphviz DOT** (stdout). DOT рендерится
`dot -Tsvg` в SVG для встраивания в документ (`book/`). `kripke` без `--property`
даёт управляющую абстракцию (0049); `buchi`/`product` требуют `--property`
(строятся по `¬φ`).

> Фича зарегистрирована по запросу заказчика; проходит жизненный цикл по правилу 17.

## Итог (что сделано)

Реализован экспорт графов верификации в Graphviz DOT (ADR 0124, Option B —
`dot` установлен, `plantuml` нет; DOT идиоматичен для автоматов):

- **CLI**: `taktc verify --emit-graph <kripke|buchi|product>` (раздельная и
  слитная `--emit-graph=…` формы; негодное значение — отказ, не молчание).
  Экспорт печатает DOT в stdout и завершает без проверки пустоты. `buchi`/
  `product` без `--property` → понятный отказ (код ≠ 0).
- **Эмиттеры** — новый модуль `verification/dot.rs`: `kripke_to_dot`
  (старт — точка-источник, тотальность/самопетли видны, для пути данных 0068
  метка несёт истинные атомы), `buchi_to_dot` (принимающее — `doublecircle`,
  начальные — точки-источники), `product_to_dot` (узел — пара
  `состояние,qN`). Порядок детерминирован (`BTreeMap`/индексный обход) —
  DOT воспроизводим (согласуется с 0048).
- **Единый источник истины отбора Крипке**: логика «управляющая (0049) vs
  данными (0068)» вынесена в `verify::select_kripke`, которым пользуются и
  проверка (`run`), и экспорт (`build_graphs`/`build_control_kripke`) — диаграмма
  показывает **ровно** проверявшийся граф. Прежний путь `run`/`--trace` —
  байт-в-байт неизменен.
- **Тесты**: 6 юнит-тестов эмиттеров (`verification::dot`) — старт, все узлы,
  `doublecircle` у принимающих, пары произведения, метки пути данных, регресс
  двойного экранирования `\n`, экранирование кавычек; 2 CLI-теста разбора
  `--emit-graph`. Рендер `dot -Tsvg` подтверждён вручную.

**Живая проверка:** `taktc verify --emit-graph …` порождает валидный DOT
(рендерится `dot -Tsvg`); `./scripts/precheck.sh` зелёный. Язык не менялся →
версия языка та же.
