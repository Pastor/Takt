## Краткое описание

Раздел документа `book/` про **инструментарий** языка: назначение и работа
`taktc` (генерация, форматирование, верификация, карта адресов), `takt-sim`
(симуляция и визуализация) и `takt-lsp` (сервер языка); команды, примеры вызова и
**реального** вывода. Раздел — **прикладной**: по решению заказчика (ADR 0117)
правило 24 дополнено исключением, разрешающим показывать команды и вывод
инструментов в выделенных прикладных разделах; языковые разделы остаются tool-free.

> Фича зарегистрирована **2026-07-24 по запросу заказчика**.

## Документирование (правило 24)

Заводит **новый раздел** документа (правило 24 — каждый раздел отдельной фичей).
Язык **не меняется**. Раздел показывает работу инструментов — это **исключение**
из правила 24, оформленное в ADR 0117 и внесённое в текст правила 24. Номера
фич/задач и сведения о процессе в раздел **не** попадают.

## Итог (что сделано)

- **Правило 24 дополнено** точечным исключением (`docs/RULE.md`): прикладные
  разделы «Инструментарий» и «Развёрнутый пример» вправе показывать команды и
  вывод инструментов; языковые разделы — по-прежнему без деталей инструментов;
  номера фич/ссылки на процесс — нигде.
- **Наполнен раздел `book/src/16-tools/index.md`** (новая часть «Применение» в
  `SUMMARY.md`): обзор трёх инструментов; `taktc` — `compile` (таблица целей
  `c`/`c-hal`/`st`/`st-at`/`rust`/`sv`/`sv-mmio`/`plantuml`, пример вывода),
  `fmt --check`, `verify` (примеры «держится»/«нарушено» с контрпримером),
  `address-map`; `takt-sim` — прогон по тактам, сценарий `-s`, визуализация `-o`
  (GIF/SVG); `takt-lsp` — LSP для редакторов.
- **Вывод команд — реальный** (захвачен прогонами `taktc`/`takt-sim` на этой
  машине), не выдуман.

**Живая проверка:** сборка PDF (`mdbook`+`xelatex`, TeX Live 2026) чистая
(`Missing character`/`Font shape undefined`/`Overfull` = 0); `precheck.sh` зелёный.
