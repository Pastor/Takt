**Класс:** семантика языка (Tier 2 — приоритет по решению заказчика
2026-08-03: синтаксис → семантика → генерация → остальное).

**Вывод типов не протягивает тип через ссылку константа→константа.** Замер при
разработке [0143](0143-after-const-duration.md) (2026-07-29):
`const BASE := 2s; const DWELL := BASE;` даёт `DWELL` тип **`Inference`**, а
`const DWELL := BASE + 1s;` — **`Unsupported`**, хотя в обоих случаях значение
очевидно `duration`. Вычислителю выдержки пришлось из-за этого трактовать оба
типа как «вывод не дошёл» и решать **по значению**: иначе автор получал бы
сообщение о слабости вывода типов вместо ошибки в своей записи.
⚠️ Последствия шире выдержки: любая проверка, которая доверится типу такой
константы, увидит `_`. ⚠️ Молчаливым дефект **не является** — тип
недоопределён, а не неверен.
