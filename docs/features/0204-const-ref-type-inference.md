## Краткое описание

Вывод типов не протягивает тип через ссылку константа→константа. Подробности находки, замеры и оговорки — в разделе «Что известно на
входе»; форма решения определяется стадиями архитектуры и анализа.

**Класс:** семантика языка (Tier 2 — приоритет по решению заказчика
2026-08-03: синтаксис → семантика → генерация → остальное).

**Вывод типов не протягивает тип через ссылку константа→константа.** Замер при
разработке [0143](0143-after-const-duration.md) (2026-07-29):
`const BASE := 2s; const DWELL := BASE;` даёт `DWELL` тип **`Inference`**, а
`const DWELL := BASE + 1s;` — **`Unsupported`**, хотя в обоих случаях значение
очевидно `duration`. Вычислителю выдержки пришлось из-за этого трактовать оба
типа как «вывод не дошёл» и решать **по значению**: иначе автор получал бы
сообщение о слабости вывода типов вместо ошибки в своей записи.
⚠️ Последствия шире выдержки: любая проверка, которая доверится типу такой
константы, увидит `_`. ⚠️ Молчаливым дефект **не является** — тип
недоопределён, а не неверен.

## Итог (что сделано)

Вывод типов протягивает тип **через ссылку** на другое объявление — при любом
порядке имён и на цепочке любой длины; арифметика длительностей получила тип
`Duration`. Крейты `takt-lang` (вывод типов) и `takt-sim` (только тесты).

Причин было **две**, независимых:

- **снимок ячейки** — `ExpressionNode::Variable` несёт копию переменной, снятую
  при разрешении имени, то есть **до** вывода типов; лечится тем, что вывод
  спрашивает **таблицу объявлений** по имени, а проходы повторяются до
  неподвижной точки (`extract_type_known`, `type_inference`);
- **`wider_type` не знал длительностей** — правила `(Duration, Duration)` не
  было вовсе, поэтому `2s + 1s` давало `Unsupported` **без единой ссылки**.

Цена прежнего устройства измерена: `var x := 42; var y := x;` — форма, которую
фикстура проекта объявляла образцом, — отвергалась **всеми пятью**
потребителями (`CC-015`, `RS-014`, `ST-002`, `SV-002`, `SIM-007` **в такте**), а
сторож фикстуры проверял лишь то, что файл разбирается. Сторож заменён на
проверку типа.

⚠️ Отвергнуто и почему: «свернуть инициализаторы до вывода типов» — это первое
напрашивающееся решение, и оно даёт `bool` вместо `bit` (порядок трёх шагов —
инвариант ADR 0192); контр-пример стоит в тестах. «Обновлять ячейки» — копий у
переменной столько, сколько упоминаний, а пропущенная даёт молча разные типы у
одного имени (класс 0096).

Живая проверка: `./scripts/precheck.sh` зелёный, вывод корпуса байт-в-байт
неизменен, мутация роняет 8 из 10 тестов компилятора. Подробности — в
[отчёте](../reports/0204-const-ref-type-inference.md); фиксов не потребовалось.

Названная граница: `wider_type(Integer, Array)` берёт тип **литерала**, из-за
чего `const A: u16 := 300; const B := A + 1;` получает `[bit;8]` и ложную
`SE-089`. Механизм другой — заведено кандидатом.
