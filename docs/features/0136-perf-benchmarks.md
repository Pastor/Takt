## Краткое описание

Производительность инструментов не измеряется вовсе. При этом масштаб —
доказанно живая тема: [0052](0052-verify-iterative-traversal.md) чинила падение
на 2800 состояниях, [0068](0068-verify-data-properties.md) ввела потолок вершин
`VERTEX_LIMIT = 1_000_000`. Сегодня замедление любой правки обнаружится только
жалобой пользователя.

> Фича зарегистрирована из бэклога кандидатов (отобрана заказчиком 2026-07-27); далее проходит жизненный цикл по правилу 17.

## Что известно на входе

- В манифестах обоих крейтов нет ни `criterion`, ни `proptest`, ни каталога
  `benches/`.
- Тесты гоняются однопоточно (`--test-threads=1`), полный `precheck.sh` — единицы
  минут; отдельного замера времени компиляции корпуса нет.

## Направление решения (наметка, не решение)

- `criterion`-бенчи: компиляция корпуса `examples/` по целям; верификация
  (построение Крипке → Бюхи → произведение → проверка пустоты); построение
  индекса LSP.
- Фиксация порядка величины в отчёте фичи — чтобы будущие правки сравнивались с
  числом, а не с ощущением.
- Гейт «не медленнее X» — **по решению заказчика**: на CI он шумит.

⚠️ Окончательный выбор — за стадиями **архитектуры** (ADR) и **анализа**: раздел
выше фиксирует то, что уже проверено, а не предрешает реализацию.
