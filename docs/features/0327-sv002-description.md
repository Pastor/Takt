## Краткое описание

Описание `SV-002` перечисляло формы («цикл в теле, досрочный возврат из
функции, `match`, срез массива»), и за один день перечень устарел: `match`,
статический `for`, приведение `as` и агрегат массива стали переводиться.
Описание переформулировано **по признаку**.

## Документирование (правило 24)

**Это и есть предмет фичи:** правится сводная таблица приложения «Ошибки» и
реестр диагностик.

## Итог (что сделано)

**Описание кода перестало называть переводимое непереводимым.**

- **Признак вместо списка:** «конструкция не выразима в синтезируемом RTL:
  цикл `loop`/`while`, цикл `for` с **неизвестными при синтезе** границами,
  досрочный возврат из функции, срез массива, приведение к нескалярному типу».
- ⚠️ **Список устарел за ОДИН день:** 0309 (агрегат массива), 0321 (`for`),
  0322 (`match`), 0323 (`as`). Перечисление форм в описании кода — знание,
  которое разъезжается с кодом молча.
- ⚠️ **Запись реестра называет фичи, менявшие состав:** следующий читатель
  видит, что перечень подвижен, и где искать историю.
- ⚠️ **Машинной сверки списка форм нет и не заводится:** формы рассыпаны по
  печатникам и различаются словами; такой гейт сверял бы формулировки, а не
  поведение.
