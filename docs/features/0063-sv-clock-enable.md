## Краткое описание

Служебный порт `en` с умолчанием `1'b1`, дающий возможность тактировать модель
**реже** тактового домена. Аддитивен поверх принятого решения 0045 (`clk`/`rst_n`
— служебные порты, которых в языке нет).

Вынесено закрытой [0045](0045-sv-backend.md) (ADR, вопрос 1, Option C — признан
«преждевременным, но **не неверным**»).

## Итог проработки (2026-07-17)

**ADR 0045 отверг Option C тремя возражениями. Проработка проверила их пробами —
два из трёх не устояли.**

| # | Возражение ADR 0045 | Вердикт |
|---|---|---|
| 1 | Расширяет зону зарезервированных имён | **в силе** — цена — **одна строка** в `RESERVED_NAMES` (`sv_module.rs:57`); механизм `SV-007` уже есть; имени `en` в корпусе **нет** |
| 2 | «Тот, кому нужен делитель, **добавит его снаружи — одна строка**» | **НЕ УСТОЯЛО** — снаружи clock enable добавить **нельзя**: либо делить `clk` (второй домен → CDC, ровно то, чего Option A избегал), либо клоковый гейт (ICG-ячейки; в FPGA-потоках не рекомендуется, задевает DFT). **Штатный** способ — именно вход `en` |
| 3 | «Усложняет тестбенч и сверку» | **ОПРОВЕРГНУТО пробой** — с умолчанием `en` не подключают, и поведение **побитово** прежнее |

**Аддитивность доказана, а не обещана** (правило 11) — двумя способами, потому что
«принял» ≠ «значит `1`» (урок 0045: `real` verilator принимает молча, петлю yosys
синтезирует молча):

- **Симуляция** (`verilator --binary` — именно им гоняет сверка):
  `en не подключён = 10 | en=1 = 10 | en=0 = 0`;
- **Синтез** (`yosys synth -flatten`): не подключён → **23 ячейки, `8 × $_DFF_PN0_`**
  (без разрешения); `en=1'b1` → **идентично**; `en=1'b0` → **1 ячейка**.

⚠️ **Ловушка самой пробы, стоящая записи:** без `-flatten` `yosys synth` иерархию
не уплощает, константы не распространяются, и все три случая дают одинаковый
результат — проба выглядит проведённой и **не доказывает ничего**. Первый прогон
именно так и выглядел.

**Принято** ([ADR](../adr/0063-sv-clock-enable.md), Option A): `en` с умолчанием
`1'b1` (IEEE 1800 §23.2.2.4); шаг — на `posedge clk` при `en == 1`; **`en` не
гейтит сброс** (иначе модуль нельзя сбросить, пока он не разрешён); `en` — в
`RESERVED_NAMES` → коллизия даёт `SV-007`. Отклонены: обязательный `en` (ломает
всех), флаг генератора (две формы вывода → два пути кода — довод 0059),
статус-кво.

⚠️ **Изменение контракта, названное честно** (правило 11): имя `en` становится
**зарезервированным** — модель с портом `en` перестанет транслироваться целью `sv`.
Корпус свободен; это единственная устоявшая плата.

Язык не меняется (`en` — как `clk`/`rst_n`, в `.lam` не выразим) → версия не
растёт (правило 22).
