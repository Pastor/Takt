## Краткое описание

Верный расчёт ширины перечисления — **по диапазону значений** — сегодня реализован
в каждом бэкенде **отдельно** (`rust_type::enum_repr`, `sv_type::enum_width`).
Кандидат: вынести в `semantic/`, чтобы четвёртый бэкенд не наступил на то же.

Повод — **три бэкенда подряд**, споткнувшихся об одно и то же: ST брал `USINT`,
Rust — `#[repr(u8)]`, SV — `⌈log₂(вариантов)⌉`; все три предположения опровергнуты
одним и тем же `enum Action { Idle = 670 }` из `elevator.lam:121` (в байт не
влезает).

Выявлено при закрытой [0045](0045-sv-backend.md).
