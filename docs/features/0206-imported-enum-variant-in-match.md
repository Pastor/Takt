**Вариант импортированного перечисления не разрешается в образце `match`.**
Вскрыто фиксом [0186-01](../fixes/0186-01-example-decomposition.md)
(2026-07-30, проба из двух файлов). `import { Op } from "lib.takt";` — и затем
`match v { Lda => … }` даёт `SE-003` «идентификатор не найден», тогда как
условие `ref Done: v = Hlt;` **в том же файле** тот же вариант разрешает. То
есть разрешение вариантов перечисления есть в выражениях и условиях, но путь
образца `match` смотрит мимо импортированных объявлений. Обход в примерах:
модели, разбирающие опкод, живут в том же файле, что и `enum`. ⚠️ Корпус класс
не покрывает: перечисления в нём не пересекают границу импорта.
