## Краткое описание

Замер 2026-08-21: `fn head(a: [u8; 3]) -> u8 { return a[0]; }` с вызовом
`head(data)` исполняют эталон, `c`, `st` (форма `VAR_IN_OUT`, фича 0348) и
`rust`; цель `sv` печатала `input logic [7:0] a [0:2]` —
**verilator принимает, yosys отвергает**: «input/output/inout ports cannot
have unpacked dimensions». Всё при **нулевом** коде возврата `taktc`.

Класс видит один инструмент из трёх: линт цели и потактовая сверка идут через
verilator.

## Документирование (правило 24)

**Не требуется** — язык не меняется: запись законна и переводится четырьмя
потребителями; правится представление у одной цели.

## Итог (что сделано)

- Параметр-массив передаётся **плоским вектором**, аргумент — конкатенацией
  `{a[N-1], …, a[0]}`, а пролог функции распаковывает вектор в массив с именем
  параметра.
- ⚠️ **Пролог дешевле знания:** вариант «индексация срезом» принят обоими
  инструментами, но потребовал бы раскладку параметра в `Scope` и правку трёх
  печатников индексации (0365). Тело функции печатается прежними печатниками.
- ⚠️ **Класс видит один инструмент из трёх** (только `yosys`) — отсюда
  отдельный тест синтеза.
- ⚠️ Наблюдаемые сверки различают **края** массива и меняются по тактам: на
  постоянных значениях перепутанный порядок конкатенации неразличим.
- Массив структур и массив массивов в параметре остаются прежними — вынесено
  кандидатом; вывод корпуса не изменился.
