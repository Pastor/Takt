## Краткое описание

Пространство имён портов симулятора **плоское**: одноимённые порты разных
под-моделей делят значение. Фича [0084](0084-address-map-qualified-key.md)
квалифицировала ключ **карты адресов** (для цели `c-hal`), но не значения портов
симулятора — это разные слои, и второй остался неисправленным.

> Фича зарегистрирована из бэклога кандидатов (отобрана заказчиком 2026-07-27); далее проходит жизненный цикл по правилу 17.

## Что известно на входе

- `Unit::get_value` / `set_value` на `Parallel` адресуют **все** ветви по голому
  имени порта.
- В корпусе дефект замаскирован: одноимённых портов у под-моделей нет.
- Прецедент решения уже есть — `qualified_port_key(model_unique, port)` в
  `address_map/resolve.rs` (фича 0084): продюсер и потребитель обязаны строить
  **одну** строку.

## Направление решения (наметка, не решение)

- Квалифицированный ключ `модель::порт` в симуляторе по образцу 0084.
- Согласовать с [0132](0132-sim-named-port-scenarios.md): обе правки трогают
  **один** контракт (адресация порта по имени), поэтому порядок «сначала 0135,
  затем 0132» зафиксирован зависимостью.
- Регрессия — тест по образцу `composition_ports_tests.rs`; драйв портов
  гейтится `run_simulations.sh` (не входит в `precheck.sh`).

⚠️ Окончательный выбор — за стадиями **архитектуры** (ADR) и **анализа**: раздел
выше фиксирует то, что уже проверено, а не предрешает реализацию.
