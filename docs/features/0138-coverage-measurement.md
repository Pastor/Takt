## Краткое описание

Покрытие тестами не измеряется вообще, а корневой `codecov.yml` — конфигурация
**чужого проекта**, создающая видимость обратного.

> Фича зарегистрирована из процессного бэклога (отобрана заказчиком 2026-07-27); далее проходит жизненный цикл по правилу 17.

## Что известно на входе

- `codecov.yml` исключает из покрытия `derive/src/lib.rs`,
  `pest/examples/parens.rs`, `pest/src/unicode/*` — **таких путей в репозитории
  нет** (остатки конфигурации `pest`).
- В `.github/workflows/ci.yml` нет ни `cargo-llvm-cov`, ни `tarpaulin`, ни
  выгрузки отчёта.
- При 2176 тестах знать непокрытые ветви полезно особенно для диагностик: проект
  ловил дефекты именно на непокрытых путях (0026, 0058, фикс 0005-01).

## Направление решения (наметка, не решение)

Развилка — **решение заказчика**:

- **(а)** завести измерение: `cargo llvm-cov` в CI + отчёт, порог — по желанию;
- **(б)** удалить чужой конфиг, чтобы не вводить в заблуждение.

Промежуточный вариант: разовый замер покрытия в отчёте фичи без гейта в CI.

⚠️ Окончательный выбор — за стадиями **архитектуры** (ADR) и **анализа**: раздел
выше фиксирует то, что уже проверено, а не предрешает реализацию.

процентов фича не заводит — находки вынесены кандидатами.
