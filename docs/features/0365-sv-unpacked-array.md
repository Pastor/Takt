## Краткое описание

Замер 2026-08-21 (`scripts/probe.sh` с разделом инструментов, фича 0362) — два
входа, и на обоих вывод цели `sv` **не проходит гейт собственной цели** при
нулевом коде возврата `taktc`:

| Вход | Ответ verilator | Прочие потребители |
|---|---|---|
| `var row: [u8; 2];` (без инициализатора) | **Ошибка** «CONST '8'h0' is not an unpacked array, but is in an unpacked array context» — печаталось `row <= '0;` | эталон, `c`, `st`, `rust` исполняют |
| `s := row[i];` при `i: u8` | `%Warning-WIDTHTRUNC: Bit extraction of array[1:0] requires 1 bit index, not 8 bits` (гейт считает предупреждение ошибкой) | то же |

Оба класса воспроизводятся и на **одномерном** массиве — к вложенности
(0363/0364) отношения не имеют, хотя нашлись при её проверке.

## Документирование (правило 24)

**Не требуется** — язык не меняется: обе записи законны и исполняются
эталоном; меняется представление у одной цели.

## Итог (что сделано)

- Сброс распакованного массива печатается **агрегатом нулей** (`'{8'd0, 8'd0}`),
  переменный индекс **сужается** до ширины, которую требует размер
  (`row[1'(i)]`), — и то, и другое по нужде и рекурсивно для вложенного
  массива.
- ⚠️ **Форму выбрал прогон обоих инструментов:** каноничная `'{default: '0}`
  принимается verilator и **отвергается yosys**.
- ⚠️ **Печатников индексации оказалось три** (выражения, условия, цель
  записи); третий нашёлся прогоном **линта цели** — сверка значений его не
  видит, потому что тестбенч собирается с `-Wno-fatal`. Отсюда два сторожа.
- ⚠️ Бит-вектор `[bit;N≤64]` не затронут (правило 0078); индекс за границей
  массива теперь усекается вместо `X` — вход за контрактом (`SIM-010`).
- Вывод корпуса не изменился; оба кандидата, заведённые 0364, сняты.
