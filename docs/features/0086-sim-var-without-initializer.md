## Краткое описание

Объявление переменной **без инициализатора** даёт в симуляторе `SIM-009`
(«переменная не найдена») — то есть объявленная переменная для симулятора не
существует.

**Не структурный дефект** — [0034](0034-sim-struct-types.md) его не чинит (выявлен
её **контрольной** пробой, вне её объёма).

> (решение заказчика: «завести фичи по кандидатам, пока без проработки»).

> стадиями 2–3 (правило 17). Текст ниже — **перенос находки кандидата** вместе с
> подтверждающими её пробами; это описание проблемы, а **не** принятое решение.
