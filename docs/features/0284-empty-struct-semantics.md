## Краткое описание

**Структура без полей принимается языком и даёт невалидный по стандарту C.**
Замер при закрытии [0172](0172-empty-enum-semantics.md)
(2026-08-16): правило `StructDefine` использует `Comma<StructField>` («ноль
или более»), поэтому `struct S { }` компилируется, а цель `c` печатает
`typedef struct S { } S;` — пустая структура есть **расширение GNU** (C11
6.7.2.1 требует непустой список объявлений). Гейт проекта (`-Wall -Werror`)
это **пропускает**; `cc -pedantic` отвергает (`-Wgnu-empty-struct`). ⚠️ Класс
тот же, что у пустого перечисления («агрегатное объявление без элементов»), но
устройство отказа иное: у структуры сегодня отвечает **чужой инструмент** и
только под флагом, которого в гейте нет. Кандидат: принять решение языка —
запрет (`SE-…` на объявлении, симметрично `SE-105`) либо законная пустая
запись с ответом от всех целей. ⚠️ Прежде чем решать, замерить остальные цели:
`st`/`rust`/`sv` на пустой структуре не проверялись.

> Фича заведена **из бэклога кандидатов пакетным переводом** (решение заказчика
> 2026-08-18: «перевести всех кандидатов в фичи без проработки, решить, делать
> или нет, позже»). Стадии 2 и 3 **не пройдены**: приоритет, зависимости и
> объём не оценивались. Далее — жизненный цикл по правилу 17.

## Итог (что сделано)

Структура без полей отвергается диагностикой **`SE-115`** — на объявлении,
накопительно, тем же устройством, каким `SE-105` (фича 0172) отвергает
перечисление без вариантов. Грамматика **не тронута**: `Comma<StructField>`
остаётся, правило языка выражает семантика — прямой урок 0172.

⚠️ **Карточка требовала замерить остальные цели перед решением, и это себя
оправдало.** Замер: цель `c` печатала расширение GNU (`cc -std=c11 -pedantic`
→ `-Wgnu-empty-struct`), порождённый ST **отвергал `iec2c`** («no structure
element declared in structure type declaration»), а эталон исполнял запись.

⚠️ **Контроль отделил причину и СУЗИЛ объём фичи.** Отказ `RS-014` у `rust` и
ссылка на необъявленный тип у `sv` (`verilator`: `Can't find typedef`)
воспроизводятся и на **непустой** структуре: эти цели не переводят структуры
**вовсе**. К пустоте они отношения не имеют — без контроля фича приписала бы
себе чужой класс и «починила» бы его запретом, который его не лечит.

⚠️ **Гейт проекта класс не видел по устройству:** он гоняет `cc` **без**
`-pedantic` (там пустая структура законна как расширение), а пустых структур
нет ни в `examples/`, ни в фикстурах.

⚠️ **Две пробы из трёх были негодными.** Первая не воспроизвела дефект у
`rust`/`sv` вовсе — переменная была неиспользуемой, и её выбросил штатный
фильтр (тот же капкан, что в 0300). Вторая дала ложный `redefinition of 'Pair'`:
файл назывался `pair.takt`, корневая модель получила имя из имени файла и
столкнулась со `struct Pair` (класс 0195).

Версия крейта `takt-lang`: `0.42.0` → `0.43.0`. Версия языка **не растёт**:
цикл `0.10.0` открыт фичей 0243 (правило 22, накопление).
