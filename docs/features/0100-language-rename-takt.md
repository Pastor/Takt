## Краткое описание

Переименовать язык проекта **Lam → Takt** сквозным образом: имя языка, расширение
исходников, имена бинарников/крейтов, идентификаторы кода, LSP, грамматику,
плагин IntelliJ, все примеры, документацию, скрипты и гейты. Ключевые слова и
семантика языка **не меняются** — переименовывается только идентичность
(название, расширение, тулчейн-имена).

- **Имя языка:** `Takt` (возможная расшифровка — **T**yped, **A**utomata,
  **K**nown **T**iming; финальный бэкроним утверждает заказчик на стадии ADR).
- **Расширение файлов:** `.lam` → `.takt`.
- **Компилятор (бинарник):** `lamc` → `taktc`.
- **LSP (бинарник):** `lam-lsp` → предположительно `takt-lsp` (уточнить в ADR).
- **Крейт:** `takt-lang` (какой из двух крейтов так называется и как быть со
  вторым — решает ADR; сейчас крейты `grammar` и `simulation`).

## Объём (метрики на 2026-07-24, ориентир для декомпозиции)

- **244** файла `.lam` (переименование + правки перекрёстных ссылок/`import`);
- **~324** трекнутых файла содержат слово `Lam`;
- **~414** файлов содержат `.lam`/`lamc`/`lam-lsp`/`lam_lsp`;
- плагин IntelliJ — отдельное дерево (`extensions/intellij-lam/`, Kotlin,
  собственный `LamKeywordSyncTest`/round-trip);
- гейты `precheck.sh`/CI, скрипты (`run_simulations.sh`, `check-*.sh`), сравнение
  порождённого кода (`examples/generated/`).

## Развилки — решены ([ADR 0100](../adr/0100-language-rename-takt.md), заказчик 2026-07-24)

1. **Обратная совместимость (правило 11)** → **жёсткий разрыв**: принимается
   только `.takt`, `.lam` не распознаётся (проект до 1.0, внешних потребителей
   нет). Обоснование — драйвер 2 ADR.
2. **Имена крейтов** → **полный ренейм**: `grammar`→`takt-lang`,
   `simulation`→`takt-sim`, **с** обновлением всех путей импорта
   (`grammar::`→`takt_lang::`, `simulation::`→`takt_sim::`).
3. **Версия языка (правило 22)** → **подъём `0.4.0`→`0.5.0`**, тег `v0.5.0`.
4. **Бэкроним `Takt`** → **Typed, Automata, Known Timing** (официально).
5. **Репозиторий/релизные артефакты** → упоминания в коде правятся; фактический
   переезд `github.com/Pastor/BuT` — **вне фичи** (административный, позже).
6. **Детерминизм/снапшоты** → `examples/generated/` меняются **законно** (имена в
   `#include`); эталоны пересобираются в слое примеров (0100-04), детерминизм-гейт
   подтверждает стабильность.

## Стратегия (черновик, финализируется в ADR)

Механическое сквозное переименование **декомпозировать** (правило 2) по слоям,
каждый слой — отдельная подзадача `0100-YY` с зелёным `precheck.sh`:
крейты/бинарники → расширение и лексер/CLI → идентификаторы кода и пути импорта →
примеры и генерация → плагин IntelliJ → документация (README/README.typ/CLAUDE.md/
CHANGES.md/docs) → скрипты/гейты. Каждая — по возможности чистое переименование с
сохранением поведения; изменения вывода (имена в `#include`) — под сверку.
