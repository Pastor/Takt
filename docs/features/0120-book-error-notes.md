## Краткое описание

Каждый языковой раздел документа `book/`, описывая конструкции и примеры, обращает
внимание на **типичные ошибки** по теме — блоком «Частые ошибки» с кодами
диагностик и ссылкой на приложение «Ошибки и предупреждения» (правило 25). Вводит
**правило 26** и ретрофитит разделы 02–07. Язык не меняется (Tier 3).

> Фича зарегистрирована **2026-07-24 по запросу заказчика**.

## Документирование (правило 24)

Кросс-секционная работа по документу: язык **не меняется**. Добавляет в разделы
блоки «Частые ошибки» (указание промаха + код + ссылка на приложение); полное
раскрытие ошибок — в приложении (правило 25). Номера фич/процесс в текст не
попадают.
