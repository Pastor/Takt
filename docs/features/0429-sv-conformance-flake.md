## Краткое описание

**Разовое падение сверки `sv` осталось необъяснённым.** Наблюдение 2026-08-23:
`conformance_sv_struct_local_tests` упал **один раз** из шести прогонов
предкоммита («`Vtb__ALL.a.verilator_deplist.tmp: No such file or directory`»,
`Undefined symbols … _main`).

Замер того же дня: воспроизвести не удалось (три изолированных прогона набора и
четыре полных — зелёные). Проверяемый признак, найденный чтением, устранён
фиксом [0190-01](../fixes/0190-01-test-temp-dir-collision.md) — но он был **не
проявлен**, то есть исходное падение объясняет лишь гипотетически.

Остаётся вторая гипотеза: `verilator --binary -j 0` (фича
[0241](0241-precheck-speedup.md)) собирает C++ на всех ядрах, и несколько таких
тестов разом перегружают машину.

⚠️ Класс дорог не поломкой, а **недоверием к красному предкоммиту**: отказ,
который «бывает», перестают читать. Беря запись в работу, начинать с
воспроизведения под нагрузкой — иначе чинить будет нечего.
