## Краткое описание

Модель-«всё сразу», на которой стоит тест `syntax_simple`, **никогда** не давала
компилируемый C, и это не замечалось: тест проверял лишь факт `Ok`.

Причины **не связаны** с состояниями: в порождённой структуре нет порт-колбэков
`read_numeric`/`write_numeric`, а `const`-массив `MATRIX: u8 := {0,…}` печатается
как **скаляр** (`CONST_..._MATRIX`), давая `expected ')'`. Проверено: строка
перевода `S(Ping) = End` ошибок **не даёт** (ошибки — на соседних строках,
обращения к портам).

Следствие: `syntax_simple` вынужден проверять **строку** в `.c`, а не компиляцию.

Смежно с [0034](0034-sim-struct-types.md) (структуры) и с фичей
[0083](0083-model-always-block-c.md) (`always` на уровне модели).

Выявлено при [0047](0047-c-state-of-model.md).

## Итог (что сделано) — 2026-07-20

Принята **Option A** (ADR 0075, решение заказчика): эталон **разделён**.
`parse_simple` (`lib.rs`) остаётся на полном `SRC` — покрытие **парсера** всех
конструкций. Компиляционная проверка переехала в
`tests/reference_model_tests.rs::reference_model_compiles_and_translates_state_ref`
на **компилируемую** модель `SYNTH_SRC` (`compile_to_c` + `cc -c`, скип без `cc`);
она сохраняет композицию `(Ping | Pong) + Toggle` и `S(Ping) = End`, но опускает
конструкции, упирающиеся в семантику `[bit;N]` (numeric-порт-бит-доступ,
const-массив-бит-доступ). `syntax_simple` удалён из `lib.rs` (стоял на
некомпилируемом `SRC`); инвариант `ref` теперь охраняет компиляционный тест;
`lib.rs` уменьшен 1450 → 1405.

**11 ошибок исходного `SRC`** остаются кандидатами: `read_numeric` для `out`-порта
с бит-доступом — **локальный баг** генератора (кандидат/0080); const `[bit;N]`
бит-доступ — за **0078**. Язык не менялся, версия не поднята.
