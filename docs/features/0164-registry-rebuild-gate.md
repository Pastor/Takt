## Краткое описание

Реестры `docs/*/README.md` не пересобираются по факту файлов: переименование
подзадачи аналитиком оставляет **битую ссылку**, а рассинхрон реестра с диском
ничем не ловится (кроме `check-links.py` на саму битую ссылку).

> Фича зарегистрирована из бэклога кандидатов (отобрана заказчиком 2026-07-28); далее проходит жизненный цикл по правилу 17.

## Что известно на входе

- Повторяющуюся боль (дубли строк при повторной регистрации) фича 0094 уже сняла
  идемпотентностью — это **остаточная, более редкая** проблема.
- ⚠️ **Ненадёжно в POSIX sh**: извлечение заголовка/статуса/ссылок из markdown —
  хрупкий парсинг, и у каждого реестра **свой** формат строки; риск испортить
  реестр.
- `scripts/check-links.py` уже написан на python3 — прецедент проверки вне sh.

## Направление решения (наметка, не решение)

- Кандидат на реализацию **вне** POSIX sh: отдельный проверочный скрипт на
  python3 (по образцу `check-links.py`).
- Либо — только гейт «реестр ↔ файлы согласованы», **без** автопочинки: чинить
  руками безопаснее, чем машинно переписывать реестр.
- ⚠️ Смежно с [0177](0177-features-registry-status-gate.md) (тот же класс:
  реестр расходится с истиной) — возможно объединение, решает аналитик.

⚠️ Окончательный выбор — за стадиями **архитектуры** (ADR) и **анализа**: раздел
выше фиксирует то, что уже проверено, а не предрешает реализацию.

## Документирование (правило 24)

**Не требуется.** `book/` описывает язык, а не процесс.

## Итог (что сделано)

**Реестры стадий полны, и полнота сторожится машиной.**

- **Гейт** `scripts/check-registries.py` (шаг предкоммита, самопроверка
  первой): множество файлов папки-стадии против множества ссылок её реестра, в
  обе стороны. Классы **R1** (файл без записи), **R2** (запись без файла),
  **R0** (пустая стадия — проверка вырождена, а не пройдена). Обе мутации
  тест-плана подтверждены.
- **Восполнено 42 записи:** adr 5, analyze 6, development 12, tests 6,
  reports 12, fixes 1. Заголовки взяты из первых строк самих файлов, статусы
  ADR — из поля `Status`, вердикты стадий 5–6 — из разделов «Вердикт» отчётов
  (у 0187 раздел назван «Вывод» и выверен вручную).

**Кандидат называл не то направление** (замер 2026-08-20): битых ссылок ноль —
их ловит `check-links.py`; живое расхождение обратное.

⚠️ **Пропуск в реестре делал слепым соседний гейт:**
`check-registry-verdicts.py` проверяет **строки**, и шесть тест-планов с
двенадцатью отчётами для него не существовали. Теперь под проверкой 494 строки
вместо 472.

⚠️ Пересборка реестра скриптом отвергнута (ADR): в строке живёт написанный
человеком текст — заголовок, статус, вердикт со ссылкой на отчёт.

Детали — в [отчёте](../reports/0164-registry-rebuild-gate.md); решение и
отвергнутые варианты — в [ADR](../adr/0164-registry-rebuild-gate.md).
