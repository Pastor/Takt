## Краткое описание

Описывает **систему типов** Takt: `bool`, `bit`, целочисленные типы, упакованный битовый вектор `[bit;N]`, массивы `[T;N]`, перечисления `enum`, структуры `struct`, фикс-точку `q(m, n)`, `float`; псевдонимы типов и вывод типов.

> Фича зарегистрирована **2026-07-24** по запросу заказчика (правило 24 — каждый раздел документа заводится отдельной фичей); далее по правилу 17.

## Документирование (правило 24)

Наполняет раздел `book/src/03-types/index.md` описанием языка (см. «Краткое описание»); примеры на Takt — в подкаталоге `03-types/examples/`, изображения — в `03-types/images/`. Раздел **описывает** уже реализованные возможности языка, синтаксис/семантику **не меняет**. В документ не попадают детали реализации, номера фич и процесс разработки.
