## Краткое описание

Замер 2026-08-21: `var g: Gains := {1.5, 2.5};` при
`struct Gains { kp: q(8, 8), ki: q(8, 8) }` исполняет эталон, а **все** цели,
кроме диаграммы, вывод не дают:

| Цель | Ответ |
|---|---|
| `c`, `c-hal` | `cc -Werror` отвергает порождённый файл |
| `st`, `st-at` | `iec2c` отвергает |
| `rust` | `rustc` отвергает |
| `sv`, `sv-mmio` | `SV-002` |

Причина: понижение дробного литерала в q-представление (0061/0096, место —
свёртка инициализаторов) шло по типу объявления, а объявление полей живёт в
`ModelNode`, которого слой свёртки не видел. Фича 0368 закрыла тот же класс
для **элементов массива** и границу «структуры» назвала прямо.

## Документирование (правило 24)

**Не требуется** — язык не меняется: запись законна и исполняется эталоном;
правится место понижения литерала.

## Итог (что сделано)

- Понижение дробного литерала в q-представление доходит до **полей структуры**
  и до полей структур внутри массива; граница, названная 0368, снята.
- ⚠️ **Границу создавала сигнатура помощника, а не устройство:** модель у слоя
  свёртки была всё это время.
- ⚠️ **Сверка смотрит на q-значения, а не на приведение `as`:** первая
  редакция теста падала из-за соседнего класса — приведения из поля, которое
  цель `c` печатает без деления на 2ⁿ. Класс вынесен кандидатом.
- Вывод корпуса не изменился: коэффициенты `q` в `examples/` объявлены
  скалярами.

Детали — в [отчёте](../reports/0370-struct-field-fixed.md).
