## Краткое описание

Новый раздел документа (`book/src/20-processor/`) — **сквозной пример
вычислительной машины**, описанной средствами Takt: учебный 8-битный процессор
с памятью, декодером команд и конвейером. Каждая часть машины — модель или
подмодель языка:

- **`Memory`** — модель памяти: хранение программы и данных (массив `[u8; N]`),
  протокол обращения — адрес/данные/строб (общие переменные, приём 0182);
- **`Processor`** — модель процессора; внутри — подмодели по стадиям машинного
  цикла: **`Fetch`** (выборка команды), **`Decoder`** (декодер: `enum` опкодов +
  `match`), **`Execute`** (АЛУ и запись результата);
- **машинный цикл** fetch → decode → execute — конечный автомат (или
  последовательная композиция `+`);
- **конвейер** — параллельная композиция `|` стадий с передачей через общие
  переменные: пока Execute исполняет команду N, Fetch выбирает команду N+1;
- **регистры процессора** — аккумулятор, счётчик команд, флаги — обычные
  переменные модели с типами `u8`/`bit`.

Раздел показывает язык «в сборе»: типы и перечисления, массивы, `match`,
композиция обоих видов, общие переменные, функции — на предмете, знакомом
каждому инженеру. Полный перечень команд учебного процессора, программа-пример
(например, сумма массива) и потактовая трасса исполнения — обязательные части
раздела.

## Документирование (правило 24)

Фича **и есть** документирование: новый раздел `book/src/20-processor/`
(каждый раздел — отдельная фича, правило 24). Примеры раздела — свои
`.takt`-файлы в каталоге раздела, проверяемые гейтом книги (0133: компиляция
целью `c` + симуляция). В корпус `examples/` пример **не** входит (иной
предмет: корпус — регрессия компилятора, книга — обучение языку); перенос в
корпус возможен отдельной фичей, если пример окажется полезен как регрессия.
