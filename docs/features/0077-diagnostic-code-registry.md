## Краткое описание

Фича [0028](0028-c-generator-stubs.md) держала **Accepted**-ADR на код `CC-014`
(«непереводимое условие перехода»), а реализованная [0029](0029-c-type-mapping.md)
заняла `CC-014`/`CC-015` под непредставимые в C типы, затем `CC-016` (ширина порта)
и `CC-017` (инициализатор массива). Обе фичи выбирали код **грепом свободного** и
друг друга не увидели — то есть механизм выдачи кодов **не защищает от коллизий**.

Ближайшее лечение применено: 0028 при реализации взяла `CC-018` и далее.
**Системное** — реестр кодов диагностик в одном месте: сейчас коды живут только в
коде и в таблице `README.md`, пополняемой **вручную**.

Выявлено при реализации [0029](0029-c-type-mapping.md).
