## Краткое описание

Фича [0028](0028-c-generator-stubs.md) держала **Accepted**-ADR на код `CC-014`
(«непереводимое условие перехода»), а реализованная [0029](0029-c-type-mapping.md)
заняла `CC-014`/`CC-015` под непредставимые в C типы, затем `CC-016` (ширина порта)
и `CC-017` (инициализатор массива). Обе фичи выбирали код **грепом свободного** и
друг друга не увидели — то есть механизм выдачи кодов **не защищает от коллизий**.

Ближайшее лечение применено: 0028 при реализации взяла `CC-018` и далее.
**Системное** — реестр кодов диагностик в одном месте: сейчас коды живут только в
коде и в таблице `README.md`, пополняемой **вручную**.

Выявлено при реализации [0029](0029-c-type-mapping.md).

> Фича зарегистрирована **2026-07-17** переводом кандидата из `FEATURES.md`
> (решение заказчика: «завести фичи по кандидатам, пока без проработки»).
> **Проработка не проводилась:** ADR, анализ, зависимости, Tier и объём — за
> стадиями 2–3 (правило 17). Текст ниже — **перенос находки кандидата** вместе с
> подтверждающими её пробами; это описание проблемы, а **не** принятое решение.

## Итог (что сделано)

Реализовано по [ADR 0077](../adr/0077-diagnostic-code-registry.md) (Option A) —
единый реестр + машинный гейт, **аддитивно** (`with_code(&str)` не тронут):

- **Реестр** [`docs/diagnostics/README.md`](../diagnostics/README.md) — единый
  источник истины: **171 код** (11 префиксов LE/SY/SE/CC/RS/SV/ST/AM/DF/PU/SIM),
  по одной строке `Код · Значение · Источник`. Пробелы **AM-001…006, PU-001 и все
  13 ST** закрыты. Соглашения: формат `XX-NNN`, `RESERVED`/`RETIRED`, «следующий
  свободный» из справки гейта.
- **Гейт** `scripts/check-diagnostic-codes.sh` (POSIX sh, образец
  `check-module-size.sh`) в `precheck.sh` (и CI через него, ADR 0090). Четыре
  условия отказа: незадокументированный код, протухшая запись (минус
  `RESERVED`/`RETIRED`), нарушение формата `XX-NNN`, дубль строки. Печатает по
  префиксам максимальный занятый номер — грепа «последнего занятого» (причина
  коллизии `CC-014`) больше не нужно.
- **Указатели на источник истины:** README §7, doc-комментарий
  `Diagnostic::with_code` (правило «новый код — сперва в реестр»), свод
  `docs/CODE.md` (раздел «Коды диагностик»).

**Прецедент — правило размера модуля (ADR 0027):** реестр без гейта повторил бы
судьбу ручных README-таблиц. Enum-типизация (`with_code(DiagnosticCode)`, Option B)
отвергнута — ≈330 мест в двух крейтах при маргинальной пользе над гейтом.

**Аддитивность (правило 11):** ни один код и ни один текст диагностики не изменён —
вывод всех целей и симулятора **байт-в-байт** прежний, детерминизм 0048 цел.
Единственная правка исходника — doc-комментарий `with_code` (комментарий). Версия
языка `0.3.0`, версии крейтов без изменений. `./scripts/precheck.sh` зелёный.
