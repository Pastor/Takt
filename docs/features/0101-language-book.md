## Краткое описание

Завести справочное **описание языка** Takt в каталоге [`book/`](../../book/)
(mdBook, вывод **PDF** со шрифтом Fira Code — ADR 0101) и **процессное правило**
его актуализации (**правило 24** в [`docs/RULE.md`](../RULE.md)): каждая языковая
фича проходит стадию «Документирование», каждый новый раздел — отдельная фича.
0101 — инфраструктурная: скелет документа (конфигурация, Makefile, оглавление,
вводная часть, seed-раздел «Обзор» с примером, приложения) + правило + шаблон
карточки. Наполнение разделов 2–15 — фичи-преемники.

## Документирование (правило 24)

**Язык не меняется** → правки существующих разделов не требуется. Фича **заводит
сам документ** `book/` и правило его ведения; seed-раздел «Обзор» наполнен как
образец структуры (папка раздела + `examples/`). Наполнение прочих разделов —
отдельные фичи, каждая со своей стадией «Документирование».
