## Краткое описание

Канонический автоформат исходников `.lam`: единый детерминированный стиль
(отступы, пробелы вокруг `:=`/`=`, переносы в списках переходов/параметров,
выравнивание блоков `enter`/`exit`/`always`, нормализация комментариев).
Форматтер строится на существующих лексере и AST (`grammar`) и переиспользуется
тремя потребителями: подкомандой CLI `lamc fmt` (`--check` для CI, in-place по
умолчанию), LSP-методом `textDocument/formatting` в `lam-lsp` (format-on-save) и
действием «Reformat Code» плагина IntelliJ (фичи 0022/0023).

## Мотивация / контекст

Сейчас форматтера нет ни в одном инструменте: у `lamc` единственная подкоманда
`compile`, `lam-lsp` не отвечает на `textDocument/formatting`, плагин IntelliJ —
без реформата. Единый стиль убирает споры о форматировании в ревью, даёт
воспроизводимые диффы и проверяемость в CI (`lamc fmt --check`).

## Объём (предварительно, уточняет аналитик)

- Ядро форматирования в крейте `grammar` (например, `format/` или `fmt.rs`):
  вход — исходный текст (или AST + токены с комментариями), выход —
  канонический текст. Идемпотентность: `fmt(fmt(x)) == fmt(x)`.
- Подкоманда `lamc fmt [--check] [--stdin] <файлы/каталоги>`.
- Реализация `textDocument/formatting` (и, по возможности,
  `rangeFormatting`) в `lam-lsp`.
- Действие «Reformat Code» в плагине IntelliJ поверх LSP/ядра.
- Сохранение комментариев и (по решению анализа) осмысленных пустых строк —
  ключевой риск, т.к. комментарии могут не храниться в AST.

## Риски / открытые вопросы

- **Комментарии и trivia.** Печать из AST теряет комментарии — понадобится либо
  токен-ориентированный проход, либо хранение trivia. Решается в ADR.
- **Идемпотентность и стабильность** на всех конструкциях (составные состояния,
  порты, `match`/`switch`, циклы) — обязательна, покрывается тест-планом.
- **Обратная совместимость (правило 11):** форматтер не меняет семантику, только
  раскладку; язык не расширяется → версия языка **не** повышается (правило 22).
- **Согласованность с 0019:** унификация грамматик может изменить набор узлов,
  которые печатает форматтер (см. «Зависит от»).
