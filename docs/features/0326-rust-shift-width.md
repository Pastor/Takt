## Краткое описание

`v := a >> 8;` при `a: i8` цель `rust` печатала как есть, и **`rustc` отвергал**
такой код при нулевом коде возврата `taktc`. Эталон и остальные семь
потребителей дают −1 (знаковый) и 0 (беззнаковый).

## Документирование (правило 24)

**Не требуется:** семантика описана фичей 0325; здесь меняется форма печати
одной цели.

## Итог (что сделано)

**Вывод цели `rust` собирается, и значение совпадает с восемью остальными.**

- **Насыщение сдвига:** при литеральной величине, не меньшей ширины типа,
  печатается `>> (ширина − 1)` для знакового (остаётся только знак: −1 либо 0)
  и `0` для беззнакового.
- **Замер 2026-08-20:** эталон, `c`, `c-hal`, `st`, `st-at`, `sv`, `sv-mmio`
  дают −1 и 0; **`rust` не компилировался** («attempt to shift right by
  `8_i32`, which would overflow»).
- ⚠️ **Не отказ, а печать:** семь потребителей вход исполняют и дают **одно и
  то же** значение — отказ сузил бы язык там, где расхождения нет.
- ⚠️ **`wrapping_shr` не годится:** он маскирует величину по ширине (`8 % 8 =
  0`) и даёт −8 вместо −1 — молча другое значение.
- ⚠️ **Граница названа:** переменная величина известна лишь в такте, и
  `checked_shr` в каждом выражении дороже пользы; вынесено кандидатом.
- ⚠️ **Проверено прогоном:** порождённый Rust собран `rustc` и запущен —
  `v = -1`, `w = 0`.
