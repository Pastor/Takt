## Краткое описание

Разделение объявления порта и назначения его адреса — задание адреса порта
отдельной конструкцией, а не в месте объявления.

## Риски

- Архитектурное изменение модели портов.
- Обратная совместимость (правило 11): затрагивает существующие `.lam`-файлы —
  на этапе анализа обосновать необходимость слома совместимости.

> Открытая фича. Источник: `STATUS.md` («пропущенные задачи», п. 11).
