## Краткое описание

Прикладной раздел документа `book/`, раскрывающий тракт Takt на одном примере
(дозатор): описание модели → генерация целей (`c`/`rust`/`sv`/`plantuml`) →
симуляция с визуализацией → верификация LTL → инвариант (guard). Показывает
реальные команды и вывод; опирается на исключение правила 24 ([ADR 0117](../adr/0117-book-tools.md)).
