# Отчёт о тестировании фичи 0369: Массив в параметре функции у цели sv

> Фича: [../features/0369-sv-array-parameter.md](../features/0369-sv-array-parameter.md) · тест-план: [../tests/0369-sv-array-parameter.md](../tests/0369-sv-array-parameter.md) · анализ: [../analyze/0369-sv-array-parameter.md](../analyze/0369-sv-array-parameter.md)

## Резюме

**Пройдено, фича готова к закрытию.** Функция с параметром-массивом
переводится, вывод проходит линт и синтез, значения совпадают с эталоном.

## Выводы и дальнейшие шаги

- **Пролог дешевле знания.** Вариант «индексация срезом» работает, но
  потребовал бы хранить раскладку параметра в `Scope` и править **три**
  печатника индексации (0365). Пролог оставляет тело прежним.
- **Класс видит один инструмент из трёх** — как и 0367; отсюда отдельный тест
  синтеза.
- **Кандидат:** массив структур (и массив массивов) в параметре функции у
  `sv` — `flat_param_width` даёт `None`, вывод остаётся прежним, формы не
  измерены.
- Исправлений (`docs/fixes/`) не потребовалось.
