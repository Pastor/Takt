# Отчёт о тестировании фичи 0371: Приведение q из поля структуры масштабируется

> Фича: [../features/0371-fixed-cast-from-field.md](../features/0371-fixed-cast-from-field.md) · тест-план: [../tests/0371-fixed-cast-from-field.md](../tests/0371-fixed-cast-from-field.md) · анализ: [../analyze/0371-fixed-cast-from-field.md](../analyze/0371-fixed-cast-from-field.md)

## Резюме

**Пройдено, фича готова к закрытию.** Приведение `q → целое` из поля
структуры масштабируется у всех четырёх целей; значения совпадают с эталоном.

## Выводы и дальнейшие шаги

- **Класс был у ЧЕТЫРЁХ целей сразу и молчал у всех.** Ни один инструмент его
  не видит: вывод валиден, значение неверно — 128 против 1. Ровно тот случай,
  ради которого заведены потактовые сверки.
- **Одной правки в семантике мало:** `rust`, `sv` и `st` семантический вывод
  типа не зовут — у каждого свой. Это и есть корень того, что класс дожил.
- **Кандидат:** вывод типа операнда живёт **четырьмя** носителями (по одному
  на цель) плюс семантика; их сведение к одному — отдельная работа, и она
  сняла бы целый класс подобных расхождений.
- Исправлений (`docs/fixes/`) не потребовалось.
