# Отчёт о тестировании фичи 0365: Распакованный массив у цели sv

> Фича: [../features/0365-sv-unpacked-array.md](../features/0365-sv-unpacked-array.md) · тест-план: [../tests/0365-sv-unpacked-array.md](../tests/0365-sv-unpacked-array.md) · анализ: [../analyze/0365-sv-unpacked-array.md](../analyze/0365-sv-unpacked-array.md)

## Резюме

**Пройдено, фича готова к закрытию.** Порождённый модуль проходит линт цели, а
значения совпадают с эталоном такт в такт.

## Выводы и дальнейшие шаги

- **Форму сброса выбрал прогон обоих инструментов.** Каноничная
  `'{default: '0}` принимается verilator и **отвергается yosys** — ровно тот
  случай, ради которого гейт цели держит два инструмента (урок 0045).
- **Сверка значений `WIDTHTRUNC` не видит:** её тестбенч собирается с
  `-Wno-fatal`. Поэтому у фичи два сторожа, и второй — прогон **линта цели** на
  том же модуле; без него правка выглядела бы законченной после двух печатников
  из трёх.
- **Печатников индексации три**, и третий (цель записи) нашёлся только линтом.
- Исправлений (`docs/fixes/`) не потребовалось.
