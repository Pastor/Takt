  координаты. Это **честная пустота**, а не ложь: сообщение просто без
  префикса. Приём готов к переносу (носитель общий), случай вынесен кандидатом.
- **`CC-023`** (узел не прошёл понижение) недостижим из корректной программы
  (0236) — его координата автору не показывается.
