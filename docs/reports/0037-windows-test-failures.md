# Отчёт о тестировании фичи 0037: Сбои тестов на Windows

> Фича: [../features/0037-windows-test-failures.md](../features/0037-windows-test-failures.md) · тест-план: [../tests/0037-windows-test-failures.md](../tests/0037-windows-test-failures.md) · анализ: [../analyze/0037-windows-test-failures.md](../analyze/0037-windows-test-failures.md) · ADR: [../adr/0037-windows-test-failures.md](../adr/0037-windows-test-failures.md)

## Резюме

Реализованы все три подзадачи: 0037-01 (параметризация пяти тестов `-I` в
`lamc.rs`), 0037-02 (удаление записи в `/tmp` из теста `viewport`), 0037-03 (job
`windows` в CI). **Локально-проверяемые критерии пройдены полностью** (T1–T7,
T10, T13).

⚠️ **Критерии, требующие реального прогона на Windows (T8, T9, T11, T12 и
приёмочные A8/A9/A11), ВЫПОЛНИТЬ НЕ УДАЛОСЬ — тот же внешний блокер, что у
[0090](0090-ci-precheck.md): GitHub Actions на аккаунте заблокирован по
биллингу**, job не стартует вовсе. Windows-машина для локального прогона также
недоступна. Работа 0037-01/02 доказана **на darwin** (все шесть целевых тестов
зелены и до, и после правки — параметризация не меняет исход на Unix), но
исполнение `cfg(windows)`-веток вживую не наблюдалось.

**Отступление от плана 0037-03 (осознанное, задокументировано в `ci.yml`).**
План подзадачи писался при CI до фичи [0090](../features/0090-ci-precheck.md) и
предполагал «job `windows` — копия `ubuntu` соステップами build/check/test». 0090
переписал CI в **единый барьер `precheck.sh`** (строгий режим), поэтому дословный
мирроринг означал бы прогон всего `precheck.sh` на `windows-latest` — с
verilator/yosys/iec2c/bison, неподъёмными на Windows и к цели 0037 (шесть
Rust-тестов) отношения не имеющими. По решению заказчика (2026-07-20) job
`windows` гоняет **`cargo test --all-features -- --test-threads=1`** —
портируемость Rust-тестов, а не аппаратные гейты. Флаг `continue-on-error: true`
сохранён (job неблокирующий), снятие (A11) отложено до первого зелёного прогона.

**Решение о закрытии (2026-07-20, прецедент 0090):** фича закрывается **`ГОТОВО`
с оговоркой** — зелёный локальный прогон принят как достаточное доказательство
работы 0037-01/02; A8/A9/A11 остаются **непроверёнными вживую** до восстановления
биллинга Actions.

**Окружение:** macOS (darwin 25.5), rustc/clippy nightly, `cargo test`
однопоточно. Windows не прогонялся.

## Оговорка (граница доказанного)

Ни одна локальная команда **не доказывает** прохождение шести тестов на Windows:
на darwin они зелены и до, и после правки. Настоящее доказательство — лог job
`windows` (A8/A9) — недостижимо, пока Actions заблокирован по биллингу. До
восстановления биллинга статус верификации на целевой платформе — **⬜ «не
проверялось»**, а `continue-on-error` остаётся на месте (job не блокирует CI).
При восстановлении биллинга первый push подтвердит шесть тестов (или вскроет
расхождение MSVC-сборки — риск из анализа), после чего снятие `continue-on-error`
(A11) закроет оговорку отдельным коммитом.
