## Мутационные проверки

| # | Мутация | Итог |
|---|---|---|
| М1 | `--verbose` снова игнорируется | ПРОВАЛ: 2 теста, в том числе адресная цель ✅ |
| М2 | канонический путь печатается всегда | ПРОВАЛ: контрпример ✅ |

М2 — причина, по которой контрпример вообще заведён: без него «печатает
канонический путь» проходило бы и у заведомо неверной реализации.

## Что показал прогон

**Замер нашёл второй разнобой, которого кандидат не называл:** в
verbose-режиме путь выхода печатался **без** слэша, в обычном — со слэшем. То
есть копии расходились не в одном месте, а в двух.

**Контроль совместимости:** `--verbose` в README не описан, строку
«Скомпилировано:» в дереве никто не разбирает — изменение наблюдаемого никого
не ломает.
