## Что вскрылось попутно

**README обещал несуществующую команду.** `cargo install --path grammar` не
работает с фичи 0100 (переименование крейта), то есть **полтора десятка фич
подряд** документ предлагал читателю мёртвый путь установки. Найдено при
разборе входа, а не гейтом: гейт ссылок проверяет пути к файлам, а не
работоспособность команд в примерах. Кандидат заведён.

**Симулятор в разделе установки отсутствовал вовсе** — при том, что это один из
двух главных инструментов проекта.

## Выводы и дальнейшие шаги

Исправления не требуются. Фича переводится в `ГОТОВО`.

Кандидат: **команды в README никем не проверяются**. Гейт ссылок (правило 14)
смотрит только на пути к файлам; примеры вызовов инструментов устаревают молча —
что и произошло с `cargo install --path grammar`. Возможная мера — прогон
помеченных блоков `sh` из README в предкоммите (по образцу гейта примеров
`book/`, фича 0133).
