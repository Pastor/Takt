| № | Условие | Результат |
|---|---|---|
| П1 | `var v: Aa;` → `v: Aa::default()` | ✅ |

| П6 | `[bit; 4096]` → `[u64; 64]`, ручной импл | ✅ |
| К1 | скалярная структура сохраняет `derive`, ручного импла нет | ✅ |
| К2 | `[bit; 40]` — скаляр, `derive` сохранён | ✅ |
| К3 | авторский инициализатор не подменяется умолчанием | ✅ |
| С1 | трасса цели `rust` = трасса эталона | ✅ |
| Гейт | шесть фикстур принимаются `clippy -D warnings` | ✅ |

Итого: `cargo test --test targets rust_default_value_tests::` — 7 тестов
зелёные; `cargo test --test conformance conformance_default_value` — 1 зелёный.

## Найденные дефекты

Дефектов, требующих фиксов, не найдено. Одна правка **внутри** разработки:
первая редакция фикстуры `PLAIN` объявляла `f` и `d`, но их **не
использовала**, и штатный фильтр цели выбрасывал переменные из вывода — тест на
умолчание прошёл бы на выводе, где переменной нет вовсе. Это ловушка,
описанная правилом 30 и проверяемая `probe.sh`; поймал её сам тест (упал на
`f: 0,`), фикстура дополнена использованием.

## Мутационная проверка сторожей

Каждый сторож проверен внесением дефекта в код и прогоном:

| Мутация | Кто упал | Что доказано |
|---|---|---|
| `derives_default` всегда `false` (импл печатается всегда) | К1, К2, гейт `clippy` | контрпримеры не декоративны: «печатать импл всегда» ловится |
| умолчание `q`/`duration` = `16` вместо `0` | **только сверка С1** | компиляция и линт неверное значение принимают — сверка обязательна |
| счёт длины бит-вектора по разрядам, а не по словам | К2 | ловушка «`[bit; 40]` — скаляр» закрыта |

⚠️ Вторая мутация — главный довод существования сверки: эмиссионные тесты и
`clippy -D warnings` её **не заметили**, порождённый Rust собрался и считал
другое (урок 0045).
