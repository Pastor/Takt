## Дефекты и находки, вскрытые работой

Внутри фичи исправлены **четыре** дефекта её собственных моделей — все найдены
**прогоном**, ни один чтением:

1. запись в память шла по чужому адресу (адрес успевала переставить соседняя
   стадия) — заведена отдельная линия адреса записи;
2. попадание в кеш стоило столько же, сколько промах, — попадание обслуживается
   тем же тактом;
3. счётчик попаданий врал: запрос снимался позже, чем принимался ответ;
4. арбитр удерживал шину со старевшим запросом — освобождение и по снятию
   запроса.

Плюс переработка структуры по замечанию заказчика — [фикс 0186-01](../fixes/0186-01-example-decomposition.md).

**Находки вне объёма** (записаны кандидатами в `FEATURES.md`, а не выданы за
сделанное):

- массив как общая переменная не переносится в цель `st` — `iec2c` отвергает
  вывод при рапорте компилятора об успехе; индекс массива не может быть
  выражением;
- форматтер выносит комментарий из тела блока наружу;
- вариант **импортированного** перечисления не разрешается в образце `match`,
  хотя в условии `ref` — разрешается;
- внешний интерфейс модели не выражается: `extern fn` не исполняется симулятором,
  агрегат не может быть аргументом параметра.
