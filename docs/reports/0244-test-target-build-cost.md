## Выводы и дальнейшие шаги

1. **Отвергнутое замером — половина работы.** `lld` оказался медленнее
   системного линкера на 11 %, устранение двойной компиляции `clippy` → `test`
   недостижимо без отказа от линтов по тестовому коду. Оба хода записаны как
   отвергнутые, чтобы к ним не возвращались по правдоподобию.
2. **Расчёт ADR оказался чуть оптимистичнее факта** (120–130 с против 138.9 с) —
   порядок верный, точность экстраполяции «20 целей → 147» ограничена дисковым
   кэшем. Это учтено в записи фичи.
3. **Главный риск фичи — обратный ход.** Файл, положенный в `tests/` верхнего
   уровня, снова станет отдельной целью и вернёт свою долю стоимости **молча**.
   Предупреждение внесено в `CLAUDE.md` и `README.md`; машинного сторожа нет —
   кандидат заведён.
4. **Исправлений (`docs/fixes/`) не потребовалось.**
