# Отчёт о тестировании фичи 0163: Исчерпывающий разбор узлов во втором вычислителе

> Фича: [../features/0163-builder-eval-exhaustive.md](../features/0163-builder-eval-exhaustive.md) · тест-план: [../tests/0163-builder-eval-exhaustive.md](../tests/0163-builder-eval-exhaustive.md) · анализ: [../analyze/0163-builder-eval-exhaustive.md](../analyze/0163-builder-eval-exhaustive.md)

## Резюме

**Пройдено; фича готова к закрытию (`ГОТОВО`).** Второй вычислитель под
правилом ADR 0093: `_ =>` по узлу языка отвергает компилятор, снятие `deny` —
гейт. Обе ловушки проверены мутацией; третья мутация вскрыла **слабость самого
гейта**, которая тоже устранена.

## Окружение

- Прогон: `cargo clippy --all-targets --all-features -- -D warnings`,
  `cargo test --all-features -- --test-threads=1`, `./scripts/precheck.sh`
  (код выхода 0).

## Примеры и контрпримеры (правило 16)

Язык не менялся, языковых примеров в `book/` не заводилось. Проверялся **сторож**:

- **пример** — неповреждённое дерево (T4, T5);
- **контрпримеры** — T1, T2, T3: три способа тихо снять инвариант, отвергаемые
  **разными** механизмами (компилятор / гейт). Без них правило жило бы только в
  документации.

## Выводы и дальнейшие шаги

1. **Мутация вскрыла слабость гейта, которую чтение не показывало.** Прежняя
   проверка (`grep -F "#![deny(...)]"`) находила атрибут **внутри
   док-комментария**, объясняющего, зачем он нужен. То есть модуль **без**
   атрибута, но с рассказом о нём, гейт проходил — и на «правильном» дереве
   выглядел работающим. Поиск привязан к началу строки; это чинит **класс**, а
   не случай: тот же обман работал и для `eval/`.
2. **Карточка перечисляла четыре подстановочные ветки — в области правила одна.**
   Остальные три разбирают `TypeNode`, `StateNode` и `Extend`, а правило ADR 0093
   названо для трёх узлов языка. Расширять его на прочие перечисления — отдельное
   решение, в объём не взято.
3. **Побочно исчерпывающим стал разбор по `Value`** (ветвь `Negate`): модульный
   `deny` не отличает узлы языка от типов крейта. Оставлено как есть — новое
   представление значения теперь потребует решить, отрицаемо ли оно.
4. **Прецедент, ради которого фича и заведена, уже был оплачен:** ветвь
   `Duration` (фича 0134) вписывали вручную после того, как
   `var left: duration := 1m30s;` молча осталась без значения. Теперь такой
   вариант ломает сборку, а не молчит.

Исправлений по самой 0163 не требуется.
