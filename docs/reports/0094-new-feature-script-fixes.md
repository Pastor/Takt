# Отчёт о тестировании фичи 0094: Доработка scripts/new-feature.sh (идемпотентность, статус ADR, поздние стадии)

## Резюме

**Пройдено, фича готова к закрытию (ГОТОВО).** Генератор заготовок стал
идемпотентным (повторный `--register` не дублирует строки — устранена
повторяющаяся боль, обходившаяся вручную ×3 за сессию), ADR-заготовка честна
(`Draft`), поддержан добор одной стадии (`--stage`, впервые `report`) и dev-подзадач
(`--subtask`). Дефолтный путь неизменен. Регресс-тест `scripts/test-new-feature.sh`
(A1–A5, 14 проверок) зелёный и подключён в `precheck.sh`; полный `precheck.sh`
зелёный. Инфраструктура — язык и крейты не затронуты.

## Окружение

- darwin 25.5.0; POSIX `sh`; прогоны в temp-дереве через `NF_ROOT`.

## Результаты по функциональности

- **`insert_row`:** идемпотентен по ключу-номеру (литерал первого столбца).
- **Статус ADR:** `Draft` в строке реестра и шаблоне.
- **`--stage`/`--subtask`:** добор одной стадии, `report` впервые, dev-подзадачи.
- **Dogfooding:** стадии 0094 добраны исправленным скриптом на **реальных**
  реестрах без дублей.

## Примеры и контрпримеры

Фича инфраструктурная — примеров языка (правило 16) нет. Контрпример поведения —
**повторный `--register`**: до 0094 давал дубль строки, после — пропуск.

## Выводы и дальнейшие шаги

**Дефект, найденный при разработке (и починенный):** `[ … ] && insert_row` под
`set -e` при `REGISTER=0` обрывал `do_stage` — ломал дефолтный путь без
`--register`. Поймано регресс-тестом (A5), заменено на `if … then … fi`. Урок:
*машинный тест окупился на первом же прогоне.*

**Отложено в кандидат (Option B ADR):** пересборка реестра из markdown-файлов
(`--rebuild`) — ненадёжна в POSIX sh; повторяющуюся боль (дубли) уже сняла
идемпотентность.
