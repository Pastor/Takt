## Что показал прогон

1. **Контроль самопроверки сам ломался.** «Законный» образец не содержал
   чек-листа, и новый класс давал на нём находку вырожденности — то есть
   проверка «законный текст не даёт находок» падала. Образец дополнен
   согласованной парой (строка чек-листа + метка). Поймано первым прогоном.
2. **Проверка вырожденности обязательна:** без неё файл без раздела
   «Критические инварианты» проходил бы молча — а это ровно та потеря, ради
   которой фича заведена.

## Дефекты

Дефектов инструментов не найдено; исправлена собственная первая редакция
самопроверки.

## Вердикт

**Готово.** Вторая точка сопровождения стала проверяемой: забытая половина
записи роняет предкоммит.
