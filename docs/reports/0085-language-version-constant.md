# Отчёт о тестировании фичи 0085: Константа версии языка в коде + гейт синхронизации с README

## Резюме

**Пройдено, фича готова к закрытию (ГОТОВО).** Введён единственный источник истины
версии языка в коде (`grammar::LANGUAGE_VERSION = "0.4.0"`) и машинный гейт
`scripts/check-language-version.sh` в `precheck.sh`. Гейт **на первом же прогоне
поймал живой рассинхрон**, оставленный фичей 0078 (README `0.3.0` при фактической
`0.4.0`), — дефект устранён в рамках фичи. Все 11 проверок тест-плана зелёные,
полный `./scripts/precheck.sh` зелёный. Вывод целей и симулятора байт-в-байт
неизменен; версия языка не поднималась (правило 22).

- Контрпримеры гейта (T4–T6) — на временных копиях `README.md` в scratchpad
