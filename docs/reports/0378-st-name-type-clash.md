## Выводы и дальнейшие шаги

1. **Класс нашла чужая проба.** В работе над 0373 имя `pair` при типе `Pair`
   дважды увело замер не туда — ровно тот случай, ради которого заведена
   проверка пробы (правило 30).
2. **Ответ инструмента не называл причину:** `iec2c` указывал на `AT %…`,
   которых в объявлении нет. Отделила причину **проба с переименованным
   типом**, а не чтение стандарта.
3. **Отказ, а не переименование** — по прецеденту самой цели (`ST-014`,
   `ST-020`): цель отказывает и говорит, что модель валидна для прочих.
4. **Текст проверен прогоном:** первая редакция несла переносы без `\`, и в
   сообщение ушли десятки пробелов (класс 0258).
5. Исправлений не потребовалось.
