# Отчёт о тестировании фичи 0368: Элемент агрегата печатается по типу элемента

> Фича: [../features/0368-aggregate-element-type.md](../features/0368-aggregate-element-type.md) · тест-план: [../tests/0368-aggregate-element-type.md](../tests/0368-aggregate-element-type.md) · анализ: [../analyze/0368-aggregate-element-type.md](../analyze/0368-aggregate-element-type.md)

## Резюме

**Пройдено, фича готова к закрытию.** Массив `q` и массив перечислений
переводят все восемь целей, инструменты вывод принимают, значения совпадают с
эталоном.

## Выводы и дальнейшие шаги

- **Правка сначала была не в том месте.** Понижение в `lower_fixed_var`
  выполнялось и **терялось**: свёртка инициализаторов подменяет значение из
  сырого АСД, а её защита `is_literal` агрегат не покрывает. Показал это
  отладочный прогон — чтение кода давало обратный вывод.
- **Частный случай маскировал класс.** Ветвь «массив структур» у цели `rust`
  (0343) выглядела полной; на деле она была одной из четырёх нужных.
- **Кандидаты:** массив в параметре функции у цели `sv` (yosys не
  синтезирует); поле `q` внутри структуры — понижение туда не доходит, потому
  что слой свёртки не видит полей структуры.
- Исправлений (`docs/fixes/`) не потребовалось.
