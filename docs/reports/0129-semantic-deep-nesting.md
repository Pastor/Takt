## Результаты по функциональности

- **Отказ устранён** (A1, A2, A9): вместо аварийного завершения — диагностика с
  позицией. Одинаково у компилятора, верификатора и симулятора, потому что слой
  общий.
- **Граница работает и названа** (A4, A5).
- **Обычный код не задет** (A3, A12): порождённый код корпуса `examples/`
  байт-в-байт прежний.
- **Механизм корректен** (A6–A8): выход из рекурсии учитывается, счётчик не
  протекает между сборками — существенно для LSP, где поток переиспользуется.
- **Долг размера уменьшен** (A11): `expression.rs` разделён и **выбыл** из
  реестра — записей 5 вместо 6.

## Найденные смежные дефекты (вне объёма фичи)

**Н1. Тела вложенных `if` семантикой не разрешаются.** Проба:

```takt
always { x := unknown_var_zzz; }              // SE-003 — ошибка выдаётся
always { if (x = 1) { x := unknown_var_zzz; } }  // компилируется МОЛЧА
```

Неизвестный идентификатор внутри `if` не диагностируется вовсе. Прямое следствие
для этой фичи: **сторож операторов недостижим** — глубокой рекурсии операторов в
сегодняшних проходах не возникает (проверено: 1000 вложенных `if` проходят
семантику). Сторож оставлен как защита на случай, когда эти тела начнут
разрешать. Вынесено кандидатом.

**Н2. Остаточные потолки стека вне семантики.** Замерено при приёмке:

| Что | Порог | Где рекурсия |
|---|---|---|
| `taktc fmt` на вложенных скобках | ~3000 | печать форматтера |
| `taktc verify`/`compile` на вложенных `if` | ~2000 | производный `Clone` для `ast::Expression` |

Это **другие** рекурсии — печать и обход структуры данных, а не семантический
спуск; сторож их не покрывает по построению. Порог на порядок выше прежнего
(240–280) и достижим только порождённым текстом. Вынесено кандидатом с
предложением: ограничивать вложенность на уровне лексера/парсера, чтобы глубокое
дерево вообще не строилось.
