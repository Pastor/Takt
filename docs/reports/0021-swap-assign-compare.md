# Отчёт о тестировании фичи 0021: `:=` присваивание, `=` сравнение

> Фича: [../features/0021-swap-assign-compare.md](../features/0021-swap-assign-compare.md) · тест-план: [../tests/0021-swap-assign-compare.md](../tests/0021-swap-assign-compare.md) · анализ: [../analyze/0021-swap-assign-compare.md](../analyze/0021-swap-assign-compare.md)

## Резюме

Фича **готова к закрытию (ГОТОВО)**. Реализован Option B: `:=` — присваивание,
`=` — сравнение на равенство (в выражениях и условиях), `<=` — реляционный
(сохранён), `==` — выведён. AST-узлы не менялись — переключена привязка токенов
в грамматике; семантика/кодоген/LSP работают на прежних узлах. Весь код языка
(141 `.lam` + inline-Lam в тестах и `#[cfg(test)]` обоих крейтов + doctests)
мигрирован AST-мигратором. Версия языка `0.0.5 → 0.1.0`.

**Прогоны** (`cargo test --features lsp -- --test-threads=1`, окружение:
Windows 11, nightly gnu + MinGW): `grammar` lib 604/604, `parser_tests` 102,
`semantic_tests` 270, `codegen_tests` 31, `lsp_tests` 60, `ast/lexer/diagnostics/
ltl` — зелёные; doctests 36/36; `simulation` 149/150.

разный порядок). Миграция enum/условий не затрагивает.

## Результаты по функциональности

Лексер, парсер (`Expression`/`Condition`/`LoopCond`), семантика/`type_inference`,
C-генератор, PlantUML, LTL/Бюхи, LSP, симуляция — регресс отсутствует (зелёные
тесты после миграции). `parser/lexer.rs` намеренно не мигрирован: его тесты
проверяют лексему `=`→`Token::Assign`, валидную и после 0021.

## Примеры и контрпримеры (правило 16)

Перенесены в README (§4–6): `var y: u8 := 5;` (инициализация), `if x = 0 { … }`
(сравнение), `cond IsZero = x = 0;` (связка + сравнение), `ref Green: timer = 255;`
(равенство в условии), `timer := timer + 1;` (присваивание в теле). Контрпримеры:
`x = 5;` в позиции присваивания и `a == b` — ошибки разбора.
