# Отчёт о тестировании фичи 0174: Цель rust: корневая модель без портов (clippy::new_without_default)

> Фича: [../features/0174-rust-new-without-default.md](../features/0174-rust-new-without-default.md) · тест-план: [../tests/0174-rust-new-without-default.md](../tests/0174-rust-new-without-default.md) · анализ: [../analyze/0174-rust-new-without-default.md](../analyze/0174-rust-new-without-default.md)

## Резюме

**Пройдено; фича готова к закрытию (`ГОТОВО`).** Цель `rust` перестала
отказывать на модели без ввода-вывода: конструктор без аргументов идёт в паре с
`impl Default`. Сторож двухслойный, **обе** мутации генератора валят его
адресно.

## Окружение

- Толчейн — пин `rust-toolchain.toml` (стабильный 1.97.1); `clippy-driver`
  доступен, пропусков не было.
- Прогон: `cargo test --all-features -- --test-threads=1`, `./scripts/precheck.sh`.

## Примеры и контрпримеры (правило 16)

Язык не менялся, поэтому языковых примеров в `book/` не заводилось. Пример и
контрпример относятся к порождаемому коду:

- **пример** — модель без портов и без `extern fn`;
- **контрпример** — модель с портом. Он ловит не симметричную мелочь, а
  **поломку сборки**: `Default` при `new(hal: H)` не скомпилируется, значение
  `H` взять неоткуда. Мутация T6 это подтвердила.

## Выводы и дальнейшие шаги

1. **Диагноз карточки уточнён замером.** Предполагалось «у каждого примера есть
   порты»; на деле у `comprehensive.takt` их **ноль**, а гейт зелёный — пример
   зовёт `extern fn` и потому получает `new(hal: H)`. Настоящий признак —
   предикат `needs_hal`, транзитивный по портам **и** `extern fn`.
2. **Пустой дифф корпуса — не «нечего было чинить», а подтверждение диагноза.**
   Ни один пример не обходится разом без портов и без `extern fn`, поэтому гейт
   этот класс не видел и без отдельного сторожа не увидел бы впредь.
3. **Сторож поставлен на фикстуре, а не корпусным примером** (отклонение от
   наметки карточки, обосновано в ADR): модель без единого порта — замкнутая
   система, и в `examples/` она была бы документацией о том, как писать
   бесполезную модель. Прецедент фикстур — `conformance_rust_tests`.
4. **Найдено попутно:** комментарии `regulator.takt`, `float_regulator.takt` и
   `pid_regulator.takt` объясняют свой выходной порт нуждой цели `rust` — после
   фичи объяснение неверно. В объём не взято (косметика по трём файлам корпуса),
   записано находкой в `FEATURES.md`.

Исправлений по самой 0174 не требуется.
