# Отчёт о тестировании фичи 0248: Встроенные функции min/max/abs/clamp/debug не исполняются эталоном

> Фича: [../features/0248-sim-builtin-functions.md](../features/0248-sim-builtin-functions.md) · тест-план: [../tests/0248-sim-builtin-functions.md](../tests/0248-sim-builtin-functions.md) · анализ: [../analyze/0248-sim-builtin-functions.md](../analyze/0248-sim-builtin-functions.md)

## Резюме

**Пройдено, фича готова к закрытию.** Девять проверок тест-плана зелёные:
эталон считает `min`/`max`/`abs`/`clamp` и совпадает с целью `c` потактово — в
том числе на `q(8, 8)`; `debug` больше не останавливает прогон; `S(Модель)` в
выражении остаётся отказом с держателем 0247. `./scripts/precheck.sh` — код 0.

Дефектов, требующих фиксов, нет. Найдены **две** соседние дыры (см. выводы) —
заведены фичей 0249 и кандидатом.

## Выводы и дальнейшие шаги

1. **Дефект реализации поймала проба, а не чтение.** Первая редакция считала
   `max` через `pick_smaller(b, a)` и возвращала **меньшее**: на входе
   `max(1, 3)` выходило `1`. Ошибка видна только на меняющейся трассе — потому
   сверка и требует, чтобы значения менялись по тактам.
2. **Реализация через общий слой окупилась сразу:** сверка на `q(8, 8)` прошла
   без единой строки Q-арифметики в новом модуле — формат, обёртка и насыщение
   пришли из `eval::ops`.
3. **Гейт 0217 сам оказался с дырой, и она нашлась в работе:** сканер искал
   маркер построчно и не видел его, когда длинный текст диагностики перенесён
   `\` на две строки. После починки открылась третья заглушка — `SIM-017`, — и
   проба показала настоящий дефект: `f(n) := 1;` семантика **принимает**, цель
   `c` печатает невалидный C (`Badplace_f(model, model->n) = 1;`), эталон
   отвечает `SIM-017`. Заведена фича
   [0249](../features/0249-assign-to-call-place.md).
4. **Документ молчит о встроенных функциях языка** — шесть имён, о которых автор
   узнаёт только из исходников компилятора. Заведено кандидатом (после 0247,
   чтобы не описывать `S` с оговоркой, которая тут же устареет).
5. Исправлений не требуется; фича переводится в `ГОТОВО`. Остаток заглушки
   `SIM-020` снимет фича [0247](../features/0247-sim-bare-state-condition.md).
