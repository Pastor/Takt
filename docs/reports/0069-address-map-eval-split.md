## Расхождение с оценкой плана (T5)

План ожидал превышение 12049 → ~10933, вычитая полные 1116 строк. Фактически
«превышение» считает лишь строки **сверх** 1000 (у файла было 116), поэтому
падение меньше — **12049 → 11920**. Оценка плана ошибочна в арифметике, факт
верен: долг сократился на одну запись (22 → 21), храповик зелёный.

## Инварианты, сохранённые при перекладке

- **`apply_binary` — единственная** (правило 5 ADR): разделение по файлам —
  типичный повод завести «свой хелпер» в каждом; здесь это дало бы разный адрес
  для одного текста. Оставлена в `eval.rs`, зовётся из обоих матчеров.
- **Фикс [0020-01](../fixes/0020-01-port-bit-out-of-range.md) не тронут** (Tier 1,
  живёт в этом же коде): перекладка обязана дать пустой дифф вывода, а фикс его
  меняет — смешение потеряло бы главного сторожа (T3).
