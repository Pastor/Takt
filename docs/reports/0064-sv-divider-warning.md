# Отчёт о тестировании фичи 0064: предупреждение о делителе (`SV-009`) в цели `sv`

> Фича: [../features/0064-sv-divider-warning.md](../features/0064-sv-divider-warning.md) · тест-план: [../tests/0064-sv-divider-warning.md](../tests/0064-sv-divider-warning.md) · ADR: [../adr/0064-sv-divider-warning.md](../adr/0064-sv-divider-warning.md)

- **Дата:** 2026-07-20
- **Окружение:** macOS (darwin 25.5.0), cargo nightly. Гейты целевого языка
  (verilator/yosys) не требуются: фича не меняет вывод (деления в корпусе нет),
  а предупреждение проверяется юнит-тестами.
- **Вердикт:** **готово.** SV-юниты `grammar` (68, +8 к базе) зелёные,
  `precheck.sh` зелёный, вывод всех целей побайтово прежний.

## Сверка с критериями приёмки (ADR 0064)

| Критерий | Проверка | Результат |
|---|---|---|
| **A1** `a / b` → `SV-009`, трансляция успешна | `variable_divide_warns_sv009` | ✅ вывод `(a / b)`, один код `SV-009` |
| **A2** `a / 2`, `a / 3` → молчание | `constant_power_of_two_divide_is_silent`, `constant_non_power_of_two_divide_is_silent` | ✅ приёмник пуст |
| **A3** `a % b` → `SV-009`; `a % 4` → молча | `variable_modulo_warns_sv009`, `constant_modulo_is_silent` | ✅ |
| **A4** `a * b` → молчание | `multiply_is_silent` | ✅ приёмник пуст, вывод `(a * b)` |
| **A5** текст: причина + следствие, без LUT | `sv009_text_names_cause_and_consequence_without_luts` | ✅ содержит «аппаратного делителя» и «частот», не содержит «LUT»/«558» |
| **A6** корпус: 0 предупреждений, вывод прежний | греп `examples/*.lam` на `/`,`%` (пусто); `precheck.sh` детерминизм-гейт | ✅ |
| **A7** `SV-009` доставляется пользователю | новый `report` в `sv/mod.rs`, зовётся в `generate_program` | ✅ канал заведён |

## Разбор проверок тест-плана

- **T1/T3 (переменный `/`,`%`)** — `SV-009` эмитится, трансляция состоялась.
- **T2/T4/T6 (константа `a/2`,`a/3`,`a%4`)** — молчание. Они же **негативный
  сторож T11**: мутация «предупреждать на любое `/`» валит T2/T4/T6.
- **T5 (`a*b`)** — молчание (замер: DSP).
- **T7 (доставка)** — до фичи у цели `sv` канала не было (греп); заведён `report`
  по образцу `rust`/`st`. ⚠️ Перехват stderr **не понадобился**: приёмник
  (`Fsm::warnings`) инспектируется напрямую в юнит-тесте через `print_with_warnings`.
- **T8 (текст)** — называет причину и следствие без конкретных LUT.
- **T9/T10 (корпус, трансляция)** — деления в `examples/` нет → вывод байт-в-байт
  прежний; детерминизм-гейт `precheck.sh` (два прогона × все цели → `diff -r`)
  зелёный.

## Отклонения и известные ограничения

- **Дефект канала доставки** (`eprintln!` из библиотеки, `--quiet` не глушит) —
  воспроизведён образец `rust`/`st` **сознательно** (action A-6 ADR); чинить в
  0064 нельзя, заведён кандидатом.
- **Константа по потоку данных** (`b := 3; a / b`) предупредит — консервативно
  и осознанно (action A-2): лишнее предупреждение честнее пропущенного.
- **`q(m,n)` (0061)** делит через `fixed_bin` — предупреждение эмитится **до** него
  (общая ария `Divide`), поэтому action A-3 закрыта на будущее: делитель тот же.

## Что изменилось в коде

- `generator/sv/sv_expr.rs`: `sv009()`, `is_constant_divisor`, `warn_variable_divisor`,
  поле `Scope::warnings`, арии `Divide`/`Modulo` зовут проверку; 8 юнит-тестов.
- `generator/sv/sv_fsm.rs`: поле `Fsm::warnings: RefCell<Vec<Diagnostic>>`,
  проброс в `Scope` (`Fsm::scope`, `emit_functions`).
- `generator/sv/mod.rs`: `report(&fsm.warnings.borrow())` в `generate_program`,
  функция `report`.
