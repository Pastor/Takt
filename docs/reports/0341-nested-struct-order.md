## Что показал прогон

1. **Одна запись — два разных корня.** Три цели ошибались порядком, четвёртая
   типом; общего лечения не существовало, и объединяет их только вход.
2. **Проба солгала дважды.** Сперва имя `ln` дало посторонний отказ `iec2c`,
   затем ложный `RS-011` цели `rust` выглядел как «структуры не поддержаны».
   Оба раза спасло снятие причин по одной (правило 30).
3. **Тест закреплял дефект второй раз за сессию** (первый — фича 0334): текст
   теста утверждал невозможность того, что уже работало.
