## Окружение

- macOS (darwin 25.5.0), POSIX sh.
- Дата прогона: 2026-08-20.

| Прогон | Результат |

## Сверка с тест-планом

| # | Условие | Итог |
|---|---|---|
| П1 | Контроль: маленький файл | ✅ |

| П7 | Жёлтая зона печатается и не роняет прогон | ✅ |
| П8 | Контроль: файл вне зоны | ✅ |

## Что показал прогон

1. **Список кандидата сдвинулся.** Он называл `sv_fsm.rs` (998) первым; сегодня
   ближе всех `generator/sv/sv_expr.rs` — **ровно 1000 строк, запас 0**: любая
   следующая строка в нём уронила бы предкоммит без предупреждения.
2. **Порог выбран замером:** при 950 в зоне 15 файлов, при 900 — 23 (стена,
   которую перестают читать), при 970 — восемь.
3. **У гейта не было самопроверки** — с фичи 0027. Кандидат этого не называл;
   теперь мутацией проверяются все пять условий отказа плюс два условия зоны.

## Дефекты

Не найдено.

## Вердикт

**Готово.** Сигнал приходит до отказа, кода возврата не меняет, а сам гейт
впервые проверяется мутацией.
