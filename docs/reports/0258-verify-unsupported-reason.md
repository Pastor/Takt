# Отчёт о тестировании фичи 0258: `Verdict::Unsupported` не различает причину отказа

## Резюме

**Пройдено, фича готова к закрытию (`ГОТОВО`).** Вердикт-отказ несёт причину;
CLI печатает **одну** — ту, по которой проверка не выполнена, — вместо
перечисления всех пяти возможных.

Окружение: macOS (darwin 25.5.0), Rust 1.97.1. Полный `./scripts/precheck.sh`
— **код 0**, 2026-08-19.

## Выводы и дальнейшие шаги

1. **Исправлений не требуется** (`docs/fixes/0258-YY-*` не заводились).
2. ⚠️ **Замер поправил документацию модуля.** `float`, `q`, массив и структура
   отсекаются **подмножеством предикатов**, а не проверкой домена: ветвь
   `DomainNotEnumerable` сегодня недостижима. Проверено на четырёх входах.
   Ветвь оставлена защитной, недостижимость названа в коде — молчаливая
   подмена причины при расширении подмножества была бы ложью.
3. ⚠️ **Мусор в выводе поймал прогон, а не чтение.** Первая редакция текстов
   использовала продолжение строки (`\`), и в сообщение попали десятки
   пробелов подряд; тексты переписаны через `concat!`. Урок общий: сообщение
   пользователя проверяется **прогоном инструмента**, а не тестом на тип.
4. ⚠️ **Ложь, снятая 0145 обезличиванием, устранена по существу:** вход за
   потолком теперь получает свою причину и совет («сузьте домены… или возьмите
   свойство над меньшим их числом»), а не список из четырёх пунктов.
