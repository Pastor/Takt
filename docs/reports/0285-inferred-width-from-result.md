# Отчёт о тестировании фичи 0285: Ширина выведенного типа

> Фича: [../features/0285-inferred-width-from-result.md](../features/0285-inferred-width-from-result.md) · тест-план: [../tests/0285-inferred-width-from-result.md](../tests/0285-inferred-width-from-result.md) · анализ: [../analyze/0285-inferred-width-from-result.md](../analyze/0285-inferred-width-from-result.md)

## Резюме

**Пройдено, фича готова к закрытию (`ГОТОВО`).** Девять проверок тест-плана
зелены, исправлений (`docs/fixes/0285-YY-*`) не потребовалось. Тестов стало
3212 (+8), предкоммит — код возврата 0.

## Фактические результаты по проверкам

| # | Проверка | Результат | Комментарий |
|---|---|---|---|
| T1 | Сложение | ✅ | `1 + 255` = `256` (было `0`) |
| T2 | Порядок операндов | ✅ | `255 + 1` = `256` |
| T3 | Умножение и сдвиг | ✅ | оба `256`; сдвиг — единственная форма, которую называл кандидат |
| T4 | Значение шире разряда | ✅ | `200 + 200` = `400` (было `144`) |
| T5 | Контроль: не изменилось | ✅ | `300 - 44` = `256`, `250` = `250` |
| T6 | Граница: явный тип | ✅ | `44` — правило 0207 в силе |
| T7 | Граница: отрицательное | ✅ | `~0` = `255` |
| T8 | Граница: тип из сигнатуры | ✅ | `[bit;32]` сохранён |
| T9 | Корпус цел | ✅ | правок `examples/` не потребовалось |

## Выводы и дальнейшие шаги

1. **Кандидат винил сдвиг — замер показал любую арифметику.** `2 * 128` и
   `200 + 200` дают тот же дефект, а `300 - 44` работал **случайно**: там левый
   операнд сам не влезал в восемь бит. Правка, сделанная по букве кандидата
   (только `<<`), закрыла бы восьмую часть класса.
2. **Правка сужалась дважды, и оба раза её сузили ЧУЖИЕ сторожа.** Первая
   редакция переопределяла тип всегда и сломала вывод Ce6 из сигнатуры функции;
   вторая смотрела и на нижнюю границу и сломала `~0` (правило 0207). Обе
   выглядели верными при чтении — это прямой довод в пользу сверок значений.
3. **Расхождения между потребителями не было и нет:** значение сворачивается в
   семантике, все девять согласны. `Tier 2` подтверждён в своём смысле —
   инструменты не противоречат друг другу, они были одинаково неправы.
4. **Исправлений не требуется.** Дефектов, заводящих `docs/fixes/0285-YY-*`,
   не найдено.
5. **Кандидатов не заведено.** Соседний класс уже описан фичей
   [0287](../features/0287-wider-type-array-literal.md) (правило `wider_type`
   побеждает объявленный тип источника); замер подтвердил, что фичи не
   пересекаются — 0285 правит выбор ширины после свёртки, 0287 само правило.
