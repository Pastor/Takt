### Трасса, из которой взяты числа

```text
Шаг 1: [Run]  early=8  later=7  level=5  n=2  probe=16  snapshot=11
```

`probe := AREA` показывает значение константы (константы в трассу не
печатаются); `n = 2` на первом такте — переменная уже выросла, а `snapshot`
остался `11`, то есть инициализатор взял её **начальное** значение.

## Примеры и контрпримеры

| Запись | Значение / ответ | Где в разделе |
|---|---|---|
| `const AREA := WIDTH * WIDTH;` | 16 | «вычисляется при сборке» |
| `var level: u8 := WIDTH + 1;` | 5 | там же |
| `var snapshot: u8 := n + 10;` при растущем `n` | 11 | «имя = начальное значение» |
| `var early: u8 := later + 1;` | 8 | «ссылка назад» |
| `var ahead: u8 := future + 1;` (future ниже) | **`SE-109`** | «только назад по тексту» |
| `var v := LATER + 1; const LATER := 3;` | 4 | «у констант порядок не важен» |

## Найденные дефекты

Дефектов текста не найдено. Главная находка сделана **до** правки документа — на
стадии сбора фактов: ссылка вперёд давала расхождение эталона и прошивки. Она
закрыта отдельной фичей [0246](../features/0246-init-forward-reference.md), без
которой этот раздел описывал бы несоблюдаемое правило.

## Правило 29 (редакторский слой)

**Не требуется, ответ зафиксирован.** Язык не меняется, правится документ.

## Вердикт

**Готово.** Требования R1…R7 выполнены, критерии A1…A6 закрыты, предкоммит
зелёный.
