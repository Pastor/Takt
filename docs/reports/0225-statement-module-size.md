## Выводы и дальнейшие шаги

1. **Замер кандидата устарел вдвойне.** Число: 999 → 976. Вывод «следующая
   правка модуля обязана начинаться с разделения, иначе гейт её отвергнет» —
   опровергнут историей: после того замера модуль правили трижды (0185, 0189,
   0243), разделения не делали, и гейт не отказывал ни разу. Настоящий предмет
   фичи — не блокировка, а **малый запас**.
2. **`statement.rs` не был самым близким к пределу** — седьмой из девяти файлов
   зоны ≥ 970 строк (ближе всех `sv_fsm.rs` — 998). Класс шире одного файла и
   вынесен **кандидатом** в `FEATURES.md`: предупреждение гейта о приближении к
   лимиту («жёлтая зона»), Option D ADR.
3. **Приём деления не изобретался:** тот же, что у `semantic/expression/`
   (ADR 0088, фича 0129) — директория-подмодуль + `use super::*`.
4. Исправлений не требуется; фича переводится в `ГОТОВО`.
