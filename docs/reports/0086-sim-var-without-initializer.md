# Отчёт о тестировании фичи 0086: `var q: u8;` без инициализатора → `SIM-009`

> Фича: [../features/0086-sim-var-without-initializer.md](../features/0086-sim-var-without-initializer.md) · тест-план: [../tests/0086-sim-var-without-initializer.md](../tests/0086-sim-var-without-initializer.md) · анализ: [../analyze/0086-sim-var-without-initializer.md](../analyze/0086-sim-var-without-initializer.md)

## Резюме

Реализована подзадача 0086-01 (Option A ADR): ветка «нет инициализатора» в
`ModelNodeContext::get_value` строит нулевое значение по типу через
`default_field`; `default_struct` удалён как частный случай. Скаляр без
инициализатора теперь существует со значением 0, а не даёт `SIM-009`. **Все
проверки тест-плана пройдены; блокеров нет.**

**Окружение:** macOS (darwin 25.5), rustc nightly, `cargo test` однопоточно,
полный `./scripts/precheck.sh`.

## Замечания

- **Массивы вне объёма (осознанно).** Первый зонд включал `arr.1` и упал на
  `SIM-011` — в Lam `.N` это **бит-доступ**, а не индекс, а исполнение массивов —
  отдельная нерабочая фича [0076](../features/0076-sim-arrays.md). Массив из
  фикстуры убран; при этом **регистрация** массива нулей (`Value::Array`) уже
  работает — то есть фикс 0086 покрывает и массивы на уровне регистрации.
- **Порты/константы без регресса.** Расширение дефолта на все типы прогнано всем
  корпусом симуляции (все conformance-сценарии с портами зелёные): порт до первой
  записи драйвером = 0 вместо падения — улучшение, `const` без init отсекается
  семантикой раньше.
- **Согласованность с C.** Ноль совпадает с C default-init (прецедент 0034);
  вывод генераторов на корпусе неизменен — потактовая сверка не расходится.
