# Отчёт о тестировании фичи 0275: Команды в README.md никем не проверяются

> Фича: [../features/0275-readme-commands-gate.md](../features/0275-readme-commands-gate.md) · тест-план: [../tests/0275-readme-commands-gate.md](../tests/0275-readme-commands-gate.md) · анализ: [../analyze/0275-readme-commands-gate.md](../analyze/0275-readme-commands-gate.md)

## Резюме

**Пройдено, фича готова к закрытию (`ГОТОВО`).** Команды README проверяются
машиной: пути крейтов и скриптов, подкоманды `taktc`, и — прогоном — те
команды, чьи входные файлы существуют.

**Главный результат — не гейт, а дефект, который он нашёл на первом же
прогоне:** команда из README `taktc compile -t st-at --address-map …`
**роняла компилятор паникой**. Причина устранена по существу: карта адресов
получила свой номер файла, печать диагностики укреплена.

Окружение: macOS (darwin 25.5.0), Rust 1.97.1. Полный `./scripts/precheck.sh`
— **код 0**, 2026-08-19.

## Выводы и дальнейшие шаги

1. **Исправлений не требуется** (`docs/fixes/0275-YY-*` не заводились):
   найденный дефект устранён в объёме фичи — иначе гейт нельзя было включить.
2. ⚠️ **Гейт окупился в первом прогоне.** Кандидат обещал ловить устаревшие
   команды; на деле первая же проверка нашла **отказ инструмента**: карта
   адресов разбиралась под номером файла модели, и печать предупреждения
   резала чужой текст — на латинице выходила ложная координата (класс 0264),
   на кириллице паника.
3. ⚠️ **Чинить симптом было бы недостаточно.** `line_column` укреплён, но это
   второй рубеж; корень — чужой номер файла — устранён отдельно, и координата
   стала указывать в карту.
4. ⚠️ **Копия дерева в стороже должна быть не беднее рабочего:** первый прогон
   сторожа «нашёл» несуществующий `examples/generated/rust/Cargo.toml` —
   потому что копия его не содержала. Сторож гоняет **настоящий** README
   именно для того, чтобы ложное срабатывание всплывало сразу.
5. **Граница названа:** команды внешних инструментов (`verilator`, `yosys`,
   `gtkwave`, `cargo install`) не исполняются — для них работает только
   проверка путей.
