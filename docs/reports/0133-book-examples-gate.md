## Найденный дефект документа

**Д1. Seed-пример раздела «Обзор» не компилировался и не соответствовал тексту.**

- `start state Off` — недопустимая форма (`SY-002`); отсутствовал верхнеуровневый
  вход, из-за чего модель давала `SE-011`.
- **Сверх того**: оба перехода проверяли `btn = 1`, то есть модель
  перещёлкивалась **каждый такт** при нажатой кнопке, хотя текст обещал
  переключение «по нажатию».

Исправлено: форма приведена к `start Off` + `start Main = Lamp;`; переходы —
`Off → On` по `btn = 1`, `On → Off` по `btn = 0` (лампа горит, пока кнопка
нажата). Текст раздела приведён в соответствие. Поведение проверено симуляцией со
сценарием входов.

## Результаты по функциональности

- **Полнота охвата** (A1, A2): проверяются все файлы дерева; библиотечные
  выводятся из содержимого, а не из списка-исключений, поэтому исключения не
  протухнут.
- **Гейт взведён** (A3, A4): обе стороны правила 27(д) проверены ловушками.
  Подмены откачены, в репозиторий не попали.
- **Найденное починено** (A5–A7).
- **Единый источник истины** (A8, A9): гейт живёт в `precheck.sh`, CI получает
  его автоматически — контракт фичи 0090 соблюдён.

## Выводы и дальнейшие шаги

Фича закрывается со статусом **ГОТОВО**. Версия языка не менялась (язык не
затронут).

**Открытые ограничения (из ADR):**

1. **Гейт не проверяет осмысленность** — прогон без сценария входов доказывает
   отсутствие отказа, но не то, что модель делает обещанное текстом. Полные
   поведенческие контракты (Option B) отвергнуты по цене; ответственность
   остаётся на ревью раздела (правило 27).
2. **Формат примеров не проверяется** (`fmt --check` к ним не применяется):
   маркеры-выноски `(1)`, `(2)` и выравнивание канонический форматтер
   переставит. Сознательное исключение.
3. **Бюджет 10 тактов — эвристика:** отказ, наступающий позже, гейт не поймает.
