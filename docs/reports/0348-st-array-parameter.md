## Что показал прогон

1. **Разбор — не доказательство.** Форма, принятая `iec2c`, дала невалидный C.
   Это новое правило для проб цели `st`, и оно стоило бы фичи, будь оно принято
   на веру.
2. **Перестановка аргументов нашлась сразу** — на функции с параметрами обеих
   секций; на односекционной она была бы невидима.
3. **Ограничение набора форм обязательно:** без него именованным становился
   каждый массив, и два юнит-теста цели покраснели немедленно.
