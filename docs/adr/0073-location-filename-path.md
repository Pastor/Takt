# ADR 0073: `Location::filename()` — удалить, а не «чинить путь»

- **Status:** Accepted
- **Date:** 2026-07-20
- **Authors:** Архитектор + Дизайнер диагностик
- **Related issues:** [Фича 0073](../features/0073-location-filename-path.md); следствие [ADR 0053](0053-diagnostics-file-id.md) (путь стал доступен честно) и [0056](../features/0056-lsp-goto-exact-file.md)

## Context

`Location::filename()` (`diagnostics.rs:645`) возвращает
`format!("{}", file_no)` — **номер файла строкой**, тогда как имя обещает
**путь/имя файла**. Doc-комментарий честен («строковое представление номера
файла»), но **имя метода лжёт**. Рядом (`diagnostics.rs:655`) уже живёт честно
названный `try_file_no() -> Option<String>` с **тем же** значением (отличие лишь:
`filename()` паникует на не-`Source`, `try_file_no()` даёт `None`).

Метод **не используется в продуктовом коде** — только в двух тестах:

- `parser_tests.rs:944` — `assert_eq!(loc.filename(), "0");`, причём **на
  следующей строке** уже есть `assert_eq!(loc.try_file_no(), Some("0"…))` — то же
  свойство проверено дважды;
- `ast_tests.rs:76` — тест `location_filename`, стоящий вплотную к тесту
  `try_file_no()`, проверяющему то же.

**Почему «сделать так, чтобы `filename()` возвращал путь» нельзя.** `Location`
несёт только `file_no: u32`; путь живёт в **отдельном** реестре `FileTable`
(`file_no → путь`, ADR 0053), к которому `Location` доступа не имеет. Честный путь
берётся через `Diagnostic::file` (0053) или `FileTable::path`, а **не** из
`Location`. Значит `filename()` в принципе не может выполнить обещание имени —
он **ловушка для следующего читателя** (`loc.filename()` читается как «дай путь»,
а вернёт `"0"`).

## Decision Drivers

1. **Честность API имён.** Метод, чьё имя обещает путь, а возвращает номер, —
   источник ошибок; хуже, что честный аналог (`try_file_no`) уже есть.
2. **Отсутствие потребителей.** Ни строки продуктового кода; только тесты,
   дублирующие проверку `try_file_no`.
3. **Минимальность и обратимость.** Правка не трогает язык, семантику, кодоген;
   вывод генераторов байт-в-байт неизменен.

## Considered Options

### Option A. Удалить `filename()`, тесты перевести на `try_file_no`

`filename()` убирается; две тестовые проверки удаляются как **дубли** (свойство
уже покрыто `try_file_no` рядом).

**Pros:**
- Убирает ложь и дублирование одним ходом; `try_file_no` остаётся единственным,
  честно названным аксессором номера.
- Тесты не теряют покрытия: `try_file_no` проверяет то же, вплотную.

**Cons:**
- Формально сужает `pub`-API (правило 11). Приемлемо: потребителей вне тестов
  нет, крейт внутренний, карта фичи прямо санкционирует «переименовать/удалить».

### Option B. Переименовать `filename()` → `file_no_string()` (честное имя)

**Pros:**
- Сохраняет метод под честным именем.

**Cons:**
- Становится **точным дублем** `try_file_no` (оба отдают номер строкой) — лишь
  паника вместо `Option`. Два аксессора одного значения — тот же запах, что
  устраняем; выбор «паникующий или нет» уже выражает пара `start()`/`try_file_no`.

### Option C. Сделать, чтобы `filename()` возвращал путь

**Pros:**
- Имя перестало бы лгать буквально.

**Cons:**
- **Неосуществимо дёшево:** `Location` не знает пути (только `file_no`); путь — в
  `FileTable`. Пришлось бы протаскивать реестр в `Location` (или в каждый вызов) —
  несоразмерно задаче и против границы 0053 («реестр — деталь компиляции, в
  публичный API `Location` не выходит»).

## Decision

Принимается **Option A** — удалить `filename()`, две тестовые проверки убрать как
дубли `try_file_no`. `try_file_no` остаётся единственным честным аксессором
номера файла; путь берётся через `Diagnostic::file` / `FileTable::path` (0053).

## Consequences

### Положительные

- Ложное имя и дублирование устранены; читатель `Location` больше не примет номер
  за путь.

### Отрицательные / Action items

- **0073-01:** удалить `Location::filename()` (`diagnostics.rs`); в
  `parser_tests.rs` убрать строку `assert_eq!(loc.filename(), "0");` (свойство
  покрыто соседним `try_file_no`); в `ast_tests.rs` удалить тест
  `location_filename` (дубль теста `try_file_no`). Проверить, что `not_a_file()`
  остаётся востребованным другими аксессорами (`start`/`end`/…).
- **Версия языка НЕ поднимается** — правка внутренняя (метод диагностики),
  синтаксис/семантика языка не меняются; вывод генераторов байт-в-байт неизменен.

### Acceptance criteria

1. `grep filename() grammar/ simulation/` не даёт совпадений (метод и его вызовы
   удалены).
2. `try_file_no()` и остальные аксессоры `Location` работают без изменений.
3. `./scripts/precheck.sh` зелёный; вывод генераторов на корпусе неизменен.
