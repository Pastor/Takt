# ADR 0387: Локальная переменная, записанная но не прочитанная

- **Status:** Accepted
- **Date:** 2026-08-22
- **Authors:** Архитектор + Аналитик
- **Related issues:** [Фича 0387](../features/0387-write-only-local.md);
  продолжает [0376](0376-unused-local-stub.md) (заглушка) и
  [0386](0386-unused-local-warning.md) (`SE-036` о локальных)

## Context

Признак «локальная не используется» (0376) считал **упоминание** использованием,
в том числе запись. Поэтому `var spare: u8 := 0; spare := n + 5;` без единого
чтения заглушки не получал. Замер 2026-08-22 (`scripts/probe.sh` + прогон
инструментов):

| Потребитель | Ответ на вывод |
|---|---|
| `c`, `c-hal` | `cc -Wall -Wextra -Werror`: `variable 'spare' set but not used` |
| `rust` | `rustc -D warnings`: `unused variable: spare` |
| `sv`, `sv-mmio` | `verilator -Wall`: `UNUSEDSIGNAL` |
| `st`, `st-at` | принимают |
| эталон | исполняет |

Пять целей из восьми порождают вывод, который отвергают **их же** инструменты,
при нулевом коде возврата `taktc`. Семантика молчала: `SE-036` считала запись
использованием.

⚠️ Кандидат называл вопрос узко («отвечает ли `cc -Wunused-but-set-variable` —
не измерялось»). Прогон показал класс шире: `rust` и `sv` ломаются тоже, причём
у `sv` заглушки для обычной локальной не было **вовсе** (0376 покрыла `c` и
`rust`).

## Decision Drivers

1. **Невалидный вывод при нулевом коде возврата** — самый дорогой класс после
   молчаливого расхождения значений.
2. **Признак один на семантику и цели** (0386): расходиться им нельзя.
3. **Мёртвая переменная — это и сообщение автору**: компиляторы C и Rust
   предупреждают ровно так же.
4. **Идиома принадлежит целевому языку**, а признак — общий (0260/0337/0376).

## Considered Options

### Option A. Оставить признак прежним, гасить у целей «по тексту»

**Cons:** знание раздвоится (что считать использованием — в двух местах), а
`SE-036` продолжит молчать о мёртвой переменной.

### Option B. Считать использованием только ЧТЕНИЕ

Признак спрашивает чтения: цель присваивания — место записи, а не чтение;
внутри неё читаются индексы и базы (`arr[i] := 5;` читает `i`, не `arr`).

**Pros:**
- один признак служит и заглушке целей, и `SE-036`;
- совпадает с тем, что говорят `cc` и `rustc` про свой же код;
- у `sv` появляется недостававшая заглушка.

**Cons:**
- меняет поведение только что закрытой 0386 (её граница «запись = использование»
  снимается) — это осознанное решение, а не побочный эффект;
- риск шума: замер по корпусу обязателен.

## Decision

Принимается **Option B**.

Режим сбора задаётся полем `UsageSet::reads_only` — **флагом вместо второго
обхода**: копия правила «что считать упоминанием» разошлась бы с оригиналом
молча (класс 0084/0193/0195). Признак локальных (`unused_locals_of_block`)
включает его; фильтры печати целей (`compute_usage`) — нет: там вопрос другой
(«нужно ли имя в выводе»).

Цель `sv` получает **поглотитель** для такой локальной — ту же идиому, что у
неиспользуемого параметра (0337) и поднятых локальных со структурой (0375).

⚠️ **Присваивание поглотителя печатается ПОСЛЕ тела:** чтение сигнала раньше
записи verilator встречает `ALWCOMBORDER` («behavior may imply latch»), а гейт
цели считает предупреждение ошибкой. Это выяснилось прогоном — первая редакция
печатала поглотитель рядом с объявлением.

## Consequences

### Положительные

- Вывод пяти целей начинает собираться под флагами их гейтов.
- `SE-036` сообщает автору о мёртвой переменной, а не молчит.
- Знание одно: и семантика, и цели спрашивают один признак.

### Отрицательные / Action items

- Граница 0386 («запись считается использованием») снята — поведение
  предупреждения расширено осознанно.
- Возможен шум: замер по корпусу дал **ноль** новых предупреждений (единственное
  существующее — `var action` уровня модели в `elevator.takt`).

### Acceptance criteria

1. Порождённый C собирается под флагами гейта (`-Wall -Wextra -Werror`).
2. Вывод всех восьми целей принимают их инструменты.
3. `SE-036` предупреждает о записанной-непрочитанной локальной.
4. Поведение не изменилось (трасса эталона прежняя).
5. Мутация «запись снова считается чтением» роняет сторожа.
6. Корпус не даёт новых предупреждений; `precheck.sh` зелёный.
