# ADR 0085: Константа версии языка в коде + гейт синхронизации с README

- **Status:** Accepted
- **Date:** 2026-07-22
- **Authors:** Архитектор + Аналитик
- **Related issues:** [Фича 0085](../features/0085-language-version-constant.md); прецеденты гейтов — [ADR 0027](0027-module-size-split.md) (размер модуля), [ADR 0077](0077-diagnostic-code-registry.md) (реестр кодов)

## Context

Версия языка Lam живёт **только** в `README.md` (строка `**Версия языка: 0.3.0**`
в разделе «10. Расширение и версии»). В коде компилятора константы версии **нет**,
`lamc` версию **не печатает**. Рассинхрон между документацией и фактическим
поведением компилятора **ничем не ловится**.

Дефект — **живой на момент заведения фичи**: фича
[0078](../features/0078-bit-array-semantics.md) (закрыта 2026-07-22) подняла версию
языка `0.3.0 → 0.4.0` и зафиксировала это в `CHANGES.md`/`CLAUDE.md`, но
`README.md` остался на `0.3.0`. Это прошло через закрытие 0078 незамеченным именно
потому, что сверять было не с чем и нечем.

Обострено решением заказчика от 2026-07-15 (правило 22: версия языка
**накапливается** по циклам, а не растёт с каждой фичей): исполнение решения
затруднено тем, что единого места версии в коде нет — пять фич пула независимо
заявляли подъём `0.2.0 → 0.3.0`, а сверить намерения было не с чем.

Прецедент проекта (ADR 0027, ADR 0077): **правило, которое нельзя проверить
командой, — не правило.** README как единственный носитель факта повторяет судьбу
доков, отстающих от кода.

## Decision Drivers

1. **Единый источник истины.** Версия языка должна иметь **одно** каноническое
   место в коде; документация обязана следовать за ним, а не наоборот.
2. **Машинная проверяемость.** Рассинхрон дока↔константа должен валить
   `precheck.sh`/CI, а не жить до следующего ручного замечания (как дефект 0078).
3. **Минимальность и аддитивность (правило 11).** Фича не меняет язык — только
   вводит константу и гейт. Ничего в поведении компилятора/симулятора и в
   порождаемом коде меняться не должно.
4. **Ограничение размера `lamc.rs`.** Файл `grammar/src/bin/lamc.rs` ровно на
   baseline размера (1993 строки, реестр `module-size-baseline.txt`) — расти он
   **не имеет права** (ADR 0027). Любое решение с CLI-подкомандой упирается в это.

## Considered Options

### Option A. Константа в коде + гейт грепает исходник, сверяя с README

`pub const LANGUAGE_VERSION: &str = "0.4.0";` в отдельном модуле
`grammar/src/version.rs` (реэкспорт из `lib.rs`). Гейт
`scripts/check-language-version.sh` извлекает значение константы из исходника и
каноническую строку `**Версия языка: X.Y.Z**` из `README.md`, сверяет; расхождение
→ красный `precheck.sh`.

**Pros:**
- Единый источник истины в коде (драйвер 1); README обязан следовать (гейт).
- Машинная проверяемость (драйвер 2) прецедентом ADR 0027/0077 — грепом исходника,
  как `check-diagnostic-codes.sh` грепает `with_code`.
- `lamc.rs` **не растёт** (драйвер 4) — CLI не трогаем.
- Аддитивно (драйвер 3): новый модуль, новый гейт, правка одной строки README.

**Cons:**
- Гейт грепает строковый литерал исходника — привязан к форме объявления
  (`LANGUAGE_VERSION: &str = "…"`). Форма стабильна и покрыта юнит-тестом формата.
- `lamc version` пользователю по-прежнему недоступен (см. Option B) — уходит в
  бэклог-кандидат.

### Option B. Константа + подкоманда `lamc version`, гейт сверяет вывод CLI с README

Как A, но версия отдаётся через `lamc version`, а гейт сверяет `lamc version` с
README (контракт — CLI, а не форма исходника).

**Pros:**
- CLI-контракт чище грепа исходника; `lamc version` полезен пользователю.

**Cons:**
- `lamc.rs` **обязан вырасти** (диспетч подкоманды) — прямое нарушение baseline
  размера (драйвер 4). Обходы (удалить строки-компенсаторы, вынести диспетч в
  библиотеку и всё равно добавить `if`-ветку) либо хрупки, либо всё равно растят
  файл.
- Гейт зависит от сборки `lamc` — медленнее и не «до тестов», как быстрые гейты.

### Option C. Rust-тест сверяет `LANGUAGE_VERSION` с README вместо shell-гейта

Константа + `#[test]`, читающий `../README.md` и сверяющий.

**Pros:**
- Проверка на языке проекта, без нового shell-скрипта.

**Cons:**
- Тест крейта `grammar` запускается из каталога крейта; `README.md` — в корне
  workspace (`../README.md`) — путь хрупкий, ломается при разных запусках
  (`cargo test` из корня vs из крейта), в отличие от shell-гейта, который
  `precheck.sh` всегда зовёт из корня репозитория.
- Смешивает doc-инвариант с юнит-тестами; прецедент проекта для doc-инвариантов —
  именно shell-гейт в `precheck.sh` (размер модуля, реестр кодов, ссылки).

## Decision

Принимается **Option A**. Единственный источник истины — константа
`grammar::version::LANGUAGE_VERSION` (реэкспорт `grammar::LANGUAGE_VERSION`); гейт
`scripts/check-language-version.sh` в `precheck.sh` сверяет её с канонической
строкой `**Версия языка: X.Y.Z**` в `README.md`. Это единственный вариант, не
растящий `lamc.rs` (драйвер 4) и следующий прецеденту машинных doc-гейтов проекта
(ADR 0027/0077, драйвер 2).

Живой рассинхрон 0078 (README `0.3.0`, факт `0.4.0`) устраняется в рамках этой
фичи — иначе гейт красный на текущем дереве: константа = `0.4.0`, каноническая
строка README правится `0.3.0 → 0.4.0`. Это **не** подъём версии языка (правило 22):
константа лишь фиксирует уже действующую `0.4.0`.

Подкоманда `lamc version` (Option B) — полезна, но заблокирована baseline размера
`lamc.rs`; выносится в **кандидат** (бэклог `FEATURES.md`), берётся после появления
запаса в `lamc.rs` или его рефакторинга.

Гейт сверяет **только** каноническую строку `**Версия языка: X.Y.Z**` (текущая
версия). Исторические упоминания версий в README (заметки «`0.2.0 → 0.3.0`»,
«версия 0.3.0 накапливает», ссылки на фичи прошлых циклов) — **корректны в своём
контексте** и гейтом не трогаются: якорь узкий по замыслу.

## Consequences

### Положительные

- Версия языка централизована в коде; рассинхрон дока↔факт ловится машиной
  (класс дефекта 0078 закрыт конструктивно).
- Исполнение правила 22 (накопление версии) обретает опору: есть единственное
  место, куда пишется номер цикла, и гейт, стерегущий согласие с README.
- Публичная константа доступна тестам и будущим тулам (напр. будущему
  `lamc version`).

### Отрицательные / Action items

- Гейт привязан к форме объявления константы — компенсируется юнит-тестом формата
  (`version::tests`) и узостью греп-паттерна.
- `lamc version` (Option B) не реализован — **кандидат** в `FEATURES.md`.
- README должен нести каноническую строку `**Версия языка: X.Y.Z**` ровно в одном
  экземпляре — гейт падает и при её отсутствии, и при нескольких (защита от
  расхождения якоря).

### Acceptance criteria

1. `grammar::LANGUAGE_VERSION` существует, публичен, равен `"0.4.0"`; юнит-тест
   проверяет формат `x.y.z`.
2. `scripts/check-language-version.sh` возвращает 0, когда константа и
   каноническая строка README совпадают, и ненулевой код при расхождении,
   отсутствии или дубле канонической строки. Проверено пробой (искусственный
   рассинхрон → красный).
3. Гейт подключён в `precheck.sh` (и, следовательно, в CI по 0090) в блоке быстрых
   проверок (до долгих тестов).
4. `README.md` приведён к `0.4.0` (каноническая строка); `./scripts/precheck.sh`
   зелёный.
5. Вывод всех целей и симулятора байт-в-байт неизменен (правило 11): фича не
   трогает генераторы. Версия языка **не** поднимается (правило 22).
