# ADR 0324: Сдвиг вправо знакового — арифметический

- **Статус:** Accepted
- **Дата:** 2026-08-20
- **Фича:** [../features/0324-arithmetic-shift-right.md](../features/0324-arithmetic-shift-right.md)

## Контекст

Живой контекст проекта утверждал: «Операторов `<<`/`>>` в языке Takt **нет** —
фича, которая их введёт, обязана задать семантику нормативно».

**Это было неверно.** Проба 2026-08-20: `v := a << 2;` и `v := a >> 1;`
разбираются, исполняются эталоном и переводятся всеми восемью целями. То есть
операторы есть, а нормативной семантики у них — нет (класс 0292: проза
приписывает коду роль, которой у него нет, только здесь наоборот — отрицает
существующее).

### Замер (2026-08-20)

Вход `var neg: i8 := -7; right := neg >> 1;`

| Потребитель | Значение |
|---|---|
| эталон, `c`, `c-hal`, `rust` | **−4** (арифметический сдвиг, округление к −∞) |
| **`st`, `st-at`** | **124** — `SHR` работает над битовой строкой, то есть логически |
| **`sv`, `sv-mmio`** | **124** — в SystemVerilog `>>` логический **даже над `logic signed`** (проверено прогоном verilator) |

Левый сдвиг (`<<`) у всех совпадает.

## Решение

**Нормативно: сдвиг вправо знакового — арифметический** (округление к −∞), как
у эталона. Довод: правило 0127 уже задало знаковую арифметику через эталон, а
`c` и `rust` дают то же значение — расходились две цели из восьми.

- **`sv`** — печатается `>>>` при знаковом операнде;
- **`st`** — floor-деление `SEL(a < 0, a / 2ⁿ, (a − (2ⁿ − 1)) / 2ⁿ)`.

## Почему у `st` не просто деление

Деление в IEC усекает **к нулю**, арифметический сдвиг округляет **к −∞**:
`-7 >> 1` есть −4, а `-7 / 2` даёт −3. Поэтому у отрицательного делимое
смещается вниз на `2ⁿ − 1`.

Величина сдвига обязана быть **литералом**: иначе `2ⁿ` пришлось бы считать
функцией `EXPT`, возвращающей вещественное, и целочисленность результата
держалась бы на приведении. Переменная величина отвергается `ST-011` с
названной причиной.

## Отвергнутые варианты

1. **Признать правыми `st` и `sv` (логический сдвиг).** Тогда `-7 >> 1` даёт
   124 у двух целей и −4 у эталона, `c` и `rust` — менять пришлось бы больше, и
   значение противоречило бы знаковой арифметике языка.
2. **Запретить сдвиг знакового.** Операторы уже работают у восьми целей;
   запрет сузил бы язык ради двух.
3. **Оставить как есть, записав расхождение в документ.** Молчаливое
   расхождение значений — то, ради устранения чего заведены сверки.

## Последствия

- Значения сдвига совпадают у девяти потребителей.
- Утверждение живого контекста исправлено: операторы есть, семантика задана.
