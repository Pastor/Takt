# ADR 0323: Приведение `as` в цели `sv` — размерная форма

- **Статус:** Accepted
- **Дата:** 2026-08-20
- **Фича:** [../features/0323-sv-integer-cast.md](../features/0323-sv-integer-cast.md)

## Контекст

Цель `sv` не переводила приведение `as` **вовсе**: ветвь `Cast` отдавала
`SV-002`, кроме случая, когда участвовал тип `q(m, n)` (фича 0061).

### Замер (2026-08-20)

Вход `w := a as u16;` (`a: u8`):

| Потребитель | Ответ |
|---|---|
| эталон, `c`, `c-hal`, `st`, `st-at`, `rust`, `plantuml` | исполняют, `w = 200` |
| **`sv`, `sv-mmio`** | **`SV-002`** «приведение типа (`as`)» |

Класс нашёлся не сам по себе: пробы на побитовые операции и на сравнение
перечислений отказывали у `sv` **той же** диагностикой — потому что обе
записывали результат через `as u8`.

## Решение

Размерная форма `<W>'(выражение)`, где `W` — ширина **цели** приведения:

- беззнаковая цель — `W'(expr)`: усечение старших разрядов и дополнение нулями
  заданы стандартом, и это ровно правило ADR 0127 (обёртка `mod 2ⁿ`);
- знаковая — `$signed(W'(expr))`.

Нескалярная цель (массив, структура) — прежний отказ: у такого приведения нет
одной ширины.

## Почему ширина указывается явно

Форма без числа перед апострофом (`'(…)`) означает «ширина по контексту», то
есть молчаливое расширение до ширины приёмника. Автор просит конкретный тип, и
подмена его контекстом дала бы другое значение при сужении.

## Почему `$signed` обязателен

Без него знаковая цель осталась бы беззнаковой для сравнений и арифметического
сдвига — молча: оба инструмента SV такой модуль принимают (урок 0045).

## Отвергнутые варианты

1. **Полагаться на присваивание** (`w = a;`). Работает при расширении и молча
   усекает при сужении — то есть форма приведения исчезла бы из вывода, а
   вместе с ней и намерение автора.
2. **`$unsigned`/`$signed` без размера.** Меняет только трактовку знака, но не
   ширину; сужение осталось бы за контекстом.

## Последствия

- `as` между целыми переводят все восемь целей.
- Заодно стали переводиться записи, которые упирались в ту же ветвь: печать
  `[bit;N] as u8`, сравнение перечисления с числом через приведение и прочее.
