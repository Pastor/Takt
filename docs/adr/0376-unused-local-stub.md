# ADR 0376: Неиспользуемая локальная переменная гасится заглушкой

- **Status:** Accepted
- **Date:** 2026-08-21
- **Authors:** Архитектор + лид разработки
- **Related issues:** [Фича 0376](../features/0376-unused-local-stub.md); связь
  с [ADR 0260](0260-c-unused-struct-parameter.md) и
  [ADR 0337](0337-unused-function-parameter.md) (идиомы заглушек),
  [ADR 0375](0375-sv-partial-struct-local.md) (поглотитель у `sv`)

## Context

Локальная переменная, объявленная и ни разу не использованная, ломает гейты
целей `c` (`-Wunused-variable`) и `rust` (`unused variable`) при нулевом коде
возврата `taktc`. Цели `st` и `sv` тот же вход принимают, эталон исполняет.

Класс — продолжение 0260/0337: там гасились **параметры**, здесь — **локальные
объявления тел**.

## Decision Drivers

1. **Вывод обязан собираться флагами гейта своей цели.**
2. **Отказывать нельзя:** запись законна и исполняется эталоном; у неё есть
   смысл (заготовка, отладка).
3. **Признак — один на цели, идиома — своя у каждой** (образец 0337).
4. **Ошибка признака не должна быть тихой.**

## Considered Options

### Option A. Заглушка по нужде, признак по семантическому дереву (принято)

`(void)x;` у `c`, `let _ = x;` у `rust` — печатаются в конце блока, где
переменная ещё в области видимости. Признак —
`generator::local_stub::unused_locals(block)`: имена объявлений верхнего уровня
блока, которых нет в `usage_from_stmt` этого блока.

**Pros:**
- Отвечает ровно на вопрос компилятора («имя нигде не используется»).
- Сборщик имён уже есть и открыт генератору (его зовёт цель `st`).
- Область видимости учитывается сама: вопрос задаётся блоку объявления.

**Cons:**
- Признак по дереву, а не по напечатанному тексту (0260/0337 делали иначе) —
  но там речь шла о параметре, чьё тело уже напечатано.

### Option B. Не печатать само объявление

**Cons:** инициализатор бывает с эффектом (вызов функции), и его потеря —
молчаливое изменение поведения. Ровно этот класс правила 0189 и 0306.

### Option C. Диагностика семантики (`SE-036` на локальные)

**Cons:** предупреждение автору полезно, но вывод целей оно не чинит — они
по-прежнему не собирались бы. Вынесено кандидатом отдельно.

### Option D. Отключить предупреждение флагом гейта

**Cons:** гейт перестал бы ловить настоящие находки (класс 0169: `lint_off`
гасит сторожа, а не причину).

## Decision

Принимается **Option A**. Заглушка печатается **в конце блока**: там переменная
ещё видима, а порядок операторов не меняется.

## Consequences

### Положительные

- Вывод `c` и `rust` собирается под флагами гейтов на записи, которую эталон
  исполняет.
- Признак общий, идиома — своя у каждой цели: то же устройство, что у 0337.

### Отрицательные / Action items

- Класс «локальная записана, но не прочитана» (`-Wunused-but-set-variable`)
  этой фичей не измерялся: признак считает запись использованием.
- `SE-036` локальные объявления по-прежнему не видит — вынесено кандидатом.

### Acceptance criteria

1. Вывод целей `c` и `rust` на входе с неиспользуемой локальной собирается
   флагами их гейтов.
2. Заглушка печатается только там, где переменная не используется
   (контрпример).
3. Вывод корпуса не изменился; предкоммит зелёный.
