# ADR 0297: Гейт живого контекста читает абзацы, а не строки

- **Status:** Accepted
- **Date:** 2026-08-20
- **Authors:** Архитектор + Аналитик
- **Related issues:** [Фича 0297](../features/0297-check-claude-md-line-blindness.md); [фикс 0202-01](../fixes/0202-01-stale-crate-version-in-context.md) (где слепота найдена), [фича 0149](../features/0149-claude-md-consistency-gate.md) (гейт), [фича 0289](../features/0289-claude-md-invariant-checklist-gate.md) (класс 5, чья находка обнажила бутафорию самопроверки), [фича 0160](../features/0160-takt-ebnf-sync.md) (тот же приём — разбор по абзацу)

## Context

`check-claude-md.py` искал совпадения **в строке**. Замер фикса 0202-01:
`check_crate_versions` требовал пару «имя крейта … `сейчас X.Y.Z`» в пределах
одной строки, а в `CLAUDE.md` она была перенесена — совпадения не возникало
**никогда**, и заявленная сверка версий не проверяла ничего. Тогда сняли
**факт** (запись свели в одну строку), а причина осталась: следующая правка
абзаца вернула бы перенос.

Тем же устройством страдали классы «путь» и «ссылка на номер строки»; класс
«статус фичи» лечился окном из пяти строк — то есть заплаткой.

## Decision Drivers

1. **Проверка, молча ничего не проверяющая, хуже отсутствующей:** она даёт
   уверенность.
2. **Перенос — норма для текста, а не исключение:** абзацы `CLAUDE.md`
   переформатируются постоянно.
3. **Приём уже есть в проекте:** гейт лексики (0160) читает **абзацы** ровно по
   этой причине.

## Considered Options

### Option A. Расширять окно строк

**Pros:** мелкая правка.
**Cons:** окно — это угадывание; класс 1 уже жил с окном в пять строк и всё
равно оставался хрупким.

### Option B. Сшивать абзацы

Текст делится по пустым строкам; поиск идёт по сшитому абзацу, номер берётся у
**первой** строки абзаца.

**Pros:** перенос перестаёт быть значимым; координата остаётся полезной.
**Cons:** находка указывает на начало абзаца, а не на точное место — приемлемо
для текста, который читают целиком.

## Decision

Принимается **Option B**: все четыре прежних класса и класс 5 переведены на
разбор по абзацам; самопроверка получила два случая с **переносом**.

**Здесь же исправлена бутафория самопроверки.** Проверка требовала «нашлось
хоть что-то», а класс 5 (фича 0289) даёт находку «раздел не найден» на **любом**
коротком образце — значит все случаи проходили независимо от своего класса.
Теперь у каждого случая своя **ожидаемая подстрока**.

## Consequences

### Положительные

- Сверка версий крейтов работает независимо от переноса — впервые с фикса
  0202-01.
- Самопроверка перестала быть бутафорской: мутация «вернуть построчный поиск»
  теперь ловится (проверено).

### Отрицательные / Action items

- **Граница названа:** перенос **внутри** одного токена в обратных кавычках
  (`` `takt-lang/src/` `` ↵ `` `mod.rs` ``) сшивкой не лечится — после склейки
  в пути появляется пробел. Случая на это в самопроверке нет намеренно: он
  утверждал бы то, чего гейт не делает.
- Координата находки указывает на **начало абзаца**.

### Acceptance criteria

1. Разорванная переносом запись версии ловится.
2. Мутация «построчный поиск» валит самопроверку.
3. Каждый случай самопроверки проверяет **свою** находку.
4. **Контроль:** законный текст находок не даёт.
5. `./scripts/precheck.sh` — код 0.
