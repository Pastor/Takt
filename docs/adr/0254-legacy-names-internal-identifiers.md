# ADR 0254: Старое имя изъято из служебных идентификаторов

- **Status:** Accepted
- **Date:** 2026-08-20
- **Authors:** Архитектор + Аналитик
- **Related issues:** [Фича 0254](../features/0254-legacy-names-internal-identifiers.md); [фича 0100](../features/0100-language-rename-takt.md) (переименование языка), [фича 0161](../features/0161-fixture-comments-rename.md) (гейт старых имён), [фича 0253](../features/0253-legacy-names-in-generated-code.md) (имена в порождаемом коде — соседняя половина класса)

## Context

Переименование `BuT` → `Lam` → `Takt` (фича 0100) прошло по видимым именам;
фича 0161 завела гейт, фича 0253 распространила его на **порождаемый** код
(хелперы `lam_q_*` → `takt_q_*`). Оставшаяся половина — **служебные
идентификаторы самих инструментов**: их не видит пользователь, и шаблонам гейта
они намеренно не отвечают (граница названа прямо в заголовке
`scripts/check-legacy-names.sh`).

**Замер 2026-08-20** (кандидат 2026-08-18 перепроверен, правило 30): в рабочих
файлах — **114** вхождений, и класс шире, чем перечислял кандидат:

| Вид | Вхождений | Где |
|---|---|---|
| `lam_file`, `LAMC` | 45 | `scripts/precheck.sh`, `scripts/run_simulations.sh` |
| `lam_*` в путях временных каталогов | ~46 | тесты обоих крейтов (`lam_conformance_*`, `lam_fmt_*`, `lam_deep_chain`, …) |
| `BUT_KEYWORDS`, `BUT_BUILTIN_TYPES` | 19 | `takt-lang/src/lsp/` и тесты LSP |
| `LAM_PROBE_OUT` | 1 | переменная окружения теста семантических токенов |
| `lam_q` в комментарии | 1 | `generator/rust/rust_expr.rs` — упоминание имени, переименованного фичей 0253 |

Кандидат называл `lam_generated`, `lam_file`, `LAMC` и `BUT_KEYWORDS`;
временные каталоги тестов и `LAM_PROBE_OUT` в его перечень не входили.

## Decision Drivers

1. **Переименование без гейта отрастает обратно** — доказано историей 0161 и
   0253: пока класс исключён, новое имя заводится по образцу соседа вместе со
   старым префиксом.
2. **Правка безрисковая**: идентификаторы внутренние, наблюдаемого поведения не
   меняют.
3. **Историю трогать нельзя** (правило 21): в `docs/`, `CHANGES.md` и в
   заголовках самих гейтов старое имя — свидетельство.

## Considered Options

### Option A. Только переименовать

**Pros:** минимум работы.
**Cons:** класс не сторожится; следующий временный каталог заведут по образцу
соседнего теста, и `lam_` вернётся. Ровно так он и дожил до сегодня.

### Option B. Переименовать и расширить гейт 0161 новым шаблоном

Шаблон ловит служебные префиксы (`lam_…`, `LAM_…`, `LAMC`, `BUT_…`) в рабочих
файлах; исключения остаются прежними — префиксами путей.

**Pros:** класс закрыт вместе с его возвратом; знание о запрещённых именах
остаётся в **одном** месте (заголовок гейта — единственный перечень, README его
намеренно не повторяет).
**Cons:** гейт становится строже к своим же историческим комментариям — их
приходится либо переписать, либо оставить в файлах-исключениях.

### Option C. Отдельный гейт служебных имён

**Pros:** независимость шаблонов.
**Cons:** два гейта об одном предмете; перечень запрещённых имён раздваивается —
класс 0084/0193/0195.

## Decision

Принимается **Option B**.

1. Переименование: `BUT_KEYWORDS` → `TAKT_KEYWORDS`, `BUT_BUILTIN_TYPES` →
   `TAKT_BUILTIN_TYPES`, `LAMC` → `TAKTC`, `lam_file` → `takt_file`,
   `LAM_PROBE_OUT` → `TAKT_PROBE_OUT`, префикс временных каталогов `lam_` →
   `takt_`, комментарий про `lam_q` — на действующее имя `takt_q`.
2. Шаблон гейта дополняется служебными префиксами; исключение
   `scripts/precheck.sh` **снимается** — он был исключён как «гейт, описывающий
   сам переезд», а на деле держал 16 живых вхождений `LAMC`.
3. Сторож `scripts/test-legacy-names.sh` получает проверку нового класса:
   мутация обязана ловиться, а действующее имя — приниматься.

## Consequences

### Положительные

- Старого имени в рабочих идентификаторах не остаётся, и возврат сторожится.
- Перечень запрещённых имён по-прежнему один — в заголовке гейта.

### Отрицательные / Action items

- Переменная окружения `LAM_PROBE_OUT` переименована: это **наблюдаемое** имя
  для того, кто гонял зонд вручную. Контракта на неё нет (упоминаний вне теста
  в дереве ноль), но имя меняется.
- Комментарии, где старое имя было свидетельством, переписаны на действующее
  там, где речь о **сегодняшнем** поведении, и оставлены там, где речь об
  истории переезда (файлы-исключения гейта).

### Acceptance criteria

1. В рабочих файлах нет `lam_*`, `LAM_*`, `LAMC`, `BUT_*` (кроме исключений).
2. Гейт ловит возврат каждого вида — доказано мутацией в стороже.
3. **Контроль:** действующие имена (`takt_*`, `TAKTC`) гейт не роняют.
4. `./scripts/precheck.sh` — код 0.
