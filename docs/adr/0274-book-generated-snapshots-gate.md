# ADR 0274: Снимки порождённого кода в book/ никем не сверяются

- **Status:** Accepted
- **Date:** 2026-08-19
- **Authors:** Архитектор + Аналитик
- **Related issues:** [Фича 0274](../features/0274-book-generated-snapshots-gate.md); [ADR 0048](0048-deterministic-codegen.md) (детерминированность — на ней стоит diff), [фича 0133](../features/0133-book-examples-gate.md) (гейт примеров документа), [фича 0193](../features/0193-shared-const-qualified.md) и [фича 0191](../features/0191-st-per-tick-conformance.md) (чьи правки снимки пропустили)

## Context

Приложение «Порождённый код примера» читает файлы
`book/src/**/generated/<цель>/…` **напрямую** (`read(...)` в Typst), то есть
показывает их читателю как настоящий вывод компилятора. Сверял их только
человек.

**Замер 2026-08-19** (пересборка всеми целями и `diff -r`): из шести каталогов
снимков **три отстали**, и каждый по существу:

| Снимок | Расхождение | Чья правка пропущена |
|---|---|---|
| `18-showcase/generated/rust` | `DWELL_TICKS` вместо `LIFT_DWELL_TICKS`; нет `assert!` инварианта | 0193, 0235 |
| `18-showcase/generated/sv` | `DWELL_TICKS` вместо `lift_DWELL_TICKS`; нет `assert (…)` | 0193, 0235 |
| `18-showcase/generated/st` | нет блока первого скана `IF state = 0` | 0191 |

Последнее особенно дорого: снимок описывал автомат, **сдвинутый на такт**, —
ровно тот дефект, который 0191 и устранила.

⚠️ Кандидат называл только цель `c` (её снимок правила фича 0213). Прогон
показал, что `c` и `c-hal` как раз совпадают: отстали три соседние цели,
которых не смотрел никто.

## Decision Drivers

1. **Документ обещает вывод инструмента.** Расхождение — не косметика: читатель
   копирует имена, которых компилятор не печатает.
2. **Класс невидим для человека.** Снимки правились дважды (0195, 0213) — и оба
   раза только та цель, которая была предметом фичи.
3. **Diff надёжен по построению:** генерация детерминирована (гейт 0048 стоит в
   том же предкоммите), значит расхождение всегда значимо.

## Considered Options

### Option A. Изъять снимки, оставив цитаты в тексте

**Pros:** нечему отставать.
**Cons:** приложение «Порождённый код примера» исчезает целиком — а это
единственное место, где читатель видит вывод **всех** целей на одной модели;
цитаты в тексте отстают ровно так же, но заметить труднее.

### Option B. Гейт: пересобрать и сравнить, падать на расхождении

**Pros:**
- Класс закрывается машиной, включая цели, о которых никто не помнит.
- Обновление снимков становится однокомандным (`--update`), то есть дешёвым.
- Отказ называет каталог и печатает начало diff — автору есть с чем работать.

**Cons:** ещё один шаг предкоммита (замер: около секунды на шесть целей).

### Option C. Генерировать снимки при сборке документа

**Pros:** снимок физически не может отстать.
**Cons:** сборка документа начинает требовать собранного компилятора и
воспроизводимой среды; `book/` перестаёт собираться отдельно. Кроме того,
дифф снимков в истории — полезное свидетельство (видно, как менялся вывод).

## Decision

Принимается **Option B**.

`scripts/check-book-generated.sh`: обходит все каталоги
`book/src/**/generated/<цель>`, находит соседний пример
(`../examples/<имя>.takt` по имени файла снимка), компилует его целью `<цель>`
во временный каталог и сравнивает `diff -r`. Частота такта берётся из
объявления `clock` примера — тем же приёмом, что у гейта примеров (иначе цель
`c` отвечает `SE-069`). Флаг `--update` пересобирает снимки на месте.

**Снимок без соседнего `examples/` — отказ**, а не пропуск: источник такого
файла неизвестен, сверить его не с чем, и молчание превратило бы гейт в
выборочный.

**Сторож** `scripts/test-book-generated.sh` (шаг предкоммита) гоняет гейт на
**копии** дерева (`BG_ROOT`) и мутацией доказывает: расхождение ловится и
называет каталог, `--update` восстанавливает согласие, снимок без примера
отвергается.

## Consequences

### Положительные

- Три отставших снимка обновлены; впредь отставание невозможно молча.
- Обновление снимков перестало быть ручной работой — одна команда.
- Приложение документа снова показывает то, что печатает инструмент.

### Отрицательные / Action items

- Предкоммит удлиняется на время шести компиляций (порядка секунды).
- Гейт опирается на соглашение об именах (`generated/<цель>/<имя>.<ext>` рядом
  с `examples/<имя>.takt`); файл, названный иначе, останется незамеченным —
  кроме случая «каталога `examples/` нет вовсе», который отвергается.

### Acceptance criteria

1. Гейт находит расхождение и называет каталог.
2. `--update` приводит дерево в согласие.
3. Снимок без соседнего примера отвергается.
4. Сторож доказывает всё перечисленное мутацией на копии дерева.
5. Все шесть снимков совпадают с выводом; `./scripts/precheck.sh` — код 0.
