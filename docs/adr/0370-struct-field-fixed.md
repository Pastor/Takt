# ADR 0370: Понижение q-литерала доходит до полей структуры

- **Status:** Accepted
- **Date:** 2026-08-21
- **Authors:** Архитектор + лид разработки
- **Related issues:** [Фича 0370](../features/0370-struct-field-fixed.md);
  связь с [ADR 0061](0061-fixed-point-type.md), [ADR 0096](0096-fixed-point-native-float.md)
  (понижение литерала), [ADR 0368](0368-aggregate-element-type.md) (тот же
  класс для элементов массива)

## Context

Понижение дробного литерала в q-представление живёт в свёртке инициализаторов
(`lower_folded_fixed`). Фича 0368 научила его массивам и **назвала границу**:
поля структуры остаются вне, потому что их объявление лежит в `ModelNode`.
Прогон 2026-08-21 показал, что за этой границей — не редкий случай, а вход,
который отвергают все восемь целей.

## Decision Drivers

1. **Скаляр, элемент массива и поле структуры обязаны отвечать одинаково.**
2. **Модель у слоя свёртки ЕСТЬ** — `fold_variable_initializers` принимает
   `&Rc<RefCell<ModelNode>>`; границу создавала сигнатура помощника, а не
   устройство.
3. **Правило округления — один носитель** (0061): своя копия разошлась бы.

## Considered Options

### Option A. Передать модель в `lower_folded_fixed` и понижать поля по их типам

**Pros:**
- Граница снимается там же, где была названа; рекурсия покрывает и массив
  структур (`[Gains; 2]`), потому что ветвь массива зовёт ту же функцию.
- Носитель округления прежний.

**Cons:**
- Помощник получает ещё один параметр.

### Option B. Понижать в целях

**Pros:** локально.

**Cons:** восемь копий правила округления — прямо против 0061.

### Option C. Отказ семантики на дробном литерале в поле `q`

**Pros:** громче молчания.

**Cons:** запись исполняет эталон, и она — обычный способ задать
коэффициенты (пример `pid_law` в корпусе).

## Decision

Принимается **Option A**: `lower_folded_fixed` принимает модель и понижает
элементы агрегата структуры по типам её полей (порядок — объявления, агрегат
позиционный по 0034); длину агрегата по-прежнему сверяет `SE-123`.

## Consequences

### Положительные

- Поле `q` и массив структур с полями `q` переводят все восемь целей.
- Граница, названная 0368, снята.

### Отрицательные / Action items

- **Найден соседний класс:** приведение `as` из **поля** структуры цель `c`
  печатает без деления на 2ⁿ (`(uint8_t)(g.kp + g.ki)` вместо
  `takt_q_floordiv(…)`), и значение расходится с эталоном молча — 0 против 4.
  Вынесено кандидатом; сверка этой фичи намеренно смотрит на q-значения, а не
  на результат приведения.

### Acceptance criteria

1. Инструменты всех целей принимают вывод на входах: поле `q`, массив структур
   с полями `q`.
2. Потактовая сверка с целью `c` совпадает по **представлениям**: `1.5` → 384,
   `1.0` → 256.
3. Мутация «не понижать поля структуры» роняет сверку.
4. Предкоммит зелёный; вывод корпуса не изменился.
