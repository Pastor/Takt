# ADR 0379: Сброс перечислимого регистра у цели sv

- **Status:** Accepted
- **Date:** 2026-08-22
- **Authors:** Архитектор + лид разработки
- **Related issues:** [Фича 0379](../features/0379-sv-enum-reset.md); связь с
  [ADR 0338](0338-enum-in-function.md) (вариант приходит печатнику числом),
  [ADR 0060](0060-enum-width-shared-layer.md) (факты перечисления),
  [ADR 0353](0353-c-default-init.md) (умолчание переменной)

## Context

`reset_value` печатала `'0` для любого регистра без инициализатора. Для
перечислимого типа verilator отвечает **ошибкой** `%Error-ENUMVALUE`, а гейт
цели считает предупреждение ошибкой. При этом `taktc` возвращает ноль, а
эталон, `c`, `st` и `rust` тот же вход исполняют.

Ветвь «есть инициализатор» была права с фичи 0338 (`enum_literal`
восстанавливает вариант по значению) — расходились именно две ветви одного
правила.

## Decision Drivers

1. **Вывод обязан проходить гейт своей цели.**
2. **Значение не должно измениться:** у эталона переменная без инициализатора
   равна нулю, и любое «удобное» умолчание — это молчаливое расхождение.
3. **Форма выбирается по наличию варианта**, а не по вкусу.

## Considered Options

### Option A. Ноль в форме, которую принимает тип (принято)

Мнемоника варианта со значением 0, если такой есть; иначе приведение
`<тип>'(0)`.

**Pros:**
- Значение то же, что у эталона, — сверка это доказывает.
- Обе формы приняты обоими инструментами (прогон 2026-08-22).
- Правило симметрично ветви «есть инициализатор» (0338).

**Cons:** приведение читается хуже мнемоники — но мнемоники для нуля в таком
перечислении не существует.

### Option B. Первый вариант перечисления

**Cons:** **меняет значение**. Мутация: `RTL=[[1, 0], …]` против
`sim=[[0, 0], …]`. Это ровно то расхождение, которое кандидат 0353 держит
как **вопрос заказчика** (эталон, `st`, `sv` и `c` дают ноль, `rust` — первый
вариант); решать его молча правкой одной цели нельзя.

### Option C. Отказ цели на перечислимом регистре без инициализатора

**Cons:** запись законна, исполняется эталоном и переводится четырьмя другими
целями; форма выразима.

## Decision

Принимается **Option A**: ветвь `ExpressionNode::None` в `sv_const::reset_value`
для `TypeNode::Enum` печатает `enum_literal(ty, 0, …)`, а при отсутствии
нулевого варианта — `<тип>'(0)`.

## Consequences

### Положительные

- Вывод цели проходит линт и синтез на перечислимом регистре и порте.
- Правило симметрично: обе ветви (`Number` и `None`) дают значение в форме,
  которую принимает тип.

### Отрицательные / Action items

- Расхождение «ноль против первого варианта» между эталоном и целью `rust`
  остаётся вопросом заказчика (кандидат 0353) — эта фича его не решает и не
  усугубляет.

### Acceptance criteria

1. `verilator --lint-only -Wall` принимает вывод; `yosys synth` — тоже.
2. Потактовая сверка: значение сброса — **ноль**, как у эталона.
3. Форма выбирается по наличию нулевого варианта (проверяется текстом).
4. Мутация «первый вариант» роняет сверку значений.
5. Вывод корпуса не изменился; предкоммит зелёный.
