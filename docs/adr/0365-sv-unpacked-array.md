# ADR 0365: Распакованный массив у цели sv — сброс и переменный индекс

- **Status:** Accepted
- **Date:** 2026-08-21
- **Authors:** Архитектор + лид разработки
- **Related issues:** [Фича 0365](../features/0365-sv-unpacked-array.md); связь с
  [ADR 0309](0309-sv-array-initializer.md) (агрегат массива),
  [ADR 0078](0078-bit-array-semantics.md) (упакованный бит-вектор),
  [ADR 0045](0045-sv-backend.md) (два инструмента SV)

## Context

Массив скаляров цель печатает **распакованным** (`logic [7:0] a [0:1]`) с фичи
0076, а его агрегатный инициализатор — с 0309. Две операции остались с формами
упакованного значения:

- **сброс без инициализатора** печатался `a <= '0;`;
- **переменный индекс** печатался полной шириной операнда.

Обе формы гейт цели отвергает, и обе воспроизводятся на одномерном массиве.
Корпус класс не покрывает: в `examples/` массивы объявлены с инициализатором и
индексируются переменной, ширина которой совпадает с требуемой.

## Decision Drivers

1. **Вывод обязан проходить гейт собственной цели.** Иначе `taktc` рапортует
   об успехе, а сборка у пользователя падает.
2. **Форму выбирают ОБА инструмента SV** (урок 0045/0235): `verilator` и
   `yosys` расходятся, и годна лишь форма, принятая обоими.
3. **Правило 0078 сильнее.** `[bit;N≤64]` — упакованный скаляр: у него сброс
   `'0` и индексация разряда законны, и трогать их нельзя.
4. **Приведение печатается по нужде** (класс 0263): лишнее сужение там, где
   предупреждения нет, — шум в выводе.

## Considered Options

### Option A. Сброс — `'{default: '0}`

**Pros:**
- Каноничная форма SystemVerilog, не зависящая от числа элементов.

**Cons:**
- **`yosys` её не принимает вовсе** — «syntax error, unexpected TOK_DEFAULT»
  (проба 2026-08-21). Форма, принятая одним инструментом, не годна.

### Option B. Сброс — агрегат нулей (`'{8'd0, 8'd0}`), индекс — сужение `W'(i)`

**Pros:**
- Агрегат — **та же** форма, которой печатается инициализатор (0309): оба
  инструмента её принимают (проверено прогоном).
- Сужение индекса снимает `WIDTHTRUNC` и печатается только когда ширина
  операнда заведомо больше требуемой.

**Cons:**
- Длина вывода растёт с числом элементов (агрегат перечисляет нули).
- Сужение меняет поведение на **невалидном** входе: индекс за границей
  массива усекается, вместо `X`. Эталон такой вход не исполняет (`SIM-010`),
  то есть случай за контрактом.

### Option C. Отказ цели на массиве без инициализатора

**Pros:**
- Громче молчания.

**Cons:**
- Вход исполняют четыре потребителя; отказ сузил бы цель без нужды.

## Decision

Принимается **Option B**. Оба правила живут в новом модуле
`generator/sv/sv_array.rs`:

- `reset_literal(ty)` — агрегат нулей для распакованного массива, рекурсивный
  для вложенного; `None` для бит-вектора и не-массива (там прежний путь);
- `index_text(base_ty, index_ty, printed)` — сужение `W'(…)`, где `W` —
  `ceil(log2(size))` (минимум 1); печатается **по нужде**.

⚠️ Печатников индексации у цели **три**: выражения, условия и **цель записи**.
Правка двух оставляла `WIDTHTRUNC` на записи, и сверка значений этого не
видела — тестбенч собирается с `-Wno-fatal`.

## Consequences

### Положительные

- Порождённый модуль проходит `verilator --lint-only -Wall` — те же флаги, что
  у гейта цели.
- Массив без инициализатора получает нули **явно**, как и у остальных целей
  (0353 у `c`, правила IEC у `st`).

### Отрицательные / Action items

- Индекс за границей массива усекается (прежде — `X`). Вход за контрактом:
  эталон отвечает `SIM-010`.
- Агрегат нулей длиннее `'0`; на больших массивах вывод растёт.

### Acceptance criteria

1. `verilator --lint-only -Wall` и `yosys synth` принимают вывод на входах:
   массив без инициализатора, переменный индекс (чтение и запись), вложенный
   массив.
2. Потактовая сверка значений совпадает; фикстура читает **нетронутый**
   элемент (проверка сброса) и пишет по переменному индексу.
3. Мутации (вернуть `'0`, снять сужение при чтении, снять при записи) роняют
   тесты.
4. Предкоммит зелёный; вывод корпуса не изменился.
