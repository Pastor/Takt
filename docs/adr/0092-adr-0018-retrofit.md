# ADR 0092: Ретроспективный ADR для 0018 — заводить ли

- **Status:** Accepted
- **Date:** 2026-07-23
- **Authors:** Архитектор + Системный аналитик
- **Related issues:** [Фича 0092](../features/0092-adr-0018-retrofit.md); касается
  [0018](../features/0018-code-guidelines.md) (нет ADR); упоминания —
  [ADR 0027](0027-module-size-split.md), [анализ 0027](../analyze/0027-module-size-split.md).

## Context

`docs/adr/0018-*` не существует: фича [0018](../features/0018-code-guidelines.md)
(«Приведение кода к требованиям `docs/CODE.md`» — рефакторинг под чек-лист Rust
Design Patterns) заводилась до того, как стадия 2 (ADR) стала оформляться.
Кандидат отмечал, что ссылки «по образцу 0018» **вводят в заблуждение** (читатель
идёт за несуществующим ADR).

**Проверка по коду (grep `ADR 0018`/`adr/0018`/`образцу 0018`):** живых вводящих
ссылок практически нет — оба реальных упоминания **уже уточнены**:

- `adr/0027-module-size-split.md`: «ADR у 0018 отсутствует … образцом структуры
  служит [ADR 0024]»;
- `analyze/0027-module-size-split.md`: «У фичи 0018 **нет ADR** … Образцом ADR
  взят 0024, образцом карточки/анализа — 0018».

**Ключевой факт:** реестр `docs/adr/README.md` требует ADR лишь у фич, **меняющих
архитектуру/синтаксис/семантику языка**. Фича 0018 — причёсывание кода под
`docs/CODE.md`; язык/архитектуру она **не меняет**, поэтому под требование ADR
**не подпадает**. То есть отсутствие у неё ADR — **норма по действующему
правилу**, а не долг.

## Decision Drivers

1. **Не плодить археологию.** Ретроспективный ADR постфактум реконструирует
   «решение» 0018 («применить `docs/CODE.md`») — очевидное и уже описанное в её
   анализе; риск выдумать несуществовавшую развилку.
2. **Согласованность с собственным правилом.** ADR — для меняющих язык/архитектуру
   (adr/README). 0018 не такова — заводить ей ADR значило бы противоречить правилу.
3. **Устранить именно боль:** вводящую ссылку, а не «пустоту ADR». Боль —
   «читатель идёт за несуществующим документом»; она уже снята уточнениями, надо
   лишь закрепить норму.

## Considered Options

### Option A. Завести ретроспективный ADR 0018

**Pros:** формально у 0018 появляется ADR; ссылки «по образцу» перестают вести в
пустоту.

**Cons:** археология (реконструкция решения постфактум, риск выдумки);
противоречит правилу «ADR — для меняющих язык/архитектуру»; 0018 таковой не
является; создаёт прецедент ретро-ADR для десятков до-процессных фич (0001–0017).

### Option B. Не заводить ADR; закрепить норму + выверить ссылки (принята)

Признать, что отсутствие ADR у 0018 законно (фича язык не меняет), закрепить это
в реестре ADR явной заметкой, и убедиться, что ни одна ссылка не ведёт к
несуществующему `adr/0018-*` как к образцу ADR (образец ADR — 0024).

**Pros:** честно (никакой выдумки); согласовано с правилом; дёшево; снимает
именно боль (вводящую ссылку); годится для всех до-процессных фич сразу.

**Cons:** у 0018 так и нет ADR — но это и есть корректное состояние.

## Decision

Принимается **Option B**: ретроспективный ADR 0018 **не заводится**. В реестр
`docs/adr/README.md` добавляется заметка: **до-процессные фичи (0001–0018) и
любые фичи, не меняющие архитектуру/синтаксис/семантику языка, ADR не имеют — это
норма, а не долг; ссылаться на такую фичу как на «образец ADR» нельзя (образец
ADR — [0024](0024-lam-formatter.md); образцом карточки/анализа 0018 служить
может).** Оставшиеся упоминания 0018 выверяются (уже уточнены в `adr/0027`/
`analyze/0027`). Язык/код не меняются.

## Consequences

### Положительные

- Норма зафиксирована один раз для **всех** до-процессных/не-архитектурных фич —
  вопрос «почему у XXXX нет ADR» закрыт системно.
- Никакой реконструкции-выдумки; согласовано с действующим правилом ADR.

### Отрицательные / Action items

- Заметка в `docs/adr/README.md` (разработка 0092-01).
- Финальный `grep` — ни одна ссылка не ведёт к `adr/0018-*` как к образцу ADR.

### Acceptance criteria

1. В `docs/adr/README.md` есть заметка-норма про фичи без ADR (0018 в т.ч.).
2. `grep -rn "adr/0018"` по `docs/` — нет ссылок на несуществующий файл как на
   образец ADR (упоминания «у 0018 нет ADR» — допустимы, они и фиксируют норму).
3. Ретроспективный ADR 0018 не создаётся (решение зафиксировано в этом ADR).
