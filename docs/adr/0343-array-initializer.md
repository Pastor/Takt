# ADR 0343: Инициализатор массива — потеря у `st`, невалидный вывод у `c` и `rust`

- **Статус:** Accepted
- **Дата:** 2026-08-20
- **Фича:** [../features/0343-array-initializer.md](../features/0343-array-initializer.md)

## Контекст

Замер 2026-08-20, два входа.

**Массив скаляров** (`var a: [u8;2] := {1, 2};`): цель `st` объявляла
`a : ARRAY [0..1] OF USINT;` — **без** `:=`. Прогон порождённого ST через
`iec2c` + `cc` дал `o = 0` против `3` у эталона: расходятся **значения**, при
нулевом коде возврата `taktc`.

**Массив структур** (`var cells: [Cell;2] := {{1, 2}, {3, 4}};`):

| Потребитель | Ответ |
|---|---|
| эталон, `sv`, `sv-mmio` | верно |
| **`c`, `c-hal`** | `model->cells[0] = {1, 2};` — `cc`: «expected expression» |
| **`rust`** | `[[1, 2], [3, 4]]` — `E0308` ×2 |
| **`st`, `st-at`** | инициализатор потерян молча |

## Решение

- **`st`, массив скаляров:** печатается `:= [1, 2]` — форма выбрана **пробой**
  `iec2c` (принимается).
- **`st`, массив структур:** агрегат такого типа `iec2c` не принимает ни в
  одном из трёх проверенных видов (`[(1, 2), …]`, `[(v := 1, …), …]`,
  `((v := 1, …), …)`), поэтому значения кладутся операторами **первого скана** —
  до входа в стартовое состояние, то есть до любого тела, которое их прочитает.
- **`c`:** элементы-структуры кладутся по полям (место выбирает носитель
  `generator::aggregate`, фича 0340).
- **`rust`:** элементы печатаются литералом структуры.

## Границы

- **Агрегат массива в аргументе ПАРАМЕТРА модели цель `st` по-прежнему
  отвергает** (`ST-017`). В объявлении переменной форма законна, а в
  инициализаторе экземпляра `FUNCTION_BLOCK` тот же массив даёт «Initialization
  element identifier … incompatible datatype». Первая редакция правки сняла
  отказ вместе с потерей и породила невалидный файл — поймал это тест фичи
  0209, «пришпиливающий» границы целей.

## Отвергнутые варианты

1. **Отказ `ST-011` на массив с инициализатором.** Форма выразима — отказ был
   бы регрессом.
2. **Инициализация массива структур одной формой.** Три пробы `iec2c` её не
   нашли.

## Последствия

- Вывод корпуса не изменился.
- Тест фичи 0210 (`shared_array_uses_a_named_type_on_both_sides`) обновлён:
  у переменной корня теперь печатается ещё и инициализатор.
