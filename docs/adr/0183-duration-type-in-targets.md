# ADR 0183: Тип `duration` в целях генерации и вычисляемая выдержка

- **Status:** Draft (стадия 2 не пройдена — фича только зарегистрирована)
- **Date:** 2026-07-29
- **Authors:** —
- **Related issues:** [Фича 0183](../features/0183-duration-type-in-targets.md);
  вскрыта при разработке [0143](../features/0143-after-const-duration.md); смежно
  с [ADR 0134](0134-language-time-model.md) (модель времени)

## Context

Тип `duration` **исполняется симулятором, но не поддерживается ни одной целью
генерации**. Проба 2026-07-29 (используемая переменная типа `duration`):

```
Ошибка компиляции [CC-020]: переменная 'left': тип 'duration' целью 'c' пока не поддерживается
Ошибка компиляции [RS-023]: переменная 'left': тип 'duration' целью 'rust' пока не поддерживается
```

Заглушки поставлены фичей 0134 **сознательно**: «молча напечатать наносекунды
обычным целым значило бы выдать выдержку, не равную заявленной». Отказ громкий.

Следствие, обнаруженное 0143: **вычисляемая выдержка** (`after (v + 1s)` со
значением, известным лишь в такте) невозможна — она была бы исполнима в отладке и
невыразима в прошивке. Поэтому 0143 ограничена константами (решение заказчика
2026-07-29), а этот разрыв закрывается здесь.

Что уже известно и не нужно решать заново:

- пересчёт «наносекунды → единицы профиля» написан **один раз**
  (`semantic::duration::units`) и годится для констант;
- у **константы** неделимость на период такта ловится `SE-063`; у значения,
  известного в такте, проверить нечего — правило округления придётся **назначить**;
- приведение `250 as duration` определено как «число — это миллисекунды»
  (раздел документа о типе `duration`), то есть единица перехода уже выбрана.

## Decision Drivers

1. **Симулятор и цели обязаны совпадать потактово.** Разрыв «в отладке работает,
   в прошивке нет» — худший из возможных для языка синтеза.
2. **Молчаливая неверность недопустима.** Округление, переполнение и ширина
   счётчика должны быть либо доказаны, либо диагностированы, а не «примерно
   верны».
3. **Прежний вывод не должен измениться** там, где `duration` не используется.

## Considered Options

Не проработаны — стадия 2 не пройдена. Направления, видимые сейчас:
целое фиксированной ширины в единицах профиля времени; хранение наносекунд с
делением в порождённом коде; ограничение типа только полями времени.

## Decision

Не принято — ADR заводится заготовкой вместе с регистрацией фичи, чтобы связь
«0143 → 0183» была прослеживаемой. Заполняется при взятии фичи в работу.

## Consequences

### Acceptance criteria

1. `var v: duration` компилируется всеми целями, и потактовая сверка с
   симулятором совпадает.
2. Правило округления при пересчёте назначено **нормативно** и проверено тестом.
3. `after` с переменной работает одинаково в симуляторе и во всех целях; снятие
   ограничения 0143 (`SE-072` о переменной) — осознанное, с правкой тестов.
