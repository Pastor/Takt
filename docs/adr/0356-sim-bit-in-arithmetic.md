# ADR 0356: Разряд — число 0/1; правило S8 остаётся в силе

- **Статус:** Accepted
- **Дата:** 2026-08-21
- **Фича:** [../features/0356-sim-bit-in-arithmetic.md](../features/0356-sim-bit-in-arithmetic.md)

## Контекст

Правило **S8** (решение фичи 0025): логическое значение не смешивается с числом
молча — `Boolean + Number` есть `TypeMismatch`. Правило разумное и снабжено
юнит-тестом.

Но доступ к разряду (`eval/access.rs::read_bit`) возвращал именно
`Value::Boolean`, и S8 бил по записям, которые все восемь целей переводят.
Замер 2026-08-21:

| Вход | эталон | цели |
|---|---|---|
| `arith := src.7 + 1;` | `SIM-005` **в такте** | считают (`c` → `((model->src >> 7) & 1ull) + 1` = 2) |
| `ref Done: src.7 = 1;` | `SIM-005` | переводят |
| `acc := src.7 + src.6;` | `SIM-005` | считают |

⚠️ **Контрольный вход показал внутреннее противоречие:** `bit`-**переменная** в
той же арифметике (`var f: bit := 1; arith := f + 1;`) эталоном исполнялась —
она хранится `Value::Number`. То есть у одного типа `bit` было два поведения,
и различал их источник значения, а не тип.

## Решение

**`read_bit` и `read_bit_words` возвращают `Value::Number` (0 либо 1).**

Тип `bit` в языке числоподобен: его значения — 0 и 1 (`validate_bit_values`),
и переменная этого типа хранится числом. Разряд числа есть значение того же
типа, поэтому и представление у него то же.

Правило S8 **не отменяется**: `Value::Boolean` приходит теперь только от
настоящих логических выражений — сравнения, `!`, логических связок, — и его
смешение с числом остаётся ошибкой. На это заведён контрпример рядом с
изменённым тестом.

Условия не затронуты: `to_bool` принимает число (`n != 0`), поэтому
`if src.7 { … }` работает как прежде.

## Отвергнутые варианты

**А. Разрешить `Boolean` быть числом в `as_num`.** Первая попытка фичи; она
**отменяет S8** для всех значений, а не для разряда — то есть `истина + 1`
стало бы законным везде. Отвергнуто собственным юнит-тестом правила: он упал
сразу, и это верное поведение сторожа.

**Б. Диагностика семантики: запретить разряд в арифметике** (привести цели к
эталону). Так предлагал кандидат. Отвергнуто замером: правило языка уже
определено `bit`-переменной, которую эталон считает, и восемью целями; запрет
сузил бы язык там, где согласие есть, и сделал бы `ref Done: src.7 = 1;`
незаконным — а это типичная запись автомата.

**В. Оставить как есть.** Означает, что типичная запись ребра не исполняется
эталоном, то есть модель нельзя проверить симуляцией перед синтезом — ровно
то, ради чего эталон существует.

## Последствия

- Записи, переводимые восемью целями, начинают исполняться эталоном.
- Значение разряда в трассах печатается числом (`1`/`0`), а не `true`/`false`.
- Язык не меняется (правило 22): версия не поднимается — правило `bit` было
  определено, менялось только внутреннее представление у эталона.
