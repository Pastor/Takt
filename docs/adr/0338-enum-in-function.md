# ADR 0338: Перечисление внутри функции у целей `st` и `sv`

- **Статус:** Accepted
- **Дата:** 2026-08-20
- **Фича:** [../features/0338-enum-in-function.md](../features/0338-enum-in-function.md)

## Контекст

Замер 2026-08-20 на `fn classify(k: u8) -> Mode { var res: Mode := Idle; … }`:

| Потребитель | Ответ |
|---|---|
| эталон, `c`, `c-hal`, `rust`, `plantuml` | верно |
| **`st`, `st-at`** | `iec2c`: «Ambiguous enumerate value or Variable not declared in this scope» |
| **`sv`, `sv-mmio`** | verilator: **`%Error-ENUMVALUE`** (неявное приведение к enum) |

Обе — при **нулевом** коде возврата `taktc` (класс 0262).

Корень один: **вариант перечисления приходит печатнику числом** — узла варианта
у `ExpressionNode` нет вовсе (та же ловушка описана для целей `rust` и `sv` в
`coerce_to`). Обе цели обошлись с ним по-своему неверно: `sv` напечатала число
(`res = 0;`), `st` напечатала имя константы, которая внутри `FUNCTION` не видна
— в IEC 61131-3 функция замкнута и видит только объявленное в ней самой.

⚠️ **Первый замер приписал отказ `sv` перечислению в ПАРАМЕТРЕ.** На деле там
сработал досрочный возврат (`SV-002`), запрещённый этой целью с 0045: проба
была негодной — посторонняя причина не снята (правило 30). Кандидат,
заведённый фичей 0336, оказался ошибочным и заменён этим замером.

## Решение

- **`sv`:** инициализатор локальной переменной печатается через `Scope::coerce`
  — ту же воронку, что и присваивание.
- **`st`:** константы перечислений, **упомянутые телом**, дублируются в
  `VAR CONSTANT` функции — тем же доводом, по которому фича 0030 дублирует туда
  константы модели.

Отбор у `st` идёт по **тексту** напечатанного тела: имя константы строит
печатник (`st_expr::coerce_to`), и второй способ узнать это имя разошёлся бы с
первым (класс 0084/0193/0195). Признак — тот же, что у заглушки параметра
(0260/0337).

## Границы

- **Дублируются упомянутые, а не все:** лишние объявления — шум в выводе,
  который читает наладчик ПЛК. Контрольная функция без перечисления проверяет
  это отдельно.
- **Границы идентификатора обязательны:** `Mode_Idle` — префикс
  `Mode_IdleLong`.

## Отвергнутые варианты

1. **Печатать число вместо имени константы у `st`.** Фичи 0066 и 0167 ушли от
   чисел к именам ради читаемости вывода; возврат был бы регрессом.
2. **Объявлять все константы всех перечислений в каждой функции.** Шум.
3. **Передавать константы параметрами.** Тот же довод, что у 0030: дублировать
   неизменное дешевле.

## Последствия

- Вывод корпуса не изменился.
- Сверка значений заведена для `st` (значение дублированной константы —
  содержательная величина).
