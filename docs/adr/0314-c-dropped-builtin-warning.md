# ADR 0314: Выброшенный вызов встроенной функции — предупреждение `CC-024`

- **Статус:** Accepted
- **Дата:** 2026-08-20
- **Фича:** [../features/0314-c-dropped-builtin-warning.md](../features/0314-c-dropped-builtin-warning.md)

## Контекст

Цель `c` не порождает кода для `debug(…)` и `S(…)` — решение фичи 0189: печать
из прошивки не подразумевается. Печатник операторов ловит отказ печати и
пропускает такой вызов.

Пропускал он его **молча**. Замер 2026-08-20 на `debug("такт");`:

| Потребитель | Ответ |
|---|---|
| эталон | печатает `debug: такт` каждый такт |
| **`c`, `c-hal`** | вызова в выводе нет вовсе — ни строки, ни комментария, ни предупреждения |
| `st`, `st-at` | `ST-011` |
| `rust` | `RS-011` |
| `sv`, `sv-mmio` | `SV-002` |

Три цели отвечают на один вход тремя разными способами, и молчаливая — худшая:
автор, отлаживший модель на симуляторе, не узнаёт, что в прошивке печати не
будет.

## Решение

**Предупреждение `CC-024`** на каждый выброшенный вызов. Поведение не меняется:
кода у этих функций нет и быть не должно.

Канал существует с фичи 0168 (`Generator::generate` возвращает
`Vec<Diagnostic>`) и был пуст — `CC-024` первое, что по нему поехало. Накопитель
живёт в карте `CMap`: печатники получают её по `&self` и доходят до каждого
оператора, поэтому `RefCell<Vec<Diagnostic>>` — заводить `&mut` через полтора
десятка сигнатур дороже пользы. Генерация однопоточна по построению.

## Отвергнутые варианты

1. **Отказ, как у `st` и `rust`.** Ломает корпус и отнимает у автора рабочий
   приём: отладить модель на симуляторе, собрать прошивку без печати.
2. **Печатать комментарий в выводе.** Комментарий читает тот, кто открыл
   порождённый файл; предупреждение видит тот, кто собирает.
3. **Одно предупреждение на модель.** Второй выброшенный вызов терялся бы —
   тот же класс, ради которого фича и делалась (счёт сторожит тест, как у
   `ST-022` в 0235).

## Последствия

- `--quiet` глушит `CC-024` вместе с прочими предупреждениями — это свойство
  канала 0168, ради которого печать и была из целей изъята.
- Вывод цели не изменился: сторож проверяет и это.
