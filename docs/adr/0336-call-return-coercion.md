# ADR 0336: Приведение к типу приёмника в аргументе и возврате функции

- **Статус:** Accepted
- **Дата:** 2026-08-20
- **Фича:** [../features/0336-call-return-coercion.md](../features/0336-call-return-coercion.md)

## Контекст

Фича 0335 научила приведению к типу приёмника **присваивание**. Замер
2026-08-20 показал, что позиций приёмника **три**, и о двух остальных не знала
ни одна цель.

| Вход | `rust` | `st` | `sv` |
|---|---|---|---|
| `take(src.7)` | `E0308` | `iec2c`: Data type incompatibility … position 1 | `WIDTHEXPAND` (FUNCREF) |
| `fn give(…) -> u8 { return x.7; }` | `E0308` | `iec2c`: Incompatible data types for ':=' | `WIDTHEXPAND` (ASSIGN) |
| `flag(1)` при `fn flag(b: bit)` | `E0308` | — | — |
| `fn ret_bit() -> bit { return 1; }` | `E0308` | — | — |
| `pick(Busy)` при `fn pick(m: Mode)` | `E0308` | — | — |

Эталон все пять записей исполняет, цель `c` переводит верно (там перечисление и
`bit` — целые). Все отказы приходят от **чужого** инструмента при **нулевом**
коде возврата `taktc` — класс 0262, 0287.

## Решение

Приведение применяется в **обеих** новых позициях у всех трёх целей:

- **аргумент вызова** — по типу параметра из `FunctionDefinitionNode::Local`;
- **возврат** — по типу возврата функции, чьё тело печатается.

Тип возврата пробрасывается контекстом печати: поле `return_type` в `Scope`
у `rust`, `function_ret` у `sv`, расширенный `FnContext` (имя POU **и** тип) у
`st`. Внешняя функция типов параметров не объявляет — там печать прежняя.

## Границы

- **У цели `rust` путей печати возврата ДВА:** `return x;` и хвостовое
  выражение (`needless_return` под `-D warnings` требует второго). Правило
  стоит в обоих — первая редакция поставила его в один, и `rustc` поймал это
  сразу: правило действовало бы через раз, в зависимости от того, последний ли
  это оператор тела.
- **Перечисление в параметре функции цель `sv` не переводит вовсе** (`SV-002`)
  — соседний класс, вынесен кандидатом.
- **Неиспользуемый параметр функции** даёт у `rust` `unused_variables`, то есть
  отказ под `-D warnings` — тоже соседний класс (у цели `c` он закрыт фичей
  0260), вынесен кандидатом.

## Отвергнутые варианты

1. **Приводить только разряд.** Замер нашёл ещё три формы (литерал `bit`,
   вариант перечисления, возврат `bit`) — правило одно, а форм много.
2. **Искать функцию по имени внутри ветви `Return`.** У `st` имя POU уже несёт
   префикс модели; обратный поиск завёл бы второе знание об имени.

## Последствия

- Вывод корпуса не изменился.
- Сверка значений заведена для цели `rust` (четыре величины, включая
  контрольную).
