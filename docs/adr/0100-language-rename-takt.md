# ADR 0100: Переименование языка Lam → Takt

- **Status:** Accepted
- **Date:** 2026-07-24
- **Authors:** Архитектор (+ решения заказчика по развилкам)
- **Related issues:** [Фича 0100](../features/0100-language-rename-takt.md); затрагивает
  инварианты ADR 0085 (константа версии языка), ADR 0043 (`bin/lamc` пришпилен к
  baseline размера), процессные гейты `precheck.sh`/CI.

## Context

Проект переименовывает язык **Lam** (Language of Automata Models) в **Takt**
(бэкроним — **T**yped, **A**utomata, **K**nown **T**iming). Это смена
**идентичности**, а не синтаксиса/семантики: ключевые слова, грамматика
(`grammar.lalrpop`), семантические проходы и генераторы кода **не меняются** —
меняются только имена, расширение файлов и тексты.

Текущее состояние (метрики 2026-07-24): язык зовётся `Lam`, расширение `.lam`
(**244** файла), компилятор `lamc`, LSP `lam-lsp`, крейты `grammar` и
`simulation`, плагин IntelliJ `extensions/intellij-lam/` (пакет `org/lam`, классы
`Lam*`), грамматика `Lam.ebnf`. Слово `Lam` встречается в **~324** трекнутых
файлах, токены `.lam`/`lamc`/`lam-lsp` — в **~414**.

> **Правило 18 (диаграмма PlantUML) неприменимо:** ADR **не** меняет синтаксис,
> семантику языка и потоки данных между компонентами — только имена и тексты.
> Конвейер компиляции (`.takt` → лексер → LALRPOP → AST → семантика → генераторы)
> структурно тождествен прежнему. Схема не требуется.

## Decision Drivers

1. **Единый источник идентичности.** После ренейма не должно остаться двух имён
   языка (дрейф «Lam в коде, Takt в доке» — тот же класс проблемы, что 0085
   закрыла для версии). Ренейм — сквозной или его нет.
2. **Обратная совместимость (правило 11).** Смена расширения и имён бинарников/
   крейтов **ломает** пользовательские сборки и скрипты. Проект **до 1.0**,
   гарантированных внешних потребителей нет — цена разрыва мала, цена
   половинчатой миграции (два расширения навсегда) велика.
3. **Прослеживаемость и зелёные гейты.** Каждый слой ренейма оставляет
   `precheck.sh` зелёным (сборка/тесты/детерминизм/размер модулей/версия-якорь).
4. **Управляемость диффа.** ~324 файла — механическая правка; нужна декомпозиция
   по слоям (правило 2), а не один гигантский коммит.

## Considered Options

### Option A. Сквозной жёсткий ренейм (полный)

Переименовать **всё**: расширение `.lam`→`.takt` (только `.takt` принимается),
бинарники `lamc`→`taktc`/`lam-lsp`→`takt-lsp`, крейты `grammar`→`takt-lang` и
`simulation`→`takt-sim` **вместе с путями импорта** (`grammar::`→`takt_lang::`),
идентификаторы кода, плагин, EBNF, все примеры и документацию. Версия языка
`0.4.0`→`0.5.0` (тег `v0.5.0`).

**Pros:**
- Единая идентичность, ноль остаточного `Lam`; крейт `takt-lang` реально
  появляется (требование заказчика).
- Чистая история: после закрытия слово `Lam` остаётся только в архивных
  артефактах стадий (карточки закрытых фич — исторический контекст).

**Cons:**
- Крупнейший дифф проекта; правка путей импорта — сотни мест.
- Снапшоты `examples/generated/` **законно** меняются (`#include "X.h"` при смене
  имён примеров) — нужна согласованная пересборка эталонов.

### Option B. Ренейм с `.lam`-алиасом (мягкая миграция)

Как A, но компилятор/LSP/симулятор продолжают принимать `.lam` наравне с `.takt`
на переходный период.

**Pros:**
- Не ломает существующие пользовательские файлы разом.

**Cons:**
- Два расширения — источник дрейфа (драйвер 1); тесты/примеры двоятся или
  фиксируют старое имя. Для до-1.0-проекта без внешних потребителей цена
  совместимости не оправдана.

### Option C. Только внешние имена (минимальный churn)

Переименовать бинарники (`taktc`/`takt-lsp`) и расширение, но **оставить**
внутренние имена крейтов `grammar`/`simulation` и пути импорта.

**Pros:**
- Минимальный дифф; пути импорта не трогаются.

**Cons:**
- Крейт `takt-lang` **не появляется** (прямо противоречит запросу заказчика);
  внутри код остаётся «Lam-проектом». Идентичность половинчата.

## Decision

Принимается **Option A** (сквозной жёсткий ренейм) — по решениям заказчика от
2026-07-24:

- **Расширение:** жёсткий разрыв — принимается **только `.takt`**; все 244 файла
  переименованы, `.lam` больше не распознаётся (драйвер 2, до-1.0).
- **Крейты и импорты:** полный ренейм — `grammar`→`takt-lang`, `simulation`→
  `takt-sim`, **все пути импорта обновляются** (`grammar::`→`takt_lang::`,
  `simulation::`→`takt_sim::`). Имя пакета крейта = `takt-lang`/`takt-sim`, имя
  для `use` = `takt_lang`/`takt_sim` (Rust заменяет `-`→`_`).
- **Бинарники:** `lamc`→`taktc` (`bin/lamc.rs`→`bin/taktc.rs`), `lam-lsp`→
  `takt-lsp` (`bin/lam_lsp.rs`→`bin/takt_lsp.rs`).
- **Плагин IntelliJ:** `extensions/intellij-lam`→`intellij-takt`, пакет
  `org/lam`→`org/takt`, классы `Lam*`→`Takt*`, `LamFileType` распознаёт `.takt`.
- **Грамматика EBNF:** `Lam.ebnf`→`Takt.ebnf`.
- **Версия языка:** `0.4.0`→`0.5.0`, коммит подъёма помечается тегом `v0.5.0`
  (правило 22): ренейм — изменение, связанное с языком (новая идентичность и
  расширение), хотя ключевые слова/семантика неизменны.
- **Бэкроним:** официально — **Typed, Automata, Known Timing**.

**Вне кода (отметить, не выполнять в рамках фичи):** переезд репозитория
`github.com/Pastor/BuT` и имена релизных артефактов CI — решение заказчика позднее;
константа/URL репозитория в коде правится, сам переезд — административный.

## Consequences

### Положительные

- Единая идентичность **Takt** во всём проекте; крейт `takt-lang` появляется.
- `check-language-version.sh` (0085) остаётся источником истины версии; ренейм
  синхронно правит контекст `LANGUAGE_VERSION` и якорь README.
- Детерминизм-гейт продолжает охранять вывод: после законной пересборки снапшотов
  `examples/generated/` дифф снова становится нулевым.

### Отрицательные / Action items

- **Крупный дифф**, декомпозируется анализом на подзадачи `0100-YY` по слоям;
  каждый слой — зелёный `precheck.sh`.
- **Снапшоты `examples/generated/` меняются законно** — пересобрать эталоны в том
  же коммите, где переименованы примеры; детерминизм-гейт подтвердит стабильность.
- **Пути импорта** (`grammar::`) — массовая механическая правка; риск — пропуск в
  файле под фичей `lsp` (ловит только `--all-features`, т.е. `precheck.sh`).
- **`bin/lamc.rs` пришпилен к baseline размера** (реестр `module-size-baseline.txt`
  — запись `grammar/src/bin/lamc.rs`): при переименовании файла запись реестра
  обязана переехать на путь нового крейта/бинарника (иначе гейт размера покраснеет
  на «новом нарушителе»). То же — все пути в реестре с `grammar/`/`simulation/`.
- **Внешний URL/имя репозитория** в текстах правится, но фактический переезд —
  вне фичи.

### Acceptance criteria

1. `git grep -nw Lam` и `git grep -n '\.lam\b\|lamc\|lam-lsp\|lam_lsp'` по коду,
   скриптам, примерам и **активной** документации дают **0** (архивные карточки
   закрытых фич — исторический контекст, из проверки исключены явным списком).
2. Сборка `cargo build --bin taktc` и `--features lsp --bin takt-lsp` — успешна;
   старые имена `lamc`/`lam-lsp` не существуют.
3. Крейты называются `takt-lang`/`takt-sim`; `cargo test` зелёный, пути импорта
   обновлены.
4. `examples/*.takt` (244), `.lam` в дереве **отсутствует**; `run_simulations.sh`
   и все скрипты работают на `.takt`.
5. `precheck.sh` зелёный (в т.ч. `check-module-size.sh` с переехавшими путями,
   `check-language-version.sh` на `0.5.0`, детерминизм на пересобранных
   снапшотах, `check-links.py`).
6. Версия языка `0.5.0`, коммит подъёма помечен тегом `v0.5.0`.
7. Плагин IntelliJ собирается (`./gradlew --offline test`) под именем Takt,
   распознаёт `.takt`.
