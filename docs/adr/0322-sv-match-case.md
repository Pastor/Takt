# ADR 0322: `match` цели `sv` — это `case`

- **Статус:** Accepted
- **Дата:** 2026-08-20
- **Фича:** [../features/0322-sv-match-case.md](../features/0322-sv-match-case.md)

## Контекст

Цель `sv` отвергала оператор `match` (`SV-002` с текстом «оператор match»), при
том что в SystemVerilog есть его прямой аналог — `case`.

### Замер (2026-08-20)

Вход: `match mode { Idle => …, Run => …, Stop => … }`.

| Потребитель | Ответ |
|---|---|
| эталон, `c`, `c-hal`, `st`, `st-at`, `rust`, `plantuml` | исполняют/переводят |
| **`sv`, `sv-mmio`** | **`SV-002`** |

Отказ был **пробелом**, а не решением: текст не называл причины, по которой
конструкция невыразима, — потому что её нет.

## Решение

Печать `case (выражение) … endcase`; несколько образцов ветки печатаются через
запятую (`0, 1: begin … end`), `_` даёт `default`.

**Ветвь `default` печатается всегда.** `case` без неё в `always_comb` оставляет
сигнал без значения на непокрытом входе, и синтезатор выводит **защёлку** —
молча. Когда автор `default` не написал, печатается пустая ветвь: сигналы уже
получили значение умолчанием `name_next = name` в начале блока.

`hoist_locals` спускается в тела веток — иначе объявление внутри ветки
ссылалось бы на необъявленное имя (тот же класс, что у цикла в 0321).

## Отвергнутые варианты

1. **`unique case`.** Обещает синтезатору полноту, которой у `match` в Takt
   нет: `_` не обязателен, а перечисление может не покрывать все значения.
2. **Печатать без `default`, полагаясь на умолчание блока.** Умолчание есть, но
   `case` без `default` — известный источник защёлок; полагаться на то, что
   синтезатор «догадается», значит проверять удачу.

## Последствия

- `match` переводят все восемь целей.
- Сверка потактовая: наблюдаемая меняется **по веткам**, поэтому выбор не той
  ветки виден значением, а не структурой вывода.
