# ADR 0179: Один адрес репозитория и гейт его единственности

- **Status:** Accepted
- **Date:** 2026-07-29
- **Authors:** Архитектор + системный аналитик
- **Related issues:** [Фича 0179](../features/0179-repo-url-cleanup.md); связь с [ADR 0100](0100-language-rename-takt.md) (переезд вынесен за её объём) и [ADR 0085](0085-language-version-constant.md) (тот же приём: правило, которое нельзя проверить командой, — не правило)

## Context

Репозиторий переехал: `origin` → `https://github.com/Pastor/Takt.git`. Старое
имя осталось **в 16 живых местах** (13 в форме URL + 3 в форме голого `BuT`).

Замер 2026-07-29 (греп + сетевая проба):

| Категория | Места | Последствие |
|---|---|---|
| Метаданные крейтов | `takt-lang/Cargo.toml:7`, `takt-sim/Cargo.toml:7` | уйдёт в crates.io при публикации |
| Инструкция пользователю | `README.md:2075` (`git clone …/BuT.git`), `README.md:2076` (`cd BuT`) | **вторая строка ломается независимо от редиректа**: клон нового URL создаёт каталог `Takt` |
| Дерево проекта в README | `README.md:2277` (`BuT/`) | читатель видит несуществующее имя корня |
| Doc-ссылки исходников | `lib.rs:431, 501, 502`, `diagnostics/mod.rs:463` | ссылки в `cargo doc` |
| Манифест плагина IntelliJ | `plugin.xml:4` (`<vendor url>`) | попадает в **установленный** плагин |
| Манифест плагина Zed | `extension.toml:7`, `install.sh:93` | `install.sh` пишет URL **в `index.json` Zed** — проверено установкой |

**Ничего не сломано сегодня — работает редирект.** Проба:
`GET https://github.com/Pastor/BuT` → **HTTP 301** на `…/Pastor/Takt`;
`git ls-remote https://github.com/Pastor/BuT.git HEAD` отдаёт коммит. Класс
проблемы — **не отказ, а скрытая зависимость** от чужой инфраструктуры плюс
дезинформация читателя.

⚠️ **Исключение из «ничего не сломано» — `cd BuT`.** Эта строка от редиректа не
зависит: `git clone https://github.com/Pastor/Takt.git` создаёт каталог `Takt`,
и следующая строка инструкции **уже не работает**. Голое `BuT` в реестре
карточки (13 вхождений URL) учтено не было — вскрыто при проработке.

## Decision Drivers

1. **Молчаливая зависимость.** Редирект GitHub исчезнет, если под `Pastor`
   появится новый репозиторий с именем `BuT`. Событие маловероятное, но
   последствие — отказ клонирования по всем инструкциям сразу.
2. **Дезинформация дороже отказа.** Отказ виден; неверное имя в README читатель
   принимает за истину и повторяет.
3. **Прецедент ADR 0085.** Разовая правка дока без гейта уже приводила к
   рассинхрону (версия языка `0.3.0` против `0.4.0` — дожило незамеченным).
   «Правило, которое нельзя проверить командой, — не правило.»
4. **Артефакты стадий — история.** Правило 21 запрещает переписывать задним
   числом принятые решения; упоминания старого адреса в артефактах 0100 —
   свидетельства, а не ошибки.

## Considered Options

### Option A. Разовая правка, без гейта

**Pros:**
- Минимальный объём; переезд — разовое событие, второй раз может не случиться.

**Cons:**
- Ничем не защищено: скопированный старый сниппет вернёт `Pastor/BuT`, и это
  снова никто не заметит.
- Ровно тот сценарий, из-за которого заведён гейт версии языка (ADR 0085).

### Option B. Правка + гейт «адрес репозитория в дереве один»

Скрипт `scripts/check-repo-url.sh` в `precheck.sh`: все вхождения
`github.com/Pastor/<имя>` вне списка исторических артефактов обязаны называть
**одно и то же** имя.

**Pros:**
- Защищает не от «имени `BuT`», а от **рассогласования вообще** — переживёт
  следующий переезд без правки скрипта.
- Дёшев (POSIX sh, греп), образец рядом — `check-language-version.sh`.
- Ловит и голое `cd BuT`, если добавить второй якорь.

**Cons:**
- Список исторических исключений придётся сопровождать: артефакты новых фич,
  цитирующие старый адрес, будут валить гейт.
- Проверяет согласованность, но не **правильность**: если все места разом
  назвать неверным именем, гейт промолчит.

### Option C. Единый источник — URL в одном месте, остальные подставляются

**Pros:**
- Рассинхрон невозможен по построению (сильнейшая гарантия).

**Cons:**
- Форматы несводимы: `Cargo.toml`, `plugin.xml`, `extension.toml`, Markdown и
  doc-комментарии Rust не имеют общего механизма подстановки.
- Пришлось бы завести шаг генерации файлов — цена несоизмерима с задачей.

## Decision

Принимается **Option B**.

Драйвер 3 решает спор между A и B: проект уже платил за «разовую правку без
гейта» рассинхроном версии языка. Option C отвергнут как несоизмеримый —
подстановка в пять разных форматов дороже проблемы.

**Нормативные правила решения:**

1. **Адрес репозитория в дереве один.** Все вхождения `github.com/Pastor/<имя>`
   вне явного списка исторических артефактов обязаны называть одно имя. Проверка
   — `scripts/check-repo-url.sh` в `precheck.sh`.
2. **Гейт проверяет согласованность, а не имя.** Имя не зашивается в скрипт: он
   берёт эталон из **манифеста** `takt-lang/Cargo.toml` (поле `repository`) и
   требует, чтобы остальные совпали. Так следующий переезд потребует правки
   файлов, а не гейта.
3. **Исторические артефакты исключаются явным списком путей**, а не «по
   умолчанию». Каждое исключение — решение, а не умолчание (тот же принцип, что
   в правиле 1 ADR 0178 о явной ветке пунктуации).
4. **Голое имя каталога — отдельная проверка.** `cd BuT` не содержит URL и под
   правило 1 не подпадает; в README оно правится, а гейт получает второй якорь:
   имя каталога в `cd` рядом с `git clone` обязано совпадать с последним
   компонентом URL.

## Consequences

### Положительные

- Инструкция `git clone` + `cd` снова работает целиком (сегодня вторая строка
  сломана).
- Метаданные крейтов и обоих плагинов называют существующий адрес.
- Следующий переезд ловится машиной на первом же несогласованном файле.

### Отрицательные / Action items

- **A-1.** Список исторических исключений — точка сопровождения. Артефакт новой
  фичи, цитирующий старый адрес, завалит гейт; лечится добавлением пути в
  список **с обоснованием**. Рост списка — сигнал ревью.
- **A-2.** Гейт проверяет согласованность, но не правильность. Это принято
  сознательно: правильность адреса — знание вне репозитория, и машинно её не
  установить, не ходя в сеть, а предкоммит обязан работать офлайн.
- **A-3.** **Установленные плагины правкой исходников не обновляются:** старый
  URL уже лежит в дистрибутиве RustRover и в `index.json` Zed. После правки
  требуется переустановка — это часть приёмки, а не побочная рекомендация.
- **A-4.** `docs/DIFF.md`, `docs/analyze/0018`, `docs/analyze/0030` упоминают
  `BuT` как **историю языка и путей**, а не как адрес репозитория. Под правило 1
  не подпадают (там нет `github.com/Pastor/`) и не трогаются.

### Acceptance criteria

1. В дереве вне исторических артефактов нет `github.com/Pastor/BuT`.
2. `README.md`: `git clone` и следующий за ним `cd` согласованы; дерево проекта
   называет корень `Takt/`.
3. `scripts/check-repo-url.sh` существует, вызывается из `precheck.sh` и
   **валит** предкоммит при рассогласовании (проверяется мутацией).
4. Гейт **не** зашивает имя `Takt`: подмена имени во **всех** файлах разом
   оставляет его зелёным (проверяется мутацией — это и есть граница A-2).
5. Оба плагина пересобраны и переустановлены; в установленных артефактах старого
   URL нет.
6. Поведение инструментов не изменено: правки — метаданные, тексты и
   doc-комментарии.
