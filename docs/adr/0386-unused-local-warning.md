# ADR 0386: `SE-036` видит локальные объявления тел

- **Status:** Accepted
- **Date:** 2026-08-22
- **Authors:** Архитектор + Аналитик
- **Related issues:** [Фича 0386](../features/0386-unused-local-warning.md);
  опирается на [0376](0376-unused-local-stub.md) (признак) и
  [0264](0264-body-judge-usage-position.md) (позиция судей тела)

## Context

`SE-036` проверяло объявления **модели**. Локальная переменная тела, ни разу не
использованная, не замечалась никем: замер 2026-08-22 —
`always { var spare: u8 := n + 5; … }`, код возврата `taktc` нулевой, ни одного
сообщения. При этом вывод целей `c` и `rust` (где такая переменная — отказ под
`-Wall -Werror` / `-D warnings`) спасает заглушка 0376, то есть инструмент
**молча правит за автора**.

Признак «локальная не используется» уже был (`unused_locals`, 0376) — не
хватало двух вещей:

1. **места вызова** в семантике;
2. **координаты**: `StatementNode::Variable` позиции не нёс вовсе, а
   предупреждение без координаты пришлось бы печатать с `1:1` — ложью, а не
   отсутствием (класс 0264).

## Decision Drivers

1. **Молчание хуже шума ровно настолько, насколько предупреждение точно.**
   Признак 0376 консервативен (запись считается использованием), поэтому
   срабатывание редко и по делу.
2. **Знание одно.** Что считать использованием, решает `usage_from_stmt`;
   второго обхода заводить нельзя.
3. **Координата — часть предмета** (правило 0130 + класс 0264).
4. **Направление зависимостей.** Признак жил в `generator/`; семантика,
   зовущая генератор, — неверное направление (урок 0384).

## Considered Options

### Option A. Печатать предупреждение с координатой блока

**Pros:** узел не меняется, правка мала.
**Cons:** координата указывает на строку `always {`, а не на объявление —
верная, но чужая строка; ровно то, что 0264 назвала худшим случаем.

### Option B. Добавить позицию узлу `StatementNode::Variable`

**Pros:**
- предупреждение указывает на объявление;
- снимается граница, названная 0264 («инициализатор локального объявления
  опирается на прежний вывод позиции»);
- компилятор проводит по всем потребителям узла (`E0023`), молча не уедет.

**Cons:** 28 мест правки в двух крейтах (механические: дописать поле в
паттерн).

### Option C. Оставить как есть

**Cons:** автор не узнаёт о мёртвом объявлении ниоткуда, а вывод целей
чинится за него.

## Decision

Принимается **Option B**.

`StatementNode::Variable` получает четвёртым полем `Location`; позиция берётся
у `ast::Statement::Variable` при понижении. Признак переезжает в
`semantic::unused::unused_locals_of_block` (возвращает имя **и** позицию), а
`generator::local_stub::unused_locals` становится обёрткой над ним — идиома
заглушки остаётся у целей, знание одно.

Проверка спускается по телам: блоки **модели**, блоки **состояний**, тела
**функций**, и рекурсивно во вложенные блоки (`if`, `else`, циклы, ветви
`match`).

⚠️ **Область видимости соблюдается по построению:** вопрос задаётся тому блоку,
где имя объявлено, — как это делает компилятор целевого языка.

## Consequences

### Положительные

- Автор узнаёт о мёртвом локальном объявлении от `taktc` и в редакторе
  (предупреждение идёт через общую точку `collect_model_warnings`, 0081/0232).
- Снята граница 0264: у локального объявления теперь есть своя позиция.

### Отрицательные / Action items

- Узел стал четырёхместным — 28 мест правки (сделаны; компилятор их и назвал).
- Возможен шум на «заготовках» автора; замер по корпусу показал **ноль** новых
  предупреждений (единственное существующее — `var action` уровня модели в
  `elevator.takt`, оно было и раньше).

### Acceptance criteria

1. Неиспользуемая локальная даёт `SE-036` с координатой **объявления**.
2. Используемая — не даёт.
3. Проверяются тела модели, состояний и функций, включая вложенные блоки;
   мутация каждого из трёх мест обхода роняет сторожа.
4. Использование во вложенном блоке считается законным.
5. Корпус не даёт новых предупреждений; `precheck.sh` зелёный.
