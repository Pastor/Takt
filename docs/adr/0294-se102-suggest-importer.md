# ADR 0294: `SE-102` называет файл, подключающий библиотеку

- **Status:** Accepted
- **Date:** 2026-08-20
- **Authors:** Архитектор + Аналитик
- **Related issues:** [Фича 0294](../features/0294-se102-suggest-importer.md); [фикс 0182-02](../fixes/0182-02-library-file-without-start.md) (где `SE-102` заведена), [фича 0279](../features/0279-qualified-import-model-reference.md) (образец: диагностика получает подсказку), [ADR 0153](0153-lsp-workspace-index.md) (граница «полнота в пределах области»), [фича 0243](../features/0243-type-redefinition-diagnostic.md) (координата чужого файла не печатается)

## Context

Библиотека — файл без единого состояния — входом исполнения быть не может, и
`SE-102` говорит об этом с фикса 0182-02. Причина названа, обходной путь
назван («скомпилируйте файл, который её импортирует»), но **найти** этот файл
автор должен сам.

**Замер 2026-08-20** — прогон на трёх файлах в каталоге (`helper.takt` —
библиотека, `app.takt` — импортёр, `other.takt` — посторонний автомат):

```
helper.takt:1:1: Ошибка компиляции [SE-102]: файл не содержит ни одного
состояния: … Скомпилируйте (или подайте симулятору) файл, который её
импортирует, либо добавьте сюда стартовое состояние ('start Имя;')
```

Ни слова о том, что импортёр лежит рядом и называется `app.takt`.

## Decision Drivers

1. **Подсказка дешевле поиска.** Инструмент знает каталог и умеет разбирать
   `.takt`; автор делает то же самое руками.
2. **Ложная подсказка хуже отсутствующей** (класс 0264): называть можно только
   тот файл, чья директива `import` действительно **разрешается** в нашу
   библиотеку.
3. **Оба инструмента отвечают одинаково.** `taktc` и `takt-sim` зовут одну
   проверку; если подсказку получит только один, автор получит разную помощь от
   инструментов одного проекта.

## Considered Options

### Option A. Текстовый поиск `grep` по каталогу

**Pros:** дёшево.
**Cons:** ловит имя в комментарии и в строке; не различает `"helper.takt"` и
`"other/helper.takt"`; при `-I` промахивается вовсе.

### Option B. Разбор соседей и разрешение их директив тем же кодом

Соседние `.takt` парсятся, их `import` разрешаются
[`read_import_file`](../../takt-lang/src/semantic/import.rs) — той же функцией,
что и при компиляции; совпадение проверяется по **каноническому пути**.

**Pros:** подсказка не врёт: названный файл действительно подключает **эту**
библиотеку; все три формы `import` учитываются автоматически.
**Cons:** дороже (разбор соседей) — но только на пути отказа, где счёт идёт на
миллисекунды и работа всё равно закончена.

### Option C. Индекс рабочей области (как в LSP)

**Pros:** полнота шире каталога.
**Cons:** слой `lsp/workspace.rs` живёт под фичей `lsp`, а `SE-102` возникает и
в CLI без неё; тащить индекс в ядро ради подсказки — несоразмерно (тот же довод,
по которому индекс отвергнут в ADR 0153).

## Decision

Принимается **Option B**.

1. Новый модуль `semantic/import/importers.rs`: `find_importers(target, search_paths)`
   и `importers_note(...)`. Обход — каталог входа плюс каталоги `-I`; порядок
   файлов сортируется (текст диагностики обязан быть воспроизводимым).
2. Подсказку добавляют **вызывающие** — `pipeline::parse_and_construct` и
   `takt-sim`, — а не сама проверка: поиск ходит по файловой системе, а
   семантика её не знает. Это та же граница, по которой `validate_entry_model`
   стоит в конвейере, а не в `validate_model_all`.
3. Заметка получает `Location::Codegen`: она говорит о **другом** файле, и
   координата в своём была бы ложью (правило 0243, образец `SE-119`).
4. Названы **три границы**: импортёр вне каталога и `-I` не найдётся;
   неразобранный сосед пропускается молча (АСД у него нет — утверждать нечего);
   при разрешении директивы кандидата к его путям добавляется каталог самой
   библиотеки — иначе файл из `-I` не нашёлся бы вовсе, а цена допущения
   (две одноимённые библиотеки в разных каталогах) — лишнее имя, не молчание.

## Consequences

### Положительные

- Автор получает следующий шаг, а не только причину.
- Подсказка проверяема: названный файл действительно подключает эту библиотеку.
- `taktc` и `takt-sim` отвечают одинаково.

### Отрицательные / Action items

- Поиск читает и разбирает соседние файлы — на пути отказа. Для каталога с
  сотнями файлов это десятки миллисекунд (замер 0257: 10 000 файлов — 0.27 с).
- Полнота ограничена каталогом и `-I`.

### Acceptance criteria

1. Импортёр найден и назван в заметке.
2. **Контрпример:** посторонний сосед не назван.
3. Нет импортёров — нет заметки.
4. Неразобранный сосед поиск не ломает.
5. Все три формы `import` распознаются.
6. Импортёр из каталога `-I` находится.
7. `./scripts/precheck.sh` — код 0.
