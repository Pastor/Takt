# ADR 0279: Вложенная модель подключённого файла — подсказка, а не новый синтаксис

- **Status:** Accepted
- **Date:** 2026-08-19
- **Authors:** Архитектор + аналитик + разработчик
- **Related issues:** [Фича 0279](../features/0279-qualified-import-model-reference.md); смежные — [0211](../features/0211-c-missing-start-state-diagnostic.md) (где замер снят, `SE-106`), [0184](../features/0184-imported-shared-variables.md) (усыновление объявлений), [0053](../features/0053-diagnostics-file-id.md) (формат диагностики — свойство диагностики, не бинарника)

## Context

Кандидат утверждал: **«ссылка на вложенную модель подключённого файла
невыразима»**, и предлагал решить, не нужна ли языку квалифицированная форма
`Lib::Helper`.

**Замер 2026-08-19 это опроверг.** Прогон четырёх форм на паре файлов
(`lib.takt` объявляет `model Helper { start Idle … }`, приложение подключает
его):

| Запись в приложении | Ответ |
|---|---|
| `import "lib.takt"; start Main = Helper;` | **`SE-001`** «Модель 'Helper' не найдена» |
| `import "lib.takt"; start Main = Lib;` | **`SE-106`** «модель 'Lib' не содержит ни одного состояния» + сноска про вложенную |
| `import "lib.takt" as Lib; start Main = Helper;` | **`SE-001`** |
| **`import { Helper } from "lib.takt"; start Main = Helper;`** | **исполняется**: `Idle`, `n = 1, 2, 3` |

То есть форма для ссылки на вложенную модель в языке **уже есть** — выборочный
импорт. Невыразимости нет; есть **недоинформированность автора**: `SE-001`
говорит «не найдена» и молчит о том, что модель рядом и подключается одной
строкой.

**Второй факт того же замера.** Сноска `SE-106`, единственная, что указывает
выход, печатается компилятором и **не печатается симулятором**: `takt-sim`
строит текст диагностики своей функцией, где цикла по заметкам нет. Один вход —
два разных объёма сведений. Это ровно тот класс, о котором предупреждает
док-комментарий `format_compile_error` («копия формата в `taktc` уже расходилась
однажды»), — вторая копия жива и разошлась.

⚠️ Записи «состояния у вложенной модели» встречаются: две фикстуры корпуса
(`tests/data/goto56/`) написаны так и не компилировались никогда.

## Decision Drivers

1. **Синтаксис не вводится там, где форма уже есть.** Язык — не место для
   второго способа сделать то же самое (`Lib::Helper` дублировал бы выборочный
   импорт).
2. **Диагностика обязана называть выход**, если он существует и известен
   компилятору: имя вложенной модели у него под рукой.
3. **Формат диагностики — свойство диагностики** (ADR 0053). Потребитель,
   печатающий её своей копией, теряет часть — что и произошло.

## Considered Options

### Option A. Ввести квалифицированную ссылку `Lib::Helper`

**Pros:** буквально исполняет кандидата.

**Cons:** второй способ выразить уже выразимое; новый токен, правки грамматики,
LSP и плагинов — ради формы, эквивалентной `import { Helper } from …`.
Отвергнуто замером.

### Option B. Ничего не делать: форма есть, автор её найдёт в документе

**Cons:** `SE-001` говорит «не найдена» — утверждение, которое автор читает как
«такой модели нет», и идёт переносить состояния на верхний уровень. Замер 0211
показал, что именно так и поступают.

### Option C. Подсказка в диагностике + починка печати заметок

**Pros:**
- автор получает ответ там, где задал вопрос;
- язык не растёт;
- заметки перестают теряться у второго потребителя — класс, названный в
  собственном док-комментарии библиотеки.

**Cons:** объём фичи меняется относительно карточки — но карточка написана до
замера, а замер её опроверг (правило 30).

## Decision

Принимается **Option C**.

1. `SE-001` получает **сноску**, когда имя найдено среди вложенных моделей
   моделей верхнего уровня: она называет владельца и форму подключения
   (`import { Имя } from "…";`).
2. Печать заметок выносится в **общий носитель** `diagnostics::format_notes`,
   который зовут и `format_compile_error`, и `takt-sim`.

⚠️ **Квалифицированная ссылка не вводится** — решение по замеру, а не по вкусу.

## Consequences

### Положительные

- Автор, написавший естественную запись, получает готовый ответ.
- Заметки диагностик доходят до пользователя эталона.

### Отрицательные / Action items

- Сноска строится по вложенным моделям **верхнего уровня** — то есть по одному
  уровню вложенности. Глубже (модель в модели в модели) она молчит; граница
  названа в коде.
- ⚠️ Подсказка не называет **файл**: у обёртки нет обратной ссылки на путь
  импорта, а имя файла автор знает по своей строке `import`.

### Acceptance criteria

1. `import "lib.takt"; start Main = Helper;` даёт `SE-001` со сноской о
   выборочном импорте (A1).
2. Обычная опечатка в имени модели сноски **не** получает (A2, контроль).
3. `takt-sim` печатает заметки диагностики так же, как `taktc` (A3).
4. Форма `import { Helper } from "lib.takt";` работает, как и прежде (A4).
5. `./scripts/precheck.sh` зелён (A5).
