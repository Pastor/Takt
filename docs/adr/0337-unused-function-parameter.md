# ADR 0337: Неиспользуемый параметр функции гасится у трёх целей

- **Статус:** Accepted
- **Дата:** 2026-08-20
- **Фича:** [../features/0337-unused-function-parameter.md](../features/0337-unused-function-parameter.md)

## Контекст

Замер 2026-08-20 на `fn constant(v: u8) -> u8 { return 7; }`:

| Потребитель | Ответ |
|---|---|
| эталон, `st`, `st-at`, `plantuml` | исполняют / переводят чисто |
| **`c`, `c-hal`** | `cc -Werror`: unused parameter 'v' |
| **`rust`** | `rustc -D warnings`: unused variable: `v` |
| **`sv`, `sv-mmio`** | `UNUSEDSIGNAL` — гейт цели считает предупреждение ошибкой |

Фича 0260 закрыла этот класс **только для структурных** параметров (`main`,
`model`, `m`) цели `c` — тех, что эмитятся по протоколу вызова. Параметр,
объявленный **автором**, не гасил никто, хотя признак «параметр использован в
напечатанном тексте тела» уже существовал и работал.

## Решение

Один признак, три идиомы:

| Цель | Заглушка |
|---|---|
| `c` | `(void)v;` — тот же `c_params`, что у 0260 |
| `rust` | `let _ = v;` (`generator/rust/rust_unused.rs`) |
| `sv` | `logic _unused_v; _unused_v = &{1'b0, v};` (`generator/sv/sv_unused.rs`) |

Форма для `sv` выбрана **пробой обоих инструментов** (verilator и yosys,
2026-08-20) и не нова: тем же способом обёртка APB поглощает сигналы записи
(`_unused_write`, фича 0169).

**Имя параметра в сигнатуре не меняется.** Форма `_v` тоже гасит
предупреждение, но сигнатура порождённого модуля читается человеком: параметр,
названный автором `v`, обязан остаться `v`.

## Границы

- **`lint_off` запрещён правилом проекта** (0169): прагма гасит сторожа, а не
  причину. В выбранной форме параметр честно используется, а константа `1'b0` в
  редукции даёт ноль — синтезатор выбрасывает логику сам (проверено yosys).
- **Признак смотрит на ТЕКСТ тела**, а не на семантику — как у 0260: это
  снимает транзитивность и не требует знать обо всех каналах использования.
- **Цель `st` не затронута:** `iec2c` о неиспользуемом параметре не говорит.

## Отвергнутые варианты

1. **Не эмитить параметр.** Вызов передаёт аргумент — сигнатура обязана его
   принять.
2. **`_v` в сигнатуре.** Меняет видимое имя.
3. **`#[allow(unused_variables)]` / `lint_off`.** Гасит сторожа, а не причину.

## Последствия

- Вывод корпуса не изменился: функций с неиспользуемым параметром в
  `examples/` нет ни одной — потому все три гейта и молчали.
