# Задача 0197-01: Раздел документа о стиле кода

> Фича: [../features/0197-language-code-style.md](../features/0197-language-code-style.md) · ADR: [../adr/0197-language-code-style.md](../adr/0197-language-code-style.md) · анализ: [../analyze/0197-language-code-style.md](../analyze/0197-language-code-style.md)

## Что было

Канон оформления существовал **в виде программы**: `taktc fmt` приводил `.takt`
к нему, предкоммит сторожил по всему корпусу, но прочитать правила словами было
негде — только по выводу инструмента или по коду `takt-lang/src/format/`.

## Что сделано

Заведён `book/src/21-code-style/index.typ` и подключён в `SUMMARY.md` последним
пунктом блока «Применение».

Свод описывает: отступы и скобки, пробелы, пустые строки, порядок элементов
модели, именование, комментарии, равноправные написания, длину строки. Плюс
функциональный пример (правило 27) и блок типичных ошибок (правило 26).

Форма — **единый сплошной список** (решение заказчика). Различие между тем, что
исполняет форматтер, и тем, что остаётся автору, несёт сама формулировка:
«это делает `taktc fmt`» против «форматтер порядок не меняет — он ваш».

## Что дала проба, а не чтение кода

Каждое правило о расстановке получено прогоном `taktc fmt --stdin` на нарочно
сбитом входе. Три факта, которые чтением `format/` я бы не получил или получил
неверно:

1. **`else` начинается с новой строки** — Takt здесь расходится с K&R, который
   заказчик назвал отправной точкой. Свод называет это отступление прямо.
2. **Однострочное тело разворачивается.** `start S { always { v := 1; } }`
   форматтер превращает в пять строк: компактная запись каноном не является.
3. **Хвостовые комментарии по колонке не выравниваются** — между оператором и
   `//` всегда один пробел.

Факт 3 найден **отказом собственного примера**: первая редакция раздела
выравнивала комментарии столбиком, и `fmt --check` её отверг. То есть свод о
стиле нарушал стиль, который описывает. Правило дописано, пример исправлен.

## Проверки

- Все шесть блоков ```takt извлечены и прогнаны через `fmt --check`: три
  самостоятельных — каноничны, три фрагмента (не разбираются отдельно)
  проверены прямой пробой.
- Функциональный пример: `taktc compile -t c` — успешно, `takt-sim -n 10` —
  успешно.
- `./scripts/precheck.sh` — код возврата 0 (включая гейт примеров документа и
  гейт символов шрифта).
