# Задача 0244-02: Слияние 147 тестовых целей в 12

> Фича: [../features/0244-test-target-build-cost.md](../features/0244-test-target-build-cost.md) · ADR: [../adr/0244-test-target-build-cost.md](../adr/0244-test-target-build-cost.md) · анализ: [../analyze/0244-test-target-build-cost.md](../analyze/0244-test-target-build-cost.md)

## Что было

Каждый файл в `tests/` — отдельная тестовая цель, то есть отдельный бинарник:
98 в `takt-lang`, 42 в `takt-sim`, плюс юнит-тесты — **147 наборов**. Замер ADR:
первый запуск свежесобранного бинарника стоит **0.60 с при загрузке ЦП 2 %**
(проверка кода ядром, чтение с диска, работа динамического загрузчика),
повторный — 0.033 с. В гейте каждый бинарник запускается впервые, поэтому
≈ 88 с из 152.9 с стадии `cargo test` уходило **только на запуск процессов**.

## Что сделано

**Семь тем — семь целей.** Наборы сгруппированы по предмету; тема — каталог
`tests/<тема>/` с файлом `main.rs`, который **только объявляет `mod`**:

| Крейт | Цель | Что внутри | Наборов |
|---|---|---|---|
| `takt-lang` | `semantic` | дерево, типы, диагностики, параметры, порты | 47 |
| `takt-lang` | `targets` | цели `c`, `c-hal`, `st`, `rust`, `sv`, `sv-mmio`, адреса | 24 |
| `takt-lang` | `syntax` | лексика, разбор, форматтер, канон стиля | 13 |
| `takt-lang` | `lsp` | языковой сервер и редакторский слой | 12 |
| `takt-lang` | `verify` | LTL и автоматы Бюхи | 2 |
| `takt-sim` | `conformance` | сверки эталона с целями | 24 |
| `takt-sim` | `sim` | остальные тесты симулятора | 18 |

⚠️ **Файлы не слиты.** Каждый набор остался своим файлом и стал модулем:
правило размера модуля (`docs/CODE.md`) не задевается, а имя теста получило
префикс набора и осталось различимым —
`cargo test --test targets c_stub_tests::`.

⚠️ **Каталоги-спутники переехали вместе с файлами.** У шести наборов есть
подкаталоги с `#[path]`-модулями (`conformance_c_tests/`, `semantic_tests/`,
`lsp_tests/`, `parser_tests/`, `lexer_tests/`, `codegen_tests/`) — они перенесены
в те же темы, поэтому относительные пути внутри не изменились.

**Что потребовало правки помимо перемещения:**

1. **Санация имени потока (инвариант 0190).** Временный каталог теста уникален
   по `std::thread::current().name()`; после слияния имя несёт префикс модуля, и
   `:` попал бы в путь. Два места в `takt-sim` его не вычищали — добавлен
   `.replace(':', "_")` с пояснением. Остальные 31 место уже санировали либо
   имя не используют.
2. **Два `include_str!`** отсчитываются от файла и стали на уровень глубже
   (`../src/grammar.lalrpop` → `../../…`, `data/lsp/…` → `../data/lsp/…`).
   ⚠️ Класс безопасный: файл не читается — сборка падает, молча не уедет.
3. **Пути в документации: 197 файлов.** Гейт ссылок (правило 14) нашёл 8 битых
   и остановил предкоммит; заодно обновлены 28 путей в живом контексте.
4. **`README.md`** получил таблицу раскладки целей с примерами запуска,
   **`CLAUDE.md`** — пункт с тремя предупреждениями: новый набор кладётся
   **в тему** (файл в `tests/` верхнего уровня снова станет целью и вернёт свою
   долю стоимости молча), имя потока теперь несёт `::`, пути `include_str!`
   стали глубже.

## Проверки

**Замер на полностью холодном каталоге** (методика «устоявшаяся ФС + второй
прогон», условия те же, что у «до»):

| Метрика | До фичи | После 0244-01 (`line-tables-only`) | После 0244-02 (слияние) |
|---|---|---|---|
| Тестовых целей | 147 | 147 | **14** |
| Стадия `cargo test` | 152.9 с | 127.8 с | **54.7 с** |
| Полный предкоммит | 233.2 с | 214.9 с | **138.9 с** |
| Тестов пройдено | 3082 (+6 ignored) | 3082 (+6) | **3082 (+6)** |

Итог фичи: стадия тестов **−98.2 с (−64 %)**, полный прогон **−94.3 с (−40 %)**.
Расчёт ADR обещал 120–130 с полного прогона — факт 138.9 с, то есть расчёт
оказался чуть оптимистичнее реальности, но порядок верный.

```sh
cargo test --all-features                     # 3082 passed, 6 ignored, 14 suites
cargo test --test targets c_stub_tests::      # набор внутри темы
./scripts/precheck.sh                         # зелёный, 138.9 с
```
