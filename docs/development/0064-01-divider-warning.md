# Задача 0064-01: `SV-009` на переменный делитель + канал предупреждений цели `sv`

> Фича: [../features/0064-sv-divider-warning.md](../features/0064-sv-divider-warning.md) · ADR: [../adr/0064-sv-divider-warning.md](../adr/0064-sv-divider-warning.md) · анализ: [../analyze/0064-sv-divider-warning.md](../analyze/0064-sv-divider-warning.md)

## Что было

`sv_expr.rs:425` — комментарий «предупреждать о цене (кандидат `SV-009` задачи
0045-06)»; трансляция `/` и `%` прямая, диагностики нет. У цели `sv`
**канала предупреждений нет вовсе** (греп по `generator/sv/`: ни
`Diagnostic::warning`, ни `report`).

## Что сделано

1. **Канал.** Завести `report` в `generator/sv/mod.rs` по образцу
   `rust/mod.rs:199` и `st/mod.rs:290`. ⚠️ **Без него `SV-009` — немая**, и фича
   цели не достигает.
   ⚠️ Образец воспроизводится **сознательно, вместе с его дефектом**: `report`
   печатает `eprintln!` из библиотеки и диагностику вызывающему не возвращает
   (`compile_to_sv` → `Result<(), Diagnostic>`), из-за чего `--quiet` его не
   глушит. Чинить это здесь **нельзя** — фича превратилась бы в рефакторинг
   доставки; дефект заведён кандидатом.
2. **Диагностика `SV-009`** — **предупреждение**, а не ошибка (правило 1 ADR):
   деление синтезируется корректно, и отказывать в трансляции рабочего кода цель
   не вправе.
3. **Условие срабатывания** (правила 2–4 ADR): `/` и `%`, **если делитель не
   константа** времени компиляции. Константа → **молча**. Про `*` → **молча**.
4. **Текст** (правило 5): называет **причину** («в RTL нет аппаратного делителя»)
   и **следствие** («длинный комбинационный путь → потолок частоты»), **без**
   конкретных LUT — они технологичны и устареют.

**Основание правил — замер, а не мнение** (`yosys synth_ice40 -dsp -flatten`, `u32`):

| Операция | `SB_LUT4` | DSP |
|---|---|---|
| `a + b` | 49 | 0 |
| `a * b` | **17** | **3** ← дешевле сложения |
| `a / b` | **558** | 0 ← ×11 от сложения |
| `a / 2` | 17 | 0 ← сдвиг |
| `a / 3` | 106 | 0 ← ≈ сложение |

## Проверки

- **T1/A1:** `a / b` → `SV-009`, трансляция успешна.
- **T2/T4/T6/A2, A3 — МОЛЧАНИЕ:** `a / 2`, `a / 3`, `a % 4` → предупреждения нет.
- **T5/A4:** `a * b` → предупреждения нет.
- **T11:** мутация «предупреждать на любое `/`» обязана **валить T2** — иначе
  шумная версия прошла бы незамеченной.
- **T7/A7:** предупреждение **доходит** до пользователя (канал заведён).
- **T8/A5:** текст называет причину и следствие, без LUT.
- **T9/A6:** корпус — ноль предупреждений; `git diff --exit-code examples/generated`
  пуст.
- **T10:** порождённый SV не изменился.
