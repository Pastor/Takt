# Задача 0268-01: Описание `SE-033` в реестре, приложении и самом тексте

> Фича: [../features/0268-se033-appendix-description.md](../features/0268-se033-appendix-description.md) · ADR: [../adr/0268-se033-appendix-description.md](../adr/0268-se033-appendix-description.md) · анализ: [../analyze/0268-se033-appendix-description.md](../analyze/0268-se033-appendix-description.md)

## Что было

Три носителя знания о `SE-033`, и все три неисправны:

- **реестр** нёс `<анонимная>` — фрагмент текста самого сообщения (умолчание
  для имени модели), а не описание;
- **приложение** имело пустую ячейку в таблице и не имело разбора вовсе;
- **текст диагностики** содержал опечатку («в мод**е**ле») и не объяснял
  правила: сообщал факт «не найдено», умалчивая, где искать.

## Что сделано

- **`docs/diagnostics/README.md`:** описание словами — «состояние, названное
  справа в проверке `S(Модель) = Состояние`, у этой модели не объявлено».
  Ссылка на источник очищена от номера строки (символ уезжает, строка
  остаётся).
- **`book/src/appendix-errors/index.typ`:** заполнена строка таблицы, добавлен
  разбор `SE-033` по образцу соседей — описание, пример на Takt, вывод
  компилятора. Вывод **скопирован из прогона**, а не сочинён.
- **`takt-lang/src/semantic/validate/common.rs`:** текст диагностики исправлен
  и дополнен правилом — «справа от `=` в проверке `S(Модель) = Состояние`
  стоит состояние названной модели, а не любое имя».

**Обратная функциональность (правило 11):** меняется текст диагностики.
Проверено грепом: тестов, сверяющих это сообщение дословно, в дереве нет —
сверяется код (`c_state_ref_tests.rs`).
