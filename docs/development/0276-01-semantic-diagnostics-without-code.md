# Задача 0276-01: Диагностика семантики без кода и позиции

> Фича: [../features/0276-semantic-diagnostics-without-code.md](../features/0276-semantic-diagnostics-without-code.md) · ADR: [../adr/0276-semantic-diagnostics-without-code.md](../adr/0276-semantic-diagnostics-without-code.md) · анализ: [../analyze/0276-semantic-diagnostics-without-code.md](../analyze/0276-semantic-diagnostics-without-code.md)

## Что было

Диагностика строилась конверсией `From<&str> for Diagnostic`: код `None`
(печатался `[?]`), позиция `Location::Source(0, 0, 0)` — «начало первого
файла». Мест было восемь в семантике; замер нашёл ещё четыре (два в цели `c` и
два с кодами, но без позиции).

## Что сделано

| Место | Стало |
|---|---|
| индексация не-массива (`condition/mod.rs`) | `SE-117`, позиция имени |
| локальная функция без тела (`function.rs`) | `SE-118`, позиция объявления |
| шесть внутренних инвариантов | `SE-119` через воронку `semantic::internal::internal(вид)` |
| два места цели `c` | существующая воронка `CC-023` (фича 0212 их пропустила) |
| `SE-004`, `SE-022` | код был, позиция восстановлена |
| `impl From<&str> for Diagnostic` | **удалён**; на его месте — комментарий, почему возвращать нельзя |

⚠️ **Класс теперь запрещает тип:** `Err("текст".into())` не компилируется.
Прежде безликое место заводилось незаметно — так и случилось дважды (0212
пропустила два места в самой цели `c`).

⚠️ **`SE-119` печатается с `Location::Codegen`**: у внутреннего инварианта
позиции нет по существу, и подставлять «начало файла» значило бы вернуть
исходный дефект.

## Проверки

```sh
cargo test --test semantic diagnostic_code_presence   # 4 теста: два поведения, два устройства
cargo test --all-features                             # 3277 тестов
./scripts/check-diagnostic-codes.sh                   # 260 кодов, реестр согласован
./scripts/precheck.sh                                 # полный гейт
```

Сторож двухслойный: поведение (код и позиция у достижимых диагностик) и
устройство (нет конверсии, нет `Err("…".into())` в `src/semantic`, падает
списком мест).
