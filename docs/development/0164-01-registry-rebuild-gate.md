# Задача 0164-01: Гейт согласованности реестров

> Фича: [../features/0164-registry-rebuild-gate.md](../features/0164-registry-rebuild-gate.md) · ADR: [../adr/0164-registry-rebuild-gate.md](../adr/0164-registry-rebuild-gate.md) · анализ: [../analyze/0164-registry-rebuild-gate.md](../analyze/0164-registry-rebuild-gate.md)

## Что сделано

`scripts/check-registries.py` (шаг предкоммита, самопроверка первой) сверяет
**множество файлов** папки-стадии с **множеством ссылок** её реестра:

| Класс | Находка |
|---|---|
| `R1` | файл есть, записи в реестре нет |
| `R2` | запись есть, файла нет |
| `R0` | стадия пуста — проверка вырождена, а не пройдена |

Проверяются семь папок жизненного цикла. `docs/templates/` не в списке (там
плейсхолдеры, а не артефакты), `docs/diagnostics/` — тоже (это реестр кодов, у
него свой гейт).

⚠️ Гейт сверяет **состав**, а не содержание строки: заголовок, статус и вердикт
проверяют правило 4 и гейты 0177/0218. Пересборка реестра скриптом отвергнута
ADR — в строке живёт написанный человеком текст.

## Проверка

```sh
python3 scripts/check-registries.py --self-test
python3 scripts/check-registries.py
```
