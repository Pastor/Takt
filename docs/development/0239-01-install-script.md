# Задача 0239-01: Скрипт релизной сборки и установки инструментов

> Фича: [../features/0239-install-script.md](../features/0239-install-script.md) · ADR: не заводился (инструментальная фича) · анализ: [../analyze/0239-install-script.md](../analyze/0239-install-script.md)

## Что было

README предлагал:

```sh
cargo build --release --bin taktc
cargo install --path grammar --bin taktc
```

Вторая строка **не работает**: крейт `grammar` переименован в `takt-lang` ещё
фичей 0100. Симулятор в разделе установки не упоминался вовсе, а языковой
сервер — только в разделе про редакторы и с тем же мёртвым путём. Вдобавок
`takt-lsp` без `--features lsp` не собирается: бинарника просто нет.

## Что сделано

`scripts/install.sh` — одна команда на все три инструмента:

```sh
scripts/install.sh                     # → ~/.local/bin
scripts/install.sh --prefix /usr/local
scripts/install.sh --no-lsp --check --dry-run --build-only
```

Устройство:

- состав инструментов задан **одной таблицей** внутри скрипта (`имя | крейт |
  флаги`), и по ней идут и сборка, и установка, и `--check`: три списка
  разъехались бы;
- каталог сборки по умолчанию — **свой** `target/install` (урок 0234:
  накопленный общий `target` растягивает минутную сборку на часы), переопределяем
  через `CARGO_TARGET_DIR`;
- установка идёт `install -m 0755` — замена inode, а не запись поверх:
  работающий бинарник не портится;
- скрипт **предупреждает**, если `$PREFIX/bin` не в `PATH`;
- `--dry-run` печатает команды и **ничего не создаёт**;
- неизвестный аргумент — отказ с кодом 2, а не молчаливое игнорирование.

⚠️ **`taktc --version` скрипт не зовёт.** Такой команды у компилятора нет
(незакрытая фича 0165), и вызов печатал бы «неизвестная команда» сразу после
успешной установки. Признак свежести — размер и время файла.

### По функциональности (правило 11)

| Составляющая | Статус |
|---|---|
| `scripts/install.sh` | новый скрипт (bash, без внешних зависимостей) |
| `scripts/test-install.sh` | сторож A1–A8 |
| `README.md` | раздел сборки переписан; мёртвый `cargo install --path grammar` убран из двух мест |
| `takt-lang` / `takt-sim` | **н/п**: кода не касается |
| `precheck.sh` | **н/п**: релизная сборка в предкоммит не входит по объёму |

## Проверки

- `scripts/test-install.sh` — A1–A8 зелёные.
- Настоящий прогон в временный префикс: три бинарника собраны и установлены,
  запускаются.
- `./scripts/precheck.sh` — зелёный.
