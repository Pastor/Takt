# Задача 0140-01: ревизия блока кандидатов

> Фича: [../features/0140-backlog-revision-doc-split.md](../features/0140-backlog-revision-doc-split.md) · ADR: [../adr/0140-backlog-revision-doc-split.md](../adr/0140-backlog-revision-doc-split.md) · анализ: [../analyze/0140-backlog-revision-doc-split.md](../analyze/0140-backlog-revision-doc-split.md)

## Что было

Блок 2 `FEATURES.md` — 28 кандидатов, часть которых описывала не то, что есть в
коде. Витрина — вход в проект для новой сессии, и по неверной записи заводят
работу, которая уже сделана, либо ищут дефект, которого нет.

## Что сделано

Проверено **17** записей из 28 — каждая пробой или грепом.

### Правки по замеру

| Запись | Замер | Правка |
|---|---|---|
| «Цель `c` **не эмитит констант перечисления вовсе**» | эмитит: `#define ENUM_EN_M_GO 1` — но **в `.c`**, а прежний греп искал в `.h`; присваивание при этом печатается числом (`model->c = 1;`) | переписана: «объявляет, но не использует» — то самое положение, из которого фича 0066 вывела `st` |
| «Пустое перечисление `enum E { }` — четыре разных ответа» | программу **нельзя написать**: `SY-002`, парсер требует вариант | переписана: вопрос остаётся, но уровнем выше — «чем должно быть перечисление без вариантов»; прежняя формулировка была о несуществующем входе |
| «`rust` глушит `too_many_arguments` **пять раз**» | восемь | поправлено число |

### Подтверждены (остаются)

`Takt.ebnf` отстал (`==` есть, `:=` нет) · комментарии фикстур со старыми
именами (9 файлов) · тега `v0.4.0` нет · `builder.rs` с `_ => None` · нет
`new-feature.sh --rebuild` · нет `taktc version` · нет корпусного SV-примера на
`+` · `eprintln!` из библиотеки (6 мест) · гейт `c` без `-Werror` · вложенные
`if` не диагностируются · маска `[bit;64]` незаписуема (`LE-009`) · бит `−1` у
`bit`-порта с голым адресом (`{ (uintptr_t)0x100u, -1, 1 }`).

### Не проверялись

Требуют IDE (действия плагина, JDK 21) либо дорогого замера (потолки стека);
задумки без «сделано/не сделано» (адаптеры шин, насыщение `q`, расхождение `>>`)
сверке не подлежат. ⚠️ Это **названо**, а не выдано за полную сверку.

## Находка вне блока 2: версия языка

`CLAUDE.md` утверждал «версия языка **сейчас `0.4.0`**», тогда как
`LANGUAGE_VERSION` и README дают **`0.6.0`**. Гейт `check-language-version.sh`
сверяет только константу и README — расхождение с живым контекстом молчало.

По этой записи в карточках недавно закрытых фич (0130, 0131, 0132) писалось
«версия `0.5.0` остаётся» — неверно. Исправлено в `CLAUDE.md`, `CHANGES.md` и
семи документах фич.

⚠️ Урок: гейт сверяет **два** источника из трёх; третий (живой контекст) остался
вне проверки и увёл за собой три карточки.
