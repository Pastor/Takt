## Что сделано

`book/src/20-processor/examples/machine.takt` — первая ступень раздела: **одно
ядро, память и две шины**.

**Две шины — два набора общих переменных** (приём 0182: протокол объявляет одна
сторона):

- шина кода — `code_addr` → `code_op`, `code_arg`;
- шина данных — `data_addr`, `data_wdata`, `data_wen` → `data_rdata`.

Память (`Memory`) обслуживает **обе** в одном такте: отдаёт команду по адресу
кода и одновременно читает (а при стробе — пишет) ячейку данных. Это и есть
предметный смысл двух шин: выборка команды не мешает обращению к данным.

**Ядро (`Core`) — трёхтактный машинный цикл** `Fetch → Decode → Execute`.
⚠️ Три такта здесь **не назначены, а вытекают** из дисциплины шины, снятой пробой
О11: ядро выставляет адрес, память отвечает в том же такте, но ядро прочитает
ответ лишь в следующем. Поэтому `Fetch` только выставляет `code_addr`, `Decode`
забирает пришедшую команду и выставляет адрес операнда, а `Execute` работает уже
с пришедшими данными.

**Декодер** на этой ступени — состояние `Decode` плюс `match` по опкоду в
`Execute`; отдельной моделью-стадией он становится в конвейере (ступень 3, задача
0186-04). Образцы `match` записаны **мнемониками** (`Lda`, `Sta`, `Add`, `Sub`,
`Jnz`), а не числами: варианты перечисления работают в образцах, и форматтер их
сохраняет (проба).

**Программа** — «умножение сложением» (`sum := x * n`), её листинг приведён
комментарием рядом с массивами: читатель видит и мнемоники, и числа, которыми они
лежат в памяти.

⚠️ **Останов ядра не завершает прогон**: `Halted` — терминальное состояние ядра,
но память продолжает обслуживать шины, поэтому композиция живёт. Для гейта книги
это законно (нужен код возврата 0, а не завершение), и предметно верно: память
не «заканчивается» оттого, что процессор встал.

## Проверки

```sh
./target/debug/taktc compile -t c book/src/20-processor/examples/machine.takt -o out/
./target/debug/takt-sim -n 80 --save-state m.json book/src/20-processor/examples/machine.takt
./scripts/precheck.sh
```

- **Программа считает верно**: снимок памяти после останова —
  `ram = [21, 7, 0, 1]`, то есть `sum = 7 × 3 = 21`, счётчик `n` обнулён,
  слагаемое и единица не тронуты. Ядро в состоянии `Halted`, `pc = 8`.
- **Гейт книги**: файл компилируется целью `c` и симулируется (`-n 10`).
- **Форматтер**: файл в каноне (`fmt --check`).
- Раздела `index.md` у каталога пока нет — текст пишется задачей 0186-06; на
  гейты это не влияет (гейт книги обходит `.takt`-файлы, `SUMMARY.md` — главы).

Соответствие анализу: закрыта первая половина **R1** (ядро, память, две шины,
ISA, программа); кеш — 0186-03, конвейер — 0186-04, два ядра — 0186-05.
