# Задача 0271-01: Гейт тем и объявленных наборов

> Фича: [../features/0271-test-target-gate.md](../features/0271-test-target-gate.md) · ADR: [../adr/0271-test-target-gate.md](../adr/0271-test-target-gate.md) · анализ: [../analyze/0271-test-target-gate.md](../analyze/0271-test-target-gate.md)

## Что сделано

`scripts/check-test-targets.py` (шаг предкоммита, самопроверка первой):

| Класс | Находка |
|---|---|
| `T1` | `.rs` в `tests/` верхнего уровня — новая тестовая цель (0.42 с первого запуска) |
| `T2` | набор лежит в теме, но не объявлен `mod` в её `main.rs` |
| `T3` | у темы нет `main.rs` |
| `T0` | тем не найдено — проверка вырождена |

⚠️ **`T2` — главный класс, и кандидат его не называл:** необъявленный набор не
собирается и не запускается **вовсе**, а `cargo test` рапортует об успехе.
Тесты, которых нет, не падают.

⚠️ `tests/data/` темой не считается: там фикстуры.

Оба класса проверены **пробой на настоящем дереве** (файл в `tests/`, файл в
теме без `mod`), а `T3`/`T0` и контроль — самопроверкой.

## Проверка

```sh
python3 scripts/check-test-targets.py --self-test
python3 scripts/check-test-targets.py    # 7 тем, 182 набора
```
