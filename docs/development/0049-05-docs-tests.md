# Задача 0049-05: Документация, примеры и тесты

> Фича: [../features/0049-model-checking-ltl.md](../features/0049-model-checking-ltl.md) · ADR: [../adr/0049-model-checking-ltl.md](../adr/0049-model-checking-ltl.md) · анализ: [../analyze/0049-model-checking-ltl.md](../analyze/0049-model-checking-ltl.md)

## Что было

LTL описан в README как разбираемая, но **непроверяемая** аннотация (после 0035).
Тестов верификации нет (`ltl_tests.rs` — только parse + диагностики 0035;
`buchi.rs` — parse + непустота). Проверки пустоты/вердикта нет нигде.

## Что сделано

> **Планируется (разработка не начата).** План по ADR 0049 (R9, R10; правила 15, 16).

1. **README** — раздел «Верификация модели (`lamc verify`)»:
   - что проверяется (управляющие свойства: достижимость, порядок состояний,
     живость) и что **не** (данные — вне абстракции, будущее расширение);
   - синтаксис команды, коды возврата, формат контрпримера;
   - **примеры и контрпримеры** (правило 16), прошедшие проверку: `G(Fault -> F
     Idle)` держится/нарушается; `F Done` по достижимости.
   - обновить статус LTL (был «не верифицируется» из 0035): теперь управляющие
     свойства проверяются.
2. **Фикстуры** `grammar/tests/data/verify/`: `holds.lam`, `fails.lam`,
   `reachable.lam`, `unreachable.lam`, `atom_not_state.lam`.
3. **Тесты:**
   - юнит-тесты `verification/` на построенных вручную Крипке (A7, A8) — **на
     вердикт/лассо**, не «непусто» (капкан 0025, риск Р7);
   - интеграционные `verify_tests.rs` через `verify_model` на фикстурах (A2, A3, A4);
   - детерминизм вердикта (A6).
4. **CHANGES.md**, **CLAUDE.md** (снять «`build_buchi` из исходника не
   вызывается»; зафиксировать абстракцию управления и `lamc verify`).
5. Версия языка **не растёт** (R10); `grammar.lalrpop`/Cargo.toml не трогаются.

## Проверки

- `./scripts/precheck.sh`; `cargo test --all-features`; `cargo test --features lsp`.
- README-примеры компилируются/верифицируются пробой (правило 16).
- Соответствие анализу: R9, R10; критерии A1–A10.
