# Задача 0147-01: Тесты состава, вложенности и диапазонов символов

> Фича: [../features/0147-lsp-document-symbol-tests.md](../features/0147-lsp-document-symbol-tests.md) · ADR: [../adr/0147-lsp-document-symbol-tests.md](../adr/0147-lsp-document-symbol-tests.md) · анализ: [../analyze/0147-lsp-document-symbol-tests.md](../analyze/0147-lsp-document-symbol-tests.md)

## Что было

`takt-lang/src/lsp/symbols.rs` — **0 %** покрытия при 183 строках, при том что
возможность объявлена клиенту и вызывается редактором при каждом открытии файла.

## Что сделано

### Зонд (первым, до тестов)

Файл со **всеми** видами объявлений верхнего уровня прогнан через
`document_symbols`, вывод захвачен целиком (имена, виды, `range`,
`selection_range`). Все ожидания тестов сняты с него — не выведены из чтения
кода. Зонд же вскрыл три расхождения.

### Две правки `symbols.rs` (ветвь `ModelElement::Struct`)

| Было | Стало | Почему |
|---|---|---|
| `selection_range` = диапазон всего объявления | диапазон **имени** | по `selection_range` редактор переходит из панели структуры; у всех прочих символов — имя. Единственная ветвь-исключение |
| `def.name.clone().unwrap()` | `match … { Some => …, None => continue }` | `IdentifierOrError` кладёт `None`, когда имя не разобралось: это паника сервера во время набора. Все соседние ветви уже пропускают безымянный элемент |

⚠️ Второй путь **сегодня недостижим**: при ошибке разбора `parse` возвращает
`Err`, и `document_symbols` выходит раньше (проверено четырьмя формами
испорченного входа). Но недостижимость обеспечена **парсером**, а фича 0152
(восстановление на границе элемента) это свойство меняет.

### Тесты

Новый `takt-lang/tests/lsp_document_symbol_tests.rs` — 13 тестов группами:

- **состав**: каждое объявление стало символом **своего вида**; пиннинг длины
  списка; `import` символом не стал;
- **вложенность**: под-модель → элементы (и не дублирует их наверху),
  состояние → блоки, перечисление → варианты, структура → поля; одноимённые из
  разных областей (`Idle`-состояние и `Mode::Idle`) различимы;
- **диапазоны**: `selection_range` покрывает имя и лежит внутри `range`; `range`
  начинается с ключевого слова объявления;
- **границы**: шесть форм неразбираемого входа → пустой список, не паника;
  возможность объявлена в `ServerCapabilities`;
- **пробел**, пришпиленный сознательно: инвариант **состояния** символом не
  становится (инвариант модели — становится).

Обратная функциональность (правило 11): затронут только LSP крейта `takt-lang`.
Плагины своих списков символов не ведут (IntelliJ — собственный PSI, Zed —
делегирует серверу), правок не требуют — **н/п** (правило 29 проверено).
