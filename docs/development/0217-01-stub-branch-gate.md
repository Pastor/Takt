# Задача 0217-01: Ветвь-заглушка до будущей задачи переживает саму задачу

> Фича: [../features/0217-stub-branch-gate.md](../features/0217-stub-branch-gate.md) · ADR: [../adr/0217-stub-branch-gate.md](../adr/0217-stub-branch-gate.md) · анализ: [../analyze/0217-stub-branch-gate.md](../analyze/0217-stub-branch-gate.md)

## Что было

Отказ «пока не поддерживается» невидим для всех существующих гейтов: гейт
исчерпаемости (0093) требует разбора всех вариантов — он выполнен; реестр
диагностик требует кода — он есть. Класс дал дефект дважды (фиксы 0134-01 и
0134-02).

Замер 2026-08-17: формулировку несут **шесть** мест (кандидат считал 17 —
большинство прежних снято фичей 0183). Две из них — постоянные отказы,
названные «пока» по недосмотру; две (по кодам `SIM-013`, `SIM-020`) — живые
заглушки, причём первая ссылалась на фичу 0025, закрытую давно, а вторая не
называла номера вовсе.

## Что сделано

**1. Реестр `scripts/stub-branches.txt`** — строка на заглушку:
`<код> <файл> <держатель> # пояснение`. Держатель — номер фичи, которая снимет
заглушку, либо `ПОСТОЯННЫЙ`. Ключ — **код + файл**: номер строки уедет при
первой правке (запрет ссылок `файл.rs:NNN` — правило 0149).

| Код | Файл | Держатель |
|---|---|---|
| `ST-016` | `generator/st/st_model.rs` | `ПОСТОЯННЫЙ` — переменный `PT` у `TON`, решение ADR 0183 |
| `FM-001` | `format/mod.rs` | `ПОСТОЯННЫЙ` — механизм отказа на непокрытый узел |
| `SIM-013` | `takt-sim/src/predicate.rs` | **0247** (заведена этой работой) |
| `SIM-020` | `takt-sim/src/unit/statement.rs` | **0248** (заведена этой работой) |

**2. Гейт `scripts/check-stub-branches.py`** с тремя условиями отказа:
незарегистрированная заглушка, держатель в терминальном статусе, запись без
места в коде. Статус держателя нормализуется (пять форм записи — урок 0218).
Есть `--self-test`, проверяющий все условия и молчание на законном.

⚠️ **Комментарии пропускаются:** док-строка `format/mod.rs` («Узел АСД пока не
поддержан печатью») рассказывает о механизме, а отказ строится ниже; считая
её, гейт потребовал бы регистрировать прозу.

**3. Гейт подключён к `precheck.sh`** рядом с 0218, с самотестом.

**4. Правило в `docs/CODE.md`** — новый раздел «Ветви-заглушки»: как писать
отказ, что регистрировать и почему постоянный отказ нельзя называть «пока».

**5. Две находки получили адрес** — карточки стадии 1 с пробами:

- **0247** — голое имя состояния/модели в условии (`ref Done: Idle;`)
  останавливает эталон `SIM-013`;
- **0248** — встроенные функции (`min`, `max`, `abs`, `clamp`, `debug`) не
  исполняются эталоном, тогда как цель `c` тот же `min(n, 3)` переводит верно
  (`(((model->n) < (3)) ? (model->n) : (3))`).

Обе внесены в `FEATURES.md` как Tier 2 (расхождение эталона с целями).

Обратная функциональность (правило 11): код компилятора и симулятора не менялся;
сами заглушки продолжают отвечать отказом до фич-держателей.

## Проверки

```sh
python3 scripts/check-stub-branches.py --self-test   # все условия срабатывают
python3 scripts/check-stub-branches.py               # 4 объявлено, расхождений нет
./scripts/precheck.sh                                # код 0
```

Три внешние мутации (реестр правится и откатывается в том же прогоне)
подтверждают каждое условие отказа — результаты в отчёте
[../reports/0217-stub-branch-gate.md](../reports/0217-stub-branch-gate.md).
