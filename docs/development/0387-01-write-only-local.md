# Задача 0387-01: Локальная переменная, записанная но не прочитанная

> Фича: [../features/0387-write-only-local.md](../features/0387-write-only-local.md) · ADR: [../adr/0387-write-only-local.md](../adr/0387-write-only-local.md) · анализ: [../analyze/0387-write-only-local.md](../analyze/0387-write-only-local.md)

## Что было

Признак «локальная не используется» (0376) считал запись использованием.
`var spare: u8 := 0; spare := n + 5;` без чтений заглушки не получал, и вывод
пяти целей отвергали их же инструменты при нулевом коде возврата `taktc`;
`SE-036` при этом молчала.

## Что сделано

**1. Режим чтений вместо второго обхода.** У `UsageSet` появился флаг
`reads_only`: цель присваивания считается **местом записи**, а не чтением;
внутри неё читаются индексы и базы (`arr[i] := 5;` читает `i`, не `arr`).
Флаг — вместо копии обхода: второе правило «что считать упоминанием»
разошлось бы с первым молча.

**2. Признак локальных включает режим.** `unused_locals_of_block` спрашивает
чтения; тем самым чинятся сразу заглушка целей `c`/`rust` (0376) и `SE-036`
(0386) — знание одно.

**3. У цели `sv` появился поглотитель обычной локальной.** Прежде он был
только у поднятых со структурой (0375); идиома та же —
`logic _unused_x; … _unused_x = &{1'b0, x};`.

⚠️ **Присваивание поглотителя печатается ПОСЛЕ тела.** Первая редакция ставила
его рядом с объявлением, и verilator ответил `ALWCOMBORDER` («always_comb reads
'spare' before assigning it later in the same block») — гейт цели считает
предупреждение ошибкой. Класс двухслойный: замер снимался дважды.

Статус по функциональности (правило 11): правка в семантике
(`semantic/unused.rs`) и у цели `sv`; цели `c`/`rust` починились сами —
заглушка у них была, не хватало признака. Редакторский слой — «н/п».

## Проверки

```sh
cargo test --all-features
cargo test --test conformance conformance_write_only_local_tests::
scripts/probe.sh -n 3 takt-sim/tests/data/eval/conformance_write_only_local.takt
./scripts/precheck.sh
```

- **Инструменты** (T1, T2): все восемь целей переводят, вывод принимают `cc`
  (с флагами гейта), `iec2c` + `cc`, `rustc` + `clippy`, `verilator` + `yosys`.
- **Поведение** (T4): трасса эталона `1, 2, 3` — прежняя.
- **`SE-036`** (T3): предупреждение выдаётся с координатой объявления.
- **Мутация** (T7): «запись снова считается чтением» роняет сборку
  порождённого C.
- **Шум** (T8): прогон по всем примерам корпуса — ноль новых предупреждений.
