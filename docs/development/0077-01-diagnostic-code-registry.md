# Задача 0077-01: Реестр кодов диагностик

> Фича: [../features/0077-diagnostic-code-registry.md](../features/0077-diagnostic-code-registry.md) · ADR: [../adr/0077-diagnostic-code-registry.md](../adr/0077-diagnostic-code-registry.md) · анализ: [../analyze/0077-diagnostic-code-registry.md](../analyze/0077-diagnostic-code-registry.md)

## Что было

Коды диагностик выдавались голыми литералами `Diagnostic::with_code(&str)` (≈330
мест + два диспетчера `code()`), **без** валидации формата и уникальности. Новый
код выбирался грепом «последнего занятого» — так фичи 0028 и 0029 независимо взяли
`CC-014` (коллизия). Документация — вручную пополняемые таблицы `README.md`,
отстающие от кода (AM-001…006 и PU-001 не описаны, ST — 2 из 13). Машинной проверки
кодов не было вовсе.

## Что сделано

Реализация по [ADR 0077](../adr/0077-diagnostic-code-registry.md) (Option A) —
единый реестр + машинный гейт (аддитивно, `with_code` не тронут):

- **Реестр** `docs/diagnostics/README.md` — единый источник истины: таблица
  `Код · Значение · Источник` по префиксам (LE/SY/SE/CC/RS/SV/ST/AM/DF/PU/SIM),
  **171 код**, по одной строке. Значения мигрированы из README/комментариев;
  пробелы **AM/PU/ST** заполнены. Соглашения: формат `XX-NNN`, `RESERVED`/`RETIRED`
  для выведенных, «следующий свободный» из справки гейта.
- **Гейт** `scripts/check-diagnostic-codes.sh` (POSIX sh, образец
  `check-module-size.sh`) в `precheck.sh` (и CI через него, ADR 0090). Извлекает
  `EMITTED` из `*/src` (литералы `"XX-NNN"`), `REGISTERED` из реестра; четыре
  условия отказа: незадокументированный код, протухшая запись (минус
  `RESERVED`/`RETIRED`), нарушение формата, дубль. Печатает по префиксам макс.
  занятый номер.
- **Указатели на источник истины:** README §7 (шапка со ссылкой на реестр),
  doc-комментарий `Diagnostic::with_code` (правило «новый код — сперва в реестр»),
  свод `docs/CODE.md` (новый раздел «Коды диагностик»).

## Проверки

```sh
./scripts/check-diagnostic-codes.sh   # зелёный: «реестр согласован (171 кодов)» + next-free
./scripts/precheck.sh                 # итоговый гейт (включая коды и детерминизм)
```

- **R1/A1** — гейт зелёный на 171 коде; пустых значений 0.
- **R3–R5/A2** — негативные пробы (undoc `ZZ-777`, stale `SE-099`, dup `SE-001`,
  формат `SE-4`) → exit 1; откат.
- **R4/A3** — stale + `RESERVED` → exit 0.
- **R6/A6** — вывод печатает макс. номер по префиксу.
- **R7/A7** — ни один код/текст не изменён; `precheck.sh` зелёный (двойной прогон,
  детерминизм 0048).
- **R8/A8** — указатели в README §7, `with_code`, `docs/CODE.md`.
