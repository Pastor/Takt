# Задача 0092-01: Заметка-норма «фичи без ADR» в реестре ADR

> Фича: [../features/0092-adr-0018-retrofit.md](../features/0092-adr-0018-retrofit.md) · ADR: [../adr/0092-adr-0018-retrofit.md](../adr/0092-adr-0018-retrofit.md) · анализ: [../analyze/0092-adr-0018-retrofit.md](../analyze/0092-adr-0018-retrofit.md)

## Что было

`docs/adr/0018-*` не существует; ссылки «по образцу 0018» могли вести к пустоте.
При проверке оказалось: `adr/0027`/`analyze/0027` уже уточнены («у 0018 нет ADR,
образец — 0024»), но **норма** «фичи без ADR — это законно» нигде не зафиксирована.

## Что сделано

В `docs/adr/README.md` (после вводного абзаца) добавлена **заметка-норма** (ADR
0092, Option B): до-процессные фичи (0001–0018) и фичи, не меняющие
архитектуру/синтаксис/семантику языка, ADR **не имеют** — это корректно по
действующему правилу реестра; ссылаться на них как на **образец ADR** нельзя
(образец — 0024); ретроспективные ADR постфактум не заводятся.

Ретроспективный `docs/adr/0018-*` **не создаётся** (решение ADR 0092). Только
документация — код/язык не затрагиваются.

## Проверки

- `grep "Фичи без ADR" docs/adr/README.md` — заметка присутствует.
- `grep -rn "adr/0018" docs/` — только мета-упоминания «не существует» + уже
  уточнённый `analyze/0027`; ни одной ссылки на `adr/0018-*` как на образец.
- `ls docs/adr/0018*` — отсутствует (ретро-ADR не заведён).
