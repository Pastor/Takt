# Задача 0021-04: документация и повышение версии языка

> Фича: [../features/0021-swap-assign-compare.md](../features/0021-swap-assign-compare.md) · ADR: [../adr/0021-swap-assign-compare.md](../adr/0021-swap-assign-compare.md) · анализ: [../analyze/0021-swap-assign-compare.md](../analyze/0021-swap-assign-compare.md)

> **Статус:** ВЫПОЛНЕНО. README (правило 15) и `CLAUDE.md` переведены на `:=`/`=`;
> инвариант `=`/`==` снят и переписан; версия языка (крейт `grammar`) повышена
> `0.0.5 → 0.1.0` (слом синтаксиса, правило 22). Doctests мигрированы в 0021-03.

## Что было

`README.md` детально описывает синтаксис/семантику (правило 15) в старой
операторной модели (`=` присваивание, `==` равенство). `CLAUDE.md` фиксирует
**инвариант `=`/`==`** как критический. Версия языка — прежняя.

## Что сделано (план)

1. **README (правило 15).** Обновить разделы синтаксиса/семантики и все примеры:
   `:=` — присваивание, `=` — сравнение, `<=` — «меньше-или-равно». Добавить
   таблицу-разграничение: `:=` (присваивание значения) vs `=` (сравнение) vs
   `=` в определениях имени. Добавить раздел «Миграция со старого синтаксиса»
   (ссылка на мигратор 0021-03).
2. **CLAUDE.md.** Снять/переписать инвариант `=`/`==`: теперь `=` — всегда
   сравнение; присваивание — `:=`. Обновить раздел «Критические инварианты».
3. **Doctests (правило 16).** Обновить компилируемые примеры в публичном API
   (`grammar/src/lib.rs` и пр.) на новый синтаксис; `cargo test` doctests зелёные.
4. **Версия языка (правило 22).** Слом синтаксиса → **мажорное** повышение
   версии языка. Зафиксировать в соответствующем месте (версия языка/крейта) и
   в `CHANGES.md`.
5. **Примеры и контрпримеры → документация (правило 16).** Перенести проверенные
   примеры из тест-плана в README.

## Проверки

- R5 (версия повышена), A6. README и doctests синхронизированы с реализацией.
- `cargo test -- --test-threads=1` (включая doctests) зелёные.
- Проверка целостности ссылок Markdown (правило 14) после правок доков.
