## P12 — ревизия doctests

**Сделано.** Два примера в `semantic/mod.rs` (`ModelNode::own_doc`,
`ModelNode::element_doc`) переведены из `rust,ignore` в **компилируемые и
исполняемые** doctests: вспомогательный код (импорты) скрыт строками `#`, `?`
заменён на `.unwrap()` (иначе нужен `-> Result`-обёртка). Теперь примеры
компилируются, исполняются и защищают публичный API от рассинхронизации.

Ожидаемые значения (`["Тест"]`, `["Состояние."]`) сверены с реальным выводом
исполнения и с интеграционными тестами `grammar/tests/semantic_tests.rs`
(`doc_comment_for_state` и т.п.) — не угаданы.

**Проверка.** `cargo test --doc --features lsp`: было 34 passed / 7 ignored →
стало **36 passed / 5 ignored** (два ранее игнорируемых примера теперь живые,
0 failed).

**Осознанно оставлены `ignore`.** Остальные `rust,ignore`/`ignore`
(`generator/indent.rs` — `Printer` в приватном модуле; `type_inference.rs`,
`tree.rs`, `docs.rs` — ссылки на внутренние/приватные функции; `simulation/lib.rs`
— иллюстративный поток через `Map::create`) корректно помечены как неисполняемые:
их код обращается к непубличным элементам либо является псевдокодом. Безымянные
` ``` `-фенсы уже компилируются (проверено ранее).

## P09 — возврат аргумента при `Err`: изменений не требуется

Требование CODE.md (возвращать потреблённый по значению аргумент в `Err`)
применимо к **дорогим владеемым** аргументам, когда у вызывающего есть сценарий
повторной попытки/восстановления. В проекте таких API нет:

- `simulation::unit::builder::build(model: Rc<RefCell<ModelNode>>)` — принимает
  `Rc`; вызывающий при желании клонирует счётчик (`Rc::clone`) до вызова —
  возвращать его в `Err` бессмысленно.
- `save(self)`/`save_output(self)` (`gif.rs`, `svg.rs`, `runner.rs`) — терминальные
  финализаторы (запись файла в конце): после них объект не переиспользуется, а
  сигнатура `Result<(), (Self, String)>` усложнила бы обычный путь без реальной
  пользы (нет вызывающего, который бы повторял запись тем же объектом).

Добавлять возврат `self` «на всякий случай» — нарушение YAGNI. **Вывод: изменений
не требуется**; при появлении API с дорогим владеемым аргументом и сценарием
повтора паттерн применить.
