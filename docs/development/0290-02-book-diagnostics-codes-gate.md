# Задача 0290-02: Приложение дополнено недостающими кодами

> Фича: [../features/0290-book-diagnostics-codes-gate.md](../features/0290-book-diagnostics-codes-gate.md) · ADR: [../adr/0290-book-diagnostics-codes-gate.md](../adr/0290-book-diagnostics-codes-gate.md) · анализ: [../analyze/0290-book-diagnostics-codes-gate.md](../analyze/0290-book-diagnostics-codes-gate.md)

## Что сделано

Сводная таблица приложения «Ошибки и предупреждения»
(`book/src/appendix-errors/index.typ`) приведена в соответствие с реестром.

**Добавлено 32 записи:**

| Секция | Коды |
|---|---|
| `LE` | `LE-010`, `LE-011` |
| `SE` | `SE-075`…`SE-089` (15 записей) |
| `CC` | `CC-014`, `CC-020`, `CC-021` |
| `RS` | `RS-023`, `RS-024` |
| `SV` | `SV-015`…`SV-019` |
| `ST` | `ST-017`…`ST-021` |

Из них четыре выведены и помечены `#emph[(снят)]` — `CC-014`, `CC-020`,
`RS-023`, `SE-082`, — как уже оформлены `SE-091`, `SE-093`, `ST-005`: номера не
переиспользуются, и старый код автор может встретить в чужом выводе.

**Удалена одна запись:** `SE-066` («периодическое действие `every` пока не
реализовано»). Код выведен задачей 0134-09, когда `every` научились все цели, —
справочник обещал диагностику, которой инструмент не выдаёт никогда.

⚠️ **Четырнадцать из добавленных кодов уже имели разбор** во второй части
приложения (`SE-075`, `SE-077`…`SE-080`, `SE-083`…`SE-089`, `ST-020`,
`SV-018`), но в сводной таблице не значились: читатель, идущий по таблице —
а она и есть вход в справочник, — кода не находил. Это и объясняет, почему
расхождение вышло больше, чем показывал греп по всему файлу (32 против 18).

## Тексты

Записи переписаны **для автора программы**: реестр писан для разработчика
инструмента и содержит номера фич и пути к исходникам, а правило 24 запрещает
им попадать в документ. Где у отказа есть обход, он назван прямо (`c-hal` для
`CC-021`, `st-at` для `ST-018`, `sv-mmio` для `SV-017`).
