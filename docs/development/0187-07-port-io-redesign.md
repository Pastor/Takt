# Задача 0187-07: Миграция корпуса, документа и тестов на `at`

> Фича: [../features/0187-port-io-redesign.md](../features/0187-port-io-redesign.md) · ADR: [../adr/0187-port-io-redesign.md](../adr/0187-port-io-redesign.md) · анализ: [../analyze/0187-port-io-redesign.md](../analyze/0187-port-io-redesign.md)

## Зачем именно сейчас

Порядок задач фичи — **01 → 07 → 02** (уточнён анализом). Миграция идёт сразу за
вводом `at`, до смены смысла `:=`: иначе между коммитами `out ready: bit := 0x600:0;`
означало бы «начальное значение 0x600:0», и предкоммит либо покраснел бы, либо —
хуже — принял бы молча неверный смысл.

## Что сделано

**Корпус, документ и фикстуры** (`.takt`, примеры в `.md`) — 106 объявлений в 41
файле переведены с `:= <адрес>` на `at <адрес>`:

```takt
-in task_valid: bit := 0x100:0;
+in task_valid: bit at 0x100:0;
```

**Inline-исходники тестов** (`.rs`) — 145 объявлений:

- 58 с настоящим адресом (`0x…`, число, форма `адрес:бит`) → `at`;
- 87 вида `:= 0` / `:= 1` → инициализатор **снят** (`in light: bit;`). Это был
  «адрес 0/1», который никто не имел в виду: тестам этих моделей адрес не нужен
  вовсе (цели `c`/`rust`/`sv` и симулятор его не потребляют), а после задачи
  0187-02 такая запись означала бы начальное значение — для входного порта
  незаконное.

**Не мигрированы намеренно:**

| Что | Почему |
|---|---|
| `out temperature: float := 0.0;` (3 места) | правая часть — **не адрес**; после 0187-02 запись получит тот смысл, который автор и имел в виду — начальное значение |
| файлы с тестами `SE-090`/`SE-091` (6 файлов) | они проверяют поведение **старой** формы и адреса 0/1; правка сломала бы сами сторожа. Их судьба решается задачей 0187-02 вместе с судьбой `SE-091` |
