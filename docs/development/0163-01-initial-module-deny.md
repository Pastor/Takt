# Задача 0163-01: Вынос вычислителя в unit/initial.rs с модульным deny и расширение гейта

> Фича: [../features/0163-builder-eval-exhaustive.md](../features/0163-builder-eval-exhaustive.md) · ADR: [../adr/0163-builder-eval-exhaustive.md](../adr/0163-builder-eval-exhaustive.md) · анализ: [../analyze/0163-builder-eval-exhaustive.md](../analyze/0163-builder-eval-exhaustive.md)

## Что было

`builder.rs::eval_expr` — второй вычислитель над `ExpressionNode` — разбирал 9
вариантов и сводил остальные 39 в `_ => None`. Ни компилятор, ни гейт
`check-exhaustive-nodes.sh` этого не замечали: правило ADR 0093 действовало
только в `takt-sim/src/eval/`.

Прецедент срабатывания уже был: ветвь `Duration` (фича 0134) пришлось вписывать
вручную после того, как `var left: duration := 1m30s;` молча осталась без
значения.

## Что сделано

### Новый модуль

`takt-sim/src/unit/initial.rs` — `eval_expr` (`pub(super)`) под
`#![deny(clippy::wildcard_enum_match_arm)]`. Имя модуля называет **тему** —
начальные значения переменных и портов, — а не место, откуда код переехал.

39 вариантов, прежде попадавших в `_ => None`, перечислены явно **одной ветвью**
«не константа» с объяснением, почему они таковы: читают состояние, зовут
функции, ветвятся или не являются выражением-значением. Поведение прежнее — те
же варианты дают тот же `None`.

⚠️ Модульный `deny` не отличает узлы языка от типов крейта, поэтому внутренний
`match` по `Value` в ветви `Negate` тоже стал исчерпывающим. Это **к лучшему**:
новое представление значения потребует решить, отрицаемо ли оно.

### Расширение гейта

`scripts/check-exhaustive-nodes.sh` проверяет `deny` теперь в **обоих**
модулях — `eval/mod.rs` и `unit/initial.rs`.

⚠️ **Мутация вскрыла слабость самого гейта:** прежний `grep -F` находил атрибут
внутри **док-комментария**, объясняющего, зачем он нужен, — то есть модуль без
атрибута, но с рассказом о нём, гейт проходил. Поиск привязан к началу строки
(`grep '^#!\[deny(...)\]'`). Это чинит **класс**, а не случай: тот же обман
работал и для `eval/`.

Обратная функциональность (правило 11): изменение внутреннее — публичный API,
поведение вычислителя, порождённый код и трассы прежние. Для прочих стеков —
**н/п**.

## Проверки

| Что | Результат |
|---|---|
| `cargo clippy --all-targets --all-features -- -D warnings` | чисто |
| `cargo test --all-features -- --test-threads=1` | зелёный |
| `scripts/check-module-size.sh` | `builder.rs` 927 → **896**, `initial.rs` 128; реестр долга не пополнен |
| `git diff examples/generated` | пусто |
| `./scripts/precheck.sh` | зелёный |

**Взведённость доказана тремя мутациями** — и ловят их **разные** механизмы:

| Мутация | Кто отвергает |
|---|---|
| вернуть `_ => None` по `ExpressionNode` | **компилятор** (`wildcard match will also match any future added variants`) |
| снять `deny` в `initial.rs` (док-текст сохранён) | **гейт**, код 1 |
| снять `deny` в `eval/mod.rs` | **гейт**, код 1 |

Вторая мутация и вскрыла слабость `grep -F`: до правки гейт её **не заметил**.
