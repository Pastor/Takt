# Задача 0221-01: Панель структуры: инвариант состояния символом не становится

> Фича: [../features/0221-lsp-state-invariant-symbol.md](../features/0221-lsp-state-invariant-symbol.md) · ADR: [../adr/0221-lsp-state-invariant-symbol.md](../adr/0221-lsp-state-invariant-symbol.md) · анализ: [../analyze/0221-lsp-state-invariant-symbol.md](../analyze/0221-lsp-state-invariant-symbol.md)

## Что было

Дети состояния в `takt-lang/src/lsp/symbols.rs` собирались из **одной** ветви —
`StateElement::NamedBlockCode`, остальное отсекала `_ => None`. Поэтому
`invariant Safe = …;` уровня модели становился символом `CONSTANT`, а такой же
`invariant Sane = …;` внутри состояния — ничем: одна конструкция языка была
видна в панели или невидима в зависимости от места объявления.

Поведение было пришпилено тестом `state_level_invariant_is_not_a_symbol_yet`
(фича 0147) — с прямым требованием снять его при осознанной смене.

## Что сделано

**1. `StateElement::Invariant` добавлен в сбор детей** с видом `CONSTANT` —
тем же, что у инварианта модели: разные виды показали бы одну конструкцию
двумя разными. Имя берётся через `?` (`name: Option<Identifier>`), как у
соседней ветви: `unwrap` здесь — паника сервера во время набора.

**2. Разбор `StateElement` стал исчерпывающим** — ветви `_` больше нет. У
каждой невключённой ветви стоит однострочное обоснование:

| Вариант | Почему не символ |
|---|---|
| `Every` | имени не объявляет: период — не идентификатор |
| `InlineFormula` | `: [Guard] …;` / `: [LTL] …;` — тоже без имени |
| `Next`, `Reference` | **ссылки** на чужое имя, а не объявления |
| `StraySemicolon` | нечего показывать |

Это сторож на будущее: пропущенный вид элемента не роняет ничего и не
диагностируется — панель просто беднее файла, и именно так дефект и дожил.

**3. Тесты.** Заглушка снята; вместо неё:

- `invariant_is_a_symbol_at_both_levels` — символ есть на обоих уровнях, вид
  один;
- `state_invariant_ranges_follow_the_contract` — `selection_range` покрывает
  имя, `range` начинается с `invariant` и содержит `selection_range`
  (отдельным тестом, а не строкой в списке пар: запись, забытая в списке,
  промолчала бы);
- `nameless_and_referencing_state_elements_are_not_symbols` — на своём входе
  с `every`, `: [Guard] …;` и `ref` детьми оказываются только `enter` и `Sane`.

Существующий `state_owns_its_named_blocks` обновлён: список детей теперь
`["enter", "always", "Sane"]`, проверка `kind == EVENT` осталась только для
блоков.

**4. Живой контекст `CLAUDE.md`** переписан: вместо записи «инвариант
состояния символом не становится — известный пробел» теперь сформулировано
правило («символом становится элемент, объявляющий имя») и названа
исчерпаемость разбора.

Обратная функциональность (правило 11): язык не менялся, версия языка не
поднимается; наблюдаемо меняется состав панели структуры — новый узел.

## Проверки

```sh

./scripts/precheck.sh                                       # код 0, 3112 тестов
```

сборку `E0004` в пяти местах, включая `takt-lang/src/lsp/symbols.rs:96`.
Мутация снята.
