# Задача 0235-01: Цели st и sv теряют охранную формулу

> Фича: [../features/0235-guard-formula-in-st-sv.md](../features/0235-guard-formula-in-st-sv.md) · ADR: [../adr/0235-guard-formula-in-st-sv.md](../adr/0235-guard-formula-in-st-sv.md) · анализ: [../analyze/0235-guard-formula-in-st-sv.md](../analyze/0235-guard-formula-in-st-sv.md)

## Что было

Цель `sv` не печатала охранную формулу **вовсе** — ни при опечатке, ни при
верном имени (находка фичи [0203](../features/0203-validate-formulas-traversal.md)).
Автор, собирающий FPGA, получал прошивку **без** объявленного им средства
безопасности, а компилятор рапортовал об успехе.

⚠️ При этом поле `SvMap::guard_enable` («эмитить ли guard-проверки — флаг
`--guard-disable` наоборот») существовало **с самого бэкенда** вместе с
геттером, и **ни один печатник его не читал**: заготовка без потребителя, тот же
класс, что 0194 и 0232.

## Что сделано

**Эмиссия охранных формул в `sv_blocks.rs`** (не в `sv_fsm.rs`: тот — 998 строк
при пределе 1000): `emit_state_guards` / `emit_model_guards`, обе через общий
`emit_guard`.

- **Форма выбрана пробой, а не вкусом:** `assert (<условие>);`. Проба
  2026-08-15: `assert (…) else $error("…");` **verilator принимает**, а **yosys
  отвергает** (`syntax error, unexpected TOK_ELSE`). Поэтому имя инварианта
  (0044) в цель `sv` **не переносится** — это свойство синтезатора, а не
  недоделка; цель `rust` его печатает, `c` игнорирует.
- **Место — там же, где у цели `c`:** формулы модели перед `unique case`,
  формулы состояния первыми в его ветви. Проверка стоит **до** присваиваний, а
  умолчание `name_next = name` уже выполнено — значит условие читает значения на
  начало такта, как `assert` в начале `_tick` цели `c`.
- **Синтез не задет:** проба показала 29 ячеек, из них `$check` — одна, логика
  прежняя (8 `$_DFF_PN0_`).
- **`guard_enable` ожил:** `--guard-disable` подавляет проверки и в цели `sv`.

Функциональности: **цель `sv`** — да; **прочие цели, симулятор, семантика** —
н/п (не тронуты).

## Проверки

```sh
cargo test --test guard_targets_tests   # 6 тестов, зелено
```

| Критерий | Тест |
|---|---|
| A1 печатается `assert` (обе формулы) | `sv_emits_guard_assertion` |
| A2 принимают **оба** инструмента | `sv_guard_output_is_accepted_by_both_tools` |
| A3 формы с `else`/`$error` нет | `sv_guard_has_no_else_branch` |
| A4 `--guard-disable` подавляет | `sv_guard_disable_suppresses_assertions` |
| A5 трасса не изменилась | `conformance_sv_tests` (предкоммит) |

**Мутация:** снятие обеих ветвей `if map.guard_enable()` красит
`sv_emits_guard_assertion`.
