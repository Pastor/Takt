# Задача 0274-01: Гейт снимков порождённого кода и его сторож

> Фича: [../features/0274-book-generated-snapshots-gate.md](../features/0274-book-generated-snapshots-gate.md) · ADR: [../adr/0274-book-generated-snapshots-gate.md](../adr/0274-book-generated-snapshots-gate.md) · анализ: [../analyze/0274-book-generated-snapshots-gate.md](../analyze/0274-book-generated-snapshots-gate.md)

## Что было

Приложение «Порождённый код примера» читает файлы
`book/src/**/generated/<цель>/…` напрямую, то есть показывает их как вывод
компилятора. Сверял их только человек — и делал это ровно для той цели, которая
была предметом очередной фичи (0195, затем 0213). Соседние цели не смотрел
никто: три снимка из шести отстали, самый старый — с 2026-07-25.

## Что сделано

**`scripts/check-book-generated.sh`** — гейт. Обходит каталоги
`book/src/**/generated/<цель>`, ищет соседний пример по имени файла снимка
(`lift.rs` → `../examples/lift.takt`), компилует его этой целью во временный
каталог и сравнивает `diff -r`. Частота такта берётся из объявления `clock`
примера — иначе цель `c` отвечает `SE-069`, и гейт падал бы не по делу
(снимок `fan` из раздела «Время» — как раз такой случай). Флаг `--update`
пересобирает снимки на месте; переменная `BG_ROOT` задаёт корень (для сторожа).

**Снимок без соседнего `examples/` — отказ.** Источник такого файла неизвестен,
сверять его не с чем, и молчание сделало бы гейт выборочным.

**`scripts/test-book-generated.sh`** — сторож (шаг предкоммита). Работает на
**копии** дерева: согласованные снимки принимаются; мутация одного файла
ловится и отказ **называет каталог**; `--update` восстанавливает согласие;
снимок без примера отвергается.

**Снимки обновлены** — три отставших: `rust` и `sv` (имя константы без
квалификации владельцем, фича 0193; отсутствие `assert` инварианта, фича 0235),
`st` (отсутствие блока первого скана, фича 0191 — снимок описывал автомат,
сдвинутый на такт).

**Обратная функциональность (правило 11):** инструменты не менялись; правятся
данные документа и добавляются два шага предкоммита.

## Проверки

```sh
sh scripts/check-book-generated.sh          # OK: снимки совпадают (целей: 6)
sh scripts/test-book-generated.sh           # 5 проверок сторожа
./scripts/precheck.sh                       # код 0
```

**Мутация:** дописанная строка в `generated/rust/lift.rs` роняет гейт с
названием каталога; `--update` возвращает зелёный прогон.
