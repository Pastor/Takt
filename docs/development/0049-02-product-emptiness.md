# Задача 0049-02: Произведение автоматов и проверка пустоты

> Фича: [../features/0049-model-checking-ltl.md](../features/0049-model-checking-ltl.md) · ADR: [../adr/0049-model-checking-ltl.md](../adr/0049-model-checking-ltl.md) · анализ: [../analyze/0049-model-checking-ltl.md](../analyze/0049-model-checking-ltl.md)

## Что было

`BuchiAutomaton` (`verification/buchi.rs:71`): `states: Vec<BTreeSet<Rc<Ltl>>>`,
`initial_states`, `transitions: BTreeMap<usize, BTreeSet<usize>>`, `accepting`.
**Разметка рёбер неявна**: литералы (`Atom`/`Not(Atom)`) лежат в `states[i]` —
извлекаются фильтром `matches!(f, Ltl::Atom(_) | Ltl::Not(_))` (образец —
`buchi.rs:90-96`). Проверки пустоты нет (`grep emptiness|nested_dfs|scc` = 0).

## Что сделано

> **Планируется (разработка не начата).** План по ADR 0049.

1. **Разметка автомата.** Функция `state_literals(&BuchiAutomaton, q) ->
   (BTreeSet<String> pos, BTreeSet<String> neg)` — множества требуемых истинных и
   ложных атомов состояния `q` (из `states[q]`).
2. **Синхронное произведение** `verification/product.rs`:
   `product(&Kripke, &BuchiAutomaton) -> Product`, где состояние — пара `(k, q)`.
   Переход `(k,q)→(k',q')` ⟺ `k→k'` (Крипке), `q→q'` (автомат) и **согласование**:
   для каждого `pos`-атома `S` состояния `q'` — `k'` есть состояние `S`; для
   каждого `neg`-атома `!S` — `k' ≠ S`. Начальные — `(initial_k, q0)` для всех
   `q0 ∈ initial_states`, согласованные. Принимающие — где `q ∈ accepting`.
3. **Проверка пустоты** `verification/check.rs`: достижимый из начальной пары
   **принимающий цикл** — классический **nested-DFS** (внешний DFS помечает
   принимающие в постпорядке, внутренний ищет обратное ребро в стек внешнего).
   Возвращает `Option<Lasso>`.
4. **Контрпример-лассо** (R6): при непустоте — путь «префикс до принимающей
   вершины + цикл через неё», спроецированный на **имена состояний Крипке**
   (`states[k]`). Помечается «абстракция управления» (over-approximation).

## Проверки

- Юнит-тесты на эталонных парах (Крипке, φ): пустой продукт (свойство держится) и
  непустой (нарушение с лассо). Тесты — **на вердикт/лассо**, не «автомат непуст».
- Известные теоремы (A7/A8): `F p` при недостижимом `p` → непусто (нарушено);
  `G p` при достижимом `!p` → непусто.
- Соответствие анализу: R3 (частично — вход `build_buchi` в 0049-03), R4, R5, R6.
