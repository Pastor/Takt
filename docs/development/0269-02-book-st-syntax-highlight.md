# Задача 0269-02: Гейт языков блоков кода

> Фича: [../features/0269-book-st-syntax-highlight.md](../features/0269-book-st-syntax-highlight.md) · ADR: [../adr/0269-book-st-syntax-highlight.md](../adr/0269-book-st-syntax-highlight.md) · анализ: [../analyze/0269-book-st-syntax-highlight.md](../analyze/0269-book-st-syntax-highlight.md)

## Что сделано

`scripts/check-book-code-langs.py` (шаг предкоммита, самопроверка первой): язык
блока ```ЯЗЫК обязан быть **объявлен** — либо встроенным в syntect, либо своим
файлом, который существует **и подключён** в шаблоне.

| Класс | Находка |
|---|---|
| `C1` | язык блока не объявлен ни в одном списке |
| `C2` | объявлен как свой, но файла `book/*.sublime-syntax` нет |
| `C3` | файл есть, но в `template.typ` не подключён |
| `C4` | язык объявлен в гейте, а блоков этого языка в документе нет |

⚠️ **`C3` — самая тихая поломка:** определение лежит, подсветки нет, ошибки
нет. Ради неё гейт и проверяет подключение, а не только наличие файла.

⚠️ **`C4` — ратчет**: мёртвая запись обещает подсветку, которой никто не
пользуется (образец — `KNOWN_GAPS` форматтера и реестр размеров модулей).

⚠️ Пустое множество блоков — **ошибка**: при смене разметки проверка
выполнилась бы тривиально (урок фикса 0202-01).

Гейт проверяет **объявленность**, а не цвет: цвет смотрит человек по рендеру
(правило 4) — та же граница, что у гейта шрифта 0146.

## Проверка

python3 scripts/check-book-code-langs.py --self-test   # 4 класса + контроль
