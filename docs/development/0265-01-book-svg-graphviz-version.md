# Задача 0265-01: Вычистка версии и каталог бинарников

> Фича: [../features/0265-book-svg-graphviz-version.md](../features/0265-book-svg-graphviz-version.md) · ADR: [../adr/0265-book-svg-graphviz-version.md](../adr/0265-book-svg-graphviz-version.md) · анализ: [../analyze/0265-book-svg-graphviz-version.md](../analyze/0265-book-svg-graphviz-version.md)

## Что сделано

**`book/scripts/render_verify_graphs.sh`:**

1. строка версии graphviz вычищается сразу при генерации —
   `sed 's/^<!-- Generated by graphviz version .*$/…(версия вычищена: фича 0265)…/'`
   после `svg_flatten_text.py`;
2. путь к `taktc` берётся у **единственного носителя**
   `scripts/target-dir.sh` (фича 0301). Прежняя копия (`target/debug`)
   сломалась в день фичи 0251 и приводила к молчаливой неудаче с нулевым кодом
   возврата.

**`scripts/precheck.sh`:**

- после сборки документа проверяются **committed** файлы: в
  `book/src/*/images/*.svg` нет строки `graphviz version`, а `.dot`-исходники
  непусты;
- комментарий о выборе цели `pdf` вместо `build` исправлен: причина
  «регенерация переписывает SVG» снята этой фичей, осталась настоящая — шрифт
  ГОСТ и собранный `taktc` есть не у всех.

**Пустышка наполнена:** `lift-kripke.dot` лежал в репозитории **пустым** — след
той самой молчаливой поломки.

## Проверка

```sh
book/scripts/render_verify_graphs.sh   # дважды: дерево не меняется
grep -rn 'graphviz version' book/src/*/images/*.svg   # пусто
```
