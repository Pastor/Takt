# Задача 0209-02: Стенд внешних функций из сценария

> Фича: [../features/0209-model-external-interface.md](../features/0209-model-external-interface.md) · ADR: [../adr/0209-model-external-interface.md](../adr/0209-model-external-interface.md) · анализ: [../analyze/0209-model-external-interface.md](../analyze/0209-model-external-interface.md)

## Что было

`extern fn mem_read(addr: u8) -> u8;` цель `c` принимала колбэком HAL, а эталон
отвечал `SIM-019` **в такте** и останавливал прогон: модель с внешним
интерфейсом была непроверяема эталоном.

## Что сделано

**1. Секция `extern` в шаге сценария** (`json_input.rs`): на функцию — либо одно
значение (`"mem_read": 42`), либо таблица по **первому** аргументу
(`"mem_read": {"0": 9, "1": 8}`). Поле необязательно: старые сценарии читаются
без правки.

**2. Стенд ставится перед тактом** тем же приёмом, что модельное время
(`Unit::set_extern_stubs`, рекурсивно по дереву — ветви композиции живут в одном
шаге сценария).

**3. Вызов спрашивает стенд** (`unit/statement.rs`), и **только** если стенд
молчит, отвечает прежним `SIM-019`. ⚠️ Умолчания нет намеренно: ноль сделал бы
прогон зелёным там, где эталон и прошивка расходятся.

⚠️ **Стенд обязан доезжать до всех областей видимости.** При первой сборке
подмена не срабатывала: тело блока и тело функции исполняются в своих контекстах
(`BlockScope`/`FunctionScope`), а такт идёт с `Unit` в роли контекста — умолчание
трейта (`None`) в любом из трёх мест означает «стенда нет». Реализовано во всех
трёх.

**4. Ошибка сценария называется:** нечисловой ключ таблицы или нечитаемое
значение — отказ с именем функции и номером шага, а не молчаливый пропуск.

## Проверки

- `takt-sim/tests/extern_stub_tests.rs` — 5 тестов: таблица по аргументу
  (разные значения по тактам), одно значение на такт, **контр-пример** «без
  стенда — прежний отказ», **контр-пример** «стенд принадлежит шагу», ошибка
  сценария на нечисловом ключе.
- `./scripts/precheck.sh` — зелёный; вывод корпуса неизменен.
