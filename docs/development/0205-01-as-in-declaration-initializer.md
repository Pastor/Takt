# Задача 0205-01: Приведение as не вычисляется в инициализаторе объявления

> Фича: [../features/0205-as-in-declaration-initializer.md](../features/0205-as-in-declaration-initializer.md) · ADR: [../adr/0205-as-in-declaration-initializer.md](../adr/0205-as-in-declaration-initializer.md) · анализ: [../analyze/0205-as-in-declaration-initializer.md](../analyze/0205-as-in-declaration-initializer.md)

## Что было

Второй вычислитель эталона (`takt-sim/src/unit/initial.rs`, фича 0163) относил
`Cast` и `Variable` к «не константе», поэтому объявление с приведением получало
**значение по умолчанию** — ноль. Замер (матрица в ADR): шесть форм из восьми
расходились с целью `c` **молча** (`5 as u16` → эталон 0, цель 5), две падали
`SIM-006` **в такте**.

## Что сделано

**1. Ветвь `Cast` зовёт `eval::cast_to_type`** — ту же функцию, что считает
приведение в такте. Своей арифметики приведения второй вычислитель не заводит:
иначе эталон разошёлся бы сам с собой между инициализатором и телом (класс
0134-02 — узел языка разбирают три места, и они расходятся).

**2. Ветвь `Variable` берёт значение константы из ТАБЛИЦЫ объявлений**
(`ModelNode::search_var`), а не из ячейки ссылки: в ячейке лежит снимок,
снятый при разрешении имени, и инициализатор в нём — ещё не понижённый
`Unresolved(АСД)` (урок 0204). Падение обратно на снимок сохранено для вызовов
без области видимости.

**3. Предел глубины `MAX_REF_DEPTH = 32`.** Взаимные константы
(`const A := B; const B := A;`) семантикой разрешаются, но значения не имеют —
без предела обход по инициализаторам ушёл бы в бесконечную рекурсию.

**4. Сигнатура.** Появился `eval_expr_in(expr, model)`; прежний
`eval_expr(expr)` сохранён (зовётся там, где области видимости нет) — вызовы в
`builder.rs` разведены по надобности.

**Обратная функциональность (правило 11):** правка целиком в крейте `takt-sim`;
`takt-lang` не затронут, вывод целей не меняется вовсе. Меняется значение,
которое эталон даёт на форме, где оно было заведомо неверным (ноль).

## Проверки

- `takt-sim/tests/cast_in_initializer_tests.rs` — 10 тестов: восемь форм
  матрицы (эталон сверяется **с тем, что печатает цель `c`**, а не с числом от
  автора теста), завершение на взаимных константах, ссылка без приведения.
- **Мутация:** правки сняты (`git stash`) — краснеют 8 из 10. Зелёными остаются
  осознанно: завершение (ломать было нечего) и ссылка без приведения (её и
  прежде спасала свёртка 0192).
- `cargo test` целиком и `./scripts/precheck.sh` — зелёные; вывод корпуса
  `examples/generated/` байт-в-байт неизменен.
