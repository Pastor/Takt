# Задача 0383-01: Приведение дробного литерала к `q(m, n)` в теле

> Фича: [../features/0383-fixed-cast-literal-in-body.md](../features/0383-fixed-cast-literal-in-body.md) · ADR: [../adr/0383-fixed-cast-literal-in-body.md](../adr/0383-fixed-cast-literal-in-body.md) · анализ: [../analyze/0383-fixed-cast-literal-in-body.md](../analyze/0383-fixed-cast-literal-in-body.md)

## Что было

Значение `2.5 as q(8, 8)` известно при компиляции (`const_eval::fixed_repr`,
0317), но носитель звался только из свёртки инициализаторов. В теле цель `c`
печатала `(int16_t)floor((2.5) * 256.0)` — вызов libm в рантайме ради
константы, а `st`, `st-at`, `rust`, `sv`, `sv-mmio` отказывали (`ST-011`,
`RS-011`, `SV-002`) на записи, которую эталон исполняет.

## Что сделано

**1. Общая обёртка для целей.** `generator/fixed_literal.rs`:
`cast_repr(inner, target)` отвечает «это приведение литерала, и вот его
представление». Счёт — у `const_eval::fixed_repr` (0317); в носитель добавлен
узкий вход `from_decimal_text` (печатник видит текст литерала, а разбор
десятичной записи живёт внутри константного вычислителя).

**2. Четыре печатника спрашивают обёртку.** `c` (уходит рантайм-`floor`), `st`,
`rust`, `sv` — и с ними `c-hal`, `st-at`, `sv-mmio`, у которых те же печатники.
У цели `sv` проверка стоит **до** печати источника: вещественный литерал сам по
себе отвергается `SV-002`, и печать пришла бы раньше.

**3. Форма печати у `sv` — размерный литерал** (`16'd640`): безразмерный даёт
`WIDTHEXPAND`, а гейт цели считает предупреждение ошибкой (уроки 0157, 0349).
Отрицательное значение печатается через унарный минус — размерный литерал в SV
беззнаков.

**4. Побочная правка у цели `rust`: приведение операнда — по нужде.** Литерал в
q-арифметике до фичи оказаться не мог (приведение отвергалось), а с фичей
`512 as i128` — это `clippy::unnecessary_cast`, то есть **отказ гейта самой
цели**; поймала это проба (класс 0263/0361). Признак задаётся напечатанному
тексту — печать литерала принадлежит соседним ветвям, и второй способ узнать
«это литерал» разошёлся бы с первым.

⚠️ **Семантическое дерево не трогалось, и это измерено.** Напрашивающаяся
подмена узла на целое-представление ломает законный вход: проверки идут ПОСЛЕ
понижения, и `q * Number` ловит `SE-059` — то есть запись
`gain * (2.0 as q(8, 8))`, которой автор смешение снимает, стала бы незаконной
(ADR 0383, Option A).

Статус по функциональности (правило 11): правка в **целях генерации**
(`takt-lang/src/generator/`), эталон не трогался. Редакторский слой — «н/п»
(обоснование в анализе, правило 29).

## Проверки

```sh
cargo test --all-features
cargo test --test conformance conformance_fixed_cast_literal_tests::
scripts/probe.sh -n 4 takt-sim/tests/data/eval/conformance_fixed_cast_literal.takt
./scripts/precheck.sh
```

- **Значения** (T1–T3, T5): трасса эталона и порождённого C совпадает —
  `[2,2,0,1]`, `[2,4,2,1]`, `[2,8,6,1]`, `[2,16,14,1]`.
- **Инструменты** (T6): все восемь целей переводят, арбитры приняли; до правки
  пять целей отказывали.
- **Мутации** (T11): «носитель → `None`» и «искажение представления на
  единицу» роняют сверку. ⚠️ Вторая мутация **сначала не ловилась**:
  наблюдаемые `as u8` грубы. Фикстура усилена кросс-проверкой путей (`eq_v`
  сравнивает значение из тела со значением того же литерала из объявления) —
  после этого ловятся обе.
- **Корпус** (T10): вывод `examples/generated/` не изменился.
