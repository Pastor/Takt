# Задача 0374-01: Приведение, совпадающее после отображения типа

> Фича: [../features/0374-mapped-type-cast.md](../features/0374-mapped-type-cast.md) · ADR: [../adr/0374-mapped-type-cast.md](../adr/0374-mapped-type-cast.md) · анализ: [../analyze/0374-mapped-type-cast.md](../analyze/0374-mapped-type-cast.md)

## Что было

Признак фичи 0361 (`from == *ty`) сравнивал типы **Takt**. Запись
`ms := d as u32;` при `d: duration` под него не подпадала, и цель `rust`
печатала `self.d as u32` — `clippy::unnecessary_cast`, то есть отказ гейта
цели при нулевом коде возврата `taktc`.

## Что сделано

- **`rust`** (`rust_expr.rs`): признак `same_printed_type` сравнивает
  `rust_type(тип операнда)` и `rust_type(цель приведения)`.
- **`c`** (`c_expr/expr.rs`): то же через `c_type_or_diagnostic` — сравнение с
  уже вычисленным `type_c`.
- **`sv`** (`sv_expr.rs`): `same_printed_type` сравнивает объявления
  `sv_type(...).declare("x")` — так в одну строку сходятся ширина, знаковость
  и упакованность.
- Неотобразимый тип операнда признак не судит (`false`): печать самого
  приведения выдаст диагностику.

**Статус по функциональности (правило 11).** Затронуты `c`/`c-hal`, `rust`,
`sv`/`sv-mmio`; `st`/`st-at` — **н/п** (приведения не печатает вовсе),
`plantuml` и эталон — **н/п**.


⚠️ **Два чужих теста пришлось обновить** (сверки 0183): они требовали текста
`(uint32_t)model->elapsed` и `self.elapsed as u32` — утверждения, переставшего
быть верным (класс 0329). Предмет их проверки — отсутствие пересчёта единиц —
сохранён и усилен: теперь они же требуют, чтобы приведения **не** было.

⚠️ Имя переменной в контрпримере пришлось сменить: `small` — ключевое слово
SystemVerilog (`SV-012`), и проба падала не на предмете.
