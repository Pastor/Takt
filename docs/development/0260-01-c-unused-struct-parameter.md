# Задача 0260-01: Заглушка неиспользуемого параметра

> Фича: [../features/0260-c-unused-struct-parameter.md](../features/0260-c-unused-struct-parameter.md) · ADR: [../adr/0260-c-unused-struct-parameter.md](../adr/0260-c-unused-struct-parameter.md) · анализ: [../analyze/0260-c-unused-struct-parameter.md](../analyze/0260-c-unused-struct-parameter.md)

## Что было

Порождённый C давал **49** предупреждений `-Wunused-parameter` на корпусе
(цель `c`) и **45** у `c-hal`; в обоих гейтах класс был отключён флагом
`-Wno-unused-parameter`, то есть не сторожил ничего, а в сборке пользователя —
шумел. Под `-DNDEBUG` предупреждений было **больше** (53): часть функций
«спасала» строка `assert(0 != main);`, которая в релизе исчезает.

## Что сделано

- новый модуль `generator/c/c_params.rs`: признак «параметр телом не
  используется» (по **границам идентификатора**, с игнорированием строк
  `assert(…)`) и текст заглушки `(void)param;`;
- `Printer::copy` (мёртвый, под `#[allow(dead_code)]`) заменён на `fork` с
  **независимым** лайфтаймом приёмника — прежний связывал лайфтаймы, из-за чего
  буфер было не прочитать, и метод не звал никто;
- `c_model.rs`: тела `_init` и `_tick` печатаются в буфер, по нему решается
  заглушка; `_is_done` получает её по своему условию (тело корнем не
  пользуется никогда);
- `c_decl.rs`: то же для параметра `model` пользовательских функций — тело там
  уже собиралось в буфер;
- `c_hal.rs`: то же для `m` в `<Root>_bind_default_hal` (он `static inline` в
  заголовке — предупреждение уезжало к пользователю);
- `precheck.sh`: `-Wno-unused-parameter` убран из **обоих** гейтов.

**Функциональность:** `takt-lang` (цель `c`, общий `Printer`); поведение
порождённого автомата не меняется — `(void)x;` компилятор отбрасывает.

## Проверки

```sh
cargo test --all-features      # 3296 тестов, 0 провалов
./scripts/precheck.sh          # код 0, оба гейта без -Wno-
```

Замер после правки (корпус, `cc -std=c11 -Wall -Wextra`): цель `c` — **0** и
без `-DNDEBUG`, и с ним; `c-hal` — **0** в обоих режимах.

Снапшоты `examples/generated/c` обновлены предкоммитом (7 файлов, 23 строки).
Снимки `book/` перегенерированы (см. отчёт: попутно устранено их отставание от
фичи 0195).
