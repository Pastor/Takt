# Задача 0062-02: Внешняя карта адресов для `sv-mmio` + потактовая сверка

> Фича: [../features/0062-sv-mmio-target.md](../features/0062-sv-mmio-target.md) · ADR: [../adr/0062-sv-mmio-target.md](../adr/0062-sv-mmio-target.md) · анализ: [../analyze/0062-sv-mmio-target.md](../analyze/0062-sv-mmio-target.md)

## Что было

`bin/lamc.rs:532` — условие `if !external_entries.is_empty() && options.target != "c-hal"`
отсекает внешнюю карту (`--address-map`) для **всех** целей, кроме `c-hal`.
Потактовой сверки у `sv-mmio` нет (цели нет).

## Что сделано

1. **Расширить отсечение** (правило 7 ADR): карта принимается и для `sv-mmio`.
   Правка **аддитивна** (правило 11): где карта отсекалась, она отсекается
   по-прежнему. Это **единственная** правка вне новой цели.
2. **Приоритет источников не трогать** (правило 8): inline < `address` < внешняя
   карта — контракт фичи 0020.
3. **Потактовая сверка** `conformance_sv_tests` — новый режим наблюдения:
   значения читаются **со стороны шины** (чтение регистра), а не иерархической
   ссылкой `dut.<сигнал>`.
   ⚠️ **Наблюдение берётся оттуда, откуда его берёт потребитель** (правило
   проекта, `CLAUDE.md`): у `c` — поля структуры, у `sv` — иерархическая ссылка,
   у `rust` — выходные порты через HAL. У `sv-mmio` потребитель — шина.
   ⚠️ **Сверку заводить ВМЕСТЕ с целью, а не после** (уроки 0045 и 0050): у 0045
   дефект «`always_comb` читает регистр вместо `_next`» приняли **оба**
   инструмента; у 0050 сверки не было вовсе при зелёном гейте — пробел нашла
   приёмка.

## Проверки

- **T9/A8:** `--address-map` с `-t sv-mmio` принимается; с прочими целями (кроме
  `c-hal`) — по-прежнему отсекается.
- **T10:** приоритет inline < `address` < карта — прежний.
- **T4/A4 — ОСНОВНАЯ:** трасса `sv-mmio` (через регистры) = трасса симулятора на
  каждом такте.
- **T6/T7/A6:** запись в бит `out` игнорируется; чтение бита `in` возвращает
  записанное.
- `./scripts/precheck.sh` — все гейты зелёные; вывод прочих целей не изменился.
