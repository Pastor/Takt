# Задача 0255-01: Коды `SIM-030`…`SIM-032` — отдельным литералом и в реестр

> Фича: [../features/0255-sim-diagnostic-codes-registry.md](../features/0255-sim-diagnostic-codes-registry.md) · ADR: [../adr/0255-sim-diagnostic-codes-registry.md](../adr/0255-sim-diagnostic-codes-registry.md) · анализ: [../analyze/0255-sim-diagnostic-codes-registry.md](../analyze/0255-sim-diagnostic-codes-registry.md)

## Что было

`takt-sim/src/runner.rs` печатал три кода **внутри текста** сообщения:

```rust
"Ошибка [SIM-030]: шаг {step_no}: порт `{name}` не найден в модели"
```

Гейт `scripts/check-diagnostic-codes.sh` собирает эмитируемые коды строковыми
литералами `"XX-NNN"` (ADR 0077) — для него такого кода не существует. В
`docs/diagnostics/README.md` их тоже не было: **с обеих сторон пусто**, прогон
зелен, а пользователь коды в выводе видит. Так они прожили от фичи 0132.

Сосед `SIM-037` (фича 0150) заведён верно — `const CODE: &str = "SIM-037";` —
и его комментарий прямо называл соседей как незакрытый долг.

## Что сделано

- **`SIM-030` и `SIM-031`** — константы `NOT_FOUND`/`AMBIGUOUS` в начале
  `check_port_name` (код `SIM-030` печатается **дважды**: для
  квалифицированного имени и для голого, поэтому константа одна на оба места).
- **`SIM-032`** — константа `CODE` рядом с местом печати в `resolve_values`.
- Комментарий у констант называет **причину** формы, а не сам факт: гейт
  собирает коды литералами, и вплавленный невидим — вместе со ссылкой на
  условие 5, которое теперь этот возврат ловит.
- Три строки в `docs/diagnostics/README.md` (порядок номеров: после `SIM-029`,
  перед `SIM-034`), каждая называет предмет и фичу-источник (0132).

**Обратная функциональность (правило 11):** тексты сообщений **не изменились** —
подстановка `{CODE}` даёт прежнюю строку; тесты 0132/0150, сверяющие коды в
выводе (`named_port_scenario_tests.rs`), зелены без правки.

## Проверки

```sh
grep -rhoE '"SIM-0(3[0-2])"' takt-sim/src   # три литерала
grep -rn '\[SIM-03' takt-sim/src            # пусто: вплавленной формы нет
sh scripts/check-diagnostic-codes.sh        # зелен, 264 кода
cargo test -p takt-sim                      # 274 + 117 + 163 — 0 провалов
```
