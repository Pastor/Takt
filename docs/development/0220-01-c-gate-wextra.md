# Задача 0220-01: Флаг -Wextra для гейта цели c: 38 предупреждений одного класса

> Фича: [../features/0220-c-gate-wextra.md](../features/0220-c-gate-wextra.md) · ADR: [../adr/0220-c-gate-wextra.md](../adr/0220-c-gate-wextra.md) · анализ: [../analyze/0220-c-gate-wextra.md](../analyze/0220-c-gate-wextra.md)

## Что было

Оба гейта цели `c` собирали порождённый код под `-Wall -Werror` (фича 0171).
Следующая ступень строгости не бралась: `-Wextra` давал предупреждения, и 0171
сознательно не смешивала включение флага с правкой сигнатур генератора.

## Что сделано

Оба гейта в `scripts/precheck.sh` переведены на
**`-Wall -Wextra -Wno-unused-parameter -Werror`**:

| Гейт | Где | Как |
|---|---|---|
| корпус `examples/generated/c` | `cmake -DCMAKE_C_FLAGS=…` | флаги задаёт гейт, не поставляемый `CMakeLists.txt` |
| дефолтный HAL цели `c-hal` | `cc -std=c11 … -c` | те же флаги: политика двух гейтов одна |

Замер, на котором стоит решение (2026-08-17, прогон `cc` по всему корпусу и по
выводу `c-hal` для всех примеров):

| Что собирали | `-Wall -Wextra` | `+ -Wno-unused-parameter` |
|---|---|---|
| корпус (39 файлов, с харнессами) | 49 — все `-Wunused-parameter` | **0** |
| `c-hal` (9 примеров) | 45 — все `-Wunused-parameter` | **0** |

Разбивка класса: `main` — 41+36, `model` — 8+7, `m` — 2. Это структурные
параметры, которые генератор эмитит единообразно; правка сигнатур в объём не
взята (решение ADR, Option A → кандидат).

Комментарии обоих гейтов переписаны: назван отключённый класс, его размер, дата
замера, причина и способ снять («убрать `-Wno-unused-parameter` в двух
местах»). Живой контекст `CLAUDE.md` приведён в соответствие — прежняя запись
обещала `-Wall -Werror` и «`-Wextra` — кандидат».

В блок кандидатов `FEATURES.md` заведена работа «эмитить структурный параметр
по нужде» вместе с замером и указанием на образец — предикат `needs_hal` цели
`rust`.

Обратная функциональность (правило 11): меняются флаги **гейта**, а не
поставляемого `CMakeLists.txt`; порождённый код и язык прежние, версия языка не
поднимается.

## Проверки

```sh
sh -n scripts/precheck.sh                  # синтаксис
./scripts/precheck.sh                      # код 0 — строгость бесплатна
git status --porcelain examples/generated/ # пусто — генератор не трогали
```

Мутация (A3): в копию корпуса внесено сравнение знакового с беззнаковым;
`cc -Wall -Werror` его **не видит**, а сборка с флагами гейта падает
`error: comparison of integers of different signs [-Werror,-Wsign-compare]`.
То есть флаг работает, а не просто вписан.
