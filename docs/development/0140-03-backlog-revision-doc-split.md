# Задача 0140-03: разделение ролей README ↔ `book/`

> Фича: [../features/0140-backlog-revision-doc-split.md](../features/0140-backlog-revision-doc-split.md) · ADR: [../adr/0140-backlog-revision-doc-split.md](../adr/0140-backlog-revision-doc-split.md) · анализ: [../analyze/0140-backlog-revision-doc-split.md](../analyze/0140-backlog-revision-doc-split.md)

## Что было

`README.md` — 2708 строк; разделы «4. Синтаксис» (306) и «5. Семантика» (207)
описывали язык. Тем же занят `book/` — 3356 строк, 17 разделов и приложения.
Правило 15 требовало детального README, правило 24 — актуального `book/`; обе
обязанности исполнялись вручную, гейта согласованности не было. Дрейф уже
случался: `Takt.ebnf` отстал от реформы операторов фичи 0021.

## Что сделано

**Роли разделены** (решение заказчика): README описывает **проект и
инструментарий**, `book/` — **язык**.

1. **Разделы 4–5 README сжаты** с 513 строк до 80: остались обзорный пример
   (сторожевой таймер), таблица «где что описано» со ссылками на 12 разделов
   документа и пять тезисов о ключевых решениях языка — каждый со ссылкой.
   README: 2708 → 2275 строк.
2. **Правило 15 свода переформулировано:** «README детально описывает проект и
   инструментарий; описание языка живёт только в `book/`». В формулировку внесён
   и довод: дубль снят **разделением ролей**, а не сверкой — сверить прозу
   нельзя, а два источника по одному предмету расходятся неизбежно.
3. **Оглавление README** согласовано с новыми заголовками.

⚠️ **`book/` не тронут** — он уже был единственным полным описанием языка; фича
лишь сняла дубль. `git diff` по `book/` пуст.

⚠️ **Что НЕ удалено:** разделы 6 («Примеры»), 7 («Ограничения и ошибки») и 8
(«Интеграция и реализация») остались в README целиком — это про инструменты и
порождённый код, то есть про проект, а не про язык.

## Проверки

```sh
python3 scripts/check-links.py   # битых ссылок нет (правило 14)
./scripts/precheck.sh            # EXIT=0
git diff --stat book/            # пусто
```

Вырезанный текст сверен с документом по темам: комментарии и идентификаторы →
«Лексика», типы → «Типы», модели и композиция → «Модели и состояния», выражения
и `:=`/`=` → «Выражения», управление → «Управление», функции → «Функции», порты
и адреса → «Порты и адреса», импорты → «Импорты», блоки и `cond` → «Именованные
блоки», такт → «Модель исполнения», грамматика → приложение «Грамматика».
Переносилась **ссылка**, а не удалялось знание.
