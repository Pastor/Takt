# Задача 0275-01: Гейт команд README и его сторож

> Фича: [../features/0275-readme-commands-gate.md](../features/0275-readme-commands-gate.md) · ADR: [../adr/0275-readme-commands-gate.md](../adr/0275-readme-commands-gate.md) · анализ: [../analyze/0275-readme-commands-gate.md](../analyze/0275-readme-commands-gate.md)

## Что было

README предлагает читателю 25 блоков `sh` (55 непустых строк), и проверял их
только человек. Замер 0239 (2026-08-17): `cargo install --path grammar --bin
taktc` — команда, мёртвая с переименования крейта (фича 0100). Гейт ссылок
(правило 14) такого не видит: он проверяет пути в markdown-ссылках, а не
работоспособность вызовов.

## Что сделано

**`scripts/check-readme-commands.sh`** — три проверки по возрастанию строгости:

1. **пути**, названные флагами `--path`/`--manifest-path` и вызовами
   `scripts/*.sh`, существуют в дереве;
2. **подкоманда** `taktc` известна инструменту;
3. команды `taktc`, **все входные файлы которых существуют**, **прогоняются**
   — вывод перенаправляется во временный каталог; `fmt` без `--check`
   пропускается (правит файлы на месте).

Плейсхолдеры (`model.takt`, `hello.takt`) и внешние инструменты
(`verilator`, `yosys`, `gtkwave`, `cargo install`) не исполняются — граница
названа в заголовке гейта.

**`scripts/test-readme-commands.sh`** — сторож (шаг предкоммита). На **копии**
дерева (`RC_ROOT`) проверяет: настоящий README проходит; устаревший путь
крейта, неизвестная подкоманда, неработающая команда и несуществующий скрипт
ловятся; **контроль** — команда с плейсхолдером гейт не роняет.

⚠️ Первый прогон сторожа показал, что копия дерева беднее рабочего (не хватало
`examples/generated/rust/Cargo.toml`, который README называет в
`--manifest-path`) — копия дополнена. Это ровно тот случай, ради которого
сторож и гоняет **настоящий** README, а не синтетический.

## Проверки

```sh
sh scripts/check-readme-commands.sh   # OK: строк 55, команд прогнано 5
sh scripts/test-readme-commands.sh    # 6 проверок сторожа
```
