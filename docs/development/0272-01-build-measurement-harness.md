# Задача 0272-01: Обвязка замера и предупреждение о холодном прогоне

> Фича: [../features/0272-build-measurement-harness.md](../features/0272-build-measurement-harness.md) · ADR: [../adr/0272-build-measurement-harness.md](../adr/0272-build-measurement-harness.md) · анализ: [../analyze/0272-build-measurement-harness.md](../analyze/0272-build-measurement-harness.md)

## Что сделано

**`scripts/measure-precheck.sh`** — обвязка замера:

1. **прогрев** — один прогон, время которого выбрасывается (наполняет кэш ФС и
   каталог сборки);
2. два **замерных** прогона;
3. **вердикт**: разброс считается от меньшего; больше `MEASURE_SPREAD` (20 %) —
   «ЗАМЕР НЕГОДЕН» с объяснением и кодом ≠ 0.

Красный прогон замером не считается: обвязка отказывает сразу — «замер
бессмыслен, пока прогон красный».

Переменные: `MEASURE_CMD` (что мерить, по умолчанию сам предкоммит),
`MEASURE_SPREAD`, `MEASURE_WARMUP=0` (отключить прогрев — нужно стороже).

**`scripts/test-measure-precheck.sh`** (шаг предкоммита) — сторож логики
вердикта на быстрых командах: стабильные прогоны годны; команда, идущая с
каждым вызовом дольше, даёт отказ; `false` отвергается; при включённом прогреве
вызовов ровно **три**, и в вердикт идут два последних.

**`scripts/precheck.sh`** печатает предупреждение, если каталога сборки нет:
«прогон ХОЛОДНЫЙ, его время замером не является» — и называет инструмент.

⚠️ Сама обвязка в предкоммит **не входит**: три прогона стоят минуты.

## Проверка

```sh
sh scripts/test-measure-precheck.sh          # 4 проверки
MEASURE_CMD='sleep 1' sh scripts/measure-precheck.sh
```
