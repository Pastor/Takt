# Задача 0294-01: Поиск импортёров и заметка диагностики

> Фича: [../features/0294-se102-suggest-importer.md](../features/0294-se102-suggest-importer.md) · ADR: [../adr/0294-se102-suggest-importer.md](../adr/0294-se102-suggest-importer.md) · анализ: [../analyze/0294-se102-suggest-importer.md](../analyze/0294-se102-suggest-importer.md)

## Что сделано

**`takt-lang/src/semantic/import/importers.rs`** — `find_importers(target,
search_paths)` и `importers_note(...)`:

- обход — каталог входа плюс каталоги `-I`; список файлов **сортируется**
  (порядок обхода каталога системно-зависим, а текст диагностики обязан быть
  воспроизводимым);
- каждый сосед разбирается, его директивы `import` разрешаются
  `read_import_file` — **той же** функцией, что и при компиляции; совпадение
  проверяется по каноническому пути, поэтому `"helper.takt"`, `"./helper.takt"`
  и путь через `-I` дают один ответ;
- разбор `ImportDefine` исчерпывающий: простая форма, `as`, выборочная;
- в подсказке до трёх имён и «и ещё N» — это подсказка, а не отчёт.

**Точки подключения:** `pipeline::parse_and_construct` (все цели) и
`takt-sim`. Поиск живёт **у вызывающего**, а не в проверке: он ходит по
файловой системе, которой семантика не знает.

**Заметка получает `Location::Codegen`.** Первая редакция ставила `loc`
диагностики, и подсказка печаталась как `примечание: 1:1: …` — координата
**своего** файла у сообщения о **чужом** (класс 0264).

⚠️ **Модуль лежит внутри слоя импорта, а не рядом с ним**, и это не вкус:
`semantic/mod.rs` — узаконенный долг размера (1240 строк), и объявление
`pub mod` в нём **роняет гейт** `check-module-size.sh`. Подмодуль объявлен в
`semantic/import.rs`, а наружу крейта подсказка выходит ре-экспортом из
`pipeline` — рядом с `validate_entry_model`, которую зовут те же потребители.

## Границы (названы в коде)

- импортёр вне каталога входа и `-I` не найдётся;
- неразобранный сосед пропускается молча: АСД у него нет, утверждать нечего;
- при разрешении директивы кандидата к его путям добавляется каталог самой
  библиотеки — иначе файл из `-I` не нашёлся бы вовсе; цена — при двух
  одноимённых библиотеках подсказка может назвать импортёра другой.

## Проверка

```sh
cargo test --test semantic importers_hint_tests::
taktc compile -t c helper.takt -o out     # примечание с именем импортёра

```
