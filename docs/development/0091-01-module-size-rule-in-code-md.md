# Задача 0091-01: Правило о размере модуля переносится в docs/CODE.md

> Фича: [../features/0091-module-size-rule-in-code-md.md](../features/0091-module-size-rule-in-code-md.md) · ADR: [../adr/0091-module-size-rule-in-code-md.md](../adr/0091-module-size-rule-in-code-md.md) · анализ: [../analyze/0091-module-size-rule-in-code-md.md](../analyze/0091-module-size-rule-in-code-md.md)

## Что было

Правило «размер модуля ≤ ~1000 строк; дели по логике» жило только в `CLAUDE.md`
(живой контекст, правило 9), смешанное с живым контекстом (реестр-долг, статус
разделений). Свод кода `docs/CODE.md` (правило 23) правила не содержал — ссылка
кандидата 0027 «см. `docs/CODE.md`» вводила в заблуждение.

## Что сделано

Реализована **Option A** [ADR 0091](../adr/0091-module-size-rule-in-code-md.md).

- **`docs/CODE.md`:** новая секция **«Размер модулей»** — лимит ~1000 строк (вместе
  с тестами), «дели по логике» (границы модулей = границы ответственности; образцы
  разделения), машинная проверка `scripts/check-module-size.sh` в `precheck.sh`/CI,
  семантика реестра-долга `module-size-baseline.txt` (замораживает; правка записи —
  только уменьшение; уложившийся в лимит удаляется), история (`validate.rs` дорос до
  3654 до фичи 0027).
- **`CLAUDE.md`:** формулировка правила заменена **указателем** на
  `docs/CODE.md`; живой контекст сохранён (реестр-долг, ратчет «готовься к отказу
  «вырос»», выполненные разделения `validate/`/`lsp/`/`c_expr/`/`index/`). Число
  файлов реестра актуализировано **22 → 18** (долг снижался фичами); добавлена
  ссылка на остаток-фичу 0088.

| Функциональность | Статус |
|---|---|
| правило в `docs/CODE.md` | ✅ секция «Размер модулей» |
| `CLAUDE.md` — указатель + контекст, 18 файлов | ✅ дубля нет |
| код/гейт/реестр | н/п — не тронуты |

## Проверки

- `scripts/check-links.py` → ссылок нет битых.
- `grep` подтверждает: формулировка правила в `CLAUDE.md` заменена ссылкой; живой
  контекст (реестр, ратчет, разделения) на месте; число «18».
- Код крейтов, гейт `check-module-size.sh`, реестр не тронуты.
- Полный `./scripts/precheck.sh` → зелёный (см.
  [отчёт](../reports/0091-module-size-rule-in-code-md.md)).
