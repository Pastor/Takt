# Задача 0290-01: Гейт сверки кодов документа с реестром

> Фича: [../features/0290-book-diagnostics-codes-gate.md](../features/0290-book-diagnostics-codes-gate.md) · ADR: [../adr/0290-book-diagnostics-codes-gate.md](../adr/0290-book-diagnostics-codes-gate.md) · анализ: [../analyze/0290-book-diagnostics-codes-gate.md](../analyze/0290-book-diagnostics-codes-gate.md)

## Что сделано

**`scripts/check-book-diagnostics.py`** — сверка множеств кодов в обе стороны:

- со стороны реестра читаются **строки таблиц** `docs/diagnostics/README.md`
  (`| \`XX-NNN\` | … |`), а не весь текст: проза реестра называет `CC-009` и
  `SE-024` в объяснении про пропуски номеров, и наивный греп добавил бы к
  расхождению два несуществующих кода;
- со стороны документа читается **только сводная таблица** приложения — участок
  между `== Сводная таблица кодов` и `== Подробный разбор`: вторая часть
  приложения раскрывает основные ошибки, а не все, и сверять её нельзя;
- падение — **списком**, раздельно по направлениям: «нет в приложении» лечится
  дописыванием записи, «нет в реестре» — удалением обещания (или возвратом кода
  в реестр). Одно сообщение на оба класса заставило бы разбираться заново;
- **пустое множество — ошибка**: и отсутствие строк таблиц реестра, и
  отсутствие раздела сводной таблицы валят гейт с объяснением. Иначе смена
  разметки молча превратила бы сверку в проверку пустоты (урок фикса 0202-01);
- корень дерева переопределяется `BD_ROOT` — этого требует сторож, гоняющий
  гейт на копии.

**`scripts/test-book-diagnostics.sh`** — сторож гейта, пять проверок на копии
дерева: контроль (согласованное принимается), пропавший код, лишний код,
документ без сводной таблицы, реестр без таблиц. Первая проверка обязательна:
без неё «гейт падает» означало бы лишь, что он падает всегда.

**`scripts/precheck.sh`** — оба шага в блоке документных гейтов (там же, где
глифы 0146 и лексика 0160), самопроверка **первой**.

## Проверка

```sh
python3 scripts/check-book-diagnostics.py   # код 0, «264 кодов сверены»
sh scripts/test-book-diagnostics.sh         # 5/5
```

## Границы

Гейт сверяет **наличие** кода, а не верность его описания: текст справочника
остаётся на человеке (правило 4), как и у `check-claude-md.py`.
