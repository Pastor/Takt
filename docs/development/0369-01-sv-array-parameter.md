# Задача 0369-01: Массив в параметре функции у цели sv

> Фича: [../features/0369-sv-array-parameter.md](../features/0369-sv-array-parameter.md) · ADR: [../adr/0369-sv-array-parameter.md](../adr/0369-sv-array-parameter.md) · анализ: [../analyze/0369-sv-array-parameter.md](../analyze/0369-sv-array-parameter.md)

## Что было

Параметр-массив печатался распакованным (`input logic [7:0] a [0:2]`). yosys
такой порт функции не принимает вовсе, verilator принимает.

## Что сделано

**`takt-lang/src/generator/sv/sv_array.rs`** — три носителя:
`flat_param_width` (ширина плоского вектора, размер и ширина элемента; `None`
для бит-вектора и неcкалярного элемента), `flat_param_name` (`<param>_flat`),
`flatten_argument` (конкатенация в обратном порядке).

**`takt-lang/src/generator/sv/sv_fsm.rs`** — сигнатура функции печатает
плоский вектор, а пролог тела распаковывает его в массив **с именем
параметра**: тело печатается прежними печатниками, и второго знания об
адресации не заводится.

**`takt-lang/src/generator/sv/sv_expr.rs`** — аргумент-массив печатается
конкатенацией.

**Сверка**: `takt-sim/tests/data/eval/conformance_sv_array_param.takt` и два
теста — потактовая сверка значений и прогон **синтеза**.

⚠️ **Форму выбрал прогон.** Проверялись три: распакованный параметр (yosys
отвергает), плоский вектор с индексацией срезом (работает, но требует знания
о раскладке в трёх печатниках) и плоский вектор с прологом (принят обоими и
не трогает печатники). Заодно измерено, что переменный индекс внутри функции
работает.

⚠️ **Наблюдаемые обязаны меняться по тактам:** первая редакция фикстуры читала
неизменные края массива, и перепутанный порядок конкатенации давал бы ту же
трассу.

## Проверки

```sh
cargo test --test conformance array_parameter   # сверка + синтез
cargo test --test conformance                   # 168
cargo test --test targets                       # 391
for f in examples/*.takt; do scripts/probe.sh -n 1 "$f"; done   # корпус чист
./scripts/precheck.sh
```

Мутации (обе пойманы): прямой порядок конкатенации — трассы разошлись;
распакованный параметр — «не синтезируется».
