# Задача 0373-01: Локальная переменная структурного типа у цели sv

> Фича: [../features/0373-sv-struct-local.md](../features/0373-sv-struct-local.md) · ADR: [../adr/0373-sv-struct-local.md](../adr/0373-sv-struct-local.md) · анализ: [../analyze/0373-sv-struct-local.md](../analyze/0373-sv-struct-local.md)

## Что было

`sv_blocks::emit_named_blocks` печатала объявления локальных тела прямо в
ветви `case` (`automatic pair_t tmp;`, фича 0304). Для переменной со структурой
yosys объявлял защёлку — «Latch inferred for signal
`$unnamed_block$1.tmp.lo`», — а verilator модуль принимал.

## Что сделано

- `Fsm` получил накопитель `hoisted_locals: RefCell<Vec<HoistedLocal>>` и метод
  `hoist_local`: он отображает тип в SystemVerilog, дедуплицирует по имени и
  собирает нулевые умолчания. Одно имя с разным типом — отказ `SV-002`,
  называющий обход.
- `sv_blocks::emit_block_body` (общий для блоков состояния и модели) делит
  локальные надвое: содержащие структуру идут в накопитель, прочие печатаются
  на месте прежним путём.
- `sv_fsm::emit_comb` печатает тело **в буфер**, затем объявления поднятых
  (первыми в процессе — этого требует SystemVerilog), затем умолчания
  регистров и поднятых, затем буфер.
- `sv_array::leaf_zero_defaults` даёт умолчания: **целиком** (`'0`) для
  упакованного значения и **по листьям** для структуры внутри распакованного
  массива; упакованное значение получает **обе** формы.
- `sv_array::contains_struct` открыт для признака «тип содержит структуру».

**Статус по функциональности (правило 11).** Затронуты цели `sv`/`sv-mmio`;
`c`/`c-hal`, `st`/`st-at`, `rust`, `plantuml` и эталон — **н/п**: тот же вход
они переводят и исполняют.

## Проверки

```sh
cargo test                                        # 3358 тестов, 0 провалов
./scripts/probe.sh -n 3 <проба>.takt              # три формы записи: все инструменты приняли
./scripts/precheck.sh
```

Мутации (каждая проверена):

| Мутация | Что падает |
|---|---|
| не поднимать (печать на месте, как прежде) | `struct_local_is_synthesizable`, `struct_local_declaration_precedes_statements` |
| умолчание только целиком | те же два |
| умолчание только по листьям | те же два |

⚠️ Сверка значений мутациями **не** падает — и это верно: прежний вывод считал
правильно, он просто не синтезировался. Сверка сторожит другое: подъём не
изменил поведения.
