# Задача 0133-01: Гейт примеров документа `book/`

> Фича: [../features/0133-book-examples-gate.md](../features/0133-book-examples-gate.md) · ADR: [../adr/0133-book-examples-gate.md](../adr/0133-book-examples-gate.md) · анализ: [../analyze/0133-book-examples-gate.md](../analyze/0133-book-examples-gate.md)

## Что было

18 файлов `book/src/**/examples/*.takt` включаются в документ директивой
`{{#include}}` и не проверялись **ничем**: слова `book` не было ни в
`scripts/precheck.sh`, ни в `.github/workflows/ci.yml`. Seed-пример раздела
«Обзор» не компилировался.

## Что сделано

1. **Гейт в `scripts/precheck.sh`** (в конце, после гейта ST):
   - для каждого примера — `taktc compile -t c`, затем `takt-sim -n 10`;
   - **библиотечные** файлы (чьё имя встречается в `from "…"` другого примера)
     пропускаются с явной отметкой: их проверяет импортёр;
   - любой отказ валит предкоммит с указанием файла и первых строк вывода.
2. **Починен `01-overview/examples/blinker.takt`:** форма `start state Off` →
   `start Off`, добавлен верхнеуровневый вход `start Main = Lamp;`. Заодно
   исправлено **поведение**: оба перехода проверяли `btn = 1`, то есть модель
   перещёлкивалась каждый такт при нажатой кнопке, хотя текст обещал иное.
   Теперь `Off → On` по `btn = 1`, `On → Off` по `btn = 0` — лампа горит, пока
   кнопка нажата.
3. **Текст раздела «Обзор»** приведён в соответствие с поведением модели.

## Взведённость (проверено экспериментом)
