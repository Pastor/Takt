# Задача 0062-01: Регистровый файл и его интерфейс (без протокола)

> Фича: [../features/0062-sv-mmio-target.md](../features/0062-sv-mmio-target.md) · ADR: [../adr/0062-sv-mmio-target.md](../adr/0062-sv-mmio-target.md) · анализ: [../analyze/0062-sv-mmio-target.md](../analyze/0062-sv-mmio-target.md)

## Что было

Цель `sv` адрес **не потребляет** (решение ADR 0045, вопрос 5): порты Lam → порты
модуля; `--address-map` с `-t sv` отсекается `bin/lamc.rs:532`. Адрес для `sv` —
мёртвые метаданные.

## Что сделано

Новая цель `-t sv-mmio`, парная к `sv` (прецедент `c`/`c-hal`, задача 0020-05, на
который прямо ссылается ADR 0045):

1. **Вариант `Language`** + ветка в `generate()` (`Language` уже
   `#[non_exhaustive]`; общий слой заводить не нужно — `minimap::Map` и `Printer`
   общие, каркас доказан целями 0041/0045/0050).
2. **Порт с адресом** → бит регистра; **без адреса** → порт модуля (правило 2 ADR).
3. **Интерфейс без протокола** (правило 3): адрес, данные записи/чтения, стробы;
   синхронный. Ширина адреса — из **максимального** адреса модели.
   ⚠️ Форма интерфейса — единственное, что здесь изобретается; всё остальное
   диктуется моделью. Держать минимальной: адаптер APB/AXI-Lite пишется поверх и
   заводится **отдельной фичей по требованию** (A-2 ADR).
4. **Направление — свойство бита** (правило 4): в одном слове допустимы биты
   `in` и `out` одновременно — это **факт корпуса** (`extend_complex.lam`:
   `out :1`, `out :2`, `in :33`), а не гипотеза.
5. **Запись шиной в бит `out` игнорируется**; чтение бита `in` возвращает
   записанное (правило 5) — иначе конфликт драйверов.
6. **Не угадывать** (правило 6): бит вне поддержанного диапазона → **диагностика**.
   ⚠️ Угадать ширину слова значило бы повторить ошибку, за которую ADR 0045 отверг
   fixed-point: генератор молча выбирает семантику.

## Проверки

- **T1/A1:** карта регистров `stacker` совпадает с адресами модели буквально.
- **T2/A2:** гейт — **verilator И yosys**.
- **T3/A3:** `git diff --exit-code examples/generated/sv` — пусто (цель `sv` не тронута).
- **T5/A5:** смешанное слово — по правилам либо **отказ**; **T12** (мутация):
  молчаливый выбор ширины обязан валить T5.
- **T8/A7:** порт без адреса — порт модуля.
- **T11:** ширина адреса выводится из максимума (`0x10000000` у `elevator`,
  `0x601` у `stacker`).
- **T13:** инварианты 0045 (two-process; `always_comb` читает **`_next`**; вход в
  стартовое состояние такта не расходует — контракт 0033).
