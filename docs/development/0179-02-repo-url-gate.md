# Задача 0179-02: Гейт единственности адреса репозитория

> Фича: [../features/0179-repo-url-cleanup.md](../features/0179-repo-url-cleanup.md) · ADR: [../adr/0179-repo-url-cleanup.md](../adr/0179-repo-url-cleanup.md) · анализ: [../analyze/0179-repo-url-cleanup.md](../analyze/0179-repo-url-cleanup.md)

## Что было

Разовой правки недостаточно: прецедент ADR 0085 — версия языка, поправленная в
README без гейта, разошлась с кодом и прожила так незамеченной. Скопированный
старый сниппет вернул бы `Pastor/BuT` тем же путём.

## Что сделано

`scripts/check-repo-url.sh` (POSIX sh, образец — `check-language-version.sh`),
вызывается из `precheck.sh` рядом с гейтом версии языка.

- **Эталон берётся из манифеста**, а не зашит: поле `repository` в
  `takt-lang/Cargo.toml`. Правило 2 ADR — гейт проверяет **согласованность**, а
  не имя `Takt`, поэтому следующий переезд потребует правки файлов, а не
  скрипта.
- **Второй якорь — имя каталога:** `cd <имя>` сразу после `git clone` обязано
  совпасть с последним компонентом URL. Именно эта строка была сломана и от
  редиректа не зависела.

⚠️ **Отклонение от ADR: denylist → allowlist.** Правило 3 ADR планировало
исключать исторические артефакты явным списком. Реализация показала, что
старый адрес законно цитируют **все** повествовательные файлы — карточка и ADR
самой фичи, `CHANGES.md`, `FEATURES.md`, — и denylist пришлось бы дополнять при
каждом упоминании. Взят обратный принцип: перечислены файлы, где адрес
**исполняется** (манифесты, README, doc-ссылки исходников, скрипт установки);
`docs/` и журналы не проверяются вовсе — там старый адрес есть свидетельство
(правило 21), а не ошибка. Замысел правила 3 («каждое исключение — решение»)
сохранён: список проверяемого тоже явный.

⚠️ **Гейт поймал сам себя на первой же пробе:** первая редакция сравнивала любой
`github.com/*/*` и упала на `lalrpop/lalrpop` — git-зависимости в том же
манифесте. Чужой репозиторий называется как называется; правило «адрес один»
касается **своего**, поэтому владелец теперь берётся из эталона и сверяются
только его адреса.

## Проверки

**Мутационные (обязательны, урок 0056):**

| Мутация | Ожидание | Результат |
|---|---|---|
| вернуть `BuT` в **один** файл (`extension.toml`) | гейт красный | `rc=1`, файл назван в сообщении ✅ |
| испортить **только** `cd` в README | гейт красный | `rc=1`, «делает `cd BuT`, а клон создаёт `Takt`» ✅ |
| переименовать во **всех** рабочих местах разом на `Nonexistent` | гейт **зелёный** | `rc=0`, «адрес один — Pastor/Nonexistent» ✅ |

⚠️ Третья мутация — не курьёз, а **проверка границы** (A-2 ADR): гейт
удостоверяет согласованность, а не правильность. Правильность адреса есть знание
вне репозитория; установить её машинно можно только походом в сеть, а предкоммит
обязан работать офлайн. Без этой проверки легко поверить, что гейт защищает от
неверного адреса.
