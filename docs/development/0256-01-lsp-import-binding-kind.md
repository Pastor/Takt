# Задача 0256-01: Вид `Imported` для выборочного импорта и согласование области

> Фича: [../features/0256-lsp-import-binding-kind.md](../features/0256-lsp-import-binding-kind.md) · ADR: [../adr/0256-lsp-import-binding-kind.md](../adr/0256-lsp-import-binding-kind.md) · анализ: [../analyze/0256-lsp-import-binding-kind.md](../analyze/0256-lsp-import-binding-kind.md)

## Что было

`each_import_binding` ставил вид `SymbolKind::Model` **любому** имени,
вводимому импортом. Вид задаёт пространство (`Namespace::Model`), а вхождения
в теле ищутся в `Namespace::Value` — и с объявлением не связывались. Ответ
редактора зависел от курсора: 1 вхождение на директиве импорта против 14 на
том же имени в теле.

## Что сделано

**Слой использований** (`semantic/usages/`):

- `SymbolKind::Imported` — новый вид: имя, введённое `import { a, b as c }`.
  Форма `import "файл" as M;` сохраняет `Model` — она вводит имя **самого
  импорта**, а не подставляет чужое объявление.
- `SymbolKind::matches(ns)` заменил сравнение `namespace() == ns` в
  `Scopes::resolve` и `resolve_member`: для `Imported` истинно при любом
  пространстве. Вид объявления живёт в **чужом** файле, и однофайловому слою
  он неизвестен по устройству.

**Рабочая область** (`lsp/workspace.rs`):

- `resolve`: символ вида `Imported` дополняется объявлением источника и
  вхождениями прочих его потребителей (свои уже собраны — фильтр по пути, иначе
  дубль).
- `consumer_occurrences`: у потребителя берутся не только `unresolved`, но и
  вхождения символа `Imported`. **Без этого правка чинит один путь и ломает
  другой** — первый прогон дал 1 вместо 2 в фикстуре 0153: связав вхождения, мы
  забрали их у прежнего сборщика.

**Сторож** — `takt-lang/tests/lsp/import_binding_kind_tests.rs` (5 проверок) и
фикстура `takt-lang/tests/data/ws0153/alias/` для контроля границы.

**Обратная функциональность (правило 11):** язык, компилятор, симулятор и цели
не затронуты. Меняется поведение редактора, и в сторону расширения: `rename`
на имени из `import { … }` прежде отказывал `ModelName`, теперь исполняется.

## Проверки

```sh
cargo test --all-features --test lsp import_binding_kind   # 5 проверок
cargo test --all-features                                  # регрессия, 0 провалов
./scripts/precheck.sh                                      # код 0
```

**Мутация:** возврат `SymbolKind::Model` в `each_import_binding` роняет
**четыре** теста из пяти; контрольный (`alias_import_is_still_a_model_name`)
остаётся зелёным — он и обязан, потому что описывает границу.

⚠️ Замер снимался **дважды**: первая проба взяла `import {` из
комментария-документации, вторая — `Lib` не из директивы. Обе давали
«связывать нечего» (правило 30).
