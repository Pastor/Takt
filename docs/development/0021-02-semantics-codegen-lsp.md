# Задача 0021-02: семантика, C-генератор, LSP под новую операторную семантику

> Фича: [../features/0021-swap-assign-compare.md](../features/0021-swap-assign-compare.md) · ADR: [../adr/0021-swap-assign-compare.md](../adr/0021-swap-assign-compare.md) · анализ: [../analyze/0021-swap-assign-compare.md](../analyze/0021-swap-assign-compare.md)

> **Статус:** ЗАПЛАНИРОВАНО (после 0021-01).

## Что было

Семантика (`semantic/`), C-генератор (`generator/c/`), PlantUML
(`generator/plantuml/`), верификация (`verification/{ltl,buchi}.rs`) и LSP
(`lsp.rs`) опираются на текущие AST-узлы `Expression::Assign`/`Equal` и
`Condition::Equal`. Изменение 0021-01 меняет **грамматическую** привязку
операторов, но **AST-узлы те же** — цель задачи убедиться, что смысловые проходы
не завязаны на конкретные лексемы и корректно работают после переназначения.

## Что сделано (план)

1. **Семантика.** `type_inference.rs` и проходы `tree.rs`: убедиться, что вывод
   типов и проверки опираются на узлы AST (`Assign`/`Equal`), а не на текст
   оператора. `Condition::Equal` (по `=`) — без изменений.
2. **Диагностики.** `nondeterministic_transition_warnings`,
   `unused_variable_warnings` — регресс; сообщения об ошибках парсера обновить
   на новую лексику (`ожидалось ':='`).
3. **C-генератор.** Ключевой инвариант: **в C по-прежнему `=`/`==`/`<=`** в
   классическом смысле. `Expression::Assign` → C `=`; `Expression::Equal` → C
   `==`; `LessEqual` → C `<=`. Проверить, что смена операторов Lam **не влияет**
   на генерируемый C (сверка байт-в-байт со старым выводом после миграции входа).
4. **PlantUML.** Аналогично — вывод диаграмм не меняется.
5. **Верификация.** LTL/Бюхи используют условия (`Condition`) — `=` там уже
   равенство, изменений нет; регресс тестами.
6. **LSP.** Подсветка/hover для `:=` (новый оператор присваивания); `position_to_offset`,
   `node_at_position`, `hover_info` — регресс LSP-тестами.

## Проверки

- R1, R2 из анализа. Регресс поведения кодогена = 0 (готовит A4).
- `cargo test --features lsp -- --test-threads=1` — все тесты и doctests зелёные
  (после миграции фикстур в 0021-03).
