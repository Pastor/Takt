# BuT (Bus and Transitions) — Язык моделирования систем

BuT — это предметно-ориентированный язык (DSL) для описания и моделирования систем с использованием конечных автоматов и компонентных моделей.

## Основные возможности

- **Конечные автоматы**: Описание состояний (`state`, `start`, `end`) и переходов (`ref`) между ними.
- **Именованные блоки кода**: `enter` (выполняется при входе в состояние), `exit` (при выходе) и `always` (выполняется постоянно в данном состоянии). Допускается использование нескольких блоков одного типа в одном состоянии или на уровне модели.
- **Система типов**: Поддержка битов (`bit`), рациональных чисел, массивов и адресных типов для портов.
- **Композиция моделей**: Возможность вкладывать модели друг в друга и объединять их.
- **Семантический анализ**: Проверка типов, разрешение ссылок на переменные и функции, вывод типов.

## Структура проекта

- `grammar/src/parser`: Лексический и синтаксический анализатор (использует LALRPOP).
- `grammar/src/semantic`: Семантический анализатор и построение семантического дерева (AST -> Semantic Tree).
- `examples`: Примеры кода на языке BuT.

## Примеры

### Простой автомат (Светофор)
```but
model TrafficLight {
    var timer: u8 = 0;
    
    start Red {
        enter { timer = 0; }
        always { timer = timer + 1; }
        ref Yellow: timer > 10;
    }
    
    state Yellow {
        enter { timer = 0; }
        always { timer = timer + 1; }
        ref Green: timer > 3;
    }
}
start Entry = TrafficLight;
```

## Документация и разработка

Проект находится в стадии активной разработки. Семантический анализ выполняется в несколько проходов:
1. Построение скелета модели (модели, состояния, переменные).
2. Разрешение типов и внешних зависимостей.
3. Разрешение выражений и условий.
4. Разрешение операторов в именованных блоках кода.
